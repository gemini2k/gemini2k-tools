돌림판 추첨기

항목을 적고 돌리면 무작위로 하나를 뽑아 줍니다. 점심 메뉴·당첨자·발표 순서 정하기에 딱이에요.

📖
사용 방법
  1. 오른쪽에 항목을 한 줄에 하나씩 입력합니다 (2개 이상)
  2. '돌리기'를 누르면 돌림판이 회전하고 결과가 나옵니다
  3. '당첨 시 제거'를 켜면 뽑힌 항목이 사라져 순서 정하기에 좋아요
▼
결과는 암호학적 난수가 아닌 일반 난수로 공정하게 무작위 선택됩니다. 항목 색상은 자동 배정됩니다. 모든 처리는 브라우저에서만 이루어집니다.

돌림판 추첨기 사용 안내

무엇을 하는 도구인가

적어 넣은 항목을 같은 크기의 칸으로 나눈 돌림판을 그리고, 버튼을 누르면 4~5초 동안 회전한 뒤 위쪽 ▼ 표시가 가리키는 항목을 당첨으로 보여 줍니다. 당첨 항목은 회전을 시작할 때 이미 무작위로 정해지고, 돌림판은 그 칸에 멈추도록 회전량을 계산해 움직입니다. 모든 계산과 그림은 브라우저 안에서 처리됩니다.

언제 쓰나

  • 점심 메뉴나 회식 장소를 두고 의견이 갈릴 때
  • 수업이나 회의에서 발표 순서를 정할 때 (「당첨 시 제거」를 켜고 한 명씩 뽑기)
  • 소규모 행사에서 경품 당첨자를 화면에 띄워 놓고 뽑을 때
  • 청소 당번, 게임 벌칙처럼 부담 없는 역할을 나눌 때

사용 방법

  1. 오른쪽 「항목 (한 줄에 하나)」 칸에 후보를 한 줄씩 적습니다. 빈 줄과 앞뒤 공백은 무시됩니다.
  2. 뽑힌 항목을 다음 회차에서 빼려면 「당첨 시 제거」를 켭니다.
  3. 「돌리기」를 누르고 회전이 멈출 때까지 기다립니다. 돌아가는 동안에는 버튼이 잠깁니다.
  4. 돌림판 아래에 당첨 항목이 표시됩니다.

결과 해석

모든 칸의 크기가 같고 당첨 칸은 항목 수로 균등하게 뽑으므로, 항목이 5개면 각각 1/5 확률입니다. 특정 항목의 확률을 높이고 싶다면 같은 이름을 여러 줄 적으면 됩니다. 예를 들어 짜장면을 두 줄 적고 나머지 3개를 한 줄씩 적으면 짜장면이 뽑힐 확률은 2/5가 됩니다. 칸이 좁아 글자가 길면 9자까지만 보이고 뒤는 줄임표로 표시되지만, 결과에는 전체 이름이 나옵니다.

주의할 점

  • 난수는 브라우저의 일반 난수(Math.random)를 씁니다. 재미용이나 내부 결정에는 충분하지만, 상금이 걸린 공식 추첨처럼 공정성을 증명해야 하는 자리에는 쓰지 마세요.
  • 항목은 최소 2개가 있어야 돌아갑니다.
  • 「당첨 시 제거」를 켜면 입력 칸의 내용이 실제로 지워집니다. 원래 목록이 필요하면 따로 복사해 두세요.

자주 묻는 질문

몇 개까지 넣을 수 있나요?
개수 제한은 없지만 칸이 좁아지면 글씨가 겹칩니다. 20개 안쪽이 보기 좋습니다. 색은 12가지가 순서대로 반복 배정됩니다.
결과가 저장되나요?
저장되지 않습니다. 기록이 필요하면 결과 화면을 캡처해 두세요.
