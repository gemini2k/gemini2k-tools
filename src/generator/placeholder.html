플레이스홀더 이미지 생성기

원하는 크기·색·문구의 더미(자리표시) 이미지를 만들어 저장합니다. 목업·테스트에 쓰세요.

외부 placeholder 서비스 없이 브라우저에서 직접 생성하므로 인터넷 없이도 동작하고 추적이 없습니다. 모든 처리는 브라우저에서만 이루어집니다.

플레이스홀더 이미지 생성기 사용 안내

무엇을 하는 도구인가

웹 화면이나 문서 시안에서 실제 사진이 들어갈 자리를 표시하는 단색 이미지를 만듭니다. 원하는 가로·세로 픽셀 크기의 캔버스를 배경색으로 칠하고, 가운데에 문구를 쓰고, 테두리에 옅은 선을 둘러 PNG로 저장합니다. 문구를 비우면 「600 × 400」처럼 크기가 대신 들어가 레이아웃에서 어느 자리가 몇 픽셀인지 바로 알 수 있습니다. 외부 플레이스홀더 서비스 주소를 쓰지 않고 브라우저에서 직접 그리므로 인터넷이 끊긴 개발 환경에서도 씁니다.

언제 쓰나

  • 홈페이지 개편 시안에서 배너, 썸네일 자리를 크기별로 잡아 둘 때
  • 보고서나 제안서 초안에서 나중에 넣을 사진·도표 자리를 표시할 때
  • 개발 중인 화면에서 이미지 비율이 바뀔 때 레이아웃이 깨지는지 시험할 때
  • 내부망처럼 외부 이미지 서비스에 접속할 수 없는 환경에서 더미 이미지가 필요할 때

사용 방법

  1. 「가로(px)」와 「세로(px)」에 크기를 넣습니다. 1~4000픽셀 범위로 맞춰집니다.
  2. 「배경색」과 「글자색」을 고르고, 필요하면 「문구」에 PHOTO, 배너 같은 글을 적습니다.
  3. 값을 바꾸면 미리보기가 바로 바뀝니다.
  4. 「⬇️ PNG 다운로드」로 「placeholder_600x400.png」 같은 이름의 파일을 받거나, 「📋 Data URI 복사」로 data:image/png;base64,… 문자열을 가져갑니다.

결과 해석

글자 크기는 가로와 세로 중 짧은 쪽을 기준으로 자동 계산됩니다. 문구가 6자 이하면 짧은 변의 1/4, 그보다 길면 1/6 크기라서, 기본 600×400 이미지의 「600 × 400」 문구는 약 67픽셀 높이로 들어갑니다. Data URI는 이미지 자체를 글자로 바꾼 것이라 HTML의 <img src="…">나 CSS 배경에 그대로 붙여 넣으면 별도 파일 없이 표시됩니다.

주의할 점

  • 문구는 줄바꿈되지 않습니다. 가로가 좁은 이미지에 긴 문구를 넣으면 양옆이 잘리니 짧게 쓰세요.
  • 이미지가 클수록 Data URI 문자열도 길어집니다. HTML에 직접 넣으면 소스가 무거워지니 작은 이미지에만 쓰세요.
  • 시안용 이미지가 실제 서비스에 그대로 남지 않도록 배포 전에 파일명에 placeholder가 들어간 이미지가 있는지 검색해 보세요.

자주 묻는 질문

JPG나 SVG로도 받을 수 있나요?
현재는 PNG만 지원합니다. 단색 이미지라 PNG로도 파일 크기가 작습니다.
배경을 투명하게 할 수 있나요?
배경은 항상 고른 색으로 채워집니다. 투명 배경 옵션은 없습니다.
