반복 일정 규칙(RRULE) 생성기

반복 규칙을 만들고 다음 실행일을 미리 봅니다. 캘린더(iCalendar)에 그대로 넣을 수 있어요.

간격주마다
오픈소스 rrule.js(BSD-3, jkbrzt/rrule)를 자체 호스팅합니다. RFC 5545 기준. 모든 처리는 브라우저에서만 이루어집니다.

반복 일정 규칙(RRULE) 생성기 사용 안내

무엇을 하는 도구인가

“2주마다 화·목요일”, “매월 같은 날 10회”처럼 반복되는 일정을 iCalendar 표준(RFC 5545)의 RRULE 문자열로 만들어 줍니다. 계산은 오픈소스 rrule.js가 맡고, 만든 규칙으로 실제 돌아오는 날짜를 최대 10개까지 바로 펼쳐 보여 주므로 규칙이 의도대로 잡혔는지 눈으로 확인할 수 있습니다.

언제 쓰나

  • 예약·회의실 시스템을 개발하면서 반복 일정 필드에 넣을 RRULE 예시가 필요할 때
  • .ics 파일을 직접 작성해 팀 정기 회의를 캘린더로 배포할 때
  • API 문서에 적힌 RRULE이 실제로 어떤 날짜를 뜻하는지 확인할 때
  • 격주 근무나 월 1회 점검처럼 사람마다 해석이 갈리는 주기를 날짜 목록으로 맞춰 볼 때

사용 방법

  1. 「시작일시」를 정합니다. 처음 열면 오늘 09:00이 들어가 있습니다.
  2. 「반복 주기」에서 매일·매주·매월·매년을 고르고 「간격」에 숫자를 넣습니다. 2를 넣고 매주를 고르면 격주입니다.
  3. 매주를 고르면 요일 체크 상자가 나타납니다. 기본은 월~금이 선택되어 있습니다.
  4. 「종료」에서 횟수, 날짜까지, 없음 중 하나를 고르고 값을 넣습니다.
  5. RRULE 칸의 문자열을 「복사」해 캘린더나 코드에 붙여 넣습니다.

결과 해석

예를 들어 매주, 간격 2, 화·목, 횟수 6을 고르면 RRULE:FREQ=WEEKLY;INTERVAL=2;BYDAY=TU,TH;COUNT=6 형태가 나오고, 아래 목록에 2주 간격의 화·목 날짜 6개가 찍힙니다. 첫 줄의 DTSTART는 브라우저의 시간대를 붙여 DTSTART;TZID=Asia/Seoul:20261110T090000처럼 입력한 현지 시각 그대로 표시됩니다. 「날짜까지」로 끝내면 UNTIL에는 그날 현지 23:59:59를 협정세계시(UTC)로 바꾼 값이 들어가므로, 한국 시간이라면 T145959Z로 끝납니다. 표준이 UNTIL을 UTC로 쓰도록 정해 둔 것이라 정상입니다.

주의할 점

  • 매월은 시작일의 날짜를 따라갑니다. 31일에 시작하면 31일이 없는 달은 건너뛰는 것이 표준 동작입니다. 말일 반복이 필요하면 캘린더 앱에서 따로 지정하세요.
  • 매월 “둘째 주 화요일” 같은 규칙과 특정 날짜 제외(EXDATE)는 이 화면에서 만들 수 없습니다.
  • 요일과 날짜는 모두 브라우저 시간대의 현지 시각 기준으로 계산합니다. 다른 시간대의 일정을 만들려면 그 시간대로 설정된 기기에서 만들거나, 복사한 DTSTART의 TZID를 직접 고치세요.

자주 묻는 질문

종료를 ‘없음’으로 하면 목록이 왜 10개뿐인가요?
끝없는 규칙이라 미리보기는 앞의 10개만 계산해 보여 줍니다. 실제 캘린더에서는 계속 반복됩니다.
구글 캘린더에 바로 넣을 수 있나요?
구글 캘린더 화면에는 RRULE 입력 칸이 없습니다. .ics 파일이나 캘린더 API에 DTSTART와 RRULE 줄을 넣는 방식으로 씁니다.
