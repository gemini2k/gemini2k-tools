컨페티(축하 효과) 생성기

버튼을 누르면 축하 효과가 터집니다. 마음에 드는 효과의 코드를 복사해 쓰세요.

오픈소스 canvas-confetti(ISC, catdad/canvas-confetti)를 자체 호스팅합니다. 코드를 쓰려면 라이브러리를 함께 불러와야 합니다. 모든 효과는 브라우저에서만 동작합니다.

컨페티(축하 효과) 생성기 사용 안내

무엇을 하는 도구인가

웹 페이지에서 색종이가 터지는 축하 효과를 미리 보고, 그 효과를 내는 자바스크립트 코드를 복사해 가는 도구입니다. 효과는 오픈소스 라이브러리 canvas-confetti로 그리며, 기본·폭죽·좌우 대포·별·색종이 비 다섯 가지가 준비되어 있습니다. 버튼을 누르면 화면에서 효과가 실행되고, 아래 칸에 그 효과를 만든 confetti(...) 호출 코드가 그대로 표시됩니다.

언제 쓰나

  • 설문 제출 완료, 회원 가입 완료 화면에 작은 축하 효과를 넣고 싶을 때
  • 사내 이벤트 추첨 페이지에서 당첨자 발표 순간을 꾸밀 때
  • 발표 중 결과 공개 장면에 브라우저로 띄운 축하 화면을 쓸 때
  • 개발 중인 화면에 넣을 효과의 개수·퍼짐 정도를 눈으로 비교할 때

사용 방법

  1. 「🎉 기본」, 「🎆 폭죽」, 「💥 좌우 대포」, 「⭐ 별」, 「🌧️ 색종이 비」 중 하나를 눌러 효과를 봅니다.
  2. 마음에 드는 효과의 코드가 아래 칸에 나오면 「📋 코드 복사」를 누릅니다.
  3. 내 페이지에 canvas-confetti 라이브러리를 먼저 불러온 다음, 버튼 클릭 같은 원하는 시점에 복사한 코드를 실행합니다.

결과 해석

코드의 숫자가 효과의 모양을 정합니다. particleCount는 조각 수, spread는 퍼지는 각도(도), angle은 발사 방향, origin은 화면에서 터지는 위치(0~1 비율)입니다. 기본 효과는 조각 120개를 70도 범위로 화면 높이 60% 지점에서 터뜨립니다. 좌우 대포는 왼쪽 끝(x: 0)에서 60도, 오른쪽 끝(x: 1)에서 120도 방향으로 80개씩 쏩니다. 폭죽은 1.5초 동안 매 프레임 양쪽에서 6개씩 계속 쏘는 방식입니다.

주의할 점

  • 복사한 코드만으로는 동작하지 않습니다. canvas-confetti 라이브러리를 페이지에 함께 넣어야 하며, ISC 라이선스라 상업적 사용도 가능합니다.
  • 조각 수를 크게 늘리면 저사양 PC나 휴대전화에서 화면이 끊길 수 있습니다.
  • 움직임에 민감한 사용자도 있으니 반복 실행되거나 자동으로 터지는 효과는 신중하게 쓰세요.
