박자
Web Audio API로 소리를 만들어 지연 없이 정확한 박자를 냅니다(외부 음원 없음). 첫 박은 강박(주황)으로 강조됩니다. 모든 기능은 브라우저에서만 동작합니다.

온라인 메트로놈 사용 안내

무엇을 하는 도구인가

정해진 빠르기로 「딱, 딱」 소리를 내 박자를 잡아 주는 메트로놈입니다. 음원 파일을 재생하는 대신 브라우저의 Web Audio API로 짧은 전자음을 직접 만들며, 다음 박을 약 0.2초 앞서 오디오 시계에 예약해 두는 방식이라 화면 처리가 잠시 밀려도 박자 간격이 흔들리지 않습니다. 마디의 첫 박은 더 높은 음(1500Hz, 나머지 박은 1000Hz)으로 울리고 화면에도 주황색 점으로 표시됩니다.

언제 쓰나

  • 피아노·기타 같은 악기 연습에서 일정한 템포를 유지하는 연습을 할 때
  • 합창단·사내 동호회 밴드 연습 때 휴대전화를 스피커에 연결해 기준 박자를 줄 때
  • 원곡의 빠르기를 알고 싶을 때 노래에 맞춰 탭 템포로 BPM을 잴 때
  • 줄넘기나 맨손 운동에서 동작 속도를 일정하게 맞출 때

사용 방법

  1. 막대를 움직이거나 「−5」, 「−1」, 「+1」, 「+5」 버튼으로 BPM(1분당 박 수)을 30~240 사이에서 맞춥니다.
  2. 「박자」에서 한 마디의 박 수(2~7)를 고릅니다. 4/4박이면 4, 왈츠라면 3입니다.
  3. 「▶ 시작」을 누르면 소리가 나고, 같은 버튼(「⏸ 정지」)으로 멈춥니다.
  4. 빠르기를 모를 때는 음악에 맞춰 「탭 템포」를 여러 번 누르면 최근 3초 안의 누른 간격 평균으로 BPM이 맞춰집니다.

결과 해석

BPM 60은 1초에 한 번, 120은 0.5초에 한 번 소리가 납니다. 박자를 4로 두면 「높은음-낮은음-낮은음-낮은음」이 반복되어 마디의 시작을 귀로 알 수 있습니다. 탭 템포에서 0.5초 간격으로 눌렀다면 60000 ÷ 500 = 120 BPM이 됩니다. 재생 중에 빠르기를 바꾸면 다음 박부터 바로 반영됩니다.

주의할 점

  • 블루투스 이어폰·스피커는 기기 자체 지연이 있어 화면의 점보다 소리가 늦게 들릴 수 있습니다. 박자 간격은 그대로이니 소리 기준으로 연습하세요.
  • 휴대전화가 무음 모드이면 브라우저 소리가 나지 않는 기종이 있습니다.
  • 다른 탭으로 오래 옮겨 가 있으면 브라우저가 백그라운드 작업을 늦춰 소리가 끊길 수 있습니다. 연습 중에는 이 탭을 앞에 띄워 두세요.
  • 8분음표 분할이나 강약 패턴 편집 같은 기능은 없습니다.

자주 묻는 질문

6/8박은 어떻게 설정하나요?
8분음표를 한 박으로 세려면 박자 6을 고르고 원하는 빠르기를 맞추면 됩니다. 점4분음표 단위 두 박으로 세고 싶다면 박자 2를 고르세요.
소리가 나지 않아요.
기기 음량과 무음 스위치를 확인한 뒤 「▶ 시작」을 다시 눌러 보세요. 브라우저는 사용자가 버튼을 누른 뒤에야 소리를 허용합니다.
