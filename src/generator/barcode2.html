고급 바코드 생성기

DataMatrix·PDF417·Aztec 등 산업용 2D/1D 바코드를 만들어 줍니다.

종류
오픈소스 bwip-js(MIT, metafloor/bwip-js)를 자체 호스팅합니다. 100여 종 심볼을 지원합니다. EAN/UPC 등은 자릿수 규칙이 있어 형식에 맞아야 합니다. 모든 처리는 브라우저에서만 이루어집니다.

고급 바코드 생성기 사용 안내

무엇을 하는 도구인가

산업 현장에서 쓰는 2차원 코드와 1차원 바코드를 만드는 도구입니다. 바코드 렌더링 엔진 bwip-js를 브라우저에서 돌려 DataMatrix, PDF417, Aztec, QR Code 같은 2차원 코드와 Code 128, Code 39, EAN-13, UPC-A, ITF, GS1-128 같은 1차원 바코드를 캔버스에 그립니다. 모든 형식에서 사람이 읽을 수 있는 글자도 함께 표시하도록 설정되어 있습니다.

언제 쓰나

  • 작은 부품이나 의료 소모품 라벨처럼 공간이 좁아 DataMatrix가 필요할 때
  • 신분증·운송장처럼 많은 정보를 한 코드에 담는 PDF417 샘플이 필요할 때
  • 물류 박스 라벨용 GS1-128 바코드를 시험 인쇄할 때
  • 바코드 스캐너를 새로 들이기 전에 여러 형식을 읽어 내는지 시험용 코드를 만들 때

사용 방법

  1. 「종류」에서 바코드 형식을 고릅니다.
  2. 아래 칸에 담을 내용을 입력합니다. 입력하는 즉시 다시 그려지며, 「생성」을 눌러도 됩니다.
  3. 「⬇️ PNG」를 누르면 barcode.png로 저장됩니다.

결과 해석

형식 규칙에 맞지 않는 값을 넣으면 그림 대신 위에 ⚠️ 표시와 함께 라이브러리의 오류 문구(영문)가 나옵니다. 예를 들어 EAN-13에 문자를 넣거나 자릿수가 맞지 않으면 오류가 납니다. GS1-128은 「(01)」 뒤에 14자리 상품코드를 붙이는 식으로, 괄호로 감싼 응용 식별자(AI) 뒤에 값을 이어 적는 형식이어야 하며 기본 예시 값으로는 만들어지지 않습니다. 같은 내용이라도 DataMatrix는 정사각형, PDF417은 가로로 긴 직사각형으로 그려지며 1차원 바코드는 일정한 높이로 그립니다.

주의할 점

  • 크기·여백·글자 표시 여부를 고르는 옵션은 없습니다. 출력 크기를 바꾸려면 받은 PNG를 문서 편집기에서 배율을 유지한 채 조절하세요. 늘릴 때 가로세로 비율이 바뀌면 인식이 안 될 수 있습니다.
  • EAN-13·UPC-A 같은 유통 상품코드는 발급 기관에서 받은 번호만 실제 상품에 써야 합니다.
  • 업무용 라벨은 실제로 쓸 스캐너로 반드시 읽혀 보고 배포하세요. 형식마다 지원하는 스캐너가 다릅니다.

자주 묻는 질문

DataMatrix와 QR Code는 무엇이 다른가요?
둘 다 2차원 코드지만 DataMatrix는 같은 정보를 더 작은 면적에 담기 좋아 부품 각인이나 작은 라벨에 많이 쓰이고, QR Code는 휴대전화 카메라로 읽는 용도에 널리 쓰입니다.
한글도 넣을 수 있나요?
형식에 따라 다릅니다. 1차원 바코드는 대부분 영문·숫자만 받습니다. 2차원 코드에 한글을 넣었다면 스캐너가 같은 문자 인코딩으로 읽는지 꼭 확인하세요.
