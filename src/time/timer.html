타이머 · 스톱워치

카운트다운 타이머와 스톱워치를 한곳에서. 타이머는 끝나면 알림음이 울리고, 스톱워치는 랩(구간)을 기록합니다.

타이머·스톱워치 사용 안내

무엇을 하는 도구인가

정해 둔 시간에서 거꾸로 세는 카운트다운 타이머와, 0부터 흘러간 시간을 재는 스톱워치를 탭 하나로 오가며 쓰는 도구입니다. 타이머는 0이 되면 짧은 알림음을 세 번 울리고 표시가 바뀌며, 스톱워치는 1/100초 단위까지 보여 주고 랩 버튼으로 구간 기록을 남깁니다. 시간은 화면 갱신 간격이 아니라 시작 시점과 현재 시점의 차이로 계산하므로, 오래 켜 두어도 표시가 조금씩 밀리는 누적 오차가 생기지 않습니다.

언제 쓰나

  • 회의에서 안건별 발언 시간을 5분, 10분으로 끊어 진행할 때
  • 발표 리허설에서 슬라이드 단락마다 걸린 시간을 랩으로 기록할 때
  • 25분 집중 후 휴식하는 방식으로 문서 작업 시간을 나눌 때
  • 교육·시험 현장에서 남은 시간을 화면에 띄워 둘 때

사용 방법

  1. [⏲️ 타이머] 탭에서 분과 초를 입력하거나 1분·3분·5분·10분·25분 버튼을 누릅니다.
  2. [시작]을 누르면 카운트다운이 시작되고, [일시정지] 뒤 다시 [시작]하면 남은 시간부터 이어집니다.
  3. [초기화]는 입력해 둔 분·초 값으로 되돌립니다.
  4. [⏱️ 스톱워치] 탭에서는 [시작]으로 재고 [랩]으로 구간을 남기며, [정지] 후 [시작]하면 이어서 잽니다.

결과 해석

타이머 표시는 MM:SS이며 1시간을 넘기면 HH:MM:SS로 바뀝니다. 예를 들어 90분을 입력하면 01:30:00부터 셉니다. 스톱워치 랩 목록은 최신 기록이 위에 오며, 한 줄에 '랩 번호 · 이번 구간 시간 · 시작부터 누적 시간'이 나란히 나옵니다. 발표 연습이라면 가운데 값으로 단락별 길이를, 오른쪽 값으로 전체 진행 정도를 보면 됩니다.

주의할 점

종료 시각을 기준으로 남은 시간을 계산하고 알림은 별도 타이머로 예약하므로, 다른 탭으로 옮기거나 창을 최소화해도 0이 되면 알림음이 울립니다. 다만 브라우저가 절전을 위해 백그라운드 탭의 타이머를 늦추는 경우가 있어 알림이 1초 남짓 늦을 수 있고, 노트북이 절전 모드에 들어가면 깨어난 뒤에 울립니다. 기기가 무음이거나 브라우저 소리가 꺼져 있으면 알림음이 들리지 않습니다. 새로고침하면 진행 중이던 시간과 랩 기록은 사라집니다.

자주 묻는 질문

타이머와 스톱워치를 동시에 돌릴 수 있나요?
네. 탭은 화면만 바꾸는 것이라 한쪽이 돌아가는 중에 다른 탭으로 가서 시작해도 둘 다 계속 진행됩니다.
999분보다 긴 시간도 되나요?
분 입력란의 권장 범위는 999분까지입니다. 그 이상은 일정 알림 앱을 쓰는 편이 낫습니다.
