리치 텍스트 에디터

워드처럼 서식을 넣어 글을 쓰면 곧바로 HTML 코드로 바꿔 줍니다.

제목 예시

여기에 굵게, 기울임, 밑줄을 적용해 보세요.

  • 목록 항목
오픈소스 Quill(BSD-3, quilljs/quill)을 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어집니다.

리치 텍스트 에디터 사용 안내

무엇을 하는 도구인가

워드프로세서처럼 도구 모음 버튼으로 서식을 넣으며 글을 쓰면, 그 내용을 HTML 코드로 바로 보여 주는 편집기입니다. 편집기는 오픈소스 Quill(1.x)을 씁니다. 쓸 수 있는 서식은 제목 1~3단계, 굵게·기울임·밑줄·취소선, 글자색·배경색, 번호 목록·글머리 목록, 정렬, 링크, 인용, 코드 블록, 그리고 서식 지우기입니다. 편집기 아래 칸의 코드는 글을 고칠 때마다 함께 바뀝니다.

언제 쓰나

  • HTML을 직접 쓰기 어려운 담당자가 홈페이지 게시판이나 쇼핑몰 상세 설명용 코드를 만들 때
  • 이메일 템플릿이나 사내 위키처럼 HTML만 받는 곳에 넣을 서식 있는 글을 준비할 때
  • 웹 문서에서 복사한 글을 붙여 넣어 군더더기 서식을 정리한 HTML로 바꿀 때

사용 방법

  1. 편집 영역의 예시 글을 지우고 내용을 쓰거나 붙여 넣습니다.
  2. 글자를 드래그해 선택한 뒤 도구 모음 버튼으로 서식을 넣습니다. 제목 단계는 맨 왼쪽 목록에서 고릅니다.
  3. 아래 칸에서 HTML 코드를 확인하고 「📋 HTML 복사」로 가져갑니다.

결과 해석

굵게는 <strong>, 기울임은 <em>, 목록은 <ol>·<ul>처럼 일반 HTML 태그로 나옵니다. 글자색과 배경색은 style="color: …" 같은 인라인 스타일로 들어갑니다. 반면 가운데 정렬은 class="ql-align-center", 코드 블록은 class="ql-syntax"처럼 Quill 전용 클래스 이름으로 표시됩니다.

주의할 점

  • 정렬처럼 Quill 클래스로 표시되는 서식은 붙여 넣을 사이트에 Quill용 CSS가 없으면 적용되지 않습니다. 가운데 정렬이 꼭 필요하면 해당 사이트의 편집기에서 다시 지정하세요.
  • 쓴 내용은 저장되지 않습니다. 새로고침하거나 창을 닫으면 사라지니 작업 중간중간 HTML을 복사해 두세요.
  • 표, 글꼴 종류, 글자 크기 지정 기능은 없습니다. 다른 곳에서 표를 붙여 넣으면 표 구조가 풀립니다.

자주 묻는 질문

만든 HTML을 다시 불러와 고칠 수 있나요?
HTML 코드를 불러오는 기능은 없습니다. 편집기에 글이 남아 있는 동안 고쳐서 다시 복사하세요.
워드 문서를 붙여 넣으면 서식이 유지되나요?
굵게, 기울임, 목록, 링크처럼 편집기가 지원하는 서식만 남고 나머지는 빠집니다.
