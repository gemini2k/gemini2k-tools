한글 로마자 변환기

한글을 로마자(국어의 로마자 표기법 근사)로 바꿉니다. 이름·주소·간판 영문 표기에 참고하세요.

 
↓
국어의 로마자 표기법 자모 대응에 연음·자음동화·구개음화·거센소리되기를 반영한 자동 변환입니다. 품사나 낱말 경계를 알 수 없어 일부 예외(묵호 Mukho 등)는 다르게 나올 수 있으니 참고용으로 쓰세요. 모든 처리는 브라우저에서만 이루어집니다.

한글 로마자 변환기 사용 안내

무엇을 하는 도구인가

한글 음절을 초성·중성·종성으로 나눈 뒤 국어의 로마자 표기법의 자모 대응표에 맞춰 로마자로 바꿉니다. ㅓ는 eo, ㅡ는 eu, ㅢ는 ui, 받침 ㄱ은 k, 받침 ㅇ은 ng입니다. 표기법 제3장 제1항에 따라 발음이 바뀌는 자리는 바뀐 발음대로 적습니다. 한 낱말 안의 음절 사이에서만 계산하고, 띄어 쓴 낱말끼리는 서로 영향을 주지 않습니다.

  • 연음: 한국어 → hangugeo, ㅎ 받침 뒤 모음은 ㅎ을 뺍니다(좋아 → joa).
  • 비음화: 백마 → baengma, 국물 → gungmul, 종로 → jongno, 합리 → hamni, 왕십리 → wangsimni
  • 유음화: 신라 → silla, 별내 → byeollae, 빨래 → ppallae
  • 구개음화: 해돋이 → haedoji, 같이 → gachi, 굳히다 → guchida
  • 거센소리되기: 좋고 → joko, 놓다 → nota, 잡혀 → japyeo

된소리되기는 표기법대로 적지 않습니다. 압구정은 apgujeong, 낙동강은 nakdonggang입니다.

언제 쓰나

  • 외국 거래처에 보낼 메일이나 명함 시안에 회사·지명 영문 표기를 잡아 볼 때
  • 행사 안내판, 메뉴판의 한글 이름 옆에 로마자 표기를 붙이기 전 초안을 만들 때
  • 파일명이나 시스템 코드값을 한글 대신 로마자로 정할 때

사용 방법

  1. 입력칸에 한글을 씁니다. 여러 줄도 줄 단위로 변환됩니다.
  2. 「단어 첫 글자 대문자」를 켜면 띄어쓰기로 나뉜 단어마다 첫 글자가 대문자가 됩니다.
  3. 사람 이름을 바꿀 때는 「발음 변화 반영」을 끕니다. 표기법은 인명에 음운 변화를 반영하지 않으므로, 끄면 음절마다 글자 그대로 적습니다. 성과 이름을 띄어 「한 복남」으로 넣으면 Han Boknam이 됩니다.
  4. 결과를 확인하고 「📋 복사」를 누릅니다.

결과 해석

「안녕하세요」는 annyeonghaseyo, 「신문로」는 [신문노]로 소리 나므로 sinmunno입니다. 영문·숫자·기호는 그대로 두며, 기호나 공백이 끼면 그 앞뒤는 별개의 낱말로 봅니다.

주의할 점

  • 품사를 구별하지 못합니다. 표기법은 체언에서 ㄱ·ㄷ·ㅂ 뒤에 오는 ㅎ을 거센소리로 합치지 않고 h로 적지만(묵호 Mukho, 집현전 Jiphyeonjeon), 이 도구는 용언처럼 늘 거센소리로 바꿔 muko로 냅니다. 지명·명사라면 이 부분을 직접 고치세요.
  • ㄴ과 ㄹ이 만날 때는 보통 ll로 적고, 둘째 음절 이후의 로·란·량·론·력 앞에서만 nn으로 적습니다(신라 silla, 신문로 sinmunno). 이 밖의 [ㄴㄴ] 발음이나 ㄴ·ㄹ 첨가(학여울 Hangnyeoul)는 계산하지 않습니다.
  • 사람 이름은 관용 표기가 따로 있는 경우가 많습니다. 「이」는 i, 「박」은 bak으로 나오므로 여권이나 공식 서류의 영문 성명은 기존에 쓰던 표기를 따르세요.
  • 도로명주소의 공식 영문 표기는 도로명주소 안내 시스템에서 확인해야 합니다.

자주 묻는 질문

음절 사이에 붙임표(-)를 넣을 수 있나요?
자동으로 넣지는 않습니다. 발음 혼동이 우려되는 곳은 결과를 복사한 뒤 직접 넣으세요.
매큔-라이샤워 방식으로도 바꿀 수 있나요?
아닙니다. 현행 국어의 로마자 표기법의 자모 대응만 씁니다.
