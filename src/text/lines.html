텍스트 줄 정리기

여러 줄로 된 목록·명단을 정렬하고, 중복·빈 줄을 없애고, 공백을 정리합니다. 버튼을 누를 때마다 결과에 적용됩니다.

📖
사용 방법
  1. 아래에 줄 단위 텍스트를 붙여넣습니다
  2. 원하는 작업 버튼을 누르면 즉시 적용되어 결과가 갱신됩니다 (이어서 여러 번 적용 가능)
  3. '복사'로 결과를 가져갑니다. '되돌리기'로 직전 상태로 돌아갑니다
↓ 결과
정렬은 한국어·영문·숫자를 자연스럽게 비교합니다(숫자순은 줄 안의 첫 숫자를 기준). 모든 처리는 브라우저에서만 이루어집니다.

텍스트 줄 정리기 사용 안내

무엇을 하는 도구인가

줄 단위 목록을 정렬하고, 중복·빈 줄을 지우고, 앞뒤 공백을 다듬는 도구입니다. 입력칸은 그대로 두고 아래 결과칸에 작업을 차례로 쌓아 적용합니다. 예를 들어 「앞뒤 공백 제거」 → 「중복 제거」 → 「가나다 정렬」을 이어서 누르면 세 작업이 모두 적용된 결과가 나옵니다. 정렬은 한국어 기준으로 비교하고, 줄 안의 숫자는 자릿수가 아닌 크기로 비교합니다.

언제 쓰나

  • 여러 부서에서 취합한 참석자 명단을 합쳐 중복을 지우고 가나다순으로 정리할 때
  • 엑셀에서 복사한 한 열짜리 목록의 빈 줄과 앞뒤 공백을 없앨 때
  • 경품 추첨이나 발표 순서를 정하려고 명단을 무작위로 섞을 때
  • 「3번 회의실」, 「10번 회의실」처럼 번호가 섞인 목록을 숫자 크기순으로 맞출 때

사용 방법

  1. 「텍스트 입력」에 한 줄에 하나씩 항목을 붙여 넣습니다.
  2. 「⬆ 가나다 정렬」, 「⬇ 역순 정렬」, 「길이순」, 「숫자순」, 「무작위 섞기」, 「중복 제거」, 「빈 줄 제거」, 「앞뒤 공백 제거」, 「줄 뒤집기」, 「줄 번호」 중 필요한 버튼을 순서대로 누릅니다.
  3. 영문 대소문자를 같게 볼 때는 「대소문자 무시」를 켭니다. 정렬과 중복 제거에 적용됩니다.
  4. 「📋 복사」로 결과를 가져갑니다. 잘못 눌렀으면 「↶ 되돌리기」, 처음부터 다시 하려면 「입력으로 초기화」를 누릅니다.

결과 해석

기본 예문에 바로 「중복 제거」를 누르면 「바나나, 사과, ␣␣딸기, (빈 줄), 포도, 체리」가 남습니다. 두 번째 「바나나」와 「사과」는 지워지고 처음 나온 줄이 남습니다. 결과 아래 「총 ○줄 · 내용 있는 줄 ○개 · 글자 ○자」로 변화를 확인할 수 있습니다. 「숫자순」은 각 줄에서 처음 나오는 숫자로 정렬하고 숫자가 없는 줄은 원래 순서를 유지한 채 뒤로 보냅니다.

주의할 점

  • 중복 판단은 줄 전체가 글자 그대로 같은지로 합니다. 「딸기」와 「␣␣딸기」는 다른 줄로 보므로 「앞뒤 공백 제거」를 먼저 누르세요.
  • 입력칸을 고치면 결과는 입력 기준으로 새로 계산되고, 그동안 쌓은 작업은 사라집니다.
  • 「되돌리기」는 최근 50단계까지만 기억합니다.

자주 묻는 질문

「줄 번호」를 다시 지울 수 있나요?
「↶ 되돌리기」로 번호 붙이기 전 상태로 돌아갈 수 있습니다.
쉼표로 구분된 목록도 되나요?
줄바꿈만 구분자로 씁니다. 쉼표 목록은 먼저 줄바꿈으로 바꿔서 붙여 넣으세요.
