키워드 하이라이터

긴 글에서 원하는 단어를 형광펜처럼 강조하고 몇 번 나오는지 세어 줍니다.

오픈소스 mark.js(MIT, julkue/mark.js)를 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어집니다.

키워드 하이라이터 사용 안내

무엇을 하는 도구인가

붙여 넣은 글에서 지정한 키워드를 형광펜처럼 칠하고, 칠해진 곳이 모두 몇 군데인지 세어 줍니다. 강조 처리는 오픈소스 mark.js 라이브러리를 씁니다. 키워드는 띄어쓰기로 여러 개를 한 번에 넣을 수 있고, 각 키워드를 따로 찾아 모두 칠합니다. 입력한 글은 HTML로 해석하지 않고 글자 그대로 보여 줍니다.

언제 쓰나

  • 보도자료나 블로그 원고에서 핵심 키워드가 몇 번, 어디에 들어갔는지 확인할 때
  • 계약서·약관 초안에서 「위약금」, 「해지」 같은 단어가 나오는 곳을 빠짐없이 훑어볼 때
  • 회의록에서 특정 담당자 이름이나 안건명이 언급된 부분만 빠르게 찾을 때
  • 자기소개서에서 같은 표현을 너무 자주 쓰지 않았는지 점검할 때

사용 방법

  1. 위쪽 큰 칸에 검사할 글을 붙여 넣습니다.
  2. 키워드 칸에 찾을 단어를 입력합니다. 여러 개면 띄어쓰기로 구분합니다.
  3. 영문의 대소문자를 구별하려면 「대소문자 구분」을 켭니다.
  4. 「부분 단어 포함」을 끄면 앞뒤가 띄어쓰기로 떨어진 단어만 찾습니다. 결과 칸과 「일치: n개」가 바로 바뀝니다.

결과 해석

기본 예문에서 키워드 「검색」은 「검색은」, 「좋은 검색은」, 「검색 결과」, 「검색 품질」의 4곳이 칠해져 「일치: 4개」가 나옵니다. 「부분 단어 포함」을 끄면 뒤에 조사가 붙은 「검색은」은 빠지고 앞뒤가 띄어쓰기인 곳만 남습니다. 한국어는 조사가 붙어 쓰이는 경우가 많으므로 보통은 켜 둔 상태가 실제 등장 횟수에 가깝습니다. 키워드를 여러 개 넣으면 숫자는 모든 키워드의 합계입니다.

주의할 점

  • 띄어쓰기가 구분자라서 「개인 정보」 같은 띄어 쓴 구절은 한 덩어리로 찾을 수 없고 「개인」과 「정보」를 따로 찾습니다.
  • 부분 일치에서는 「검색」이 「검색어」, 「재검색」 안에서도 칠해집니다. 정확한 단어만 세려면 결과를 눈으로 한 번 더 확인하세요.
  • 결과는 화면 확인용입니다. 칠해진 상태를 문서로 내려받는 기능은 없습니다.

자주 묻는 질문

합계만 표시됩니다. 키워드별로 알고 싶으면 하나씩 넣어 보세요.
글이 길어도 되나요?
됩니다. 다만 수십 쪽 분량이면 입력할 때마다 다시 칠하므로 반응이 느려질 수 있습니다.
