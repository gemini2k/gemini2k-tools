#단어횟수비율
단어는 공백·문장부호 기준으로 나눕니다(한국어는 형태소 분석이 아니라 어절 단위 근사). 불용어 제외는 자주 쓰는 조사·접속사 일부를 거릅니다. 모든 처리는 브라우저에서만 이루어집니다.

단어 빈도 분석기 사용 안내

무엇을 하는 도구인가

붙여넣은 글을 단어 단위로 잘라 각 단어가 몇 번 나왔는지 세고, 많이 나온 순서로 표를 만듭니다. 글자·숫자가 아닌 문자(공백, 마침표, 쉼표, 괄호 등)를 경계로 자르기 때문에 한국어는 형태소가 아니라 띄어쓰기 단위인 어절로 집계됩니다. 위쪽에는 전체 단어 수, 중복을 뺀 고유 단어 수, 공백을 포함한 글자수가 함께 나옵니다.

언제 쓰나

  • 보고서 초안에서 '검토', '추진' 같은 단어를 지나치게 반복했는지 확인할 때
  • 블로그 글이나 보도자료에 넣으려던 핵심 키워드가 실제로 몇 번 들어갔는지 셀 때
  • 설문 주관식 응답을 한데 붙여 넣고 자주 나온 표현을 훑어볼 때
  • 영문 초록이나 이메일에서 같은 단어를 반복한 곳을 찾을 때

사용 방법

  1. 입력란의 예시 문장을 지우고 분석할 글을 붙여넣습니다. 입력하는 즉시 표가 갱신됩니다.
  2. '최소 글자수'로 너무 짧은 단어를 거릅니다. 기본값 2는 한 글자 단어를 제외합니다.
  3. '흔한 조사·불용어 제외'와 '영문 대소문자 통합'을 필요에 따라 켜고 끕니다.
  4. '상위'에서 50·100·전체 중 표에 보일 개수를 고릅니다.
  5. [📋 CSV 복사] 또는 [⬇️ CSV 다운로드]로 단어와 횟수를 가져가 엑셀에서 정리합니다.

결과 해석

예를 들어 분석은 단어를 세는 일입니다. 단어 빈도 분석은 유용합니다.를 넣으면 '분석은'은 2회, '단어'와 '단어를'은 서로 다른 단어로 각각 1회씩 나옵니다. 조사가 붙은 어절은 다른 단어로 세어지므로, 같은 명사의 총 사용 횟수를 보려면 표에서 '단어', '단어를', '단어의'처럼 앞부분이 같은 행을 합쳐 봐야 합니다. 비율 막대는 1위 단어의 횟수를 100으로 놓은 상대 길이이지 전체 대비 백분율이 아닙니다.

주의할 점

불용어 목록은 '은·는·이·가·을·를·그리고·하지만'과 영어 the, and, of 같은 소수의 단어뿐이며, 띄어 쓴 조사처럼 따로 떨어진 경우에만 걸러집니다. 붙어 있는 조사까지 떼어 내는 형태소 분석은 하지 않으므로 학술적인 텍스트 마이닝 용도라면 별도의 형태소 분석기를 쓰는 것이 맞습니다. 글은 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다.

자주 묻는 질문

숫자도 단어로 세나요?
예. 2024, 3분기의 '3분기'처럼 숫자가 포함된 토큰도 하나의 단어로 셉니다. 숫자를 빼고 싶다면 최소 글자수를 늘리거나 CSV에서 걸러 내세요.
CSV를 엑셀로 열면 한글이 깨지나요?
다운로드 파일은 UTF-8 BOM을 붙여 저장하므로 엑셀에서 바로 열어도 한글이 정상으로 보입니다.
