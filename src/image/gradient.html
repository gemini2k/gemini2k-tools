CSS 그라데이션 생성기

선형·원형 그라데이션을 눈으로 보며 만들고, 그대로 쓸 수 있는 CSS를 복사하거나 PNG 이미지로 내려받습니다.

📖
사용 방법
  1. 유형(선형/원형)과 각도를 고릅니다
  2. 색상 정지점의 색과 위치를 조절하거나 '＋ 색상 추가'로 늘립니다
  3. 아래 CSS를 복사하거나 PNG로 내려받습니다
생성된 background 값을 그대로 CSS에 붙여 넣으면 됩니다. PNG는 1200×600 크기로 저장됩니다. 모든 처리는 브라우저에서 이루어집니다.

CSS 그라데이션 생성기 사용 안내

무엇을 하는 도구인가

색상 정지점(color stop)의 색과 위치를 슬라이더로 맞추며 CSS linear-gradient 또는 radial-gradient 값을 만듭니다. 미리보기는 만들어진 CSS를 그대로 적용한 것이라 화면에 보이는 모습이 곧 코드 결과입니다. 정지점은 2개에서 8개까지 둘 수 있고, 위치 순서대로 정렬해 코드를 만듭니다. 같은 그라데이션을 1200×600 PNG로도 내려받을 수 있습니다.

언제 쓰나

  • 랜딩 페이지 히어로 영역이나 버튼 배경에 넣을 CSS 한 줄이 필요할 때
  • 발표 자료나 유튜브 썸네일 배경 이미지를 빠르게 만들 때
  • 디자이너가 준 색 두세 개로 그라데이션 각도를 여러 개 시험해 볼 때
  • 배색 아이디어가 없을 때 「랜덤」으로 조합을 여러 번 뽑아 볼 때

사용 방법

  1. 「유형」에서 선형(linear) 또는 원형(radial)을 고릅니다. 선형이면 「각도」를 0~360° 사이로 정합니다.
  2. 각 정지점의 색상 상자를 누르거나 16진수 칸에 #2563EB처럼 여섯 자리 값을 넣고, 오른쪽 슬라이더로 위치(0~100%)를 정합니다.
  3. 「＋ 색상 추가」로 정지점을 늘리고 ✕로 지웁니다(최소 2개, 최대 8개).
  4. 「CSS 복사」로 코드를 복사하거나 「PNG 내려받기」로 gradient.png를 저장합니다.

결과 해석

처음 상태에서는 background: linear-gradient(90deg, #7C3AED 0%, #2DD4BF 100%);가 나옵니다. 90deg는 왼쪽에서 오른쪽으로, 180deg는 위에서 아래로 색이 바뀝니다. 두 정지점을 같은 위치(예: 둘 다 50%)에 두면 부드럽게 섞이지 않고 경계가 딱 끊기는 줄무늬가 됩니다. 원형은 가운데 원에서 바깥으로 퍼지는 circle 모양만 만듭니다.

주의할 점

  • PNG는 브라우저 CSS가 아니라 캔버스로 다시 그린 것입니다. 원형 그라데이션은 CSS 기본값과 같이 가운데에서 가장 먼 모서리까지를 반지름으로 잡아 그리지만, 미리보기 상자와 PNG(1200×600)의 가로세로 비율이 다르면 색이 퍼지는 모양이 조금 달라 보일 수 있습니다.
  • 16진수 칸은 여섯 자리 값만 받습니다. #FFF 같은 세 자리 표기나 rgba 투명도는 쓸 수 없습니다.
  • 채도가 높은 보색끼리(예: 빨강과 초록) 이으면 가운데가 탁한 회색빛으로 보이기 쉽습니다. 중간에 정지점을 하나 더 두면 나아집니다.

자주 묻는 질문

글자에 그라데이션을 넣으려면요?
복사한 값을 background에 넣고, 같은 요소에 -webkit-background-clip: text와 color: transparent를 함께 지정하면 됩니다.
PNG 크기를 바꿀 수 있나요?
1200×600으로 고정입니다. 다른 크기가 필요하면 CSS 값을 쓰거나 이미지 편집기에서 조정하세요.
