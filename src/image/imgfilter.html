CSS 필터를 캔버스에 적용해 저장합니다. 모든 처리는 브라우저에서만 이루어지며 이미지는 서버로 전송되지 않습니다.

이미지 필터 사용 안내

무엇을 하는 도구인가

사진에 밝기, 대비, 채도, 블러, 색조 회전, 세피아 여섯 가지 조정을 겹쳐 적용하고 PNG로 저장합니다. 조정값은 CSS 필터 문법으로 묶어 캔버스에 그릴 때 한 번에 입히며, 저장 이미지는 원본과 같은 해상도로 만들어집니다. 흑백·세피아·쿨톤·웜톤·선명 같은 프리셋은 이 슬라이더 값을 미리 정해 둔 조합입니다. 사진은 브라우저 안에서만 처리되고 전송되지 않습니다.

언제 쓰나

  • 블로그나 상세페이지 사진이 어둡게 찍혀 밝기와 대비만 살짝 올리고 싶을 때
  • 발표 자료에 넣을 사진들의 분위기를 흑백이나 세피아로 통일할 때
  • 배경 이미지 위에 글자를 얹기 전에 블러를 넣어 글자가 잘 읽히게 할 때
  • 사진 편집 프로그램을 설치하지 않은 PC에서 간단히 보정할 때

사용 방법

  1. 점선 영역에 이미지를 끌어다 놓거나 클릭해서 고릅니다.
  2. 프리셋 버튼(원본·흑백·세피아·반전·쿨톤·웜톤·선명)을 눌러 출발점을 정합니다.
  3. 「밝기」「대비」(0~200%), 「채도」(0~300%), 「블러」(0~10px), 「색조」(0~360°), 「세피아」(0~100%) 슬라이더로 세부 조정합니다.
  4. 「PNG 저장」으로 filtered.png를 내려받습니다.

결과 해석

밝기·대비·채도는 100%가 원본이고, 숫자가 작으면 줄고 크면 늘어납니다. 흑백 프리셋은 채도를 0으로, 세피아 프리셋은 세피아를 90%로 둔 것입니다. 웜톤은 밝기 105%, 채도 120%, 색조 330°, 세피아 20%를 함께 써서 붉은 기운을 더합니다. 블러는 원본 픽셀 기준이라 4000px 폭의 휴대폰 사진에 10px을 줘도 화면 미리보기에서는 약하게 보일 수 있습니다. 저장 파일은 원본 크기이므로 저장 후 확대해 확인하세요.

주의할 점

  • 「반전」은 다른 프리셋과 달리 슬라이더 값을 그대로 두고 색만 뒤집습니다. 반전한 상태에서 슬라이더를 움직여도 반전은 유지되고, 한 번 더 누르면 풀립니다. 다른 프리셋을 누르면 반전도 함께 해제됩니다.
  • 저장 형식은 PNG 하나라 사진은 원본 JPG보다 용량이 크게 늘 수 있습니다.
  • 캔버스 필터를 지원하지 않는 브라우저에서는 조정이 결과에 반영되지 않을 수 있습니다. 미리보기가 그대로라면 다른 브라우저를 써 보세요.

자주 묻는 질문

원본 사진이 바뀌나요?
아닙니다. 원본 파일은 그대로 두고 새 파일로 저장합니다.
여러 장에 같은 설정을 한 번에 적용할 수 있나요?
한 번에 한 장만 처리합니다. 슬라이더 값은 다음 사진을 올려도 유지되므로 같은 설정으로 이어서 작업할 수 있습니다.
