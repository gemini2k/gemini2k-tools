이미지 픽셀화·도트화

사진을 픽셀아트 느낌으로 바꿉니다. 픽셀 크기를 키울수록 더 큰 도트가 됩니다.

🟦
이미지를 끌어다 놓거나 클릭
픽셀 크기만큼 블록 평균색으로 묶고, 색 단계로 색을 양자화합니다. 모든 처리는 브라우저에서만 이루어지며 이미지는 서버로 전송되지 않습니다.

이미지 픽셀화·도트화 사용 안내

무엇을 하는 도구인가

사진을 큰 네모 블록으로 바꿔 도트 그림처럼 만듭니다. 처리 방식은 단순합니다. 이미지를 「픽셀 크기」만큼 작게 줄였다가 부드럽게 하는 보간 없이 원래 크기로 다시 키웁니다. 그 사이에 「색 단계」 값으로 빨강·초록·파랑 각 채널을 몇 단계로만 표현할지 정해 색 수를 줄입니다. 결과 이미지는 원본과 같은 가로세로 픽셀 크기의 PNG입니다.

언제 쓰나

  • 프로필 사진이나 썸네일을 레트로 게임 느낌의 도트 이미지로 바꾸고 싶을 때
  • 픽셀아트나 십자수·비즈 도안을 만들기 전에 색과 형태를 대략 잡아 볼 때
  • 발표 자료에서 사진이 너무 사실적이어서 분위기를 가볍게 바꾸고 싶을 때

사용 방법

  1. 점선 영역에 이미지를 끌어다 놓거나 클릭해 고릅니다.
  2. 「픽셀 크기」(2~40, 기본 10)를 움직이면 블록 크기가 바로 바뀝니다.
  3. 「색 단계」(2~32, 기본 32)를 낮추면 색이 포스터처럼 단순해집니다.
  4. 마음에 들면 「⬇️ PNG 저장」으로 pixel.png를 받습니다.

결과 해석

1200×800px 사진에 픽셀 크기 10을 주면 가로 120개, 세로 80개 블록으로 표현됩니다. 색 단계는 채널별 단계 수라서 2로 두면 각 채널이 0 또는 255만 남아 최대 8가지 색, 4로 두면 4×4×4 = 64가지 색이 됩니다. 기본값 32에서는 색 변화가 거의 눈에 띄지 않고 블록 효과만 보입니다.

주의할 점

  • 이미지 전체에 한꺼번에 적용됩니다. 얼굴이나 차량번호 한 곳만 가리는 부분 모자이크 기능은 없습니다.
  • 픽셀화는 개인정보를 확실히 지우는 방법이 아닙니다. 블록이 작으면 윤곽이 남아 알아볼 수 있으므로, 가려야 할 정보가 있으면 단색으로 덮는 편이 안전합니다.
  • 블록 색은 브라우저가 이미지를 축소하면서 계산한 색이라 브라우저마다 약간 다를 수 있습니다.

자주 묻는 질문

결과 파일 크기가 원본보다 커졌어요.
원본 해상도 그대로 PNG로 저장하기 때문입니다. 용량이 문제라면 이미지 크기 줄이기나 압축 도구를 이어서 쓰세요.
투명 배경 PNG도 되나요?
됩니다. 투명도 값은 색 단계로 줄이지 않고 그대로 둡니다.
