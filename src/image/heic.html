HEIC → JPG·PNG 변환기

아이폰에서 찍은 HEIC 사진을 JPG나 PNG로 바꿔 줍니다. 여러 장도 한 번에.

📷 HEIC 파일을 끌어다 놓거나 클릭해서 선택 (여러 장 가능)
형식 품질 90%
오픈소스 heic2any(MIT, alexcorvi/heic2any · 내부 libheif는 LGPL/MIT)를 자체 호스팅합니다. 모든 변환은 브라우저에서만 이루어지며 사진은 업로드되지 않습니다.

HEIC → JPG·PNG 변환기 사용 안내

무엇을 하는 도구인가

아이폰과 아이패드가 기본으로 저장하는 HEIC(HEIF) 사진을 어디서나 열리는 JPG나 PNG로 바꿉니다. 해독은 오픈소스 heic2any와 그 안에 들어 있는 libheif가 브라우저 안에서 처리하므로, 사진이 서버로 올라가지 않습니다. 여러 파일을 한 번에 넣으면 각각 변환해 썸네일과 내려받기 링크를 격자로 보여 줍니다.

언제 쓰나

  • 아이폰에서 옮긴 사진이 윈도우 PC나 회사 그룹웨어에서 열리지 않을 때
  • 관공서·쇼핑몰 게시판처럼 JPG·PNG만 받는 곳에 사진을 첨부해야 할 때
  • 개인 사진이라 온라인 변환 사이트에 올리기 꺼려질 때
  • 문서 편집기에 넣을 스크린샷이나 사진을 한꺼번에 바꿔야 할 때

사용 방법

  1. 「형식」에서 JPG 또는 PNG를 고르고, JPG라면 「품질」 슬라이더(50~100%, 기본 90%)를 정합니다. 형식과 품질은 파일을 넣기 전에 정해야 그 값으로 변환됩니다.
  2. 점선 영역에 .heic/.heif 파일을 끌어다 놓거나 클릭해 고릅니다. 여러 장을 함께 골라도 됩니다.
  3. 상태 줄에 완료 개수가 올라가며 변환된 사진이 아래에 나타납니다.
  4. 각 썸네일 아래의 파일 이름 링크를 눌러 저장합니다. 원래 이름에서 확장자만 .jpg 또는 .png로 바뀝니다.

결과 해석

예를 들어 IMG_0412.HEIC를 JPG로 바꾸면 IMG_0412.jpg가 됩니다. JPG 품질 90%는 눈으로 원본과 차이를 느끼기 어려우면서 용량은 PNG보다 훨씬 작아 일반 첨부용으로 무난합니다. PNG는 손실 없는 형식이라 품질 슬라이더의 영향을 받지 않고 파일이 크게 나옵니다. 사진은 JPG, 글자가 많은 스크린샷이나 편집용 원본은 PNG가 맞습니다. 결과 격자는 변환이 끝난 순서대로 채워지므로 올린 순서와 다를 수 있습니다.

주의할 점

  • 변환은 기기의 처리 능력을 씁니다. 고해상도 사진을 수십 장 한 번에 넣으면 휴대폰에서는 느리거나 멈출 수 있으니 나눠서 넣으세요.
  • 연속 촬영처럼 한 파일에 여러 장이 든 HEIC는 첫 장만 저장됩니다.
  • 변환 과정에서 촬영 위치·기기 정보 같은 메타데이터가 유지된다고 보장할 수 없습니다. 원본은 지우지 말고 보관하세요.
  • 손상된 파일이나 지원하지 않는 변형은 실패 표시가 뜹니다.

자주 묻는 질문

아예 아이폰이 JPG로 찍게 할 수는 없나요?
아이폰의 설정 → 카메라 → 포맷에서 ‘높은 호환성’을 고르면 이후 사진은 JPG로 저장됩니다.
라이브 포토의 움직임도 변환되나요?
아니요. 정지 사진 한 장만 JPG·PNG로 만들어집니다.
