스크린샷 꾸미기

밋밋한 스크린샷에 배경 여백·둥근 모서리·그림자를 더해 발표나 SNS에 어울리는 이미지로 만듭니다.

📖
사용 방법
  1. 스크린샷을 끌어다 놓거나 클릭해 올립니다
  2. 배경·여백·모서리·그림자를 조절합니다
  3. 'PNG 다운로드'로 저장합니다
🎀
스크린샷을 끌어다 놓거나 클릭
JPG · PNG · WebP
여백은 원본 너비 기준 비율로 적용됩니다. 그림자와 둥근 모서리로 입체감을 줍니다. 모든 처리는 브라우저에서만 이루어지며 이미지는 서버로 전송되지 않습니다.

스크린샷 꾸미기 사용 안내

무엇을 하는 도구인가

스크린샷 둘레에 색 배경 여백을 두르고, 이미지 모서리를 둥글게 깎고, 아래로 떨어지는 그림자를 넣어 한 장의 PNG로 만들어 줍니다. 배경은 미리 준비된 8가지 색 조합 중에서 고르며, 대각선 그라데이션이나 조합의 첫 번째 색 단색으로 칠할 수 있습니다. 원본 해상도를 그대로 살려 그리므로 글자가 흐려지지 않고, 처리는 브라우저 안에서만 이루어집니다.

언제 쓰나

  • 서비스 화면 캡처를 발표 슬라이드에 넣을 때 밋밋한 사각형보다 정돈돼 보이게 하고 싶을 때
  • SNS나 블로그에 앱 업데이트 소식을 올리며 대표 이미지가 필요할 때
  • 흰 바탕 캡처가 흰 문서 배경에 묻혀 경계가 안 보일 때
  • 코드 편집기 화면을 캡처해 기술 블로그 본문에 넣을 때

사용 방법

  1. 점선 영역에 스크린샷을 끌어다 놓거나 클릭해서 고릅니다.
  2. 색 견본 중 하나를 누르고, 「배경 종류」에서 그라데이션 또는 단색을 고릅니다.
  3. 「여백」(0~25%, 기본 8%), 「모서리 둥글기」(0~12%, 기본 2%), 「그림자」(0~80, 기본 30)를 조절합니다.
  4. 「PNG 다운로드」로 framed.png를 저장합니다.

결과 해석

여백과 모서리 둥글기는 모두 원본 가로 폭에 대한 비율입니다. 1920×1080 캡처에 여백 8%를 주면 사방에 약 154px씩 붙어 결과는 2228×1388이 됩니다. 세로로 긴 휴대폰 캡처도 가로 폭 기준으로 여백이 정해지므로 위아래 여백이 상대적으로 얇아 보일 수 있습니다. 그림자 값을 올리면 그림자가 더 진하고 넓게 퍼지며 아래쪽으로 더 내려갑니다.

주의할 점

  • 여백을 0이나 아주 작게 두면 그림자가 그릴 공간이 없어 잘려 보입니다. 그림자를 쓰려면 여백을 어느 정도 남기세요.
  • 결과는 원본보다 가로·세로가 커지므로 용량도 늘어납니다. 웹에 올리기 전에 이미지 압축 도구로 줄이는 것을 권합니다.
  • 캡처 화면에 이름, 연락처, 내부 주소가 보이지 않는지 꾸미기 전에 먼저 확인하세요. 이 도구에는 가리기 기능이 없습니다.

자주 묻는 질문

원하는 색으로 배경을 지정할 수 있나요?
지금은 준비된 8가지 색 조합만 쓸 수 있습니다. 흰색 계열과 어두운 남색 계열도 포함되어 있어 대부분의 문서 배경에 맞출 수 있습니다.
배경을 투명하게 저장할 수 있나요?
배경은 항상 색으로 채워집니다. 투명 여백이 필요하면 이 도구 대신 원본을 그대로 쓰세요.
