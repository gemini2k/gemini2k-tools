이미지를 끌어다 놓거나 클릭

    
밝기를 글자 농도로 변환합니다. 너비가 클수록 정교하지만 무거워집니다. 어두운 배경이면 '반전'을 켜 보세요. 모든 처리는 브라우저에서만 이루어집니다.

  

  

    
이미지 ASCII 아트 사용 안내

    
무엇을 하는 도구인가

    
사진을 작은 격자로 줄인 뒤 칸마다 밝기를 구하고, 그 밝기에 해당하는 글자를 골라 텍스트 그림(ASCII 아트)으로 바꿉니다. 밝기는 R×0.3 + G×0.59 + B×0.11로 계산하고, 글자는 공백부터 . : - = + * # % @까지 열 단계로 나눠 씁니다. 결과는 그냥 텍스트라 복사해서 메모장, 코드 주석, 채팅창에 붙일 수 있습니다. 처리는 브라우저 안에서만 이루어집니다.

    
언제 쓰나

    
    
      
  • 프로그램 실행 화면이나 README 맨 위에 넣을 텍스트 로고를 만들 때
    • 
      
  • 코드 주석이나 터미널 출력에 재미 삼아 그림을 넣고 싶을 때
    • 
      
  • 이미지 첨부가 안 되는 게시판이나 메일에 간단한 그림을 보낼 때
    • 
      
  • 컴퓨터 그래픽 수업에서 밝기를 문자 농도로 바꾸는 원리를 보여 줄 때
    • 
    

    
사용 방법

    
    
      
  1. 점선 영역에 이미지를 끌어다 놓거나 클릭해서 고릅니다.
    2. 
      
  2. 「너비」 슬라이더로 한 줄의 글자 수를 40~160 사이에서 정합니다(기본 100).
    3. 
      
  3. 결과가 음화처럼 보이면 「반전」을 켭니다.
    4. 
      
  4. 「복사」를 눌러 텍스트를 클립보드에 담고 원하는 곳에 붙여 넣습니다.
    5. 
    

    
결과 해석

    
이 도구는 밝은 칸일수록 @, % 같은 꽉 찬 글자를, 어두운 칸일수록 공백을 넣습니다. 그래서 흰 바탕에 검은 글씨로 볼 때는 명암이 뒤집힌 듯 보이고, 「반전」을 켜야 밝은 곳이 비고 어두운 곳이 채워져 원본과 같은 느낌이 됩니다. 검은 바탕 터미널에 붙일 생각이라면 반전을 끈 상태가 맞습니다. 줄 수는 글자의 세로가 가로보다 길다는 점을 고려해 너비 × 세로/가로 비율 × 0.5로 정해지므로, 가로 1000·세로 800 사진을 너비 100으로 바꾸면 40줄이 나옵니다.

    
주의할 점

    
    
      
  • 고정폭 글꼴에서만 모양이 유지됩니다. 일반 문서나 메신저처럼 글자 폭이 제각각인 곳에 붙이면 형태가 무너집니다.
    • 
      
  • 배경과 피사체의 밝기 차이가 뚜렷한 사진일수록 결과가 알아보기 쉽습니다. 어둡고 복잡한 사진은 미리 대비를 높여 두면 낫습니다.
    • 
      
  • 색 정보는 쓰지 않습니다. 결과는 흑백 텍스트입니다.
    • 
    

    
자주 묻는 질문

    

      
결과를 이미지 파일로 받을 수 있나요?

      
텍스트 복사만 지원합니다. 이미지가 필요하면 결과 화면을 캡처하세요.

화면에는 6px 글꼴로 표시해 전체 모양을 보기 쉽게 했습니다. 복사한 텍스트는 붙여 넣는 곳의 글꼴 크기로 보입니다.
