GIF 만들기 (움짤)

이미지 여러 장을 순서대로 합쳐 움직이는 GIF를 만듭니다.

🎬

2장 이상
⬇️ GIF 저장
오픈소스 gif.js(MIT, jnordberg/gif.js)를 자체 호스팅(웹워커 포함)합니다. 이미지는 가운데 맞춤으로 배치됩니다. 모든 처리는 브라우저에서만 이루어집니다.

GIF 만들기 사용 안내

무엇을 하는 도구인가

여러 장의 정지 이미지를 한 프레임씩 이어 붙여 반복 재생되는 GIF 애니메이션을 만듭니다. 인코딩은 오픈소스 gif.js가 웹 워커 두 개로 나눠 처리하므로 페이지가 멈추지 않고 진행률이 표시됩니다. 모든 프레임은 같은 크기의 흰 바탕 캔버스에 가운데 맞춤으로 그려지며, 사진 파일은 서버로 올라가지 않습니다.

언제 쓰나

  • 프로그램 사용 순서를 화면 캡처 몇 장으로 보여 주는 짧은 안내 이미지를 만들 때
  • 제품 사진을 여러 각도로 돌려 보이는 상세페이지용 움짤이 필요할 때
  • 디자인 시안 A·B·C를 번갈아 보여 주며 비교할 때
  • 연속 촬영한 사진으로 간단한 스톱모션을 만들 때

사용 방법

  1. 점선 영역에 이미지를 여러 장 끌어다 놓거나 클릭해 고릅니다. 2장 이상이어야 설정 칸이 나타납니다.
  2. 미리보기 썸네일의 번호가 재생 순서입니다. 빼고 싶은 장은 오른쪽 위 ✕로 지웁니다.
  3. 「프레임 간격(ms)」(기본 400)과 「가로(px)」(60~800, 기본 320)를 정합니다.
  4. 「GIF 만들기」를 누르고 진행률이 끝나면 결과를 확인한 뒤 「GIF 저장」으로 animation.gif를 받습니다.

결과 해석

세로 길이는 올린 이미지 중 가장 세로로 긴 비율에 맞춰 정해집니다. 예를 들어 가로 320에 1000×500 사진과 600×800 사진을 섞으면 높이는 320 × 800/600 ≈ 427px이 되고, 가로로 긴 사진은 위아래에 흰 여백이 생깁니다. 프레임 간격 400ms면 1초에 2.5장이 넘어가는 속도입니다. 완료 메시지에 파일 크기(KB)가 나오므로, 용량 제한이 있는 곳에 올릴 때는 가로 폭을 줄이거나 장수를 줄여 다시 만드세요.

주의할 점

  • GIF는 한 프레임에 256색까지만 담을 수 있어 사진은 그라데이션 부분에 얼룩이 생기기 쉽습니다. 캡처 화면이나 단순한 그림에 더 잘 맞습니다.
  • 투명 배경은 유지되지 않고 흰색으로 채워집니다.
  • 여러 장을 한꺼번에 올리면 파일 선택 창(또는 끌어다 놓은 목록)이 넘겨준 순서대로 붙습니다. 이 순서는 운영체제에 따라 이름순일 수 있으니, 원하는 순서가 따로 있다면 파일 이름 앞에 번호를 붙이거나 한 장씩 차례로 추가하세요.
  • 프레임별 간격을 다르게 하거나 순서를 끌어서 바꾸는 기능은 없습니다.
