이미지 압축·리사이즈

용량을 줄이고 크기·포맷을 바꿉니다. 업로드 없이 브라우저에서만 처리됩니다.

이미지 압축·리사이즈 사용 안내

무엇을 하는 도구인가

사진 한 장을 브라우저 캔버스에 다시 그려 가로 폭을 줄이고, JPG·WebP·PNG 중 원하는 형식으로 새로 저장해 용량을 줄입니다. 가로 폭을 줄이면 세로는 원래 비율대로 따라 줄고, JPG와 WebP는 품질 값(10~100)으로 압축 정도를 정합니다. 설정을 바꿀 때마다 결과 크기와 원본 대비 절감률이 바로 다시 계산됩니다. 파일은 서버로 올라가지 않습니다.

언제 쓰나

  • 민원·채용 사이트처럼 첨부 용량 제한이 있는 곳에 휴대폰 사진을 올려야 할 때
  • 블로그나 쇼핑몰 상세페이지 이미지를 가볍게 만들어 로딩을 빠르게 할 때
  • 메일로 사진을 여러 장 보내기 전에 크기를 줄일 때
  • PNG 스크린샷을 웹용 WebP나 JPG로 바꿀 때

사용 방법

  1. 「이미지 선택 (JPG·PNG·WebP)」에서 파일을 고르면 원본 해상도와 용량이 표시됩니다.
  2. 「최대 가로 폭」 슬라이더로 결과 폭을 정합니다. 처음에는 원본 폭(최대 4000px)으로 맞춰지고, 원본보다 크게 늘릴 수는 없습니다.
  3. 「출력 포맷」에서 JPG, WebP, PNG 중 하나를 고르고, JPG·WebP라면 「품질」(기본 80)을 조절합니다.
  4. 미리보기와 결과 용량을 확인한 뒤 「다운로드」를 누르면 원래이름_min.jpg 같은 이름으로 저장됩니다.

결과 해석

예를 들어 4000×3000 휴대폰 사진을 가로 1280으로 줄이면 1280×960이 되어 픽셀 수가 약 10분의 1로 줄고, JPG 품질 80이면 용량도 크게 떨어집니다. 결과 줄에 “몇 % 절감”이 함께 나오며, 오히려 커졌을 때는 이 표시가 나타나지 않습니다. 이미 잘 압축된 JPG를 PNG로 바꾸거나 품질을 100으로 올리면 원본보다 커질 수 있으니 결과 용량을 꼭 확인하세요. 같은 품질 숫자라도 WebP가 JPG보다 작게 나오는 경우가 많습니다.

주의할 점

  • 투명 배경이 있는 PNG를 JPG로 바꾸면 투명한 부분이 검게 채워집니다. 투명을 유지하려면 PNG나 WebP를 고르세요.
  • 캔버스로 다시 저장하므로 촬영 일시, 위치(GPS) 같은 사진 정보(EXIF)는 결과 파일에 남지 않습니다. 개인정보 면에서는 장점이지만, 촬영 정보가 필요한 원본은 따로 보관하세요.
  • 한 번에 한 장씩 처리합니다. 여러 장을 연달아 처리할 때는 새 파일을 고를 때마다 폭 값이 제대로 잡혔는지 확인하세요.

자주 묻는 질문

품질은 얼마로 두는 게 좋나요?
웹 게시용이라면 70~80 사이에서 미리보기를 확대해 보고 정하는 경우가 많습니다. 글자가 많은 캡처 화면은 품질을 낮추면 글자 주변이 번지므로 PNG가 더 나을 수 있습니다.
세로 크기를 따로 정할 수는 없나요?
가로 폭만 정하고 세로는 비율에 맞춰 자동으로 정해집니다. 특정 비율로 자르려면 이미지 자르기 도구를 먼저 쓰세요.
