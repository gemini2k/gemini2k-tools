HTML → 이미지(PNG) 캡처

HTML·CSS로 만든 요소를 그대로 PNG 이미지로 저장합니다. 카드·배지·인용구 이미지화에 좋아요.

오픈소스 dom-to-image-more(MIT, 1904labs/dom-to-image-more)를 자체 호스팅합니다. 외부 이미지·폰트는 보안상 포함되지 않을 수 있습니다. 모든 처리는 브라우저에서만 이루어집니다.

HTML → 이미지(PNG) 캡처 사용 안내

무엇을 하는 도구인가

입력 칸에 적은 HTML·CSS 조각을 페이지 안에 실제로 그린 뒤, 그 결과를 PNG 이미지로 떠 주는 도구입니다. 캡처는 오픈소스 dom-to-image-more가 맡으며, 요소를 SVG 안에 옮겨 담아 캔버스로 다시 그리는 방식이라 화면에 보이는 모양을 거의 그대로 이미지로 얻을 수 있습니다. 코드와 이미지 모두 브라우저 안에서만 다룹니다.

언제 쓰나

  • SNS나 블로그에 올릴 인용구 카드, 공지 배너를 CSS로 빠르게 만들어 이미지로 쓸 때
  • README나 발표 자료에 넣을 배지, 라벨, 가격표 같은 작은 그래픽이 필요할 때
  • 디자인 도구 없이 그라디언트·둥근 모서리·그림자가 들어간 버튼 시안을 보여 줄 때
  • 이메일 본문처럼 HTML이 깨질 수 있는 곳에 표를 이미지로 넣어야 할 때

사용 방법

  1. 입력 칸에 HTML을 붙여 넣습니다. 스타일은 style 속성이나 <style> 태그로 함께 넣습니다. 입력을 멈추고 잠시 뒤 아래 미리보기가 갱신되며, 「미리보기」를 눌러 바로 갱신할 수도 있습니다.
  2. 「배율」에서 1, 2(기본), 3 중 하나를 고릅니다.
  3. 「PNG 저장」을 누르면 capture.png가 내려받아집니다.

결과 해석

캡처 대상은 입력한 HTML의 첫 번째 최상위 요소입니다. 예제처럼 바깥을 <div> 하나로 감싸면 그 상자 전체가 이미지가 됩니다. 최상위 요소를 두 개 나란히 쓰면 첫 번째 것만 찍히니, 여러 요소를 담으려면 바깥에 감싸는 div를 하나 두세요. 배율 2를 고르면 화면에서 360px 폭인 카드가 720px 폭 이미지로 저장되어 고해상도 화면에서도 선명합니다. 미리보기 뒤의 바둑판무늬는 투명 영역 표시로, 배경을 지정하지 않은 부분은 투명하게 저장됩니다.

주의할 점

  • 다른 사이트의 이미지나 웹폰트는 브라우저 보안 정책 때문에 빠진 채 찍힐 수 있습니다. 글꼴은 이 사이트에 이미 있는 글꼴이나 시스템 글꼴을 쓰는 편이 안정적입니다.
  • 입력한 HTML은 이 페이지 안에 그대로 그려집니다. 출처를 알 수 없는 코드를 붙여 넣지 마세요.
  • 아주 큰 요소를 배율 3으로 찍으면 브라우저 메모리 한계로 실패할 수 있습니다.

자주 묻는 질문

웹사이트 주소를 넣어 페이지 전체를 캡처할 수 있나요?
안 됩니다. 이 도구는 직접 입력한 HTML 조각만 이미지로 바꿉니다.
JPG로도 저장되나요?
PNG만 지원합니다. JPG가 필요하면 이 사이트의 이미지 변환 도구에서 형식을 바꾸세요.
