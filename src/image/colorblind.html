색각이상(색맹) 시뮬레이터

이미지가 색각이상 사용자에게 어떻게 보이는지 보여 줍니다. 웹·디자인 접근성 점검에 활용하세요.

🖼️ 이미지를 끌어다 놓거나 클릭해서 선택
유형
Brettel/Viénot 계열의 표준 변환 행렬을 사용한 근사 시뮬레이션입니다. 실제 인지는 개인차가 있어 참고용입니다. 모든 처리는 브라우저에서만 이루어지며 이미지는 업로드되지 않습니다.

색각이상 시뮬레이터 사용 안내

무엇을 하는 도구인가

올린 이미지의 각 픽셀 RGB 값에 3×3 변환 행렬을 곱해, 적색맹·녹색맹·청색맹·전색맹인 사람에게 대략 어떻게 보이는지 흉내 낸 이미지를 원본 옆에 나란히 보여 줍니다. 전색맹은 R·G·B에 0.299, 0.587, 0.114를 곱해 더하는 밝기 계산으로 흑백을 만듭니다. 이미지는 브라우저의 캔버스에서만 처리되고 서버로 올라가지 않습니다.

언제 쓰나

  • 그래프 범례를 빨강·초록으로만 구분해 놓았는데 괜찮은지 확인할 때
  • 지도, 노선도, 대시보드의 상태 색(정상·경고·위험)이 서로 구별되는지 점검할 때
  • 웹 접근성 검토 보고서에 전후 비교 화면을 넣을 때
  • 디자인 시안 단계에서 팀원에게 색 대비 문제를 설명할 때

사용 방법

  1. 점선 영역에 이미지를 끌어다 놓거나 클릭해서 파일을 고릅니다. 화면 캡처 이미지도 됩니다.
  2. 「유형」에서 적색맹, 녹색맹(기본), 청색맹, 전색맹 중 하나를 고르면 오른쪽 결과가 바로 바뀝니다.
  3. 보고서에 쓸 이미지는 「결과 저장」으로 colorblind.png를 받습니다.

결과 해석

녹색맹 변환에서는 순수한 빨강(255, 0, 0)이 약 (159, 179, 0)의 탁한 황록색으로, 순수한 초록(0, 255, 0)이 약 (96, 77, 77)의 어두운 회갈색으로 바뀝니다. 원본에서 빨강과 초록으로 나눈 두 계열이 결과에서 비슷한 색으로 뭉쳐 보이면 색만으로 정보를 전달하고 있다는 뜻입니다. 이때는 선 모양, 무늬, 아이콘, 글자 표시를 함께 써서 색 없이도 구분되게 고치는 것이 일반적인 해법입니다.

주의할 점

  • 단순화한 근사 변환입니다. 실제 색각이상은 정도가 사람마다 다르고 약한 이상(색약)이 더 흔하므로, 결과는 “이렇게 보일 수도 있다”는 점검용으로 쓰세요.
  • 가로가 520픽셀보다 큰 이미지는 비율을 유지한 채 520픽셀로 줄여 처리하며, 저장 파일도 그 크기입니다.
  • 모니터 색 설정이나 야간 모드가 켜져 있으면 비교가 부정확해질 수 있습니다.

자주 묻는 질문

색약 정도(약하게)는 시뮬레이션할 수 없나요?
이 도구는 해당 원추세포 기능이 완전히 없는 경우를 가정한 네 가지 유형만 제공합니다.
웹 페이지 전체를 검사할 수 있나요?
페이지를 화면 캡처한 뒤 그 이미지를 올리면 됩니다. 주소를 넣어 바로 검사하는 기능은 없습니다.
