PDF 쪼개기·페이지 추출 사용 안내

무엇을 하는 도구인가

PDF 한 개에서 지정한 페이지들만 골라 새 PDF 한 개로 만듭니다. 처리에는 오픈소스 pdf-lib을 쓰며, 페이지를 그대로 복사하므로 글자 선택과 화질이 원본과 같습니다. 페이지는 「1-3, 5, 8-10」처럼 쉼표로 나눈 번호와 범위로 지정합니다.

언제 쓰나

  • 수십 쪽짜리 계약서에서 서명 페이지만 따로 떼어 보낼 때
  • 통합 보고서 PDF에서 우리 부서 담당 장만 추출해 검토 요청할 때
  • 스캔 묶음에서 특정 증빙 페이지만 골라 정산 시스템에 올릴 때
  • 교재 PDF에서 이번 주 진도 부분만 잘라 공유할 때

사용 방법

  1. 「PDF 파일 선택」에서 파일을 고르면 「총 n 페이지」가 표시되고, 입력칸에 1-전체쪽수가 미리 채워집니다.
  2. 「추출할 페이지」에 원하는 번호를 씁니다. 예: 1-3, 5, 8-10
  3. 「✂️ 페이지 추출」을 누르면 「추출 완료 — 페이지 수 · 용량」이 나옵니다. 「전체 선택」은 입력을 1-전체쪽수로 되돌립니다.
  4. 파일 이름(기본 extracted_날짜_시각)을 확인하고 「⬇️ 다운로드」를 누릅니다.

결과 해석

결과 페이지 순서는 입력한 순서를 그대로 따릅니다. 5, 1-2라고 쓰면 5, 1, 2쪽 순서가 되고, 1, 1처럼 같은 번호를 두 번 쓰면 그 페이지가 두 번 들어갑니다. 범위를 10-8처럼 거꾸로 써도 8, 9, 10쪽 오름차순으로 들어갑니다. 전체 쪽수를 넘는 번호나 숫자가 아닌 글자가 섞이면 「페이지 범위가 올바르지 않습니다」가 나오고 아무것도 만들지 않습니다.

주의할 점

  • 한 번 실행에 결과 파일은 한 개입니다. 10쪽씩 여러 파일로 나누려면 범위를 바꿔 가며 여러 번 추출하세요.
  • 추출한 페이지가 몇 쪽 안 되어도 원본 글꼴·이미지가 함께 들어가 용량이 생각보다 크게 나올 수 있습니다.
  • 암호가 걸린 PDF는 결과가 비정상일 수 있으니 열어서 확인하세요. 책갈피와 쪽 번호 표시 설정은 옮겨지지 않습니다.

자주 묻는 질문

특정 페이지를 빼고 나머지를 남기려면?
남길 범위를 적으면 됩니다. 10쪽 중 4쪽만 빼려면 1-3, 5-10을 입력하세요. 페이지 정리 도구에서 삭제 표시로 처리해도 됩니다.
페이지 번호는 문서에 인쇄된 쪽 번호인가요?
아닙니다. 표지를 포함해 파일의 첫 장을 1로 세는 실제 순번입니다.
