PDF 페이지 정리

PDF 페이지를 회전하거나 삭제하고, 순서를 바꿔 새 PDF로 저장합니다.

📄 PDF 파일을 끌어다 놓거나 클릭해서 선택
오픈소스 pdf-lib(MIT, Hopding/pdf-lib)를 자체 호스팅합니다. 미리보기는 페이지 번호로 표시되며, 모든 처리는 브라우저에서만 이루어집니다.

PDF 페이지 정리 사용 안내

무엇을 하는 도구인가

PDF 한 개를 불러와 페이지별로 회전, 삭제, 순서 이동을 지정한 뒤 새 PDF로 저장합니다. 처리에는 오픈소스 pdf-lib을 씁니다. 페이지 내용을 다시 그리지 않고 원래 페이지를 그대로 복사하므로 글자와 화질은 바뀌지 않습니다. 화면에는 페이지 그림 대신 원래 페이지 번호가 적힌 상자가 나오고, 상자 아래에 새 순서상 몇 번째인지가 표시됩니다.

언제 쓰나

  • 스캔하면서 거꾸로 들어간 페이지나 가로로 누운 표 페이지를 바로 세울 때
  • 보고서 PDF에서 빈 페이지나 내부 검토용 메모 페이지를 빼고 외부에 보낼 때
  • 붙임 문서 순서가 바뀌어 스캔된 것을 원래 순서로 바로잡을 때

사용 방법

  1. 점선 영역에 PDF를 끌어다 놓거나 클릭해 고릅니다. 파일명과 전체 쪽수가 표시됩니다.
  2. 각 상자의 ⟲ ⟳로 왼쪽·오른쪽 90도 회전, ← →로 앞뒤 이동을 합니다.
  3. 🗑를 누르면 삭제 표시가 되고, 같은 자리의 「복원」으로 되살릴 수 있습니다.
  4. 「💾 새 PDF로 저장」을 누르면 edited.pdf가 내려받아집니다.

결과 해석

예를 들어 5쪽 PDF에서 2쪽을 삭제하고 5쪽을 ←로 맨 앞까지 옮기면 결과는 원래 5, 1, 3, 4쪽 순서의 4쪽짜리 PDF입니다. 상자 안 큰 숫자가 원래 쪽 번호, 아래 「n번째」가 새 순서이므로 저장 전에 둘을 맞춰 보면 됩니다. 회전은 원본에 이미 들어 있던 회전 값에 더해지므로, 원래 90도로 표시되던 페이지에 ⟳를 한 번 누르면 180도가 됩니다.

주의할 점

  • 미리보기 그림이 없으므로 어느 쪽이 거꾸로인지는 PDF 뷰어로 원본을 열어 놓고 번호로 대조해야 합니다.
  • 모든 페이지를 삭제 표시하면 저장되지 않습니다. 최소 한 쪽은 남겨야 합니다.
  • 암호가 걸린 PDF는 저장 결과가 비정상일 수 있으니 결과를 꼭 열어 확인하세요. 원본의 책갈피는 결과에 옮겨지지 않습니다.

자주 묻는 질문

원본 파일이 바뀌나요?
아닙니다. 원본은 그대로 두고 edited.pdf라는 새 파일을 내려받습니다.
여러 PDF의 페이지를 섞을 수 있나요?
한 번에 한 파일만 다룹니다. PDF 합치기로 먼저 하나로 만든 뒤 여기서 순서를 정리하세요.
