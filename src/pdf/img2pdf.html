여러 이미지를 원하는 순서로 한 개의 PDF로 만듭니다.

    .pdf

    이미지 → PDF 변환 사용 안내

    무엇을 하는 도구인가

    여러 장의 이미지를 한 페이지에 한 장씩 넣어 PDF 하나로 묶습니다. PDF 생성에는 오픈소스 pdf-lib을 씁니다. 모든 이미지는 먼저 캔버스에서 JPEG(품질 92%)로 다시 인코딩된 뒤 들어가며, 투명한 부분은 흰색으로 채워집니다. 페이지 크기는 A4 맞춤과 이미지 원본 크기 중에서 고릅니다.

    언제 쓰나

    • 휴대폰으로 찍은 영수증·증빙 사진 여러 장을 하나의 PDF로 만들어 경비 정산에 첨부할 때
    • 스캔 앱 없이 찍은 계약서·신청서 사진을 페이지 순서대로 묶어 제출할 때
    • 화면 캡처 여러 장을 매뉴얼이나 보고 자료 하나로 정리해 전달할 때
    • 온라인 접수처가 PDF 한 개만 받는데 첨부할 자료가 사진 여러 장일 때

    사용 방법

    1. 「이미지 선택」에서 JPG·PNG·WebP 파일을 여러 장 고릅니다. 다시 고르면 목록 뒤에 추가됩니다.
    2. 목록의 ↑ ↓로 페이지 순서를 맞추고, ✕로 뺄 이미지를 지웁니다.
    3. 「페이지 크기」에서 「A4 (이미지를 가운데 맞춤)」 또는 「이미지 원본 크기」를 고릅니다.
    4. 「📄 PDF 만들기」를 누른 뒤, 파일 이름을 확인하고 「⬇️ 다운로드」를 누릅니다. 기본 이름은 images_날짜_시각입니다.

    결과 해석

    A4 모드에서는 가로가 더 긴 이미지는 가로 A4, 세로가 긴 이미지는 세로 A4 페이지에 놓입니다. 비율을 유지한 채 페이지에 꽉 차도록 확대·축소하고 가운데 정렬하므로 여백은 남는 한쪽 방향에만 생깁니다. 원본 크기 모드에서는 이미지 1px이 PDF의 1pt(1/72인치)가 됩니다. 예를 들어 3024×4032px 사진은 약 106.7×142.2cm 페이지가 되어 화면에서는 문제없지만 그대로 인쇄하기는 어렵습니다. 인쇄할 자료라면 A4를 고르세요.

    주의할 점

    • A4 모드는 여백 없이 페이지 끝까지 채우므로 프린터에 따라 가장자리가 잘릴 수 있습니다.
    • 글자가 많은 PNG 캡처도 JPEG로 바뀌어 글자 주변이 약간 번질 수 있고, 결과 PDF의 글자는 선택·검색되지 않는 이미지입니다.
    • 브라우저가 열지 못하는 형식(일부 환경의 HEIC 등)은 변환 중 오류가 납니다. 먼저 JPG로 바꿔 올리세요.

    자주 묻는 질문

    한 페이지에 사진 두 장을 넣을 수 있나요?
    이 도구는 한 페이지에 한 장만 넣습니다. 이미지 이어붙이기로 먼저 합친 뒤 변환하면 됩니다.
    PDF 용량이 너무 커요.
    원본 해상도 그대로 들어가기 때문입니다. 이미지를 미리 줄이거나, 만든 PDF를 PDF 압축 도구로 한 번 더 줄이세요.
