    모든 처리는 브라우저에서 이루어지며, 파일은 서버로 전송되지 않습니다.

    .pdf

    PDF 합치기 사용 안내

    무엇을 하는 도구인가

    여러 PDF 파일의 모든 페이지를 목록 순서대로 복사해 새 PDF 하나로 만듭니다. 처리에는 오픈소스 pdf-lib을 쓰며, 페이지를 이미지로 바꾸지 않고 원래 내용 그대로 옮기므로 글자 선택·검색과 화질이 유지됩니다. 파일마다 페이지 크기가 달라도 각자의 크기를 그대로 둡니다.

    언제 쓰나

    • 공문 본문 PDF와 붙임 문서 여러 개를 하나로 묶어 시스템에 한 번에 올릴 때
    • 입찰·지원 서류처럼 「PDF 1개로 제출」 조건이 붙은 서류를 준비할 때
    • 월별로 받은 거래명세서·청구서 PDF를 분기 단위로 모아 보관할 때
    • 스캔을 여러 번 나눠 받은 문서를 원래 쪽 순서대로 다시 붙일 때

    사용 방법

    1. 「PDF 파일 선택」에서 파일을 여러 개 고릅니다. 다시 고르면 목록 뒤에 추가됩니다.
    2. 목록의 ↑ ↓로 합칠 순서를 정하고, ✕로 빠뜨릴 파일을 지웁니다. 파일이 2개 이상이어야 버튼이 켜집니다.
    3. 「📎 PDF 합치기」를 누르면 「합치기 완료 — 페이지 수 · 용량」이 표시됩니다.
    4. 파일 이름(기본 merged_날짜_시각)을 확인하고 「⬇️ 다운로드」를 누릅니다.

    결과 해석

    3쪽, 5쪽, 2쪽짜리 파일을 합치면 결과는 10쪽이고 페이지 순서는 목록 순서를 그대로 따릅니다. 결과 용량은 대체로 원본들의 합과 비슷합니다. 여러 파일에 같은 글꼴이 들어 있어도 각자 따로 들어가므로 합계보다 크게 줄지는 않습니다.

    주의할 점

    • 열기 암호나 편집 제한이 걸린 PDF는 오류가 나거나 페이지가 비정상적으로 나올 수 있습니다. 결과를 반드시 열어 확인하고, 문제가 있으면 원본 프로그램에서 보안을 해제한 뒤 다시 합치세요.
    • 원본의 책갈피(목차)는 결과에 옮겨지지 않습니다. 입력 양식(폼) 필드가 있는 PDF는 합친 뒤 입력이 제대로 되지 않을 수 있습니다.
    • 전자서명이 들어간 PDF는 합치는 순간 서명 검증이 깨집니다. 서명본은 원본 그대로 따로 제출하세요.

    자주 묻는 질문

    특정 페이지만 골라 합칠 수 있나요?
    이 도구는 파일 전체를 합칩니다. 필요한 페이지만 PDF 쪼개기로 먼저 추출한 뒤 합치세요.
    합친 뒤 페이지를 회전하거나 지우고 싶어요.
    PDF 페이지 정리 도구에 결과 파일을 올려 회전·삭제·순서 변경을 하면 됩니다.
