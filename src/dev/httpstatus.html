HTTP 상태 코드 사전

HTTP 상태 코드의 의미를 한국어 설명과 함께 검색합니다.

클릭하면 코드가 복사됩니다. 자주 쓰이는 표준 상태 코드를 정리했습니다. 모든 처리는 브라우저에서만 이루어집니다.

HTTP 상태 코드 사전 사용 안내

무엇을 하는 도구인가

웹 서버가 응답 첫 줄에 돌려주는 세 자리 상태 코드 가운데 실무에서 자주 마주치는 32개를 한국어 설명과 함께 모아 둔 사전입니다. 첫 자리로 1xx 정보, 2xx 성공, 3xx 리다이렉트, 4xx 클라이언트 오류, 5xx 서버 오류로 나뉘며, 코드 번호·영문 이름·한국어 설명 어디에 걸리든 검색됩니다.

언제 쓰나

  • 브라우저 개발자 도구나 nginx 접근 로그에 찍힌 코드가 무슨 뜻인지 바로 확인할 때
  • REST API를 설계하면서 생성은 201, 검증 실패는 400과 422 중 무엇을 줄지 정할 때
  • 모니터링 알림의 502·503·504가 각각 어느 구간 문제인지 장애 대응 중에 구분할 때

사용 방법

  1. 검색 칸에 코드(예: 404), 영문 이름(예: redirect), 한국어 단어(예: 권한)를 입력합니다.
  2. 오른쪽 분류 목록에서 2xx 성공처럼 범위를 좁힐 수 있습니다.
  3. 항목을 클릭하면 코드 번호가 클립보드에 복사됩니다.

결과 해석

"권한"으로 검색하면 403 Forbidden이 나옵니다. 401은 "인증 필요", 403은 "인증은 됐으나 접근이 금지됨"으로 구분되는데, 로그인 토큰이 없거나 만료됐다면 401, 로그인은 됐지만 그 자원에 대한 권한이 없으면 403이 맞습니다. 리다이렉트도 302는 임시 이동, 307·308은 POST 같은 원래 메서드를 유지한 채 이동한다는 차이가 있습니다. 5xx 중 502는 프록시가 뒤쪽 서버에서 잘못된 응답을 받은 경우, 504는 뒤쪽 서버가 제때 응답하지 않은 경우라서, nginx 앞단 장애인지 애플리케이션 지연인지 가르는 단서가 됩니다.

주의할 점

목록은 자주 쓰는 코드만 추린 것이라 303 See Other, 412 Precondition Failed, 451 같은 표준 코드와 nginx의 499, Cloudflare의 52x 같은 비표준 코드는 들어 있지 않습니다. 설명은 일반적인 의미이고, 실제로는 서비스마다 같은 상황에 다른 코드를 쓰기도 하니 API 문서를 함께 보세요.

자주 묻는 질문

418 I'm a teapot은 실제로 쓰이나요?
만우절 농담으로 만들어진 코드라 정식 의미는 없습니다. 일부 서비스가 봇 차단 응답 등에 장난스럽게 쓰는 정도입니다.
404와 410은 어떻게 다른가요?
404는 지금 찾을 수 없다는 뜻이고, 410은 의도적으로 영구 삭제했다는 뜻이라 검색엔진이 색인에서 더 빨리 뺄 수 있습니다.
