CSS 이징 곡선 생성기

제어점을 드래그해 cubic-bezier 이징을 만들고, 실제 움직임을 확인하세요.

곡선 위·아래의 두 제어점을 드래그하세요. 결과를 transition-timing-function이나 animation-timing-function에 사용하세요. 모든 처리는 브라우저에서만 이루어집니다.

CSS 이징 곡선 생성기 사용 안내

무엇을 하는 도구인가

CSS의 cubic-bezier(x1, y1, x2, y2) 이징 함수를 그래프 위 두 제어점을 끌어서 만듭니다. 가로축은 시간 진행, 세로축은 움직임 진행을 뜻하며, 결과는 transition-timing-function: cubic-bezier(...); 한 줄로 바로 나옵니다. 「미리보기 재생」을 누르면 공이 1.2초 동안 그 곡선대로 움직여 실제 느낌을 볼 수 있습니다.

언제 쓰나

  • 버튼·모달·드로어 애니메이션이 기본 ease보다 더 경쾌하거나 부드럽게 보이도록 다듬을 때
  • 디자이너가 말한 「끝에서 살짝 튕기는 느낌」을 코드 값으로 옮길 때
  • 디자인 시스템의 모션 토큰(진입·퇴장 곡선)을 정할 때
  • ease-in과 ease-out의 차이를 팀원에게 눈으로 보여 줄 때

사용 방법

  1. 위쪽 프리셋(ease, linear, ease-in, ease-out, ease-in-out, bounce) 중 하나로 시작합니다.
  2. 그래프의 두 점을 끌어 곡선을 조정합니다. 누른 위치에서 더 가까운 점이 움직입니다.
  3. 「미리보기 재생」으로 움직임을 확인하고, 마음에 들면 「복사」를 누릅니다.

결과 해석

기본값은 CSS 키워드 ease와 같은 cubic-bezier(0.25, 0.10, 0.25, 1.00)입니다. 곡선이 처음에 가파르면 빨리 출발하고, 끝에서 평평해지면 천천히 멈춥니다. bounce 프리셋 cubic-bezier(0.68, -0.55, 0.27, 1.55)처럼 y 값이 0보다 작거나 1보다 크면 움직임이 시작점 뒤로 살짝 물러났다가 목표를 지나쳐 되돌아오는 효과가 납니다.

주의할 점

  • CSS 규칙상 x 값은 0~1 범위여야 하므로 가로 방향은 그 안으로 제한됩니다. y 값은 범위 제한이 없습니다.
  • 값은 소수 둘째 자리로 반올림해 표시하고 복사합니다.
  • 복사되는 줄은 transition-timing-function 속성입니다. 키프레임 애니메이션에 쓸 때는 속성 이름을 animation-timing-function으로 바꾸세요.
  • 움직임에 민감한 사용자를 위해 prefers-reduced-motion 설정에서는 과한 튕김 효과를 줄이는 것이 좋습니다.

자주 묻는 질문

스프링처럼 여러 번 튕기는 효과도 만들 수 있나요?
cubic-bezier는 제어점이 두 개뿐이라 한 번 넘쳤다 돌아오는 정도까지만 표현됩니다. 여러 번 튕기려면 키프레임을 나누거나 linear() 이징 함수를 검토하세요.
재생 시간도 바꿀 수 있나요?
미리보기는 1.2초로 고정입니다. 실제 시간은 CSS의 transition-duration에서 정합니다.
