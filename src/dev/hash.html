해시 생성기

텍스트나 파일의 MD5 · SHA-1 · SHA-256 · SHA-512 해시값을 만듭니다. 파일이 변조되지 않았는지 체크섬 확인에 쓰세요.

📄
파일을 끌어다 놓거나 클릭해서 선택
파일 무결성·체크섬 확인에 SHA-256을 주로 씁니다. MD5·SHA-1은 충돌 위험이 있어 보안 용도(비밀번호 저장 등)에는 권장하지 않습니다. 모든 해시는 브라우저에서만 계산되며 입력·파일은 서버로 전송되지 않습니다.

해시 생성기 사용 안내

무엇을 하는 도구인가

입력한 텍스트를 UTF-8 바이트로 바꿔 MD5, SHA-1, SHA-256, SHA-512 해시를 16진수로 계산합니다. SHA 계열은 브라우저 내장 Web Crypto API로, MD5는 페이지에 포함된 자바스크립트 구현으로 계산합니다. 파일 탭에서도 선택한 파일의 바이트 전체로 MD5, SHA-1, SHA-256, SHA-512를 모두 계산합니다.

언제 쓰나

  • 내려받은 ISO나 설치 파일의 SHA-256을 배포처에 공개된 체크섬과 맞춰 볼 때
  • API 문서에 나온 예제 해시값과 내 구현 결과가 같은지 확인할 때
  • 캐시 키나 중복 판별용으로 쓰는 문자열 해시가 서버 계산과 일치하는지 볼 때

사용 방법

  1. '텍스트' 탭에서 입력 칸에 글을 넣으면 네 가지 해시가 바로 나옵니다.
  2. 파일은 '파일' 탭으로 옮겨 상자를 클릭하거나 파일을 끌어다 놓습니다.
  3. 각 결과 오른쪽의 복사 버튼으로 값을 가져갑니다.

결과 해석

abc 세 글자의 결과는 표준 테스트 값과 같아야 합니다. MD5는 900150983cd24fb0d6963f7d28e17f72, SHA-1은 a9993e364706816aba3e25717850c26c9cd0d89d, SHA-256은 ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad입니다. 끝에 줄바꿈 하나만 더 들어가도 값이 완전히 달라지므로, 터미널의 echo abc | sha256sum과 비교할 때는 echo -n을 써야 같은 값이 나옵니다. 대소문자는 의미가 없으며 이 도구는 소문자로 표시합니다.

주의할 점

MD5와 SHA-1은 충돌을 만드는 공격이 알려져 있어 서명이나 위변조 방지에는 쓰지 않습니다. 비밀번호 저장에는 SHA-256도 그대로 쓰면 안 되고, bcrypt·scrypt·Argon2처럼 솔트와 반복 비용이 있는 전용 함수를 써야 합니다. 파일 전체를 메모리로 읽어 계산하므로 수 GB 파일은 브라우저가 멈출 수 있고, 특히 MD5는 자바스크립트로 계산해 큰 파일에서 SHA 계열보다 느립니다.

자주 묻는 질문

윈도우에서 파일 해시를 직접 확인하려면요?
명령 프롬프트에서 certutil -hashfile 파일명 SHA256을 실행하면 같은 값을 얻을 수 있습니다.
한글 텍스트 해시가 다른 도구와 다르게 나와요.
이 도구는 UTF-8 기준입니다. 상대 쪽이 EUC-KR이나 UTF-16으로 바이트를 만들었다면 값이 달라집니다.
