HTML·CSS·JavaScript를 보기 좋게 정렬하거나 한 줄로 압축합니다.

오픈소스 js-beautify(MIT, beautifier/js-beautify)를 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어집니다.

코드 정리·포매터 사용 안내

무엇을 하는 도구인가

CSS·JavaScript·HTML 코드를 오픈소스 js-beautify로 들여쓰기해 읽기 좋게 정렬합니다. 들여쓰기는 2칸·4칸·탭 중에서 고를 수 있습니다. 「압축(Minify)」은 공백·줄바꿈과 주석 일부를 정규식으로 지우는 간이 기능으로, 전용 압축기처럼 변수명을 줄이거나 문법을 분석하지는 않습니다.

언제 쓰나

  • 한 줄로 압축된 CSS·JS를 받아서 구조를 읽고 디버깅해야 할 때
  • CMS나 이메일 편집기에서 뽑아낸 HTML의 들여쓰기가 엉망일 때
  • 코드 리뷰나 문서에 붙일 예제 코드의 들여쓰기를 맞출 때
  • 짧은 CSS 조각을 인라인 스타일이나 설정값에 넣으려고 한 줄로 줄일 때

사용 방법

  1. 입력칸에 코드를 붙여 넣고 「언어」에서 CSS, JavaScript, HTML 중 하나를 고릅니다.
  2. 「들여쓰기」에서 2칸, 4칸, 탭 중 하나를 고릅니다.
  3. 「정렬(Beautify)」 또는 「압축(Minify)」을 누르고, 결과를 「복사」합니다. 언어나 들여쓰기를 바꾼 뒤에는 버튼을 다시 눌러야 반영됩니다.

결과 해석

CSS로 두고 .box{color:red;margin:0}를 정렬하면 선택자 뒤에 줄을 바꾸고 속성마다 한 줄씩, 콜론 뒤에 공백을 넣어 color: red;, margin: 0으로 나눕니다. 마지막 속성에 세미콜론이 없으면 정렬 후에도 붙이지 않습니다. 정렬은 공백과 줄바꿈만 바꾸므로 코드의 의미는 그대로입니다.

주의할 점

  • JavaScript 압축은 문자열 안의 공백까지 지우고("x = y" → "x=y"), 줄을 하나로 이으면서 // 한 줄 주석 뒤의 코드까지 주석으로 만들어 버립니다. 실제 배포용 압축에는 쓰지 말고 terser 같은 전용 압축기를 쓰세요.
  • CSS 압축은 콜론 앞 공백도 지우므로 div :first-child가 div:first-child로 바뀌어 선택자 의미가 달라질 수 있습니다.
  • HTML 압축은 태그 사이 공백을 모두 지워 <pre> 안의 서식이나 인라인 요소 사이 띄어쓰기가 사라질 수 있습니다.
  • 언어 선택을 코드와 다르게 두면 결과가 이상해집니다. 처음 열었을 때의 예시는 CSS와 JS가 섞여 있어 CSS 기준으로만 정리됩니다.

자주 묻는 질문

문법 오류도 찾아 주나요?
아닙니다. 정렬기는 문법을 검사하지 않으므로 오류가 있어도 가능한 만큼 들여쓰기만 합니다.
Prettier와 결과가 다른 이유는요?
도구마다 줄바꿈·따옴표 규칙이 다릅니다. 팀 프로젝트에서는 저장소에 정한 포매터 설정을 따르세요.
