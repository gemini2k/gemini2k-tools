HTML 엔티티 인코딩/디코딩

HTML 특수문자를 안전한 엔티티로 바꾸거나 되돌립니다. 코드를 글에 그대로 보여줄 때 태그가 깨지지 않게 해 줍니다.

↓
기본 인코딩은 & < > " '를 엔티티로 바꿉니다. 옵션을 켜면 한글 등 비ASCII 문자도 숫자 엔티티(&#xxxx;)로 변환합니다. 디코딩은 명명·숫자 엔티티를 모두 원래 문자로 되돌립니다. 모든 처리는 브라우저에서만 이루어집니다.

HTML 엔티티 인코딩/디코딩 사용 안내

무엇을 하는 도구인가

HTML에서 특별한 뜻을 갖는 다섯 문자 &, <, >, ", '를 각각 &amp;, &lt;, &gt;, &quot;, &#39;로 바꾸고, 반대로 엔티티를 원래 문자로 되돌립니다. 디코딩은 브라우저의 HTML 해석기를 쓰기 때문에 &nbsp;, &copy; 같은 이름 엔티티와 &#50504;, &#xC548; 같은 숫자 엔티티를 모두 처리합니다.

언제 쓰나

  • 블로그나 문서에 HTML 코드 예제를 화면에 그대로 보이게 넣어야 할 때
  • DB나 API 응답에 &lt;, &quot;처럼 이중으로 인코딩된 문자열이 섞여 원문을 확인하고 싶을 때
  • 템플릿 엔진 없이 HTML 속성값에 사용자 문자열을 넣는 코드가 어떤 결과를 내야 하는지 기대값을 만들 때

사용 방법

  1. '입력'에 텍스트를 넣습니다.
  2. [인코딩 ↓] 또는 [디코딩 ↓]를 누르면 '결과'에 나옵니다. 한글까지 숫자 엔티티로 바꾸려면 '모든 비ASCII 문자도 인코딩' 옵션을 켭니다.
  3. [⇅ 입력↔출력]으로 결과를 입력으로 옮겨 한 번 더 변환할 수 있고, [📋 복사]로 가져갑니다.

결과 해석

기본 예시 <div class="box">안녕 & 환영</div>를 인코딩하면 &lt;div class=&quot;box&quot;&gt;안녕 &amp; 환영&lt;/div&gt;가 됩니다. 옵션을 켜면 한글도 바뀌어 안녕이 &#50504;&#45397;가 됩니다. 디코딩 결과에 아직 &amp;lt; 같은 형태가 남아 있다면 두 번 인코딩된 것이니 디코딩을 한 번 더 하면 됩니다.

주의할 점

여기서 하는 인코딩은 HTML 본문과 따옴표로 감싼 속성값에 넣을 때 기준입니다. 자바스크립트 문자열, URL, CSS 안에 넣는 값은 각각 다른 이스케이프가 필요하므로 이 결과만으로 XSS가 막히지 않습니다. '모든 비ASCII 문자도 인코딩' 옵션은 이모지처럼 두 개의 UTF-16 코드 단위로 된 문자도 한 글자로 묶어 &#128512;처럼 유니코드 코드 포인트 하나짜리 엔티티로 바꿉니다.

자주 묻는 질문

디코딩하면 스크립트가 실행될 위험은 없나요?
디코딩은 화면에 붙이지 않는 textarea 요소 안에서 이루어져 태그가 실행되지 않고 문자로만 돌아옵니다.
요즘도 한글을 엔티티로 바꿔야 하나요?
페이지가 UTF-8이면 필요 없습니다. 문자 인코딩을 통제할 수 없는 오래된 시스템이나 메일 본문에 넣을 때 정도에만 씁니다.
