INI ↔ JSON 변환기

INI 설정 파일과 JSON을 서로 변환합니다.

↓
섹션 [name], key = value, 주석 ;·#을 처리합니다. true/false/숫자는 자동 인식합니다. 모든 처리는 브라우저에서만 이루어집니다.

INI ↔ JSON 변환기 사용 안내

무엇을 하는 도구인가

[섹션]과 키 = 값 줄로 이루어진 INI 설정 파일을 JSON 객체로, JSON을 다시 INI로 바꿉니다. INI → JSON에서는 ;나 #으로 시작하는 주석 줄과 빈 줄을 건너뛰고, 섹션은 한 단계 아래 객체가 되며, 첫 섹션보다 앞에 있는 키는 최상위에 놓입니다. 값이 숫자 모양이면 숫자로, true/false면 불리언으로 바꿉니다.

언제 쓰나

  • php.ini, my.cnf, setup.cfg, .gitconfig 같은 파일 내용을 코드에서 쓰기 좋게 JSON으로 볼 때
  • 레거시 프로그램의 INI 설정을 새 서비스의 JSON 설정으로 옮길 때
  • JSON으로 관리하는 값을 INI만 읽는 프로그램에 넣어야 할 때

사용 방법

  1. [INI → JSON] 또는 [JSON → INI]를 고릅니다. 방향을 바꾸면 입력 칸이 예시로 바뀌니 먼저 고른 뒤 붙여넣으세요.
  2. 입력 칸에 내용을 넣으면 결과가 바로 나옵니다. JSON 문법 오류는 빨간 문구로 표시됩니다.
  3. [📋 복사]로 결과를 가져갑니다.

결과 해석

기본 예시는 {"server": {"host": "localhost", "port": 8080, "debug": true}, "db": {"name": "mydb"}}가 됩니다. port가 문자열이 아니라 숫자 8080으로, debug가 불리언으로 바뀐 것을 확인하세요. 반대로 JSON → INI에서는 최상위 객체 값이 섹션이 되고, 배열은 쉼표로 이은 한 줄 값이 됩니다.

주의할 점

INI는 표준이 하나로 정해진 형식이 아니라 프로그램마다 문법이 조금씩 다릅니다. 이 도구는 값의 따옴표를 벗기지 않고, 값 뒤에 붙은 주석도 값으로 남기며, 여러 줄 값은 지원하지 않습니다. 숫자 변환 때문에 007은 7이 되어 앞자리 0이 사라집니다. 같은 이름의 섹션이 두 번 나오면 뒤의 섹션이 앞의 것을 통째로 덮어쓰고, JSON → INI에서 두 단계보다 깊이 중첩된 객체는 [object Object]로 출력되니 평평한 구조로 바꿔서 넣으세요.

자주 묻는 질문

[a.b] 같은 섹션은 중첩 객체가 되나요?
아니요. "a.b"라는 이름의 섹션 하나로 들어갑니다.
TOML 파일도 넣을 수 있나요?
모양이 비슷한 단순한 TOML은 읽히지만 문자열 따옴표, 배열, 날짜 같은 TOML 문법은 해석하지 않습니다.
