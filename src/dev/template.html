Handlebars 템플릿 렌더러

템플릿과 JSON 데이터를 합쳐 결과를 만듭니다. 메일 머지·반복·조건 출력에 좋아요.

오픈소스 Handlebars(MIT, handlebars-lang/handlebars.js)를 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어집니다.

Handlebars 템플릿 렌더러 사용 안내

무엇을 하는 도구인가

Handlebars 4 템플릿과 JSON 데이터를 합쳐 최종 텍스트를 만들어 보여 줍니다. {{name}} 같은 자리표시자에 값을 넣고, {{#each}}로 목록을 반복하고, {{#if}}로 조건부 문장을 넣는 식입니다. 템플릿이나 데이터를 고치고 잠시 멈추면(약 0.3초) 결과가 다시 만들어지며, JSON 문법 오류와 템플릿 오류는 구분해서 알려 줍니다.

언제 쓰나

  • 주문 확인 메일이나 알림톡 문구 템플릿을 개발 서버에 올리기 전에 미리 확인할 때
  • 사람마다 이름·금액만 다른 안내문 초안을 데이터만 바꿔 가며 만들 때
  • Handlebars·Mustache 계열 문법이 처음이라 반복·조건 동작을 익힐 때
  • API 응답 JSON을 붙여 넣어 템플릿에서 필드 경로가 맞는지 점검할 때

사용 방법

  1. 왼쪽 「템플릿 (Handlebars)」에 템플릿을 씁니다.
  2. 오른쪽 「데이터 (JSON)」에 템플릿에서 쓸 값을 JSON 객체로 넣습니다.
  3. 아래 「결과」에서 완성된 문장을 확인하고, 오류 문구가 나오면 JSON인지 템플릿인지 보고 고칩니다.
  4. 「복사」로 결과를 가져갑니다.

결과 해석

기본 예제는 「안녕하세요 홍길동님,」 다음에 - 사과 x 3, - 바나나 x 5 두 줄이 나오고, vip가 true라서 「VIP 고객 혜택이 적용되었습니다.」가 붙습니다. {{#each items}}처럼 블록 태그만 있는 줄은 Handlebars가 줄째 지우므로 빈 줄이 생기지 않습니다. 데이터에서 vip를 false로 바꾸면 그 문장이 사라집니다. 반복 안에서는 {{this.name}} 대신 {{name}}로 써도 되고, {{@index}}로 0부터 시작하는 순번을 쓸 수 있습니다.

주의할 점

  • 중괄호 두 개는 HTML 이스케이프를 합니다. 값에 &나 <가 있으면 결과에 &amp;, &lt;로 보입니다. 원문 그대로 넣으려면 중괄호 세 개 {{{name}}}를 쓰세요.
  • 데이터에 없는 이름을 쓰면 오류 없이 빈칸으로 나옵니다. 필드 이름 오타를 놓치기 쉬우니 결과를 꼭 읽어 보세요.
  • 사용자 정의 헬퍼를 등록하는 기능은 없습니다. if, unless, each, with, lookup 같은 기본 헬퍼만 쓸 수 있습니다.

자주 묻는 질문

숫자에 천 단위 쉼표를 넣을 수 있나요?
기본 헬퍼에는 서식 기능이 없습니다. 데이터 JSON에 "12,000"처럼 이미 서식을 입힌 문자열을 넣어 쓰세요.
Mustache 템플릿도 되나요?
Handlebars는 Mustache 문법을 대부분 받아들이므로 단순한 자리표시자·섹션은 그대로 동작하는 경우가 많습니다. 다만 일부 문법 차이가 있어 결과를 확인해야 합니다.
