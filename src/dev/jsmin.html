JavaScript 압축기 (minify)

자바스크립트 코드를 안전하게 압축해 용량을 줄입니다.

오픈소스 terser(BSD-2, terser/terser)를 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어집니다.

JavaScript 압축기(minify) 사용 안내

무엇을 하는 도구인가

자바스크립트 코드를 terser 5로 파싱해 공백·주석을 지우고, 쓰이지 않는 코드나 바로 계산되는 식을 정리(compress)하고, 선택하면 지역 변수 이름을 짧게 바꿔(mangle) 파일 크기를 줄입니다. 압축 후 원본과 결과의 바이트 수, 절감 비율을 함께 보여 줍니다. 코드를 실행하지는 않고 구문 분석만 합니다.

언제 쓰나

  • 빌드 도구가 없는 레거시 페이지나 사내 정적 페이지의 스크립트를 가볍게 만들 때
  • 북마클릿처럼 한 줄로 만들어야 하는 짧은 스크립트를 준비할 때
  • 번들러 설정을 바꾸기 전에 terser가 특정 코드를 어떻게 바꾸는지 확인할 때
  • 붙여넣은 코드에 문법 오류가 있는지 빠르게 확인할 때

사용 방법

  1. 입력 칸에 코드를 붙여넣고 [압축]을 누릅니다.
  2. '변수명 단축(mangle)'과 '주석 유지'를 켜고 끄면 결과가 다시 계산됩니다.
  3. 위쪽의 크기 비교를 확인하고 [📋 복사]로 결과를 가져갑니다.

결과 해석

기본 예시(209바이트)는 mangle을 켜면 function add(n,o){return n+o}const numbers=[1,2,3,4,5],total=numbers.reduce(((n,o)=>add(n,o)),0);console.log(total); 116바이트로 약 44% 줄어듭니다. 함수 안의 result 변수는 compress 단계에서 없어지고, 매개변수 이름만 짧아진 것을 볼 수 있습니다. add, numbers, total처럼 최상위에 선언된 이름은 다른 스크립트가 참조할 수 있어 그대로 둡니다. mangle을 끄면 138바이트입니다.

주의할 점

'주석 유지'를 꺼도 /*! ... */나 @license·@preserve가 붙은 라이선스 주석은 남기고 나머지 주석만 지웁니다. 켜면 일반 주석까지 모두 남습니다. 다른 사람의 라이선스 고지를 일부러 지우는 일은 없도록 하세요. 문법 오류가 있으면 오류 메시지만 나오고 결과는 비어 있습니다. TypeScript나 JSX는 먼저 자바스크립트로 변환한 뒤 넣어야 합니다. 압축 결과는 사람이 고치기 어려우므로 원본은 반드시 따로 보관하세요.

자주 묻는 질문

압축하면 코드 동작이 바뀌지 않나요?
terser는 의미를 보존하도록 변환하지만, Function.prototype.name이나 eval로 변수 이름에 의존하는 코드는 mangle 후 달라질 수 있습니다. 그런 코드가 있으면 mangle을 끄세요.
소스맵도 만들 수 있나요?
이 도구는 소스맵을 만들지 않습니다. 디버깅이 필요한 배포 파일은 빌드 도구에서 terser를 소스맵 옵션과 함께 쓰세요.
