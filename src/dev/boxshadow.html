CSS 박스 그림자 생성기

슬라이더로 그림자를 조절하면 CSS box-shadow 코드가 만들어집니다.

결과 코드를 복사해 CSS에 붙여넣으세요. 모든 처리는 브라우저에서만 이루어집니다.

CSS 박스 그림자 생성기 사용 안내

무엇을 하는 도구인가

슬라이더로 가로·세로 위치, 흐림(blur), 번짐(spread), 불투명도, 그림자 색을 조절하면 미리보기 상자에 그림자를 바로 적용하고 CSS box-shadow 선언 한 줄을 만들어 줍니다. 「내부 그림자(inset)」로 안쪽 그림자도 만들 수 있습니다. 색은 HEX로 고르고 결과는 불투명도를 반영한 rgba()로 나옵니다.

언제 쓰나

  • 카드·드롭다운·모달에 은은한 깊이감을 줄 그림자 값을 찾을 때
  • 입력창이 눌린 듯 보이게 안쪽 그림자를 줄 때
  • 디자인 시안의 그림자 수치(X, Y, Blur, Spread, 불투명도)를 CSS로 옮길 때
  • 디자인 시스템의 그림자 단계(작음·중간·큼)를 정하며 서로 비교할 때

사용 방법

  1. 「가로 위치 (x)」·「세로 위치 (y)」(−50~50px)로 그림자 방향을 정합니다.
  2. 「흐림 (blur)」(0~100px), 「번짐 (spread)」(−30~50px), 「불투명도」(0~100%)를 조절합니다.
  3. 「그림자 색」을 고르고, 필요하면 「내부 그림자(inset)」에 체크합니다. 「박스 색」은 미리보기 확인용이며 결과 코드에는 들어가지 않습니다.
  4. 아래 결과를 확인하고 「복사」를 누릅니다.

결과 해석

처음 값은 box-shadow: 0px 10px 25px 0px rgba(30,58,138,0.25);입니다. 가로 이동 0, 아래로 10px 내려간 그림자를 25px 흐리게 퍼뜨리고, 짙은 남색(#1e3a8a)을 25% 불투명도로 깔았다는 뜻입니다. y를 키우고 blur를 함께 키우면 물체가 바닥에서 더 떠 보이고, spread를 음수로 주면 그림자가 상자보다 작아져 아래쪽에만 그림자가 비치는 효과를 낼 수 있습니다.

주의할 점

  • 그림자는 한 겹만 만듭니다. 자연스러운 그림자를 위해 여러 겹을 쉼표로 이어 쓰려면 결과를 여러 번 만들어 직접 합치세요.
  • blur 값이 큰 그림자를 수많은 요소에 쓰거나 애니메이션하면 스크롤·렌더링이 느려질 수 있습니다.
  • 어두운 배경(다크 모드)에서는 어두운 그림자가 거의 보이지 않으므로 테두리나 배경 명도 차이로 구분을 보완하세요.

자주 묻는 질문

blur와 spread는 무엇이 다른가요?
blur는 그림자 가장자리를 흐리게 퍼뜨리는 정도이고, spread는 그림자 자체의 크기를 키우거나(양수) 줄입니다(음수).
이미지 모양을 따라 그림자를 주고 싶어요.
box-shadow는 상자 테두리 모양을 따르므로, 투명 PNG의 모양을 따르려면 filter: drop-shadow()를 쓰세요.
