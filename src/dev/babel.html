Babel 트랜스파일러

최신 자바스크립트(ES6+)와 JSX를 구형 브라우저용 ES5로 변환합니다.

오픈소스 Babel(MIT, babel/babel)을 자체 호스팅합니다. preset-env(+JSX 선택 시 preset-react)로 변환합니다. 모든 처리는 브라우저에서만 이루어집니다.

Babel 트랜스파일러 사용 안내

무엇을 하는 도구인가

브라우저용 Babel(standalone, 7.x)로 ES2015 이후 자바스크립트를 ES5 문법으로 바꿉니다. 프리셋은 preset-env를 쓰며 별도 대상 브라우저를 지정하지 않으므로 화살표 함수, 클래스, 템플릿 문자열, 구조 분해, 나머지 연산자 같은 최신 문법을 모두 ES5로 내립니다. 「JSX 변환」에 체크하면 preset-react도 함께 적용합니다.

언제 쓰나

  • 구형 사내 브라우저나 키오스크용 스크립트를 빌드 도구 없이 ES5로 바꿔야 할 때
  • 화살표 함수·클래스가 내부적으로 어떤 코드로 바뀌는지 공부할 때
  • JSX가 React.createElement 호출로 어떻게 바뀌는지 확인할 때
  • 빌드 결과물에서 낯선 헬퍼 함수가 어디서 왔는지 추적할 때

사용 방법

  1. 왼쪽 「입력 (ES6+)」 칸에 코드를 붙여 넣습니다. 입력을 멈추면 잠시 뒤 자동으로 변환합니다.
  2. JSX가 들어 있으면 「JSX 변환」에 체크합니다. 체크하지 않으면 JSX는 문법 오류로 표시됩니다.
  3. 오른쪽 「출력 (ES5)」을 확인하고 「복사」를 누릅니다.

결과 해석

const greet = (name = 'world') => `Hello, ${name}!`;는 "use strict";로 시작하는 결과에서 var greet = function greet() { … }로 바뀝니다. 기본 매개변수는 arguments.length를 검사하는 코드가 되고, 템플릿 문자열은 "Hello, ".concat(name, "!")가 됩니다. 클래스나 구조 분해를 쓰면 결과 위쪽에 _classCallCheck 같은 헬퍼 함수가 함께 들어갑니다.

주의할 점

  • 문법만 바꿀 뿐 폴리필은 넣지 않습니다. Promise, Array.prototype.includes, fetch처럼 구형 브라우저에 없는 기능은 따로 폴리필을 추가해야 합니다.
  • import/export는 CommonJS(require, exports)로 바뀝니다. 이 결과는 번들러 없이 브라우저에서 바로 실행되지 않습니다.
  • JSX는 클래식 방식(React.createElement)으로 바뀌므로 실행하는 곳에 React가 있어야 합니다. TypeScript 문법은 처리하지 않습니다.

자주 묻는 질문

대상 브라우저(browserslist)를 지정할 수 있나요?
이 화면에서는 지정할 수 없고 항상 ES5까지 내립니다. 대상별 최적화가 필요하면 프로젝트 빌드 설정에서 Babel을 쓰세요.
결과를 그대로 배포해도 되나요?
작은 스크립트라면 가능하지만 압축(minify)은 하지 않으므로 운영 배포 전에는 별도 압축 도구를 거치는 편이 좋습니다.
