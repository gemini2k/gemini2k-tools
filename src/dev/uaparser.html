User-Agent 분석기

User-Agent 문자열에서 브라우저·버전·운영체제·기기 종류를 분석합니다.

널리 알려진 브라우저·OS 패턴을 기준으로 추정합니다. User-Agent는 위조될 수 있어 정확성을 보장하지 않습니다. 모든 처리는 브라우저에서만 이루어집니다.

User-Agent 분석기 사용 안내

무엇을 하는 도구인가

브라우저가 요청마다 보내는 User-Agent 문자열을 읽어 브라우저 이름과 버전, 렌더링 엔진, 운영체제와 버전, 기기 종류(데스크톱·모바일·태블릿·봇/크롤러)를 추정합니다. 외부 라이브러리 없이 이 페이지에 들어 있는 패턴 규칙으로 판별하며, Edge·삼성 인터넷·오페라·네이버 웨일처럼 문자열에 Chrome이 함께 들어 있는 브라우저를 먼저 걸러 낸 다음 Chrome·Firefox·Safari 순으로 확인합니다.

언제 쓰나

  • 웹 서버 접속 로그에 찍힌 UA 문자열이 어떤 환경인지 빠르게 읽을 때
  • "특정 폰에서만 화면이 깨진다"는 문의에 고객의 UA를 받아 환경을 확인할 때
  • 통계 도구에 잡힌 방문이 사람인지 크롤러인지 1차로 가를 때
  • 내 브라우저가 서버에 어떤 UA를 보내는지 확인할 때

사용 방법

  1. 입력란에는 처음에 지금 쓰는 브라우저의 UA가 들어 있습니다.
  2. 분석할 UA 문자열을 붙여 넣으면 표가 바로 갱신됩니다.
  3. 다시 내 브라우저 값으로 돌아가려면 「내 브라우저 넣기」를 누릅니다.

결과 해석

예를 들어 Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36는 브라우저 Google Chrome 120.0.0.0, 렌더링 엔진 WebKit/Blink, 운영체제 Windows 10/11, 기기 종류 데스크톱으로 나옵니다. 같은 문자열 끝에 Edg/120.0.0.0이 붙어 있으면 Microsoft Edge로 판정합니다. Windows가 「10/11」로 묶여 나오는 것은 Windows 11도 UA에 Windows NT 10.0을 보내 문자열만으로는 둘을 구분할 수 없기 때문입니다. 엔진도 WebKit과 Blink를 하나로 묶어 표시합니다.

주의할 점

  • 최근 크롬 계열 브라우저는 UA를 축소해 보내므로 안드로이드 버전이나 기기 모델이 실제와 다르게 고정된 값으로 나올 수 있습니다. 맥의 OS 버전도 실제보다 낮게 고정되어 나오는 경우가 많습니다.
  • 아이패드는 기본 설정에서 맥과 같은 UA를 보내므로 macOS 데스크톱으로 판정될 수 있습니다.
  • 아이폰용 크롬(CriOS)·파이어폭스(FxiOS)처럼 규칙에 없는 표기는 브라우저가 「알 수 없음」으로 나올 수 있습니다.
  • UA는 누구나 바꿔 보낼 수 있습니다. 보안 판단이나 접근 차단의 유일한 근거로 쓰지 마세요.

자주 묻는 질문

봇은 어떻게 판정하나요?
문자열에 bot, crawler, spider, slurp 같은 단어가 있으면 기기 종류를 봇/크롤러로 표시합니다. 이 단어를 쓰지 않는 수집기는 걸러지지 않습니다.
붙여 넣은 UA가 서버로 전송되나요?
아닙니다. 분석은 브라우저 안에서만 이루어집니다.
