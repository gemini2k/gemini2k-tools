SVG 최적화·압축기

SVG의 주석·메타데이터·불필요한 공백을 제거해 용량을 줄입니다.

XML 선언·주석·<metadata>·<title>·<desc>·태그 사이 공백·소수점 자릿수를 정리합니다(안전한 범위). 복잡한 패스 최적화까지는 하지 않습니다. 모든 처리는 브라우저에서만 이루어집니다.

SVG 최적화·압축기 사용 안내

무엇을 하는 도구인가

SVG 원문에서 그림에 영향을 주지 않는 부분을 정규식 규칙으로 걷어 내 파일을 줄입니다. 지우는 대상은 XML 선언(<?xml …?>), 주석, <metadata>·<title>·<desc> 요소, 태그 사이 공백과 연속 공백입니다. 소수점 아래 네 자리 이상인 숫자는 셋째 자리까지만 남기고, /> 앞의 공백도 붙입니다. 결과 아래에는 실제로 그려 본 미리보기가 나옵니다.

언제 쓰나

  • 일러스트레이터·피그마·잉크스케이프에서 내보낸 아이콘에 붙은 편집기 메타데이터를 지울 때
  • HTML에 SVG를 인라인으로 넣기 전에 줄바꿈과 주석을 걷어 낼 때
  • CSS 배경용 data URI로 바꾸기 전에 길이를 줄일 때
  • 빌드 도구 없이 아이콘 몇 개만 빠르게 정리할 때

사용 방법

  1. 입력란에 SVG 코드 전체를 붙여 넣습니다. 입력하는 즉시 결과가 계산됩니다.
  2. 입력란 아래의 원본·최적화 바이트 수와 절감 비율을 확인합니다.
  3. 결과 코드 아래 미리보기에서 그림이 원본과 같은지 확인합니다.
  4. 「복사」로 결과를 가져갑니다. 「최적화」 버튼은 같은 작업을 다시 실행합니다.

결과 해석

기본 예제는 XML 선언, 주석, metadata가 모두 빠지고 <svg xmlns="http://www.w3.org/2000/svg" width="100" height="100"><circle cx="50" cy="50" r="40" fill="#5B5BF5"/></svg> 한 줄로 바뀝니다. 디자인 툴에서 나온 12.3456789 같은 좌표는 12.345가 되는데, 반올림이 아니라 넷째 자리부터 잘라 내는 방식입니다. 경로 데이터가 대부분인 큰 파일은 절감 폭이 작고, 메타데이터가 많은 파일일수록 효과가 큽니다.

주의할 점

  • <title>은 화면 낭독기와 툴팁에 쓰이는 이름입니다. 접근성이 필요한 아이콘이면 지운 뒤 aria-label 등으로 대신하세요.
  • 규칙이 문맥을 보지 않아 <text> 안의 연속 공백이 하나로 줄고, id나 텍스트 안의 긴 소수점 숫자도 잘립니다.
  • 경로 단순화, 불필요한 그룹 정리, 색상 축약 같은 구조 최적화는 하지 않습니다. 그런 작업은 SVGO 같은 전용 도구가 맞습니다.
  • 미리보기는 붙여 넣은 SVG를 이 페이지에 그대로 그립니다. 출처를 모르는 SVG는 넣지 마세요.

자주 묻는 질문

최적화 후 그림이 미세하게 달라졌어요.
소수점 절삭 때문일 가능성이 큽니다. 아주 작은 크기로 설계한 그림은 셋째 자리 절삭에도 모양이 바뀔 수 있으니 원본을 쓰세요.
