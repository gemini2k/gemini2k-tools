표기(케이스) 변환기

문장이나 식별자를 입력하면 camelCase·snake_case·kebab-case 등 모든 표기로 한 번에 바꿔 줍니다. 변수명·DB 컬럼·URL 슬러그 만들 때 쓰세요.

단어는 공백·하이픈·밑줄, 그리고 대소문자 경계(camelCase)로 구분해 인식합니다. 한글 등 대소문자가 없는 문자는 그대로 이어 붙입니다. 모든 변환은 브라우저에서 이루어집니다.

표기(케이스) 변환기 사용 안내

무엇을 하는 도구인가

문장이나 식별자를 단어로 나눈 뒤 camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE, Title Case, Sentence case, lowercase, UPPERCASE, dot.case, path/case 11가지 표기로 한꺼번에 바꿉니다. 단어 경계는 공백·하이픈·밑줄·점·슬래시, 그리고 소문자 뒤 대문자가 오는 지점(camelCase 경계)으로 인식합니다.

언제 쓰나

  • DB 컬럼명(snake_case)을 자바스크립트 변수명(camelCase)으로 옮길 때
  • 기획서의 영문 기능명을 URL 슬러그(kebab-case)나 상수 이름(CONSTANT_CASE)으로 만들 때
  • API 응답 필드 이름을 클래스 이름(PascalCase)으로 바꿔 타입을 정의할 때
  • 영문 제목을 Title Case로 정리할 때

사용 방법

  1. 입력칸에 문장이나 식별자를 넣습니다.
  2. 아래 11개 줄에서 원하는 표기를 찾습니다.
  3. 줄 오른쪽의 복사 버튼을 누릅니다.

결과 해석

getUserID를 넣으면 get, User, ID 세 단어로 나뉘어 snake_case는 get_user_id, CONSTANT_CASE는 GET_USER_ID, PascalCase는 GetUserId가 됩니다. XMLHttpRequest처럼 대문자가 이어진 약어도 XML, Http, Request로 나눠 xml_http_request가 됩니다.

주의할 점

  • camelCase·PascalCase로 바꿀 때 각 단어를 첫 글자만 대문자로 만들기 때문에 ID, URL 같은 약어가 Id, Url이 됩니다. 팀 규칙이 약어를 대문자로 유지한다면 직접 고치세요.
  • 숫자 뒤의 대문자도 단어 경계로 봅니다. v2Api는 v2와 Api로 나뉩니다. 숫자와 글자 사이(utf8)는 나누지 않습니다.
  • 한글처럼 대소문자가 없는 문자는 그대로 남습니다. 변수명·컬럼명에는 영문을 쓰는 편이 도구·DB 호환에 안전합니다.
  • Title Case는 모든 단어의 첫 글자를 대문자로 만듭니다. a, of, the 같은 짧은 단어를 소문자로 두는 영문 편집 규칙은 적용하지 않습니다.
