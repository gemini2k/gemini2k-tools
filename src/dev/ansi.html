ANSI 터미널 색상 → HTML

터미널 로그의 색상 코드(ANSI)를 색이 입혀진 HTML로 바꿔 줍니다.

오픈소스 ansi_up(MIT, drudru/ansi_up)을 자체 호스팅합니다. 실제 ESC 문자가 포함된 로그를 붙여넣거나, [·\x1b[·^[[ 표기를 사용해도 됩니다. 모든 처리는 브라우저에서만 이루어집니다.

ANSI 터미널 색상 → HTML 사용 안내

무엇을 하는 도구인가

터미널 로그에 섞인 ANSI 이스케이프 코드(SGR 색상·굵게·밑줄 등)를 오픈소스 ansi_up으로 해석해, 색이 입혀진 HTML로 바꿉니다. 위쪽 미리보기에서 터미널처럼 보이는 결과를, 아래쪽에서 <span style="...">로 된 HTML 원문을 확인할 수 있습니다. 실제 ESC 문자뿐 아니라 \x1b, \u001b, \033, \e, ^[처럼 글자로 적힌 표기도 ESC로 바꿔 처리합니다.

언제 쓰나

  • CI 빌드 로그나 테스트 결과를 색을 살린 채 위키·이슈 댓글·보고서에 붙일 때
  • 로그 파일을 열었더니 [32m 같은 코드가 잔뜩 섞여 있어 읽기 어려울 때
  • CLI 프로그램이 출력하는 색상 코드가 의도대로 나오는지 확인할 때
  • 사내 대시보드에 서버 로그를 색 그대로 보여 주는 화면을 만들기 전 결과 HTML을 확인할 때

사용 방법

  1. 입력칸에 로그를 붙여 넣습니다. 처음에는 예시 로그가 들어 있으며, 지운 뒤 「예시 다시 넣기」로 되살릴 수 있습니다.
  2. 미리보기에서 색이 제대로 나오는지 확인합니다.
  3. 「HTML 복사」로 변환된 HTML을 복사해 원하는 곳에 붙여 넣습니다.

결과 해석

\x1b[31m에러\x1b[0m은 <span style="color:rgb(187,0,0)">에러</span>가 됩니다. 기본 16색은 ansi_up의 팔레트 값으로, 256색(38;5;n)과 RGB 직접 지정(38;2;r;g;b)은 해당 색 그대로 바뀝니다. 로그 안의 <, > 같은 문자는 HTML 이스케이프되므로 로그 내용이 태그로 해석되지 않습니다.

주의할 점

  • 커서 이동, 화면 지우기 같은 제어 코드는 화면 동작으로 재현되지 않고 지워집니다. 진행률 표시줄처럼 같은 줄을 덮어쓰는 출력은 여러 줄이 이어진 모양으로 남습니다.
  • 글자로 적힌 \e는 바로 뒤에 [가 올 때(\e[31m 등)만 ESC로 바꿉니다. 그래서 C:\example 같은 경로는 그대로 남습니다. \x1b, \033, \u001b는 위치와 상관없이 ESC로 바꿉니다.
  • 결과 HTML은 인라인 style을 쓰므로 배경색은 붙여 넣는 페이지의 배경을 따릅니다. 밝은 배경에서는 노랑·흰색 글씨가 잘 보이지 않을 수 있습니다.

자주 묻는 질문

로그를 파일로 저장하면 코드가 사라지나요?
프로그램에 따라 다릅니다. 파이프나 파일로 출력하면 색을 끄는 도구가 많고, 강제로 켜는 옵션(예: --color=always)을 쓰면 코드가 남습니다.
HTML 대신 색 없는 순수 텍스트만 얻을 수 있나요?
미리보기 영역을 드래그해 복사한 뒤 메모장 같은 일반 텍스트 편집기에 붙여 넣으면 색 코드 없이 글자만 남습니다.
