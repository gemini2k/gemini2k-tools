SVG 아이콘 검색 (Lucide)

아이콘을 검색하고 클릭하면 SVG 코드가 복사됩니다.

굵기
오픈소스 Lucide(ISC, lucide-icons/lucide)를 자체 호스팅합니다. 성능을 위해 최대 120개까지 표시합니다. 모든 처리는 브라우저에서만 이루어집니다.

SVG 아이콘 검색(Lucide) 사용 안내

무엇을 하는 도구인가

오픈소스 아이콘 세트 Lucide(이 사이트에 올린 버전은 0.408.0)의 아이콘을 영문 이름으로 검색하고, 클릭 한 번으로 해당 아이콘의 <svg> 코드를 복사합니다. Lucide 아이콘은 24×24 격자에 선(stroke)으로 그린 형태라 선 굵기를 바꿔도 모양이 유지됩니다. 목록에는 별칭 이름도 함께 들어 있어 같은 아이콘이 두 이름으로 보일 수 있습니다.

언제 쓰나

  • 아이콘 폰트나 패키지를 설치하지 않고 관리자 화면·사내 도구에 아이콘 몇 개만 넣고 싶을 때
  • 디자이너 없이 버튼·메뉴에 쓸 아이콘을 빠르게 골라야 할 때
  • React·Vue용 Lucide 패키지를 쓰기 전에 아이콘 이름을 확인할 때

사용 방법

  1. 검색 칸에 영문 이름 일부(예: arrow, home, user)를 입력합니다. 한국어 검색은 되지 않습니다.
  2. '굵기' 슬라이더로 선 두께를 1~3 사이에서 0.5 단위로 조절합니다.
  3. 원하는 아이콘을 클릭하면 SVG 코드가 클립보드에 복사됩니다.

결과 해석

검색 칸 아래에 "96개 중 96개 표시"처럼 일치한 수와 표시한 수가 나옵니다(기본 검색어 arrow 기준). 한 번에 최대 120개까지만 그리므로 결과가 많으면 검색어를 더 구체적으로 적으세요. 아이콘 아래 이름은 arrow-down처럼 케밥 표기이며, React 패키지에서는 ArrowDown 같은 파스칼 표기로 같은 아이콘을 가져올 수 있습니다. 복사한 SVG는 stroke="currentColor"라서 부모 요소의 글자색을 그대로 따라갑니다.

주의할 점

복사되는 SVG에는 width·height가 28로 들어가 있으니 쓰는 곳에 맞게 고치거나 CSS로 크기를 지정하세요. 의미 전달이 필요한 아이콘이라면 aria-label이나 옆에 보이는 텍스트를 함께 두어야 스크린리더 사용자도 이해할 수 있습니다. Lucide는 ISC 라이선스라 상업적 사용이 가능하지만, 라이선스 고지는 남겨 두는 것이 원칙입니다.

자주 묻는 질문

색은 어떻게 바꾸나요?
SVG가 들어간 요소에 CSS color를 지정하면 됩니다. 직접 바꾸려면 stroke 값을 색상 코드로 고치세요.
채워진(fill) 아이콘도 있나요?
Lucide는 선 아이콘 세트라 fill="none"이 기본입니다. 채움이 필요하면 fill 속성을 직접 바꿔야 하는데 모든 아이콘이 자연스럽지는 않습니다.
