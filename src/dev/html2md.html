HTML → 마크다운 변환기

HTML을 붙여넣으면 깔끔한 마크다운으로 바꿔 줍니다. 블로그 이전·문서화에 좋아요.

↓
오픈소스 Turndown(MIT, mixmark-io/turndown)을 자체 호스팅합니다. 표·코드블록은 GFM 스타일로 처리합니다. 모든 처리는 브라우저에서만 이루어집니다.

HTML → 마크다운 변환기 사용 안내

무엇을 하는 도구인가

붙여넣은 HTML을 Turndown 7로 해석해 마크다운 텍스트로 바꿉니다. 제목은 # 형식(ATX), 코드 블록은 백틱 세 개로 감싸는 펜스 형식, 글머리 목록은 -를 씁니다. Turndown 기본 규칙에는 표가 없어서, 이 페이지에 <table>을 GFM 표로 바꾸는 간단한 규칙을 따로 붙였습니다.

언제 쓰나

  • 워드프레스·티스토리 같은 블로그 글을 마크다운 기반 정적 사이트나 GitHub 저장소로 옮길 때
  • Confluence나 사내 위키 페이지의 HTML 소스를 README나 노션으로 옮길 때
  • CMS가 저장한 HTML 본문을 마크다운 필드로 마이그레이션할 데이터를 손으로 확인할 때

사용 방법

  1. 입력 칸에 HTML 소스를 붙여넣습니다. 브라우저 화면을 복사한 것이 아니라 태그가 보이는 소스여야 합니다.
  2. 입력하는 즉시 아래에 마크다운이 나옵니다.
  3. [📋 복사]로 결과를 가져갑니다.

결과 해석

기본 예시는 # 제목, 안녕하세요 [링크](https://gemini2k.co.kr)입니다., 목록 두 줄, 그리고 console.log(1)을 감싼 펜스 코드 블록으로 바뀝니다. 목록은 Turndown 기본값대로 - 첫째처럼 기호 뒤에 공백 세 칸이 들어가는데, 대부분의 마크다운 렌더러에서 정상적인 목록으로 표시됩니다. 일반 문장 안의 *, _, [ 같은 문자나 줄 맨 앞의 #은 마크다운 문법으로 오해되지 않도록 앞에 백슬래시가 붙습니다.

주의할 점

표 변환은 각 셀의 텍스트만 가져오므로 셀 안의 링크, 굵게, 줄바꿈은 사라지고, 셀 내용에 |가 있으면 표가 깨집니다. 병합 셀(colspan, rowspan)은 반영되지 않으며 구분선 칸 수는 첫 행을 기준으로 정해집니다. <style>, 인라인 스타일, 클래스 같은 꾸밈 정보는 버려지고, <span>, <div>처럼 마크다운에 대응하는 문법이 없는 태그는 태그 없이 안의 글만 남으니 결과를 한 번 훑어보세요.
