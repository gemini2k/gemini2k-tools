Prettier 코드 포매터

JS·CSS·HTML·JSON·마크다운 코드를 Prettier 규칙으로 깔끔하게 정렬합니다.

언어 들여쓰기
오픈소스 Prettier(MIT, prettier/prettier)를 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어집니다.

Prettier 코드 포매터 사용 안내

무엇을 하는 도구인가

Prettier 3의 브라우저용 빌드로 JavaScript, CSS, HTML, JSON, Markdown 코드를 다시 찍어 냅니다. Prettier는 원래 코드의 줄바꿈·들여쓰기를 거의 무시하고 구문 트리를 만든 뒤 정해진 규칙으로 처음부터 다시 출력하는 방식이라, 누가 쓴 코드든 같은 모양으로 맞춰집니다. 이 도구에서 바꿀 수 있는 옵션은 들여쓰기 폭, 세미콜론, 작은따옴표 세 가지이고 나머지는 Prettier 기본값(한 줄 80자 기준 등)을 따릅니다.

언제 쓰나

  • 압축되었거나 한 줄로 뭉친 스크립트·스타일을 읽기 좋게 펼쳐 볼 때
  • 프로젝트에 Prettier가 설정되어 있지 않은 PC에서 코드 조각만 빠르게 정리할 때
  • 코드 리뷰나 문서에 붙일 예제 코드의 모양을 통일할 때
  • 팀에 세미콜론·따옴표 규칙을 정하기 전에 옵션별 결과를 비교해 볼 때

사용 방법

  1. 입력란에 코드를 붙여 넣습니다.
  2. 「언어」에서 JavaScript·CSS·HTML·JSON·Markdown 중 하나를 고릅니다. 언어를 잘못 고르면 구문 오류가 납니다.
  3. 「들여쓰기」(2칸/4칸), 「세미콜론」, 「작은따옴표」를 정합니다.
  4. 「정렬」을 누르면 입력란의 내용이 정리된 코드로 바뀝니다. 「복사」로 가져갑니다.

결과 해석

기본 예제의 const x={a:1,b:2,c:[1,2,3]};는 const x = { a: 1, b: 2, c: [1, 2, 3] };처럼 연산자와 중괄호 안쪽에 공백이 들어가고, 한 줄에 붙어 있던 function foo(a,b){return a+b}는 함수 본문이 따로 들여 쓴 줄로 나뉩니다. 화살표 함수의 매개변수가 하나여도 x=>x*2가 (x) => x * 2로 괄호가 붙는데, 이는 Prettier 3의 기본 규칙입니다. 「세미콜론」을 끄면 문장 끝 세미콜론이 빠지고, 괄호나 대괄호로 시작해 앞 줄과 붙어 해석될 위험이 있는 줄에만 맨 앞에 세미콜론이 붙습니다.

주의할 점

  • 결과가 입력란을 덮어씁니다. 원본이 필요하면 「정렬」 전에 따로 보관하세요.
  • 문법 오류가 있으면 아무것도 바뀌지 않고 오류 메시지만 나옵니다. 메시지 안의 (줄:열) 위치를 확인하세요.
  • TypeScript, SCSS, YAML처럼 목록에 없는 언어는 이 화면에서 지원하지 않습니다. 프로젝트의 .prettierrc 설정도 반영되지 않습니다.

자주 묻는 질문

ESLint처럼 코드 오류도 잡아 주나요?
아닙니다. Prettier는 모양만 바꾸는 도구라 사용하지 않는 변수나 잘못된 비교 같은 논리 문제는 알려 주지 않습니다.
정렬 결과가 동작에 영향을 주나요?
Prettier는 의미가 같은 범위에서만 공백·괄호·따옴표를 바꾸도록 설계되어 있습니다. 그래도 운영 코드라면 정렬 후 테스트를 한 번 돌리는 것이 기본입니다.
