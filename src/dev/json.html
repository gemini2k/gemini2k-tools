JSON 포맷터·검증기

JSON을 정리·압축하고 오류를 검사합니다.

들여쓰기

JSON 포맷터·검증기 사용 안내

무엇을 하는 도구인가

붙여넣은 텍스트를 브라우저 내장 JSON.parse로 읽어 표준 JSON(RFC 8259) 문법에 맞는지 검사하고, 맞으면 들여쓰기한 형태나 공백 없는 한 줄 형태로 다시 써 줍니다. 원하면 모든 단계의 객체 키를 알파벳 순으로 정렬합니다. 문법 오류가 있으면 브라우저가 알려 주는 오류 위치와 내용을 그대로 보여 줍니다.

언제 쓰나

  • curl이나 로그로 받은 한 줄짜리 API 응답을 읽기 좋게 펼쳐 볼 때
  • 손으로 고친 설정 파일(package.json, appsettings.json 등)에 쉼표·따옴표 실수가 없는지 확인할 때
  • 두 JSON을 비교하기 전에 키 순서를 정렬해 diff 노이즈를 줄일 때
  • 요청 본문에 넣을 JSON을 한 줄로 압축할 때

사용 방법

  1. 'JSON 입력'에 내용을 붙여넣습니다.
  2. '들여쓰기'(공백 2, 공백 4, 탭)와 '키 정렬(A→Z)'을 고릅니다.
  3. [✨ 정리(들여쓰기)] 또는 [🗜️ 압축(한 줄)]을 누릅니다. 이후에는 입력을 고칠 때마다 마지막에 고른 방식으로 다시 변환됩니다.
  4. '결과'에서 [📋 결과 복사]로 가져갑니다.

결과 해석

{"b":1,"a":[1,2]}에 키 정렬을 켜고 정리하면 "a"가 먼저 오고 배열이 여러 줄로 펼쳐집니다. 배열 안의 순서는 의미가 있으므로 정렬하지 않습니다. 반면 {a:1}, {'a':1}, 마지막 요소 뒤의 쉼표, // 주석은 모두 표준 JSON이 아니어서 오류로 나옵니다. 이런 입력은 JSON5 변환기를 거친 뒤 넣으세요.

주의할 점

자바스크립트 숫자 한계 때문에 9007199254740991보다 큰 정수(예: 트위터·디스코드 ID, 일부 DB의 bigint)는 정리 과정에서 끝자리가 바뀝니다. 그런 값은 문자열로 다뤄야 합니다. 같은 키가 두 번 나오면 오류 없이 마지막 값만 남고, 1.0은 1로 출력됩니다. 또 객체 키 정렬을 켜도 "10", "2"처럼 숫자 모양의 키는 자바스크립트 규칙상 숫자 크기 순으로 맨 앞에 놓입니다.
