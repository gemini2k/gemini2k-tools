JSON ↔ CSV 변환

JSON 객체 배열과 CSV 표를 양쪽으로 변환합니다. 엑셀에 붙이거나 코드에 넣기 좋게.

JSON → CSV는 객체 배열의 모든 키를 모아 머리글로 만들고, 값에 쉼표·따옴표·줄바꿈이 있으면 자동으로 따옴표 처리합니다. CSV → JSON은 첫 줄을 머리글로 보고 객체 배열을 만듭니다. 모든 변환은 브라우저에서만 이루어집니다.

JSON ↔ CSV 변환 사용 안내

무엇을 하는 도구인가

JSON 객체 배열을 CSV 표로, CSV 표를 JSON 객체 배열로 바꿉니다. JSON → CSV에서는 모든 객체에 나온 키를 처음 등장한 순서대로 모아 머리글을 만들고, 어떤 객체에 없는 키는 빈 칸으로 둡니다. 값에 쉼표·큰따옴표·줄바꿈이 있으면 큰따옴표로 감싸고, 값이 객체나 배열이면 JSON 문자열로 넣습니다. CSV → JSON에서는 첫 줄을 키로 삼아 각 줄을 객체로 만듭니다.

언제 쓰나

  • API 응답 목록을 엑셀로 열어 비개발자 동료에게 공유할 때
  • 엑셀로 정리한 기초 데이터를 테스트 픽스처나 목(mock) 응답 JSON으로 만들 때
  • 로그에서 뽑은 JSON 이벤트들을 스프레드시트에서 필터·정렬해 볼 때

사용 방법

  1. [JSON → CSV] 또는 [CSV → JSON] 방향을 고릅니다.
  2. 입력 칸에 붙여넣으면 바로 변환되고, [변환]으로 다시 실행할 수도 있습니다.
  3. [📋 결과 복사]로 복사하거나 [⬇ 다운로드]로 converted.csv 또는 converted.json 파일을 받습니다.

결과 해석

[{"name":"철수","age":20},{"name":"영희","city":"부산"}]을 CSV로 바꾸면 머리글은 name,age,city, 둘째 줄은 철수,20,, 셋째 줄은 영희,,부산이 됩니다. 이 CSV를 다시 JSON으로 바꾸면 "age": "20"처럼 모든 값이 문자열이 되고, 빈 칸은 ""로 들어갑니다. 숫자·불리언 타입이 필요하면 받는 쪽 코드에서 변환하세요.

주의할 점

CSV 다운로드 파일에는 엑셀에서 한글이 깨지지 않도록 UTF-8 BOM이 붙고, 줄바꿈은 LF입니다. 입력 CSV의 구분자는 첫 줄을 보고 쉼표·세미콜론·탭·파이프(|) 중에서 자동으로 고릅니다. 머리글에 같은 이름이 두 번 있으면 두 번째부터 name_2처럼 번호를 붙여 값이 사라지지 않게 하고, 머리글보다 열이 많은 줄의 넘치는 값은 버려집니다. JSON → CSV에서 =, +, -, @로 시작하는 글자 값은 엑셀에서 수식으로 실행될 수 있어 앞에 작은따옴표(')를 붙여 내보냅니다. -5 같은 순수 숫자는 그대로 둡니다.

자주 묻는 질문

중첩된 객체를 열로 펼쳐 주나요?
펼치지 않습니다. {"addr":{"city":"서울"}}의 addr 칸에는 {"city":"서울"} 문자열이 그대로 들어갑니다.
최상위가 객체 하나인 JSON은요?
배열이어야 한다는 오류가 납니다. [ ]로 감싸서 넣으세요.
