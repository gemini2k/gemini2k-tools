단어 단위 텍스트 비교

두 글을 비교해 추가·삭제된 부분을 한 줄에 색으로 보여 줍니다. 교정·버전 비교에 좋아요.

오픈소스 jsdiff(BSD-3, kpdecker/jsdiff)를 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어집니다.

단어 단위 텍스트 비교 사용 안내

무엇을 하는 도구인가

원본과 수정본을 jsdiff 5의 diffWords 또는 diffChars로 비교해, 바뀐 부분을 한 덩어리의 글 안에서 삭제는 빨간 배경과 취소선, 추가는 초록 배경으로 표시합니다. 줄 단위 diff와 달리 문장 안의 어느 단어가 바뀌었는지 바로 보입니다.

언제 쓰나

  • 릴리스 노트, 약관, 공지문 초안을 검토자가 고쳐 왔을 때 무엇이 바뀌었는지 확인할 때
  • 에러 메시지나 로그 한 줄이 두 환경에서 어떻게 다른지 글자 단위로 볼 때
  • 번역문이나 UI 문구 리소스의 수정 전후를 비교할 때

사용 방법

  1. 왼쪽 '원본'과 오른쪽 '수정본'에 글을 넣습니다. 입력하는 동안 결과가 바로 갱신됩니다.
  2. '단위'에서 단어 또는 글자를 고릅니다.
  3. 아래 결과에서 빨간 배경(취소선) 부분은 원본에만, 초록 배경 부분은 수정본에만 있는 내용입니다.

결과 해석

기본 예시 "빠른 갈색 여우가 게으른 개를 뛰어넘었다."와 "빠른 갈색 여우가 아주 게으른 강아지를 뛰어넘는다."를 단어 단위로 비교하면 아주 가 추가, 개를→강아지를, 뛰어넘었다.→뛰어넘는다.가 각각 삭제+추가로 표시됩니다. 한국어는 띄어쓰기로 나뉜 어절 하나가 한 단위가 되기 때문에 어미만 바뀌어도 어절 전체가 바뀐 것으로 나옵니다. 단위를 글자로 바꾸면 같은 부분이 었 삭제, 는 추가로 좁혀집니다.

주의할 점

단어 단위 비교는 공백 차이를 무시하고 단어만 맞춰 보므로, 띄어쓰기를 하나 더 넣거나 뺀 변경은 잡히지 않을 수 있습니다. 공백까지 확인해야 하면 글자 단위를 쓰세요. 수천 줄짜리 문서를 글자 단위로 비교하면 계산이 오래 걸릴 수 있으니, 그런 경우는 줄 단위 diff로 바뀐 구역을 먼저 찾는 편이 낫습니다.

자주 묻는 질문

결과를 복사해서 문서에 붙일 수 있나요?
별도 복사 버튼은 없습니다. 결과 영역을 드래그해 복사하면 서식을 지원하는 편집기에서는 배경색·취소선이 함께 붙는 경우가 있습니다.
여러 줄 글도 되나요?
됩니다. 줄바꿈도 비교 대상에 포함되어 결과에 그대로 나타납니다.
