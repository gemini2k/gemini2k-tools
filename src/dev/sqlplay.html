SQL 연습장 (SQLite)

브라우저에서 진짜 SQLite를 실행합니다. 쿼리를 작성해 바로 결과를 확인하세요. SQL 학습·테스트에 좋아요.

오픈소스 sql.js(MIT, sql-js/sql.js · SQLite는 퍼블릭 도메인)를 WASM으로 자체 호스팅합니다. 샘플 테이블 emp(id,name,dept,salary)가 미리 만들어져 있습니다. 모든 처리는 브라우저(메모리)에서만 이루어집니다.

SQL 연습장(SQLite) 사용 안내

무엇을 하는 도구인가

SQLite를 WebAssembly로 컴파일한 sql.js를 브라우저에서 띄워, 입력한 SQL을 실제 데이터베이스 엔진으로 실행하고 결과 표를 보여 줍니다. 흉내 내는 해석기가 아니라 SQLite 그 자체이므로 JOIN, GROUP BY, 서브쿼리, 윈도 함수, CREATE TABLE·INSERT·UPDATE까지 SQLite 문법 그대로 동작합니다. 데이터베이스는 이 탭의 메모리 안에만 있습니다.

언제 쓰나

  • SQL을 처음 배우면서 DB 설치 없이 SELECT·WHERE·ORDER BY를 직접 쳐 볼 때
  • GROUP BY와 HAVING, LEFT JOIN 결과가 헷갈려 작은 표로 확인하고 싶을 때
  • 면접·사내 교육용 SQL 문제를 만들고 정답 쿼리를 검증할 때
  • 운영 DB에 던지기 전에 CASE 식이나 날짜 함수의 동작을 작은 데이터로 시험할 때

사용 방법

  1. 엔진 파일을 내려받는 동안 잠시 기다리면 샘플 테이블 emp(직원 5명)가 만들어지고 기본 쿼리가 실행됩니다.
  2. 입력란에 SQL을 쓰고 「▶ 실행 (Ctrl+Enter)」을 누르거나 Ctrl+Enter(맥은 Cmd+Enter)를 누릅니다.
  3. 아래 표에서 결과를 확인합니다. 오류가 나면 SQLite의 오류 메시지가 그대로 표시됩니다.
  4. 데이터를 망가뜨렸다면 「샘플 DB 초기화」로 emp 테이블을 처음 상태로 되돌립니다.

결과 해석

기본 쿼리는 월급 3000 이상을 높은 순으로 고르므로 김영희(4100), 박민수(3600), 홍길동(3200) 세 행이 나옵니다. SELECT dept, AVG(salary) FROM emp GROUP BY dept;를 실행하면 개발 부서는 두 사람 평균인 3850으로 나옵니다. INSERT·UPDATE·CREATE처럼 행을 돌려주지 않는 문장은 「결과 행이 없습니다 (또는 실행 완료)」로 표시되며, 조건에 맞는 행이 하나도 없는 SELECT도 같은 문구가 나옵니다.

주의할 점

  • 세미콜론으로 여러 문장을 한 번에 실행할 수 있지만, 결과 표는 행을 돌려준 첫 번째 문장 것만 보여 줍니다. SELECT를 두 개 넣으면 두 번째 결과는 보이지 않습니다.
  • 새로고침하거나 탭을 닫으면 직접 만든 테이블과 데이터가 모두 사라집니다. 「샘플 DB 초기화」는 emp만 다시 만들고 직접 만든 다른 테이블은 그대로 둡니다.
  • SQLite 문법이라 MySQL의 LIMIT 10, 20은 되지만 오라클의 ROWNUM, SQL Server의 TOP 같은 방언은 쓸 수 없습니다. 자료형 검사도 느슨해서 INTEGER 열에 문자를 넣어도 오류가 나지 않습니다.

자주 묻는 질문

내 CSV나 .db 파일을 불러올 수 있나요?
파일 불러오기 기능은 없습니다. CREATE TABLE과 INSERT 문을 직접 붙여 넣어 데이터를 만들어야 합니다.
실행한 쿼리가 서버로 전송되나요?
아닙니다. 엔진 파일만 이 사이트에서 받고, 쿼리 실행은 모두 브라우저 메모리 안에서 이루어집니다.
