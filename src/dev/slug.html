슬러그(slug) 생성기

제목을 URL에 쓰기 좋은 슬러그로 바꿉니다. 공백은 하이픈, 특수문자는 제거하고 소문자로 정리합니다.

'한글 유지'를 끄면 영문·숫자만 남깁니다. 연속된 공백·기호는 하나의 구분자로 합치고 앞뒤 구분자는 제거합니다. 한글 슬러그는 브라우저 주소창에서 자동 인코딩되어 동작합니다. 모든 처리는 브라우저에서 이루어집니다.

슬러그(slug) 생성기 사용 안내

무엇을 하는 도구인가

글 제목이나 문장을 URL 경로에 넣기 좋은 짧은 문자열로 바꿉니다. 영문 소문자·숫자(그리고 「한글 유지」가 켜져 있으면 한글)만 남기고, 그 밖의 공백·기호 덩어리는 구분자 하나로 바꾼 뒤 앞뒤 구분자를 잘라 냅니다. 입력 전에 유니코드 NFC 정규화를 하므로 맥에서 복사해 자모가 분리된 한글도 정상 음절로 합쳐서 처리합니다.

언제 쓰나

  • 블로그·CMS에 글을 올릴 때 주소 부분(퍼머링크)을 직접 정해야 할 때
  • 정적 사이트 생성기에서 마크다운 파일 이름을 제목에 맞춰 지을 때
  • 상품명이나 게시판 제목으로 URL 경로를 만드는 기능을 개발하면서 기대값을 확인할 때
  • 파일 이름에 쓸 수 없는 기호를 걷어 내고 일관된 이름을 만들 때

사용 방법

  1. 「제목 / 문장」에 원문을 입력합니다.
  2. 「한글 유지」, 「소문자로」를 켜거나 끄고, 「구분자」에서 하이픈 - 또는 밑줄 _을 고릅니다.
  3. 「슬러그」에 나온 결과를 「복사」로 가져갑니다.

결과 해석

기본 예문 「빛의여행 gemini2k 무료 온라인 도구 모음!」은 빛의여행-gemini2k-무료-온라인-도구-모음이 됩니다. 느낌표는 지워지고 끝에 남는 구분자도 정리됩니다. 「한글 유지」를 끄면 영문·숫자만 남아 gemini2k가 됩니다. 악센트가 붙은 라틴 문자는 영문으로 바꾸지 않고 지우므로 Café Menu는 caf-menu가 됩니다. 원문에 있던 하이픈도 기호로 보고 구분자로 바꾸기 때문에 밑줄 구분자를 고르면 하이픈이 밑줄로 바뀝니다.

주의할 점

  • 한글 슬러그는 링크를 복사하면 %EB%B9%9B…처럼 퍼센트 인코딩되어 한 글자가 9자로 늘어납니다. 메신저나 문서에 붙일 링크가 길어지는 것이 싫다면 영문 슬러그를 쓰세요.
  • 한글을 로마자로 바꿔 주는 기능은 없습니다. 「한글 유지」를 끄면 한글이 사라질 뿐입니다.
  • 이미 공개된 글의 슬러그를 바꾸면 기존 링크가 끊기므로 리디렉션 설정을 함께 하세요.

자주 묻는 질문

하이픈과 밑줄 중 무엇을 쓰는 게 좋나요?
URL에서는 하이픈이 더 흔히 쓰이고, 구글 검색 센터 문서도 단어 구분에 밑줄보다 하이픈을 권합니다. 파일 이름이나 코드 식별자에는 밑줄이 편할 때가 있습니다.
입력한 제목이 저장되나요?
아닙니다. 변환은 브라우저에서만 이루어집니다.
