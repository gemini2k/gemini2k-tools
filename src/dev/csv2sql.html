CSV → SQL INSERT

CSV를 붙여넣으면 SQL INSERT 문으로 변환합니다. 첫 줄을 컬럼명으로 사용해요.

↓
숫자·true/false·null은 그대로, 그 외는 작은따옴표 문자열로 처리하고 내부 작은따옴표는 이스케이프합니다. 빈 값은 NULL. CSV 파싱은 따옴표·쉼표를 지원합니다. 모든 처리는 브라우저에서만 이루어집니다.

CSV → SQL INSERT 변환기 사용 안내

무엇을 하는 도구인가

CSV의 첫 줄을 컬럼명으로, 나머지 줄을 데이터로 읽어 INSERT INTO 테이블 (컬럼…) VALUES (…); 문을 만들어 줍니다. 구분자는 첫 줄을 보고 쉼표·세미콜론·탭·세로줄(|) 중에서 자동으로 고르며, 큰따옴표로 감싼 셀 안의 쉼표와 줄바꿈, "" 이스케이프도 처리합니다.

언제 쓰나

  • 엑셀로 받은 코드표나 테스트 데이터를 개발 DB에 몇십 줄 넣어야 할 때
  • 마이그레이션 스크립트나 시드(seed) SQL 파일에 넣을 INSERT 문을 만들 때
  • DB 접속 도구의 가져오기 기능을 쓸 수 없는 환경에서 SQL만 전달해야 할 때

사용 방법

  1. 입력 칸에 헤더가 포함된 CSV를 붙여넣습니다.
  2. '테이블명'을 입력합니다. 비워 두면 tbl이 쓰입니다.
  3. 필요하면 '다중행 INSERT(한 문장)'와 '컬럼명 따옴표(")'를 켭니다.
  4. 결과가 자동으로 갱신되며 [📋 복사]로 클립보드에 담습니다.

결과 해석

기본 예시의 둘째 행 2,김영희,,false는 INSERT INTO users (id, name, age, active) VALUES (2, '김영희', NULL, false);가 됩니다. 정수·소수는 따옴표 없이, true/false는 소문자 그대로, 빈 칸과 null은 NULL, 나머지는 작은따옴표 문자열이 되고 값 속의 '는 ''로 바뀝니다. 다중행 옵션을 켜면 VALUES 뒤에 행들이 쉼표로 이어진 한 문장이 됩니다.

주의할 점

타입은 값 모양만 보고 정합니다. 우편번호 01234나 사번 007처럼 앞자리 0이 의미 있는 값도 숫자로 출력되어, 컬럼이 숫자형이면 0이 사라지고 문자형이면 DB가 암시적 변환을 합니다. 날짜는 문자열로 나가므로 DB의 날짜 형식과 맞는지 확인하세요. 테이블명과 컬럼명은 이스케이프하지 않으니 신뢰할 수 있는 이름만 쓰고, MySQL에서는 큰따옴표 컬럼명이 ANSI_QUOTES 설정 없이는 문자열로 해석된다는 점도 유의하세요.

자주 묻는 질문

수만 줄도 되나요?
브라우저 메모리 안에서는 동작하지만, 대량 적재는 DB의 COPY나 LOAD DATA 같은 전용 기능이 훨씬 빠르고 안전합니다.
열 개수가 모자란 행은요?
헤더보다 짧은 행은 빈 값으로 채워져 해당 컬럼이 NULL로 들어갑니다.
