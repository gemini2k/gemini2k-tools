코드 신택스 하이라이터

코드를 붙여넣으면 색을 입히고, 블로그·문서에 그대로 붙일 수 있는 HTML을 만들어 줍니다.

오픈소스 highlight.js(BSD-3, highlightjs/highlight.js)를 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어집니다.

코드 신택스 하이라이터 사용 안내

무엇을 하는 도구인가

붙여넣은 소스 코드를 highlight.js 11로 토큰 단위로 분석해 키워드·문자열·숫자·주석마다 색을 입히고, 그 결과를 <pre><code class="hljs">…</code></pre> 형태의 HTML로 복사해 주는 도구입니다. 언어를 고르지 않으면 highlight.js의 자동 감지(highlightAuto)가 가장 그럴듯한 언어를 골라 오른쪽에 감지된 언어 이름을 보여 줍니다.

언제 쓰나

  • 기술 블로그나 사내 위키에 코드 블록을 색과 함께 넣고 싶은데 편집기가 하이라이트를 지원하지 않을 때
  • 발표 자료나 문서에 넣을 코드 캡처를 라이트·다크 테마로 미리 비교해 볼 때
  • 출처를 모르는 코드 조각이 어떤 언어인지 대략 확인하고 싶을 때

사용 방법

  1. 입력 칸에 코드를 붙여넣습니다. 입력하는 즉시 아래 미리보기가 갱신됩니다.
  2. '언어'에서 자동 감지 또는 javascript, python, sql, yaml 등 19개 언어 중 하나를 고릅니다. 자동 감지가 틀리면 직접 지정하세요.
  3. '테마'에서 라이트(github) 또는 다크(github-dark)를 고릅니다. 테마는 미리보기 색에만 적용됩니다.
  4. [📋 HTML 복사]를 눌러 하이라이트된 HTML을 클립보드에 담습니다.

결과 해석

언어를 javascript로 두고 const x = 1;을 넣으면 복사되는 HTML 안쪽은 <span class="hljs-keyword">const</span> x = <span class="hljs-number">1</span>;처럼 됩니다. 즉 색 정보가 인라인 스타일이 아니라 hljs-keyword, hljs-string 같은 클래스 이름으로 들어갑니다.

주의할 점

복사한 HTML을 그대로 붙이면 클래스만 있고 색 규칙이 없으므로, 붙여넣을 페이지에 highlight.js 테마 CSS(github.css 등)가 함께 로드돼 있어야 색이 보입니다. 입력한 코드는 한 글자도 바꾸지 않고 그대로 처리하므로, printf("a\n")처럼 문자열 안에 들어 있는 백슬래시 이스케이프도 원래 모양대로 남습니다.짧은 코드는 자동 감지가 엉뚱한 언어를 고르기 쉽습니다.

자주 묻는 질문

목록에 없는 언어도 되나요?
드롭다운에는 19개만 있지만 자동 감지는 번들에 포함된 다른 언어도 후보로 봅니다. 결과가 맞는지는 감지된 언어 표시로 확인하세요.
줄 번호를 붙일 수 있나요?
지원하지 않습니다. 줄 번호가 필요하면 붙여넣을 쪽의 CSS나 플러그인으로 처리해야 합니다.
