목업·더미 데이터 생성기

열과 타입을 정해 가짜 테스트 데이터를 CSV·JSON으로 만듭니다. 개발·테스트·시연용 데이터를 빠르게 채우세요.

📖
사용 방법
  1. 열 이름과 타입(이름·이메일·날짜·숫자·UUID 등)을 정합니다 (＋로 추가)
  2. 행 수와 출력 형식(CSV/JSON)을 고릅니다
  3. '생성' 후 복사하거나 내려받습니다
생성되는 데이터는 무작위 가짜 값입니다(실제 개인정보 아님). 같은 설정이라도 매번 다른 값이 나옵니다. 모든 처리는 브라우저에서만 이루어집니다.

목업·더미 데이터 생성기 사용 안내

무엇을 하는 도구인가

열 이름과 값의 종류를 정해 주면 그 구조대로 가짜 행을 최대 1,000개까지 만들어 CSV나 JSON으로 내줍니다. 값 종류는 순번 ID, 이름, 이메일, 전화번호, 정수, 소수, 날짜, 참/거짓, UUID, 도시, 회사, 문장 12가지입니다. 이름은 흔한 한국 성과 이름을 조합하고, 도시는 국내 주요 시 목록에서 고르는 식으로 한국어 화면 시연에 맞춘 값이 나옵니다.

언제 쓰나

  • 개발 중인 목록 화면에 페이지 넘김·정렬을 확인할 만큼 행을 채워야 할 때
  • 엑셀 업로드 기능을 테스트할 샘플 CSV가 필요할 때
  • 고객 시연이나 교육 자료에 실제 고객 정보를 쓸 수 없을 때
  • API 목업 서버에 넣을 JSON 배열을 빠르게 만들 때

사용 방법

  1. 기본으로 id·name·email·created 네 열이 들어 있습니다. 각 행의 이름 칸과 종류 선택상자를 고치고, 필요 없는 열은 ✕로 지웁니다.
  2. 「＋ 열 추가」로 열을 늘립니다.
  3. 「행 수」(1~1000)와 「형식」(CSV/JSON)을 정하고 「생성」을 누릅니다.
  4. 「복사」 또는 「내려받기」로 결과를 가져갑니다.

결과 해석

값의 범위는 정해져 있습니다. 정수는 0~999, 소수는 소수 둘째 자리까지의 0~100 사이 값, 날짜는 2020~2025년이며 일(日)은 1~28일 안에서만 나옵니다. 전화번호는 010-####-####, 이메일은 user####@example.com처럼 예시용 도메인을 씁니다. UUID는 버전 4 형식이지만 Math.random으로 만든 값이라 테스트용으로만 쓰세요. 순번 ID는 1부터 차례로 늘어납니다.

주의할 점

  • 무작위 값끼리는 관계가 없습니다. 이름과 이메일이 서로 맞지 않고, 이메일·전화번호도 중복될 수 있으니 유일성 제약이 있는 컬럼에는 그대로 넣지 마세요.
  • 열 이름이 같으면 JSON에서는 뒤 열이 앞 열을 덮어씁니다. 열 이름은 서로 다르게 지으세요.
  • 「내려받기」한 CSV는 엑셀에서 한글이 깨지지 않도록 BOM을 붙여 저장하지만, 「복사」한 텍스트에는 BOM이 없습니다.

자주 묻는 질문

같은 데이터를 다시 만들 수 있나요?
안 됩니다. 시드 값을 지정하는 기능이 없어 「생성」을 누를 때마다 값이 바뀝니다. 재현이 필요하면 결과 파일을 저장해 두세요.
만들어진 이름이나 번호가 실존 인물과 같으면요?
흔한 성·이름 조합이라 우연히 겹칠 수는 있지만 실제 인물 정보를 가져온 것이 아닙니다. 외부 공개 자료라면 이 점을 함께 밝혀 두는 편이 안전합니다.
