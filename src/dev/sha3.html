SHA-3 · Keccak 해시 생성기

텍스트의 SHA-3 계열과 이더리움에서 쓰는 Keccak-256 해시를 만들어 줍니다.

오픈소스 js-sha3(MIT, emn178/js-sha3)를 자체 호스팅합니다. 값을 클릭하면 복사됩니다. SHA-3와 Keccak은 패딩이 달라 결과가 다릅니다. 모든 처리는 브라우저에서만 이루어집니다.

SHA-3 · Keccak 해시 생성기 사용 안내

무엇을 하는 도구인가

입력한 텍스트를 UTF-8 바이트로 바꿔 js-sha3 라이브러리로 여덟 가지 해시를 한꺼번에 계산합니다. 표준 SHA-3 계열인 SHA3-224/256/384/512, 이더리움이 쓰는 원래 Keccak 방식의 Keccak-256과 Keccak-512, 출력 길이를 고를 수 있는 SHAKE128(256비트 출력)과 SHAKE256(512비트 출력)입니다. 결과는 소문자 16진수로 나오고, 값을 클릭하면 복사됩니다.

언제 쓰나

  • 스마트 컨트랙트 개발 중 함수 시그니처나 이벤트 이름의 Keccak-256 값을 확인할 때
  • 서버에서 계산한 SHA3-256 값이 맞는지 같은 입력으로 대조할 때
  • 라이브러리가 "SHA3"라고 부르는 함수가 실제로는 Keccak인지 구분이 필요할 때
  • 교육 자료에서 같은 입력이 알고리즘별로 얼마나 다른 값이 되는지 보여 줄 때

사용 방법

  1. 입력란에 해시할 텍스트를 입력합니다. 글자를 바꿀 때마다 표가 다시 계산됩니다.
  2. 표에서 필요한 알고리즘 행의 값을 클릭해 복사합니다.
  3. 비교할 값과 붙여 놓고 대조합니다. 대소문자는 구분하지 않고 보면 됩니다.

결과 해석

입력 abc의 SHA3-256은 3a985da7…11431532이고 Keccak-256은 4e03657a…a12d6c45입니다. 둘 다 같은 Keccak 순열을 쓰지만, 2015년 FIPS 202로 표준화되면서 SHA-3에는 입력 끝에 붙이는 패딩 비트가 달라졌기 때문에 값이 전혀 다릅니다. 이더리움 주소 계산이나 Solidity의 keccak256()과 맞춰야 하면 Keccak-256 행을, 표준 문서에서 SHA3-256을 요구하면 SHA3-256 행을 쓰세요. SHAKE 계열은 출력 길이를 늘리거나 줄일 수 있는 함수라 여기서는 각각 256비트, 512비트로 고정해 보여 줍니다.

주의할 점

  • 입력란 끝에 줄바꿈이나 공백이 하나만 더 있어도 해시가 완전히 바뀝니다. 다른 곳과 값이 다르면 보이지 않는 문자부터 의심하세요.
  • 텍스트만 받습니다. 파일 해시나 16진수 바이트열을 그대로 해시하는 기능은 없습니다. 예를 들어 0x1234를 넣으면 여섯 글자의 문자열로 해시됩니다.
  • 비밀번호 저장에는 SHA-3를 바로 쓰지 말고 bcrypt, Argon2 같은 전용 함수를 쓰세요.

자주 묻는 질문

Node.js의 sha3-256과 결과가 같나요?
Node.js(OpenSSL)의 sha3-256은 FIPS 202 표준이므로 이 표의 SHA3-256 행과 같아야 합니다. Keccak-256과 비교하면 다르게 나옵니다.
입력값이 서버로 전송되나요?
아닙니다. 계산은 브라우저에서만 이루어집니다.
