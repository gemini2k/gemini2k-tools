텍스트 비교 (diff)

두 글을 줄 단위로 비교해 추가·삭제된 부분을 색으로 보여 줍니다. 문서 버전, 코드 변경 확인에.

줄(line) 단위로 가장 긴 공통 부분(LCS)을 찾아 차이를 표시합니다. 초록(+)은 B에만 있는 줄, 빨강(−)은 A에만 있는 줄입니다. 모든 비교는 브라우저에서만 이루어지며 입력은 전송되지 않습니다.

텍스트 비교(diff) 사용 안내

무엇을 하는 도구인가

두 텍스트를 줄 단위로 나눈 뒤 최장 공통 부분열(LCS)을 구해, A에만 있는 줄은 빨강(−), B에만 있는 줄은 초록(+), 양쪽에 같은 줄은 그대로 보여 줍니다. 결과 위에는 추가·삭제·같은 줄 수가 요약됩니다. 별도 라이브러리 없이 페이지 안의 짧은 스크립트로 계산합니다.

언제 쓰나

  • 운영 서버와 개발 서버의 설정 파일(nginx.conf, application.yml 등)이 어디가 다른지 볼 때
  • Git 저장소 밖에 있는 문서나 SQL 스크립트의 두 버전을 비교할 때
  • 배포 전후로 뽑은 패키지 목록이나 환경변수 목록에서 바뀐 항목을 찾을 때

사용 방법

  1. 왼쪽 '원본 (A)'에 이전 내용, 오른쪽 '비교 (B)'에 새 내용을 붙여넣습니다.
  2. 필요하면 '줄 끝 공백 무시'(기본 켜짐)와 '대소문자 무시'를 조정합니다.
  3. [비교하기]를 누르면 요약과 줄별 결과가 나옵니다. 이후 옵션을 바꾸면 자동으로 다시 비교합니다.

결과 해석

A가 a / b / c 세 줄, B가 a / B / c / d 네 줄이면 결과는 a(같음), − b, + B, c(같음), + d 순서로 나오고, 요약은 추가 2줄·삭제 1줄·같은 줄 2줄입니다. '대소문자 무시'를 켜면 b와 B가 같은 줄로 취급되어 추가 1줄·삭제 0줄이 됩니다. 한 줄 안에서 일부만 바뀌어도 줄 전체가 삭제+추가 한 쌍으로 표시됩니다.

주의할 점

Windows(CRLF)와 리눅스(LF) 파일을 비교하면 줄 끝의 보이지 않는 CR 때문에 모든 줄이 다르게 나올 수 있는데, '줄 끝 공백 무시'를 켜 두면 이 차이는 무시됩니다. 줄 앞의 들여쓰기 차이는 무시하지 않습니다. 계산량이 두 텍스트 줄 수의 곱에 비례하므로 수만 줄짜리 파일끼리 비교하면 브라우저가 매우 느려지거나 메모리 부족으로 멈출 수 있습니다.
