XML 포매터

복잡한 XML을 보기 좋게 들여쓰기하거나 한 줄로 압축하고, 형식 오류를 확인합니다.

📖
사용 방법
  1. XML(RSS·SVG·설정 파일 등)을 붙여넣습니다
  2. '정렬'로 들여쓰기, '압축'으로 한 줄로 만듭니다
  3. 형식 오류가 있으면 위치를 안내합니다. '복사'로 결과를 가져가세요
↓
브라우저의 표준 XML 파서로 형식을 검사한 뒤 다시 직렬화합니다. 주석·CDATA는 보존됩니다. 텍스트 내용의 공백은 정렬 시 다듬어질 수 있습니다. 모든 처리는 브라우저에서만 이루어집니다.

XML 포매터 사용 안내

무엇을 하는 도구인가

붙여 넣은 XML을 브라우저 내장 XML 파서(DOMParser)로 먼저 읽어 형식이 올바른지 확인한 뒤, 「정렬(Beautify)」이면 요소마다 줄을 나누고 단계별로 들여 써서 다시 출력하고, 「압축(Minify)」이면 태그 사이의 공백만 지워 한 줄로 만듭니다. 태그가 닫히지 않았거나 속성 따옴표가 빠진 문서는 결과 대신 파서가 알려 준 오류 위치를 보여 주고, 문제가 없으면 「형식이 올바릅니다」가 표시됩니다.

언제 쓰나

  • 공공데이터 API나 SOAP 응답이 한 줄로 와서 구조를 읽기 어려울 때
  • RSS 피드, sitemap.xml을 올리기 전에 태그 짝이 맞는지 확인할 때
  • 스프링·메이븐 설정 파일(pom.xml 등)의 들여쓰기를 정리할 때
  • 전송 용량을 줄이려고 XML의 불필요한 줄바꿈을 걷어 낼 때

사용 방법

  1. 입력란에 XML을 붙여 넣습니다.
  2. 「들여쓰기」에서 스페이스 2, 스페이스 4, 탭 중 하나를 고릅니다.
  3. 「정렬(Beautify)」 또는 「압축(Minify)」을 누릅니다. 입력만 바꾸고 버튼을 누르지 않으면 결과는 갱신되지 않습니다.
  4. 결과를 확인하고 「복사」를 누릅니다.

결과 해석

기본 예제인 한 줄짜리 RSS는 정렬하면 <rss version="2.0"> 아래 <channel>이 한 단계, 그 안의 <title>과 <item>이 두 단계 들여 써지고, 글자만 담은 요소는 <title>첫 글</title>처럼 한 줄에 유지됩니다. 자식이 없는 요소는 <tag/>로 줄여 씁니다. 원문 첫머리에 XML 선언이 있으면 encoding·standalone 값까지 원문 그대로 맨 위에 두고, 선언이 없으면 새로 만들어 붙이지 않습니다.

주의할 점

  • DOCTYPE과 <?xml-stylesheet?> 같은 처리 명령은 원래 위치에 그대로 남습니다. 속성 값은 파서가 읽은 뒤 다시 이스케이프하므로 a="x &amp; y"는 그대로 유지되지만, 작은따옴표로 감싼 속성은 큰따옴표로 바뀌고 &#65; 같은 문자 참조는 실제 글자로 풀려 나옵니다.
  • 글자와 하위 요소가 섞인 요소(혼합 콘텐츠)는 글자 앞뒤 공백이 잘리고 줄이 나뉩니다. 공백이 의미를 갖는 문서에는 쓰지 마세요.
  • 압축은 태그 사이에 공백만 있는 부분을 지울 뿐, 글자가 들어 있는 텍스트·CDATA·속성 값 안의 공백과 줄바꿈은 건드리지 않습니다. 다만 <b>굵게</b> <i>기울임</i>처럼 요소 사이의 공백 한 칸도 지워지니 혼합 콘텐츠 문서는 결과를 확인하세요. 주석은 지우지 않습니다.
  • 오류 문구는 브라우저마다 표현이 다르며 앞부분 160자까지만 보여 줍니다.

자주 묻는 질문

XSD 스키마로 검증해 주나요?
아닙니다. 태그 짝과 문법이 맞는지(well-formed)만 확인하며, 스키마나 DTD 기준 유효성 검사는 하지 않습니다.
XML이 서버로 전송되나요?
아닙니다. 파싱과 정렬은 브라우저에서만 이루어집니다.
