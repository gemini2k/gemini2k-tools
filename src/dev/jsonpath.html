JSON 경로 추출기

JSON에서 점 표기 경로로 원하는 값만 뽑아냅니다. API 응답을 탐색하거나 디버깅할 때 쓰세요.

📖
사용 방법
  1. JSON을 붙여 넣습니다
  2. 경로를 입력합니다. 예: items[0].name, users.*.email
  3. 일치하는 값이 아래에 표시됩니다(여러 개면 배열로)

예시: users[0].name · users[*].email · users.*.name

점(.)으로 키를, 대괄호([0])로 배열 인덱스를 지정합니다. * 또는 [*]는 배열·객체의 모든 항목을 펼칩니다. 결과가 여러 개면 배열로 모아 보여 줍니다. 모든 처리는 브라우저에서만 이루어집니다.

JSON 경로 추출기 사용 안내

무엇을 하는 도구인가

JSON을 붙여넣고 users[0].name 같은 점 표기 경로를 입력하면 그 위치의 값만 꺼내 보여 줍니다. 점(.)으로 객체 키를, 대괄호 숫자([0])로 배열 위치를 지정하고, *나 [*]를 쓰면 그 단계의 모든 원소(객체라면 모든 값)로 펼칩니다. 외부 라이브러리 없이 페이지 안의 간단한 해석기로 동작하며, 표준 JSONPath(RFC 9535) 전체 문법을 구현한 것은 아닙니다.

언제 쓰나

  • 긴 API 응답에서 필요한 필드 하나가 어디에 있고 값이 무엇인지 빨리 확인할 때
  • 목록 응답에서 id나 email만 모아 다른 곳에 붙여넣을 때
  • 프런트엔드 코드에서 쓸 접근 경로(data.items[0].title)가 맞는지 미리 확인할 때

사용 방법

  1. 'JSON' 칸에 데이터를 붙여넣습니다. [샘플]을 누르면 예시 데이터가 들어갑니다.
  2. 경로 칸에 경로를 입력합니다. 아래 예시 경로를 클릭하면 바로 입력됩니다. 경로를 비우면 JSON 전체가 정리되어 나옵니다.
  3. '결과'를 확인하고 [📋 복사]로 가져갑니다.

결과 해석

처음 열었을 때의 샘플에서 users[*].name은 ["홍길동", "김영희"], users[0].name은 "홍길동"입니다. 일치하는 값이 여러 개면 배열로 모으고, 하나면 그 값만 보여 주므로 결과가 배열인지 단일 값인지는 원본 구조가 아니라 일치 개수에 따라 달라집니다. 일치하는 값이 없으면 일치 없음 문구가 나옵니다.

주의할 점

표준 JSONPath의 루트 기호 $는 붙여도 되고 생략해도 됩니다($.users = users). 재귀 탐색 ..(예: $..email은 깊이와 상관없이 모든 email), 음수 인덱스 [-1](마지막 원소), 따옴표 키 ['first name']를 지원합니다. 필터식 [?(@.age > 20)], 슬라이스 [0:2], 여러 키 선택 ['a','b']는 지원하지 않으며, 해석할 수 없는 문법을 넣으면 결과 대신 문제가 시작된 위치를 오류로 보여 줍니다. 조건 검색이 필요하면 JSONata 도구를 쓰세요.

자주 묻는 질문

점이나 공백이 들어간 키는 어떻게 지정하나요?
대괄호와 따옴표로 감싸면 됩니다. 예: users[0]['first name'], config["a.b"].
