마크다운 목차(TOC) 생성기

마크다운의 제목(#)을 읽어 GitHub 호환 앵커가 달린 목차를 만들어 줍니다.

코드 블록(```) 안의 #은 제외합니다. 앵커는 GitHub 규칙(소문자화, 공백→하이픈, 특수문자 제거, 한글 유지)을 따릅니다. 모든 처리는 브라우저에서만 이루어집니다.

마크다운 목차(TOC) 생성기 사용 안내

무엇을 하는 도구인가

마크다운 원고에서 #으로 시작하는 제목 줄을 읽어, 각 제목으로 이동하는 링크가 달린 목록형 목차를 만듭니다. 링크 주소(앵커)는 GitHub가 제목에 붙이는 id 규칙을 흉내 내어 소문자로 바꾸고, 공백을 하이픈으로 바꾸고, 문장부호를 지우되 한글은 그대로 둡니다. 펜스 코드 블록(```) 안에 있는 # 주석 줄은 제목으로 보지 않습니다.

언제 쓰나

  • 길어진 README 맨 위에 목차를 넣어 설치·사용법·라이선스로 바로 이동하게 할 때
  • 사내 위키나 기술 문서의 장·절 구성을 한눈에 점검할 때
  • 제목을 고친 뒤 기존 목차 링크가 끊겼는지 다시 만들어 비교할 때
  • 블로그 원고의 제목 단계(H2·H3)가 뒤섞이지 않았는지 확인할 때

사용 방법

  1. 입력란에 마크다운 원고 전체를 붙여 넣습니다.
  2. 「최소 레벨」과 「최대 레벨」로 목차에 넣을 제목 범위를 정합니다. 기본값은 H2~H3입니다.
  3. 아래에 만들어진 목차를 확인하고 「복사」를 누릅니다.
  4. 원고의 원하는 위치(보통 첫 제목 아래)에 붙여 넣습니다.

결과 해석

기본 예제에서는 # 프로젝트 이름이 최소 레벨(H2)보다 높아 빠지고, - [소개](#소개), - [설치 방법](#설치-방법) 순으로 나옵니다. H3인 「요구 사항」은 두 칸 들여 써서 「설치 방법」의 하위 항목이 됩니다. 같은 제목이 두 번 나오면 두 번째부터 앵커 끝에 -1, -2가 붙어 GitHub처럼 구분됩니다. 제목 안의 **, ` 같은 강조 기호는 목차 글자에서 지웁니다.

주의할 점

  • # 뒤에 공백이 있는 제목만 인식합니다. 밑줄(===, ---)로 표시한 제목이나 물결표(~~~) 코드 블록은 처리하지 않습니다.
  • 앵커 규칙은 플랫폼마다 다릅니다. GitLab, 노션, 정적 사이트 생성기에 올릴 문서라면 링크 몇 개를 눌러 실제로 이동하는지 확인하세요.
  • 제목 안에 링크 문법이 있으면 목차 링크가 이중으로 겹쳐 깨질 수 있습니다.

자주 묻는 질문

최대 레벨에 H5가 없는데요?
선택지는 H2·H3·H4·H6입니다. H5까지 넣고 싶다면 H6을 고르면 H5가 함께 포함됩니다.
원고를 수정하면 목차도 바뀌나요?
입력란을 고치는 즉시 다시 만들어집니다. 다만 원고에 이미 붙여 넣은 목차는 자동으로 바뀌지 않으니 다시 복사해 교체해야 합니다.
