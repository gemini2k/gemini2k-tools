.env ↔ JSON 변환기

.env 환경변수 파일과 JSON을 서로 변환합니다.

↓
.env → JSON: KEY=VALUE 라인을 파싱하고 # 주석·빈 줄을 무시하며 따옴표를 제거합니다. JSON → .env: 값에 공백·특수문자가 있으면 따옴표로 감쌉니다. 모든 처리는 브라우저에서만 이루어집니다.

.env ↔ JSON 변환기 사용 안내

무엇을 하는 도구인가

KEY=VALUE 형식의 .env 파일을 JSON 객체로, JSON 객체를 다시 .env 줄 목록으로 바꿉니다. .env → JSON에서는 빈 줄과 #으로 시작하는 줄을 건너뛰고, 값 양쪽을 감싼 큰따옴표나 작은따옴표를 벗겨 냅니다. JSON → .env에서는 값에 공백, #, 따옴표, =가 있으면 큰따옴표로 감쌉니다.

언제 쓰나

  • 로컬 .env 내용을 AWS Lambda·Cloudflare Workers 같은 곳의 JSON 설정이나 IaC 변수로 옮길 때
  • JSON으로 받은 설정 묶음을 docker-compose의 env_file용 .env로 만들 때
  • 두 환경의 .env를 JSON으로 바꿔 JSON 비교 도구에 넣어 차이를 볼 때

사용 방법

  1. 위쪽에서 [.env → JSON] 또는 [JSON → .env] 방향을 고릅니다. 방향을 바꾸면 입력 칸이 해당 예시로 바뀌니 먼저 방향을 고른 뒤 붙여넣으세요.
  2. 입력 칸에 내용을 붙여넣으면 아래에 결과가 바로 나옵니다.
  3. JSON 문법이 틀리면 빨간 오류 문구가 표시됩니다. [📋 복사]로 결과를 가져갑니다.

결과 해석

기본 예시를 변환하면 {"DB_HOST": "localhost", "DB_PORT": "5432", "API_KEY": "se cret-123", "DEBUG": "true"}가 됩니다. .env에는 타입 개념이 없으므로 숫자나 true도 모두 문자열로 나옵니다. 반대로 JSON → .env에서 "DEBUG": true는 DEBUG=true, null은 빈 값, 중첩 객체나 배열은 JSON 문자열을 따옴표로 감싼 한 줄이 됩니다.

주의할 점

dotenv 문법 중 자주 쓰는 부분만 처리합니다. export KEY=value처럼 앞에 export가 붙은 줄은 export를 떼고 읽고, 값 뒤에 공백을 두고 붙인 # 주석은 버립니다. URL=a#b처럼 공백 없이 붙은 #이나 따옴표 안의 #은 값으로 남습니다. 여러 줄 값과 \n 같은 이스케이프, ${VAR} 변수 치환은 해석하지 않습니다. 같은 키가 두 번 나오면 마지막 값이 남습니다. 비밀번호·API 키가 들어 있는 파일을 다룰 때는 결과를 복사한 뒤 입력 칸을 비워 두세요.

자주 묻는 질문

JSON 최상위가 배열이면요?
객체를 전제로 만든 기능이라 배열을 넣으면 인덱스 번호가 키가 된 줄이 나옵니다. 최상위는 객체로 넣으세요.
입력한 값이 서버로 가나요?
변환은 페이지 안의 스크립트로만 이루어지며 입력 내용을 전송하지 않습니다.
