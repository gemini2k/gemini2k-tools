JSON → TypeScript 인터페이스

JSON 예시를 붙여넣으면 TypeScript interface 타입을 자동으로 만들어 줍니다.

↓
중첩 객체는 별도 interface로 분리하고, 배열은 요소 타입을 추론합니다. null·혼합 타입은 적절히 union/any로 처리합니다. 모든 처리는 브라우저에서만 이루어집니다.

JSON → TypeScript 인터페이스 사용 안내

무엇을 하는 도구인가

예시 JSON 하나를 보고 TypeScript export interface 선언을 만들어 줍니다. 값이 숫자면 number, 문자열이면 string, 참/거짓이면 boolean, 중첩 객체는 키 이름을 대문자로 시작하게 바꾼 별도 interface로 뽑아냅니다. 배열은 요소들의 타입을 모아 string[]이나 (number | string)[]처럼 표시합니다.

언제 쓰나

  • 백엔드 API 응답 예시를 받아 프런트엔드 타입 정의 초안을 만들 때
  • 외부 서비스 웹훅 페이로드에 타입을 붙여 자동완성을 쓰고 싶을 때
  • 설정 JSON 파일을 읽는 코드에 타입을 붙일 때

사용 방법

  1. 입력 칸에 실제 응답과 같은 모양의 JSON을 붙여넣습니다.
  2. '루트 이름'에 최상위 타입 이름을 적습니다(기본 Root).
  3. 입력하면 결과가 바로 갱신되며, [📋 복사]로 가져가 .ts 파일에 붙입니다.

결과 해석

기본 예시는 Root에 id: number;, name: string;, tags: string[];, profile: Profile;, score?: null;이 생기고, 그 아래 Profile interface에 age: number;, vip: boolean;가 따로 만들어집니다. 값이 null인 필드는 선택 속성 ?와 null 타입으로만 나오므로, 실제 타입이 무엇인지 알면 score?: number | null;처럼 직접 고쳐야 합니다. 최상위가 배열이면 모든 요소를 합쳐 RootItem을 만들고 export type Root = RootItem[];을 덧붙입니다.

주의할 점

예시 한 개에서 추론하므로 예시에 없는 필드나 때때로 빠지는 필드는 반영되지 않습니다. 배열 안 객체들은 모든 요소의 키를 합쳐 interface 하나로 만들고, 일부 요소에만 있는 키는 ?가 붙은 선택 속성이 됩니다. 서로 다른 곳에 같은 키 이름의 객체가 있는데 모양이 다르면 User, User2처럼 번호를 붙여 따로 만들고, 모양이 같으면 하나를 함께 씁니다. 빈 배열은 any[]가 됩니다. 결과는 초안으로 보고 API 문서와 대조해 다듬으세요.
