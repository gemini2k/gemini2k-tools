JSON5 ↔ JSON 변환기

주석·홑따옴표·후행 쉼표가 들어간 JSON5를 표준 JSON으로 바꾸고 검증합니다.

↓
오픈소스 JSON5(MIT, json5/json5)를 자체 호스팅합니다. JSON5는 주석·홑따옴표·후행 쉼표·16진수 등을 허용하는 JSON 확장입니다. 모든 처리는 브라우저에서만 이루어집니다.

JSON5 ↔ JSON 변환기 사용 안내

무엇을 하는 도구인가

JSON5 2.x 라이브러리로 입력을 읽어 표준 JSON으로 다시 씁니다. JSON5는 사람이 손으로 쓰기 편하도록 JSON을 넓힌 형식으로, //·/* */ 주석, 따옴표 없는 키, 작은따옴표 문자열, 마지막 요소 뒤의 쉼표, 0xFF 같은 16진수, +1, .5, Infinity, NaN을 허용합니다. 읽기에 성공하면 "✓ 유효한 JSON5" 표시와 함께 결과가 나오고, 실패하면 줄·열 위치가 담긴 오류가 나옵니다.

언제 쓰나

  • 주석이 달린 설정 파일(.babelrc, tsconfig.json 류, json5 설정)을 표준 JSON만 받는 도구에 넘길 때
  • 자바스크립트 객체 리터럴을 복사해 와서 API 요청 본문용 JSON으로 바꿀 때
  • 손으로 쓴 JSON5 설정에 문법 오류가 있는지 확인할 때

사용 방법

  1. 입력 칸에 JSON5(또는 그와 비슷한 객체 리터럴)를 붙여넣습니다. 입력하는 동안 들여쓰기 2칸 JSON으로 자동 변환됩니다.
  2. 한 줄 JSON이 필요하면 [압축]을 누르고, 다시 펼치려면 [→ 표준 JSON]을 누릅니다.
  3. [📋 복사]로 결과를 가져갑니다.

결과 해석

기본 예시는 {"name": "gemini2k", "tags": ["a", "b"], "hex": 255}가 됩니다. 키에 큰따옴표가 붙고, 후행 쉼표가 없어지고, 0xFF가 10진수 255로 바뀌며, 주석은 사라집니다. 결과는 어떤 JSON 파서로도 읽을 수 있는 표준 형식입니다.

주의할 점

표준 JSON에는 Infinity와 NaN이 없어서 이런 값은 결과에서 null로 바뀝니다. 주석은 되살릴 수 없으므로 원본 JSON5 파일은 지우지 마세요. 함수, undefined, 정규식 같은 자바스크립트 문법은 JSON5에서도 허용되지 않아 오류가 납니다. 이 페이지는 JSON5 → JSON 방향만 변환하며, 표준 JSON을 넣으면 그대로 정리되어 나옵니다.

자주 묻는 질문

tsconfig.json 주석도 이걸로 지우면 되나요?
됩니다. 다만 tsconfig는 TypeScript가 원래 주석을 허용하므로, 다른 도구에 넘기는 경우가 아니라면 바꿀 필요가 없습니다.
여러 줄 문자열도 되나요?
JSON5는 줄 끝에 백슬래시를 붙여 문자열을 다음 줄로 잇는 문법을 허용하며, 결과에서는 한 줄 문자열이 됩니다.
