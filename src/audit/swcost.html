SW 사업대가·투입공수(MM)

기능점수 기반 개발원가와 투입 인월(MM)을 추정합니다.

FP단가는 예시 기본값이며 매년 고시되는 'SW사업 대가산정 가이드' 값으로 바꿔 쓰세요. 보정계수(규모·연계·성능 등)는 사업 특성에 맞게 조정합니다. 참고용 추정입니다.

SW 사업대가·투입공수 계산기 사용 안내

무엇을 하는 도구인가

기능점수(FP, Function Point)는 개발할 소프트웨어의 규모를 기능 기준으로 잰 값입니다. 공공 SW 개발사업에서는 이 기능점수에 단가와 보정계수를 곱해 개발원가를 추정하는 방식이 널리 쓰입니다. 이 계산기는 기능점수, FP 단가, 보정계수, 생산성(FP/MM)을 넣으면 개발원가, 투입공수(MM, 인월), FP당 원가를 바로 계산합니다.

언제 쓰나

  • 사업 기획 단계에서 기능점수 산정 결과로 개발비 예산 규모를 가늠할 때
  • 보정계수를 바꿔 가며 예산이 얼마나 달라지는지 민감도를 볼 때
  • 수행사 제안의 투입 인력 규모가 기능점수에 비해 지나치게 적거나 많은지 감리에서 비교할 때
  • FP 단가가 갱신된 뒤 기존 산정 결과를 다시 계산할 때

사용 방법

  1. "기능점수(FP)"에 별도로 산정한 기능점수 합계를 넣습니다.
  2. "FP 단가(원)"는 예시 값이 들어 있으므로, 해당 연도 SW사업 대가산정 가이드에 공표된 값으로 바꿔 넣습니다.
  3. "보정계수"에 규모·연계 복잡성·성능 요구 등을 반영한 값을 넣습니다. 보정 없이 보려면 1.0으로 둡니다.
  4. "생산성(FP/MM)"에 1인월당 처리할 수 있다고 보는 기능점수를 넣습니다. 조직 실적치가 있으면 그 값을 쓰세요.

결과 해석

계산식은 개발원가 = FP × 단가 × 보정계수, 투입공수 = FP ÷ 생산성, FP당 원가 = 단가 × 보정계수입니다.

화면 기본값(FP 500, 단가 553,000원, 보정 1.0, 생산성 20)이면 개발원가 276,500,000원, 투입공수 25.0MM, FP당 원가 553,000원이 나옵니다. 보정계수를 1.15로 올리면 개발원가는 317,975,000원으로 늘지만 투입공수는 25.0MM 그대로입니다. 이 계산기에서 공수는 기능점수와 생산성만으로 정해지기 때문입니다. 예를 들어 사업기간이 5개월이면 평균 5명 정도가 상주해야 한다는 계산이 됩니다.

주의할 점

  • 기본 FP 단가는 화면 시연용 예시입니다. 실제 예산 산정에는 반드시 최신 공표 단가를 확인해 넣으세요.
  • 기능점수 자체를 세 주지는 않습니다. 기능점수 산정은 별도 산정 결과를 입력해야 합니다.
  • 개발원가만 계산하며, 직접경비·이윤·부가가치세, HW·상용SW 구매비, 감리비 등은 포함하지 않습니다.
  • 보정계수 0이나 생산성 0을 넣으면 1로 처리되니 빈칸 입력에 주의하세요.

자주 묻는 질문

생산성 20 FP/MM은 표준값인가요?
아닙니다. 화면 예시일 뿐이며 언어, 개발 방식, 조직 숙련도에 따라 크게 다릅니다. 과거 사업의 실적(완료 FP ÷ 실제 투입 MM)을 쓰는 것이 가장 현실적입니다.
투입공수를 인건비 단가로 곱하면 원가와 같아야 하나요?
두 방식은 산정 근거가 달라 일치하지 않는 것이 보통입니다. 큰 차이가 나면 기능점수, 생산성, 보정계수 가정 중 어느 쪽이 비현실적인지 점검하는 신호로 보세요.
