조합 테스트 케이스 생성

파라미터별 값을 입력하면 모든 조합(곱집합)을 표로 만듭니다.

한 줄에 파라미터: 값1, 값2, 값3 형식으로 입력합니다. 조합 수 = 각 값 개수의 곱이므로 폭증 시 페어와이즈를 사용하세요. 모든 처리는 브라우저에서만 이루어집니다.

조합 테스트 케이스 생성 도구 사용 안내

무엇을 하는 도구인가

테스트에 영향을 주는 조건(파라미터)과 각 조건이 가질 수 있는 값을 적으면, 가능한 모든 경우의 수를 빠짐없이 나열한 표를 만들어 줍니다. 수학적으로는 곱집합(데카르트 곱)입니다. 브라우저 3종, 운영체제 3종, 네트워크 2종처럼 환경 조건이 겹치는 호환성 테스트에서 손으로 표를 만들다 한두 조합을 빠뜨리는 일을 막아 줍니다.

언제 쓰나

  • 웹 서비스의 브라우저·OS·해상도 호환성 테스트 매트릭스를 짤 때
  • 권한 등급 × 메뉴 × 처리 상태처럼 업무 조건이 겹치는 기능의 테스트 케이스 목록을 뽑을 때
  • 설정 옵션이 몇 개 안 되는 배치 프로그램에서 옵션 조합 전체를 시험해야 할 때
  • 감리 중 테스트 계획서의 환경 조합 수가 실제 경우의 수와 맞는지 확인할 때

사용 방법

  1. 입력란에 한 줄에 하나씩 "파라미터: 값1, 값2, 값3" 형식으로 적습니다. 콜론(:) 앞이 파라미터 이름, 뒤가 쉼표로 구분한 값입니다.
  2. [조합 생성]을 누르면 옆에 총 조합 수가 표시되고 아래에 번호가 매겨진 표가 나옵니다.
  3. [CSV]를 누르면 combos.csv로 내려받아 테스트 관리 도구나 엑셀에 붙일 수 있습니다.

결과 해석

조합 수는 각 파라미터 값 개수의 곱입니다. 기본 예시(브라우저 3, OS 3, 네트워크 2)는 3 × 3 × 2 = 18개 케이스가 나옵니다. 표는 마지막 줄의 파라미터가 가장 빨리 바뀌는 순서로 정렬되어 있어 1번은 Chrome·Windows·WiFi, 2번은 Chrome·Windows·LTE입니다. 여기에 해상도 4종을 더하면 72개로 늘어나는 것처럼 조건이 하나 늘 때마다 케이스가 곱으로 불어나므로, 표를 받아 들고 실제로 의미 없는 조합(예: Safari와 Android)을 먼저 걸러내는 것이 실무 순서입니다.

주의할 점

조합이 5,000개를 넘으면 생성을 막고 안내 문구를 띄웁니다. 화면 표는 앞의 500행까지만 보여 주지만 CSV에는 전체가 들어갑니다. 이 도구는 모든 조합을 만들 뿐 조합을 줄여 주지는 않습니다. 대부분의 결함은 두 조건의 조합에서 드러난다는 경험칙에 따라 모든 값 쌍이 한 번 이상 나오도록 케이스를 줄이는 페어와이즈 기법이 있는데, 그 계산은 별도 도구가 필요합니다. 또 "macOS에서는 Edge 제외" 같은 제약 조건을 적용하는 기능이 없으므로 불가능한 조합은 직접 지워야 합니다. 값에 쉼표가 들어가면 두 값으로 나뉘니 다른 표기로 바꿔 넣으세요.

자주 묻는 질문

콜론이 없는 줄은 어떻게 처리되나요?
파라미터로 인식하지 않고 무시합니다. 메모를 남기고 싶다면 콜론 없이 적으면 됩니다.
페어와이즈로 줄이면 몇 개가 되나요?
값 개수가 가장 많은 두 파라미터 값 수의 곱이 하한입니다. 기본 예시라면 3 × 3 = 9개 이상이 필요해 18개에서 절반 가까이 줄일 수 있습니다.
