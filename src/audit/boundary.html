경계값·동등분할 도우미

입력 범위로 경계값(BVA)·동등분할(EP) 테스트 값을 만듭니다.

경계값 분석은 경계 주변(min−1, min, min+1 …)에서 결함이 자주 발생한다는 점을, 동등분할은 같은 처리 그룹에서 대표값 하나만 테스트한다는 점을 활용합니다.

경계값·동등분할 도우미 사용 안내

무엇을 하는 도구인가

숫자 입력 항목의 허용 범위를 넣으면 블랙박스 테스트의 기본 기법인 경계값 분석(BVA)과 동등분할(EP)에 쓸 테스트 값을 뽑아 줍니다. "1 이상 100 이하"라는 조건을 코드로 옮길 때 <와 <=를 헷갈리거나 마지막 값 하나를 빠뜨리는 실수가 흔한데, 이런 결함은 범위 한가운데가 아니라 양 끝에서 드러납니다. 도구는 하한·상한 바로 바깥과 안쪽 값, 중간값을 유효/무효로 구분해 표로 보여 줍니다.

언제 쓰나

  • 단위 테스트나 통합 테스트 케이스를 작성하면서 수량, 나이, 금액, 페이지 크기 같은 입력 검증 로직의 시험 값을 정할 때
  • 감리 시 테스트 설계서를 보고 경계 바깥 값(무효 값) 케이스가 빠지지 않았는지 대조할 때
  • 요구사항의 "최대 50자", "1~12월" 같은 조건을 시험 데이터로 바꿔 테스터에게 넘길 때
  • 소수 단위 금액(0.01원 단위 등)처럼 증분이 1이 아닌 범위의 경계를 확인할 때

사용 방법

  1. [최소값]과 [최대값]에 허용 범위의 양 끝을 넣습니다. 두 값 모두 포함되는 닫힌 구간으로 간주합니다.
  2. [증분(단위)]에 값이 바뀌는 최소 단위를 넣습니다. 정수 입력이면 1, 소수 둘째 자리까지 받는 금액이면 0.01입니다.
  3. 입력하는 즉시 아래에 경계값 분석 표와 동등분할 대표값 표가 갱신됩니다. 최소가 최대보다 크면 안내 문구가 나옵니다.

결과 해석

경계값 표에는 일곱 개 값이 나옵니다. 최소−증분과 최대+증분은 빨간색 무효 값으로, 거부되어야 정상입니다. 최소, 최소+증분, 중간값, 최대−증분, 최대는 초록색 유효 값으로, 받아들여져야 합니다. 기본값 1~100, 증분 1이면 0, 1, 2, 51, 99, 100, 101이 나옵니다. 중간값은 (1 + 100) ÷ 2 = 50.5를 반올림한 51입니다. 동등분할 표는 범위를 하한 미만, 범위 안, 상한 초과 세 그룹으로 나누고 그룹마다 대표값 하나(0, 51, 101)를 제시합니다. 같은 그룹 안의 값은 프로그램이 똑같이 처리한다고 보고 하나만 시험하는 방식입니다.

주의할 점

이 도구는 단일 숫자 범위 하나만 다룹니다. 등급별로 처리가 달라지는 구간(예: 0~59 불합격, 60~100 합격)이 있으면 구간마다 따로 넣어야 하고, 문자열 길이·날짜·여러 입력의 조합 조건은 직접 설계해야 합니다. 중간값은 정수로 반올림되므로 소수 범위에서는 필요에 맞게 바꿔 쓰세요. 소수 증분은 브라우저의 부동소수점 계산 때문에 끝자리가 0.30000000000000004처럼 보일 수 있습니다. 빈칸, 문자, 음수 기호만 입력 같은 비정상 입력 케이스는 별도로 추가해야 합니다.

자주 묻는 질문

경계 바로 안쪽 값(최소+1, 최대−1)까지 시험할 필요가 있나요?
2값 방식은 경계와 바로 바깥만, 3값 방식은 안쪽 값까지 시험합니다. 이 도구는 3값 방식에 중간값을 더한 구성이라 필요 없는 값은 빼고 쓰면 됩니다.
최소와 최대가 같으면 어떻게 되나요?
허용 값이 하나뿐인 범위로 보고 계산합니다. 이때 최소+증분은 사실상 범위를 벗어나므로 표의 유효 표시를 그대로 믿지 말고 판단해야 합니다.
