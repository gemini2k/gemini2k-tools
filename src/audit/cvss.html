CVSS 3.1 점수 계산기

취약점의 기본 메트릭으로 CVSS 3.1 기본 점수와 심각도를 산출합니다.

FIRST CVSS v3.1 기본점수(Base Score) 공식 기준입니다. 시간·환경 지표는 제외한 기본 평가입니다.

CVSS 3.1 점수 계산기 사용 안내

무엇을 하는 도구인가

CVSS(Common Vulnerability Scoring System)는 FIRST가 관리하는 취약점 심각도 평가 체계입니다. 이 도구는 그중 v3.1의 기본 메트릭(Base Metrics) 8개를 고르면 기본 점수(0.0~10.0), 심각도 등급, 벡터 문자열을 바로 계산합니다. 취약점 진단 결과를 "높음/낮음" 같은 감으로 적는 대신, 공격 조건과 피해 범위를 항목별로 따져 같은 기준으로 비교할 수 있게 해 줍니다.

언제 쓰나

  • 모의해킹이나 웹 취약점 진단 결과 보고서에 항목별 위험도를 근거와 함께 적어야 할 때
  • CVE 공지에 나온 벡터 문자열의 각 항목이 무슨 뜻인지 하나씩 맞춰 보며 이해할 때
  • 여러 취약점의 조치 우선순위를 정하면서 같은 기준으로 점수를 매길 때
  • 보안 점검 결과를 검토하면서 진단 업체가 매긴 점수가 선택한 메트릭과 맞는지 검산할 때

사용 방법

  1. [공격 경로(AV)]에서 공격자가 어디서 공격할 수 있는지 고릅니다. 인터넷에서 바로 가능하면 네트워크, 같은 망 안이어야 하면 인접, 시스템에 로그인해야 하면 로컬, 기기를 직접 만져야 하면 물리입니다.
  2. [공격 복잡도(AC)], [필요 권한(PR)], [사용자 상호작용(UI)]으로 공격 성공 조건을 정합니다. 피해자가 링크를 눌러야 성공한다면 UI는 필요(R)입니다.
  3. [범위(S)]는 취약한 구성요소를 넘어 다른 구성요소까지 영향이 미치면 변경됨(C)을 고릅니다. 웹 페이지의 XSS가 사용자 브라우저에 영향을 주는 경우가 대표적입니다.
  4. [기밀성(C)], [무결성(I)], [가용성(A)]에서 피해 정도를 고르면 아래에 점수와 벡터가 갱신됩니다.

결과 해석

심각도 구간은 CVSS v3.1 표준을 따릅니다. 0.0 없음, 0.1~3.9 낮음, 4.0~6.9 중간, 7.0~8.9 높음, 9.0~10.0 심각입니다. 처음 열었을 때의 기본 선택(네트워크·낮음·없음·불필요·변경없음·높음·높음·높음)은 인증 없이 원격에서 시스템을 완전히 장악하는 경우로 9.8 심각이 나옵니다. 흔한 반사형 XSS를 예로 들면 AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N으로 6.1 중간입니다. 벡터 문자열은 CVSS:3.1/AV:N/... 형식이라 보고서에 그대로 붙이면 다른 사람이 같은 점수를 재현할 수 있습니다.

주의할 점

계산 대상은 기본 점수뿐입니다. 공격 코드 공개 여부를 반영하는 시간 메트릭과, 해당 시스템의 중요도를 반영하는 환경 메트릭은 포함하지 않으므로 같은 취약점이라도 우리 기관 환경에서의 실제 위험은 다를 수 있습니다. 점수는 메트릭을 어떻게 고르느냐에 따라 크게 달라지며, 판단이 애매한 항목은 근거를 보고서에 함께 적는 것이 좋습니다. 최신 버전인 CVSS v4.0과는 메트릭과 계산식이 다르므로 v4.0 점수와 직접 비교하지 마세요. 결과는 참고용이며 공식 점수는 해당 CVE를 게시한 기관의 평가를 확인하세요.

자주 묻는 질문

범위를 변경됨으로 바꾸면 왜 점수가 올라가나요?
영향이 다른 구성요소로 번지는 경우를 더 위험하게 보도록 영향도 계산식이 바뀌고, 전체 합에 1.08을 곱하기 때문입니다. 필요 권한이 낮음·높음일 때의 가중치도 함께 커집니다.
기밀성·무결성·가용성이 모두 없음이면 몇 점인가요?
영향이 없으면 공격 조건과 관계없이 0.0 없음으로 계산됩니다.
