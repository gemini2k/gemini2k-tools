코드 복잡도 분석

JavaScript 함수별 순환복잡도를 계산합니다.

오픈소스 acorn(MIT) 파서로 AST를 분석합니다. 순환복잡도 10 이하 권장, 20 초과는 리팩터링 대상입니다. 모든 처리는 브라우저에서만 이루어집니다.

코드 복잡도 분석 도구 사용 안내

무엇을 하는 도구인가

JavaScript 코드를 붙여넣으면 함수마다 순환복잡도(Cyclomatic Complexity)를 계산합니다. 순환복잡도는 함수 안을 지나는 서로 독립적인 실행 경로의 수로, 값이 클수록 분기가 많아 이해하기 어렵고 시험해야 할 경우도 늘어납니다. 이 도구는 오픈소스 acorn 파서로 코드를 구문 트리로 바꾼 뒤, 기본값 1에서 시작해 분기 요소를 만날 때마다 1씩 더합니다. 더하는 요소는 if, for, for-in, for-of, while, do-while, catch, 삼항 연산자(?:), default가 아닌 case, 논리 연산자 &&와 || 입니다.

언제 쓰나

  • 코드 리뷰 전에 조건문이 과하게 얽힌 함수를 골라내 리팩터링 대상을 정할 때
  • 정보시스템 감리나 소스코드 품질 점검에서 표본 스크립트의 복잡도 수준을 빠르게 확인할 때
  • 단위 테스트를 설계하면서 한 함수에 최소 몇 개의 경로 케이스가 필요한지 가늠할 때
  • 오래된 화면 스크립트를 유지보수 인수인계받을 때 손대기 위험한 함수를 먼저 파악할 때

사용 방법

  1. 입력란의 예시 코드를 지우고 분석할 JavaScript를 붙여넣습니다.
  2. 입력이 바뀔 때마다 자동으로 다시 계산되어 결과 표에 함수 이름과 복잡도가 나옵니다.
  3. 문법 오류가 있으면 파싱 오류 문구와 위치가 표시되므로 해당 줄을 고친 뒤 다시 확인합니다.

결과 해석

상단에 가장 큰 복잡도와 함수 개수가 나오고, 표에는 함수별 값과 판정이 표시됩니다. 10 이하는 양호(초록), 11~20은 주의(주황), 20 초과는 위험(빨강)입니다. 예시로 들어 있는 classify 함수는 if 1, else if 1, for 1, 반복문 안의 if 1, && 1, 삼항 연산자 1을 더해 1 + 6 = 7로 양호입니다. 이름 없는 함수 표현식, 화살표 함수, 클래스 메서드는 "(익명)"으로 나오고, 함수가 하나도 없는 코드는 전체를 한 덩어리로 계산해 "(전체)"로 표시합니다.

주의할 점

함수 안에 다른 함수가 들어 있으면 안쪽 함수의 분기도 바깥 함수 값에 함께 더해집니다. 콜백을 많이 쓰는 코드는 바깥 함수 값이 실제보다 크게 나올 수 있으니 안쪽 함수 행도 함께 보세요. 널 병합 연산자(??)나 옵셔널 체이닝은 세지 않습니다. 스크립트 모드로 파싱하므로 import/export 문이 있는 모듈 코드, TypeScript, JSX는 파싱 오류가 납니다. 복잡도는 코드 품질의 한 단면일 뿐이라 이름 짓기, 중복, 함수 길이 같은 문제는 따로 봐야 하고, 판정 기준은 참고용입니다.

자주 묻는 질문

switch 문은 어떻게 세나요?
case 하나당 1을 더하고 default는 더하지 않습니다. case가 15개인 switch는 그것만으로 16이 되므로 객체 매핑 등으로 바꾸는 방안을 검토해 볼 만합니다.
Java나 Python 코드도 넣을 수 있나요?
JavaScript 파서만 쓰므로 다른 언어는 파싱 오류가 납니다. 해당 언어용 정적 분석 도구를 쓰세요.
