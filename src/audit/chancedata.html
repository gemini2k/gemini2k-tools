테스트 더미데이터 생성기

컬럼=타입을 정의하면 테스트용 가짜 데이터를 표·CSV·JSON으로 만듭니다.

타입: 이름·이메일·전화·주소·도시·국가·회사·정수·금액·날짜·불리언·문장·단어·GUID·IP·나이
오픈소스 Chance.js(MIT, chancejs/chancejs)를 자체 호스팅합니다. 같은 시드를 넣으면 같은 데이터가 재현됩니다. 모든 처리는 브라우저에서만 이루어집니다.

테스트 더미데이터 생성기 사용 안내

무엇을 하는 도구인가

"컬럼명=타입"을 한 줄에 하나씩 적으면 그 구조대로 가짜 데이터를 최대 1,000행까지 만들어 표로 보여 주고, CSV 파일이나 JSON으로 내보냅니다. 개발 서버에 화면을 띄워 보거나 목록 페이징, 정렬, 엑셀 다운로드를 시험하려면 그럴듯한 데이터가 수십~수백 건 필요한데, 운영 데이터를 복사해 쓰면 개인정보 문제가 생깁니다. 이 도구는 오픈소스 Chance.js로 실제 사람과 무관한 값을 만들어 그 문제를 피하게 해 줍니다.

언제 쓰나

  • 개발·테스트 환경에 운영 개인정보 대신 넣을 회원, 거래처 샘플 데이터가 필요할 때
  • 화면 시안이나 사용자 매뉴얼 캡처에 실명이 아닌 이름, 이메일이 들어간 목록을 보여 줘야 할 때
  • CSV 일괄 업로드 기능을 시험하면서 행 수를 바꿔 가며 입력 파일을 만들 때
  • 같은 데이터를 다시 만들어야 하는 회귀 테스트에서 시드를 고정해 재현할 때

사용 방법

  1. [컬럼 정의] 입력란에 한 줄씩 컬럼명=타입을 적습니다. 예: cust_name=이름, amount=금액.
  2. 쓸 수 있는 타입은 이름, 이메일, 전화, 주소, 도시, 국가, 회사, 정수, 금액, 날짜, 불리언, 문장, 단어, GUID, IP, 나이입니다. 목록에 없는 타입을 적으면 임의의 영어 단어가 들어갑니다.
  3. [행 수]에 1~1000 사이 값을 넣고, 같은 결과를 다시 얻고 싶으면 [시드]에 아무 문자열이나 넣은 뒤 [생성]을 누릅니다.
  4. [CSV]를 누르면 testdata.csv가 내려받아지고, [JSON]을 누르면 객체 배열 형태의 JSON이 클립보드에 복사됩니다.

결과 해석

화면 표에는 앞의 100행까지만 보이지만 CSV와 JSON에는 생성한 행 전체가 들어갑니다. 정수는 1~1000, 금액은 1,000~1,000,000 사이의 정수이고, 날짜는 2020~2025년 사이 임의 날짜가 라이브러리 기본 문자열 형식으로 나옵니다. 불리언은 true/false, GUID는 하이픈이 들어간 36자 문자열입니다. 시드를 "test1"로 두고 10행을 만들면 언제 다시 눌러도 같은 10행이 나오므로 테스트 결과서에 시드 값을 적어 두면 재현이 쉬워집니다.

주의할 점

이름, 주소, 전화번호, 회사명은 영어권 형식으로 만들어집니다. 한글 이름이나 국내 주소 형식이 꼭 필요하다면 별도 도구를 써야 합니다. 정수 타입은 무작위 값이라 같은 숫자가 반복될 수 있으므로 기본키처럼 고유해야 하는 컬럼에는 맞지 않습니다. 생성 값은 서로 관계가 없어서 이메일과 이름이 짝지어지지 않고, 나이와 생년월일도 일치하지 않습니다. 업무 규칙이나 코드값 제약을 반영하지 않으므로 검증 로직 시험용 데이터는 직접 손봐야 합니다. 우연히 실제 존재하는 이메일 주소와 같아질 수 있으니 생성한 이메일로 실제 메일을 발송하지 마세요.

자주 묻는 질문

CSV를 엑셀에서 열면 한글 컬럼명이 깨지나요?
파일 앞에 UTF-8 BOM을 붙여 저장하므로 엑셀에서 바로 열어도 한글 컬럼명이 정상으로 보입니다.
시드를 비우면 어떻게 되나요?
누를 때마다 다른 데이터가 나옵니다. 재현이 필요 없는 일회성 샘플이면 비워 두면 됩니다.
