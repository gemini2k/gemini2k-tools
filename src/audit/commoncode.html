공통코드 정의서

공통코드(코드그룹·코드값)를 정의하고 중복을 점검합니다.

같은 코드그룹 내 코드값이 중복되면 경고합니다. CSV로 내보내 표준 산출물로 쓰세요. 데이터는 브라우저에만 저장됩니다.

공통코드 정의서 도구 사용 안내

무엇을 하는 도구인가

업무 시스템에서 성별, 처리상태, 결재구분처럼 여러 화면과 테이블이 함께 쓰는 코드를 정의하는 표입니다. 열은 코드그룹, 코드값, 코드명, 설명, 정렬, 사용(Y/N)으로 실제 공통코드 테이블 구조와 비슷하게 잡혀 있습니다. 행을 입력하는 동안 같은 코드그룹 안에 같은 코드값이 두 번 이상 나오는지 바로 확인해, 중복이 있으면 빨간색으로 건수와 해당 키를 보여 줍니다. 완성한 정의서는 CSV로 내려받아 산출물이나 데이터 적재용 원본으로 씁니다.

언제 쓰나

  • 설계 단계에서 데이터 표준 산출물의 하나로 공통코드 정의서를 작성할 때
  • 기존 시스템 코드표를 엑셀에서 옮겨 와 중복이나 오타가 섞이지 않았는지 정리할 때
  • 감리에서 공통코드 정의서와 실제 코드 테이블을 대조하기 전에 정의서 자체의 중복부터 걸러낼 때
  • 코드 테이블 INSERT 문을 만들기 전에 정렬 순서와 사용 여부를 한눈에 검토할 때

사용 방법

  1. 처음에는 GENDER 그룹의 M(남성), F(여성) 두 행이 예시로 들어 있습니다. 필요 없으면 ✕로 지웁니다.
  2. [+ 행 추가]로 행을 만들고 코드그룹(예: APRV_STAT), 코드값(예: 01), 코드명(예: 결재대기)을 입력합니다.
  3. 설명에 업무 의미를, 정렬에 화면 콤보박스에서 보일 순서를 숫자로 적고, 폐기된 코드는 사용을 N으로 둡니다.
  4. 표 아래 상태 줄을 보며 중복을 정리한 뒤 [CSV]로 내려받습니다.

결과 해석

중복이 없으면 초록색으로 "중복 없음"과 전체 행 수가 나옵니다. 중복이 있으면 "중복 1건"과 함께 그룹|코드값 형태로 겹친 키가 나열됩니다. 예를 들어 APRV_STAT 그룹에 01이 두 번 들어가면 "중복 1건 APRV_STAT|01"로 표시되고, 같은 값이 세 번이면 첫 번째를 뺀 두 번이 중복으로 세어져 2건이 됩니다. 다른 그룹에 같은 코드값이 있는 것은 정상이므로 GENDER|01과 APRV_STAT|01은 중복이 아닙니다.

주의할 점

비교는 입력한 글자 그대로 합니다. 대소문자가 다르거나(m과 M) 끝에 공백이 붙어 있으면 다른 값으로 보므로 실제 DB 제약과 결과가 다를 수 있습니다. 코드그룹과 코드값을 비워 둔 행이 두 개 이상이면 빈 키끼리 중복으로 잡히니 빈 행은 지우세요. 코드명 중복, 정렬 번호 중복, 코드값 자릿수 규칙 같은 점검은 하지 않습니다. 데이터는 이 브라우저의 localStorage에만 저장되므로 정식 관리본은 CSV로 따로 보관해야 합니다.

자주 묻는 질문

사용 N인 코드도 중복 검사에 포함되나요?
포함됩니다. 폐기된 코드라도 테이블에는 남아 있는 경우가 많아 같은 키를 다시 쓰면 기본키 충돌이 나기 때문입니다.
코드그룹 자체의 이름과 설명은 어디에 적나요?
이 표는 코드값 단위로만 관리합니다. 그룹 설명이 필요하면 그룹 대표 행의 설명 칸에 적거나 별도 그룹 목록을 함께 관리하세요.
