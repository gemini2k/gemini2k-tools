CSV/JSON SQL 쿼리 실행

표 데이터에 SQL을 바로 실행해 집계·필터·정렬합니다. 테이블명은 t 또는 data 입니다.

오픈소스 AlaSQL(MIT, AlaSQL/alasql)을 자체 호스팅합니다. 데이터는 전송되지 않고 브라우저에서만 처리됩니다.

CSV/JSON SQL 쿼리 실행기 사용 안내

무엇을 하는 도구인가

엑셀로 열기엔 번거롭고 DB에 적재하기엔 과한 작은 표 데이터를, 붙여넣자마자 SQL로 집계·필터·정렬해 보는 도구입니다. 내부적으로 오픈소스 AlaSQL을 써서 입력한 데이터를 t와 data라는 두 이름의 테이블로 동시에 등록하므로, FROM t 또는 FROM data 어느 쪽으로 써도 같은 결과가 나옵니다.

언제 쓰나

  • 데이터 이관 검증에서 원본·이관본 CSV의 건수나 합계를 GROUP BY로 비교할 때
  • 감리 중 받은 추출 자료에서 특정 조건(예: 금액 0, 상태값 누락) 건만 골라낼 때
  • API가 돌려준 JSON 배열을 그대로 붙여 지역별·코드별 집계를 내 볼 때
  • 신입 직원에게 SELECT·GROUP BY·ORDER BY 동작을 실제 데이터로 보여 줄 때

사용 방법

  1. "입력 형식"에서 CSV 또는 JSON 배열을 고릅니다.
  2. 큰 입력칸에 데이터를 붙여넣습니다. CSV는 첫 줄을 열 이름으로 쓰고, JSON은 [{"name":"김철수","age":30}, …] 같은 객체 배열이어야 합니다.
  3. 아래 한 줄짜리 칸에 SQL을 적고 "실행"을 누릅니다. 데이터나 쿼리 칸에서 포커스를 옮겨도 자동으로 다시 실행됩니다.

결과 해석

결과 위에 전체 행 수가 표시되고, 표에는 앞에서부터 최대 200행까지만 그려집니다. 기본 예시(5명, 서울 3·부산 2)에 들어 있는 쿼리 SELECT city, COUNT(*) AS n, ROUND(AVG(age),1) AS avg_age FROM t GROUP BY city ORDER BY n DESC를 실행하면 "2행"과 함께 서울 3명 평균 35.7세, 부산 2명 평균 26.5세가 나옵니다. 결과가 없으면 "결과 0행", 배열이 아닌 결과를 돌려주는 문장은 "실행 완료"로 표시됩니다.

주의할 점

  • CSV는 쉼표로 단순 분리합니다. 따옴표로 감싼 값 안에 쉼표가 있으면 열이 밀리니, 그런 데이터는 JSON으로 바꿔 넣으세요.
  • CSV에서는 정수·소수 형태의 값만 숫자로 바뀝니다. 앞에 0이 붙은 코드값도 숫자로 바뀌므로 주의하세요(예: 007은 숫자 7이 됩니다). 1,000처럼 천 단위 쉼표가 들어간 값은 열이 갈라집니다.
  • 쿼리는 한 번에 한 문장씩 실행하는 것이 안전합니다. 실행할 때마다 테이블을 새로 만들기 때문에 INSERT·UPDATE 결과는 다음 실행에 남지 않습니다.
  • 집계 결과는 확인 보조용입니다. 공식 보고 수치는 원본 시스템에서 다시 확인하세요.

자주 묻는 질문

JOIN도 되나요?
현재 화면에는 테이블이 하나(t와 data는 같은 데이터)만 등록되므로, 서로 다른 두 파일을 JOIN하는 용도로는 쓸 수 없습니다. 같은 테이블끼리 자기 조인하는 것은 가능합니다.
데이터가 외부로 나가나요?
아닙니다. 파싱과 쿼리 실행 모두 브라우저 안에서 끝납니다. 그래도 개인정보가 든 원본은 가명처리 후 넣는 습관을 권합니다.
