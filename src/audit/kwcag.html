웹 접근성(KWCAG 2.2) 자가점검

4대 원칙별 접근성 검사항목을 점검합니다.

KWCAG 2.2 검사항목 기준입니다. 전자정부 웹사이트 품질관리·인증 준비에 활용하세요. 자동 점검은 마크업 점검 도구를 함께 사용하세요.

웹 접근성(KWCAG 2.2) 자가점검 사용 안내

무엇을 하는 도구인가

한국형 웹 콘텐츠 접근성 지침(KWCAG) 2.2의 4대 원칙인 인식의 용이성, 운용의 용이성, 이해의 용이성, 견고성에 따라 주요 검사항목을 충족·미충족·해당없음으로 표시하는 자가점검표입니다. 원칙별로 8개, 8개, 5개, 2개씩 모두 23개 항목이 있습니다. 대체 텍스트, 자막, 표 구성, 명도 대비 4.5:1, 키보드 사용, 초점 함정, 건너뛰기 링크, 페이지 제목, 기본 언어(lang), 서식 레이블, 마크업 오류, ARIA 같은 실무에서 자주 지적되는 항목을 중심으로 묶었습니다.

언제 쓰나

  • 공공 웹사이트 개편 사업의 시험 단계에서 개발팀이 스스로 1차 점검할 때
  • 웹 접근성 품질인증 심사나 외부 진단을 받기 전에 큰 결함을 먼저 정리할 때
  • 감리에서 접근성 요구사항이 화면 단위로 반영됐는지 표본 화면을 확인할 때
  • 운영 중 게시판·팝업·신규 메뉴를 추가한 뒤 기존 수준이 유지되는지 볼 때

사용 방법

  1. 점검할 대표 화면(메인, 목록, 상세, 입력 서식, 로그인)을 정해 둡니다.
  2. 항목마다 직접 확인한 뒤 충족·미충족·해당없음을 고릅니다. 동영상이 없는 사이트라면 자막 항목은 해당없음입니다.
  3. 미충족 항목의 '비고' 칸에 화면 경로와 문제 요소(예: 검색 버튼 이미지 alt 누락)를 적습니다.
  4. [⬇️ CSV]로 내려받아 조치 계획표로 씁니다. 입력은 이 브라우저에 자동 저장됩니다.

결과 해석

상단 충족률은 '충족 수 ÷ (23 − 해당없음 수)'입니다. 고르지 않은 항목은 미충족처럼 분모에만 들어갑니다. 예를 들어 해당없음 3개, 충족 17개라면 17 ÷ 20 = 85%입니다. 다만 접근성은 평균 점수보다 막히는 지점이 있느냐가 중요합니다. 키보드로 메뉴에 들어갈 수 없거나 로그인 서식에 레이블이 없으면 다른 항목이 모두 충족이어도 해당 이용자는 서비스를 쓸 수 없으니, 운용의 용이성 미충족 항목부터 고치는 것을 권합니다.

주의할 점

이 점검표는 KWCAG 2.2의 33개 검사항목 가운데 23개를 간추린 것입니다. 2.2에서 새로 강조된 항목 중 일부는 목록에 없으므로 인증 대비용이라면 지침 원문의 전체 항목과 대조해야 합니다. 결과는 사람이 판단해 표시한 자가점검 결과일 뿐 공식 인증이나 진단을 대신하지 않습니다. 실제 확인에는 키보드만으로 화면을 끝까지 다녀 보기, 화면 낭독 프로그램으로 들어 보기, 명도 대비 계산기와 마크업 점검 도구를 함께 쓰는 방법이 필요합니다.

자주 묻는 질문

한 화면만 문제여도 미충족인가요?
보수적으로는 그렇습니다. 점검 대상 화면 중 하나라도 위반이 있으면 미충족으로 두고 비고에 해당 화면을 적어 두는 편이 조치 누락을 막습니다.
자동 점검 도구로 다 확인할 수 있지 않나요?
대체 텍스트가 있는지, lang이 있는지는 자동으로 잡히지만 그 대체 텍스트가 적절한지, 초점 순서가 논리적인지는 사람이 봐야 합니다. 자동 도구는 이 점검표의 일부 항목만 도와준다고 생각하는 것이 맞습니다.
