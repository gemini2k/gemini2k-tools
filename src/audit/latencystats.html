응답시간 분포·통계 분석

지연시간 목록의 백분위·표준편차·Apdex·히스토그램을 계산합니다.

오픈소스 simple-statistics(ISC, simple-statistics/simple-statistics)를 자체 호스팅합니다. Apdex는 임계 T 이하=만족, 4T 이하=허용으로 계산합니다. 모든 처리는 브라우저에서만 이루어집니다.

응답시간 분포·통계 분석 사용 안내

무엇을 하는 도구인가

응답시간 목록(ms)을 넣으면 샘플 수, 평균, 중앙값(p50), 최소/최대, 표준편차, p90·p95·p99 백분위수, Apdex 점수와 등급, 분포 히스토그램을 한 화면에 보여 줍니다. 통계 계산은 오픈소스 simple-statistics 라이브러리를 씁니다. 평균 하나로는 "대부분은 빠른데 일부가 아주 느린" 상황을 놓치기 쉬운데, 백분위수와 히스토그램을 같이 보면 느린 꼬리가 얼마나 긴지 바로 드러납니다.

언제 쓰나

  • 성능시험 도구가 내보낸 응답시간 열을 복사해 목표 응답시간 충족 여부를 판단할 때
  • 운영 중인 시스템의 접근 로그에서 특정 화면의 응답시간만 뽑아 분포를 볼 때
  • 성능 개선 전후 데이터를 각각 넣어 p95와 Apdex가 얼마나 달라졌는지 비교할 때
  • 감리 성능 점검에서 사업자가 제시한 평균 응답시간이 분포 전체를 대표하는지 확인할 때

사용 방법

  1. 입력란에 응답시간을 ms 단위로 한 줄에 하나씩, 또는 쉼표나 공백으로 구분해 붙여 넣습니다. 숫자가 아닌 값은 건너뜁니다.
  2. 'Apdex 임계 T (ms)'에 사용자가 만족하는 기준 응답시간을 넣습니다. 기본값은 200ms입니다.
  3. '히스토그램 구간 수'(2~30)를 조정해 분포 모양을 봅니다. 숫자가 2개 이상이면 즉시 계산됩니다.

결과 해석

Apdex는 (만족 건수 + 허용 건수 ÷ 2) ÷ 전체 건수로 계산합니다. T 이하는 만족, T 초과 4T 이하는 허용, 4T 초과는 불만입니다. 등급은 0.94 이상 우수, 0.85 이상 양호, 0.70 이상 보통, 0.50 이상 미흡, 그 미만 불량으로 표시합니다. 기본 예시 20건(T=200)에서는 200ms 이하가 15건, 200~800ms가 5건(210, 205, 264, 340, 410)이라 Apdex는 (15 + 2.5) ÷ 20 = 0.88, 양호입니다. 같은 데이터에서 평균은 172.7ms, 중앙값 149.0ms, p90 302.0ms, p95 375.0ms, p99 410.0ms, 표준편차 80.0ms가 나옵니다. 평균이 중앙값보다 꽤 크면 느린 요청 몇 개가 평균을 끌어올리고 있다는 신호입니다.

주의할 점

백분위수는 정렬한 값에서 위치를 찾아 계산하며, 위치가 정확히 두 값 사이에 걸리면 두 값의 평균을 씁니다. 샘플이 적으면 p99는 사실상 최댓값과 같아지므로, p99를 판정 기준으로 쓰려면 최소 수백 건 이상을 넣는 것이 좋습니다. 표준편차는 입력값 전체를 모집단으로 보고 계산합니다. 히스토그램은 최솟값~최댓값을 같은 폭으로 나누기 때문에 극단적인 값이 하나 있으면 대부분이 첫 구간에 몰려 보입니다. 시간대별 추이나 오류 응답은 이 목록만으로 알 수 없습니다.

자주 묻는 질문

Apdex 임계 T는 몇으로 잡나요?
정해진 값은 없습니다. 요구사항에 "응답시간 3초 이내"처럼 목표가 있으면 그 값을 T로 쓰는 것이 자연스럽고, 단순 조회 API처럼 빨라야 하는 기능은 더 짧게 잡습니다.
성능시험 결과 분석 도구와 무엇이 다른가요?
이 도구는 Apdex와 히스토그램을 제공하고, 백분위 위치가 두 값 사이에 걸리면 평균을 씁니다. 성능시험 결과 분석 도구는 항상 실제 관측값 하나를 고르는 순위 방식 백분위수와 단일 스레드 기준 추정 처리량을 보여 줍니다. 같은 데이터라도 백분위수 계산 방식이 달라 값이 조금 다를 수 있습니다.
