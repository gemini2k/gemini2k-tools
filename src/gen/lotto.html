로또 번호 생성기

1~45 중 6개를 무작위로 뽑아 5게임을 생성합니다.

재미로 즐기세요. 당첨을 보장하지 않으며, 암호학적 난수로 공정하게 추첨합니다.

로또 번호 생성기 사용 안내

무엇을 하는 도구인가

1부터 45까지의 숫자 가운데 서로 겹치지 않는 6개를 뽑아 한 게임을 만들고, 이를 A부터 E까지 5게임 만들어 줍니다. 번호는 브라우저의 암호학적 난수 생성기(crypto.getRandomValues)로 뽑으며, 특정 숫자가 더 자주 나오지 않도록 나머지 연산의 치우침을 걸러 내고 45개 숫자 묶음을 섞어 앞의 6개를 취하는 방식입니다. 뽑힌 번호는 작은 수부터 정렬해 보여 줍니다.

언제 쓰나

  • 판매점에서 자동 선택 대신 미리 정한 번호로 마킹하고 싶을 때
  • 사무실 동료끼리 공동 구매할 때 각자 번호를 정하기 귀찮을 때
  • 생일이나 기념일 숫자만 고르는 습관에서 벗어나 1~45 전체에서 고르게 뽑고 싶을 때

사용 방법

  1. 페이지를 열면 바로 5게임이 만들어져 있습니다.
  2. 마음에 들지 않으면 「🎲 번호 생성」을 눌러 5게임 전체를 새로 뽑습니다.
  3. 「📋 복사」를 누르면 「A: 3, 11, 19, 27, 38, 42」 형식으로 다섯 줄이 복사됩니다. 메모장이나 메신저에 붙여 두면 마킹할 때 편합니다.

결과 해석

공 색깔은 실제 추첨 방송처럼 1~10, 11~20, 21~30, 31~40, 41~45 구간별로 다르게 칠한 것으로, 의미는 구간 표시뿐입니다. 6개 번호를 모두 맞힐 확률은 어떤 조합이든 똑같이 45개 중 6개를 고르는 경우의 수인 8,145,060분의 1입니다. 「1, 2, 3, 4, 5, 6」처럼 보기에 어색한 조합도 다른 조합과 당첨 확률이 같습니다.

주의할 점

  • 이 도구는 지난 회차 당첨 번호, 많이 나온 번호, 출현 주기 같은 통계를 쓰지 않으며, 그런 통계로 다음 번호를 예측할 수도 없습니다. 매 회차 추첨은 이전 결과와 무관합니다.
  • 보너스 번호는 뽑지 않습니다. 보너스 번호는 추첨 때 정해지는 것이라 구매자가 고를 필요가 없습니다.
  • 공정한 난수를 쓴다는 것은 번호가 고르게 뽑힌다는 뜻일 뿐, 당첨 가능성을 높여 주지 않습니다. 구매는 형편에 맞게 하세요.

자주 묻는 질문

한 게임 안에 같은 숫자가 두 번 나올 수 있나요?
없습니다. 45개 숫자 묶음에서 꺼내는 방식이라 한 게임의 6개는 항상 서로 다릅니다. 게임끼리는 따로 뽑으므로 다른 게임에 같은 숫자가 나올 수는 있습니다.
생성한 번호가 저장되나요?
저장되지 않습니다. 새로 생성하거나 페이지를 닫으면 사라지니 필요하면 복사해 두세요.
