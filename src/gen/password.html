비밀번호 생성기

안전한 무작위 비밀번호를 원하는 조건으로 만들어 드립니다.

···

암호학적 난수(crypto)로 브라우저에서 생성하며, 어디에도 전송·저장되지 않습니다.

비밀번호 생성기 사용 안내

무엇을 하는 도구인가

고른 문자 종류(소문자 26자, 대문자 26자, 숫자 10자, 특수문자 23자)를 하나의 문자 묶음으로 합친 뒤, 브라우저의 암호학적 난수(crypto.getRandomValues)로 한 글자씩 뽑아 비밀번호를 만듭니다. 고른 종류마다 최소 한 글자는 반드시 들어가도록 먼저 뽑고, 나머지를 채운 다음 전체 순서를 다시 섞습니다. 그래서 「대문자·숫자·특수문자를 각 1자 이상 포함」 같은 사이트 가입 조건을 대부분 한 번에 통과합니다.

언제 쓰나

  • 업무 시스템의 정기 비밀번호 변경 때 기존 비밀번호를 조금만 바꾸는 습관을 끊고 싶을 때
  • 공유기, NAS, 서버 관리자 계정처럼 한 번 정하면 잘 안 바꾸는 계정을 만들 때
  • 신규 직원 계정의 초기 비밀번호를 발급할 때
  • 비밀번호 관리자에 저장할 사이트별 비밀번호를 만들 때

사용 방법

  1. 「길이」 막대로 6~40자 사이에서 길이를 정합니다. 기본은 16자입니다.
  2. 소문자·대문자·숫자·특수문자 중 쓸 종류를 고릅니다. 사이트가 특수문자를 받지 않으면 끕니다.
  3. 손으로 옮겨 적거나 불러 줘야 한다면 「헷갈리는 문자 제외 (Il1O0)」를 켭니다.
  4. 옵션을 바꾸면 바로 새로 만들어지고, 「🔄 새로 생성」으로 다시 뽑을 수 있습니다. 「복사」로 가져갑니다.

결과 해석

강도는 「길이 × log2(문자 묶음 크기)」로 계산한 엔트로피(비트)입니다. 네 종류를 모두 쓰면 묶음이 85자이고 한 글자당 약 6.4비트이므로, 기본 16자는 약 103비트로 「매우 강함」, 8자는 약 51비트로 「보통」입니다. 기준은 40비트 미만 약함, 60비트 미만 보통, 80비트 미만 강함, 그 이상 매우 강함입니다. 1비트가 늘 때마다 무작위로 맞혀 보는 데 드는 경우의 수가 두 배가 되므로, 종류를 늘리는 것보다 길이를 늘리는 쪽이 효과가 큽니다.

주의할 점

  • 이 비트 수는 비밀번호가 완전히 무작위로 만들어졌다고 가정한 값입니다. 사람이 이 화면을 보고 일부를 고치면 계산이 맞지 않습니다. 「종류별 최소 1자」 규칙 때문에 실제 값은 표시보다 아주 조금 낮습니다.
  • 강한 비밀번호라도 여러 사이트에 같이 쓰면 한 곳에서 유출될 때 모두 위험해집니다. 사이트마다 다르게 쓰고 비밀번호 관리자에 보관하세요.
  • 복사한 비밀번호는 클립보드에 남습니다. 공용 PC에서는 사용 후 다른 글자를 복사해 덮어 두세요.

자주 묻는 질문

만든 비밀번호가 어디에 기록되나요?
기록되지 않습니다. 브라우저 안에서 만들어 화면에 보여 줄 뿐 서버로 보내거나 저장하지 않습니다.
외우기 쉬운 비밀번호가 필요해요.
무작위 문자열은 외우기 어렵습니다. 자주 직접 입력해야 하는 비밀번호라면 단어 여러 개를 이어 붙이는 패스프레이즈 생성기를 쓰는 편이 낫습니다.
