부가세(VAT) 계산기

공급가액에서 부가세를 더하거나, 합계에서 부가세를 거꾸로 뽑아냅니다. 세금계산서·영수증 작성에 쓰세요.

세율%
원
공급가액
부가세
합계 (공급대가)
한국 부가가치세 기본 세율은 10%입니다. '합계 → 공급가액'은 공급가액 = 합계 ÷ (1 + 세율), 부가세 = 합계 − 공급가액으로 역산합니다. 원 단위는 반올림해 표시하며, 실제 세금계산서의 절사 방식과 1원 단위에서 차이가 날 수 있습니다. 계산은 모두 브라우저에서 이루어집니다.

부가세(VAT) 계산기 사용 안내

무엇을 하는 도구인가

공급가액에 부가가치세를 더해 합계(공급대가)를 구하거나, 부가세가 포함된 합계에서 공급가액과 부가세를 나눠 내는 계산기입니다. 세율 칸의 기본값은 10%이고 직접 바꿀 수 있습니다. 더하기는 부가세 = 공급가액 × 세율, 빼기는 공급가액 = 합계 ÷ (1 + 세율), 부가세 = 합계 − 공급가액으로 계산하며, 각 금액은 원 단위로 반올림해 표시합니다. 결과마다 '복사' 버튼이 있어 세금계산서나 견적서 입력칸에 바로 붙여 넣을 수 있습니다.

언제 쓰나

  • 견적서에 공급가액만 적혀 있을 때 실제 결제 금액을 확인할 때
  • 카드 영수증의 결제 금액을 공급가액과 세액으로 나눠 장부에 적을 때
  • 전자세금계산서 발행 전에 공급가액·세액 칸 값을 맞춰 볼 때
  • 'VAT 별도' 가격과 'VAT 포함' 가격을 비교할 때

사용 방법

  1. '공급가액 → 합계 (부가세 더하기)' 또는 '합계 → 공급가액 (부가세 빼기)'를 고릅니다.
  2. 세율이 10%가 아니라면 '세율' 칸을 고칩니다.
  3. 금액 칸에 숫자를 넣습니다. 쉼표는 자동으로 붙습니다.
  4. 공급가액, 부가세, 합계를 확인하고 필요한 값 옆의 '복사'를 누릅니다.

결과 해석

기본값 100,000원을 더하기 모드로 계산하면 부가세 10,000원, 합계 110,000원입니다. 빼기 모드에서 110,000원을 넣으면 공급가액 100,000원, 부가세 10,000원으로 정확히 나뉩니다. 50,000원처럼 1.1로 딱 나누어지지 않는 합계는 공급가액 45,454.54…원을 반올림한 45,455원, 부가세 4,545원이 됩니다. 흔히 '합계의 10%가 부가세'라고 생각해 5,000원으로 잡는 실수가 있는데, 합계에 이미 세금이 들어 있으므로 1/11인 약 4,545원이 맞습니다.

주의할 점

이 도구는 원 단위를 반올림하지만, 세금계산서 발행 프로그램이나 POS는 원 미만을 절사하는 경우가 많아 1원 차이가 날 수 있습니다. 실제 발행할 때는 사용하는 시스템의 처리 방식을 따르세요. 면세 품목, 영세율 거래, 간이과세자의 부가세 계산은 일반과세자와 방식이 다르므로 이 계산 결과를 그대로 신고에 쓰지 말고 국세청 홈택스 안내나 세무 전문가 확인을 거치세요.

자주 묻는 질문

소수점 금액도 넣을 수 있나요?
금액 칸은 원 단위 정수 입력에 맞춰져 있어 소수점은 사라집니다. 외화 금액은 다른 계산기를 쓰세요.
세율을 바꾸면 다른 나라 VAT도 계산되나요?
계산식은 같아 세율만 바꾸면 됩니다. 다만 금액이 원 단위로 반올림되고 '원' 표시가 붙는다는 점은 감안하세요.
