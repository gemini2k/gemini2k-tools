시간 계산기 사용 안내

무엇을 하는 도구인가

시:분:초 단위 시간을 더하거나 빼고, 두 시각 사이가 얼마나 되는지 구하는 계산기입니다. 내부적으로 모든 값을 초로 바꿔 계산한 뒤 다시 '시간 분 초'로 보여 주므로, 분이 60을 넘거나 초가 90처럼 큰 값을 넣어도 알아서 올림 처리됩니다. 결과 아래에는 총 초와 소수 시간(예: 4.25시간)도 함께 나와 근무시간 정산표나 엑셀에 옮겨 적기 좋습니다.

언제 쓰나

  • 영상 클립 길이를 여러 개 더해 전체 재생 시간을 구할 때
  • 출근·퇴근 시각으로 하루 근무시간을 계산할 때(야간 근무 포함)
  • 주간 근무시간 합계를 소수 시간으로 바꿔 시급과 곱할 때
  • 마라톤 구간 기록이나 공정별 소요 시간을 합산할 때

사용 방법

  1. 위쪽에서 '더하기/빼기' 또는 '시각 차이'를 고릅니다.
  2. 더하기/빼기: '시간 A'와 아래 줄에 시·분·초를 넣습니다. '＋/－ 전환'을 누르면 뺄셈으로 바뀝니다.
  3. 시각 차이: '시각 1'(시작)과 '시각 2'(끝)를 고릅니다.
  4. 결과와 총 초·소수 시간이 바로 표시됩니다.

결과 해석

기본값 1:30:00 + 2:45:30은 4시간 15분 30초, 총 15,330초이며 4.26시간으로 표시됩니다. 같은 값을 빼기로 바꾸면 결과가 음수인 -1시간 15분 30초가 나옵니다. 시각 차이에서 09:00:00부터 18:30:00까지는 9시간 30분, 9.50시간, 570분입니다. 휴게시간 1시간을 빼야 한다면 더하기/빼기 모드에서 9:30:00 − 1:00:00으로 실근무 8시간 30분을 구하면 됩니다.

주의할 점

'시각 차이'에서 시각 2가 시각 1보다 이르면 자정을 넘긴 것으로 보고 24시간을 더합니다. 22:00부터 06:00까지는 8시간으로 계산되지만, 24시간 이상 차이 나는 기간(이틀에 걸친 근무 등)은 이 모드로 구할 수 없으니 날짜가 포함된 계산은 일수 계산 도구를 함께 쓰세요. 소수 시간은 둘째 자리에서 반올림한 값이라 급여 계산에는 총 초나 분 값을 기준으로 하는 편이 정확합니다.

자주 묻는 질문

세 개 이상의 시간을 더하려면요?
앞의 두 값을 더한 결과를 다시 '시간 A'에 넣고 다음 값을 더하는 식으로 이어 가면 됩니다.
90분을 그대로 넣어도 되나요?
됩니다. 분 칸에 90을 넣으면 1시간 30분으로 계산됩니다.
