영업일(근무일수) 계산기

두 날짜 사이의 영업일을 세거나, 기준일에서 영업일만큼 앞뒤로 이동한 날짜를 구합니다. 주말은 제외하고, 공휴일을 직접 추가할 수 있습니다.

📖
사용 방법
  1. '기간 계산'(두 날짜 사이) 또는 '영업일 더하기/빼기' 탭을 고릅니다
  2. 날짜와 값을 입력합니다 (주말은 자동 제외)
  3. 공휴일이 있으면 아래 칸에 한 줄에 하나씩(YYYY-MM-DD) 넣으면 함께 제외됩니다
주말(토·일)은 항상 제외합니다. '대한민국 공휴일 자동 반영'을 켜 두면 2024~2027년 관공서 공휴일(대체공휴일·선거일·임시공휴일 포함)이 자동으로 빠집니다. 회사 휴무일이나 이후 새로 지정되는 임시공휴일은 아래 칸에 직접 넣으세요. '기간 계산'은 시작일·종료일 사이의 영업일을, '더하기/빼기'는 기준일에서 영업일만큼 이동한 날짜를 구합니다.

영업일(근무일수) 계산기 사용 안내

무엇을 하는 도구인가

토요일과 일요일, 대한민국 공휴일, 사용자가 직접 넣은 휴무일을 뺀 영업일을 세는 계산기입니다. '기간 계산'은 두 날짜 사이 하루하루를 훑어 영업일, 전체 일수, 주말, 공휴일을 따로 집계하고, '영업일 더하기/빼기'는 기준일 다음 날부터 영업일만 세어 N번째 영업일이 언제인지 알려 줍니다. 2024~2027년 관공서 공휴일(설날·추석 연휴, 대체공휴일, 선거일, 임시공휴일, 2026년부터 공휴일이 된 노동절·제헌절 포함)이 내장되어 있어 '대한민국 공휴일 자동 반영'을 켜 두면 자동으로 빠집니다. 회사 휴무일 등은 한 줄에 하나씩 YYYY-MM-DD 형식으로 더 넣을 수 있습니다.

언제 쓰나

  • 계약서의 '영업일 기준 7일 이내' 같은 기한이 언제인지 확인할 때
  • 프로젝트 일정에서 실제로 일할 수 있는 날이 며칠인지 셀 때
  • 배송·처리 기간이 영업일 기준일 때 도착 예상일을 잡을 때
  • 단기 계약직의 근무일수로 일급 합계를 계산할 때

사용 방법

  1. '기간 계산' 또는 '영업일 더하기/빼기' 탭을 고릅니다.
  2. 기간 계산: '시작일'과 '종료일'을 넣고, 시작일을 셀지 '시작일 포함' 체크로 정합니다.
  3. 더하기/빼기: '기준일'과 '영업일 (음수=이전)'을 넣습니다. -5를 넣으면 5영업일 전 날짜가 나옵니다.
  4. 공휴일은 기본으로 자동 반영됩니다. 회사 창립기념일 같은 추가 휴무일만 '공휴일 제외' 칸에 한 줄에 하나씩 넣습니다.

결과 해석

2026-03-01(일)부터 2026-03-31(화)까지 시작일 포함으로 계산하면 전체 31일, 주말 9일, 공휴일 1일(3월 2일 삼일절 대체공휴일), 영업일 21일입니다. 3월 1일 삼일절은 일요일이라 주말로 먼저 집계됩니다. 여기에 회사 창립기념일 2026-03-16(월)을 칸에 넣으면 공휴일 2일, 영업일 20일로 바뀝니다. 더하기 모드에서 2026-03-06(금)을 기준으로 10영업일을 더하면 2026-03-20(금)이 나옵니다. 기준일 자체는 세지 않습니다.

주의할 점

내장 공휴일은 우주항공청·한국천문연구원 월력요항과 정부 발표를 바탕으로 2024~2027년만 들어 있습니다. 그 밖의 연도나 앞으로 새로 지정되는 임시공휴일은 직접 입력하세요. 노동절(5월 1일)은 2026년부터 관공서 공휴일이지만 민간 사업장의 유급휴일 처리는 근로기준법을 따릅니다. 법정 기한 계산에는 기간의 첫날을 넣지 않는 원칙(초일 불산입)이나 말일이 공휴일이면 다음 날로 넘기는 규정이 따로 있으니, 소송·행정 기한은 해당 법령과 기관 안내를 우선하세요.

자주 묻는 질문

토요일 근무하는 회사는 어떻게 계산하나요?
이 도구는 토·일을 항상 제외합니다. 토요일 근무일은 결과에 직접 더해 주세요.
시작일과 종료일을 바꿔 넣으면요?
앞뒤를 자동으로 바꿔서 계산하므로 같은 결과가 나옵니다.
