Excalidraw

손으로 그린 듯한 느낌의 화이트보드. 시스템 아키텍처·플로차트·와이어프레임·브레인스토밍을 자유롭게 그리고 PNG·SVG로 저장하세요.

📖
사용 방법
  1. 상단 도구바에서 사각형·화살표·텍스트 등을 골라 캔버스에 그립니다
  2. 요소를 선택해 색·굵기·글꼴을 바꾸고, 드래그로 이동·연결합니다
  3. 왼쪽 메뉴에서 이미지로 내보내기(PNG/SVG) 또는 .excalidraw 파일로 저장

Excalidraw 화이트보드 사용 안내

무엇을 하는 도구인가

Excalidraw는 손으로 그린 듯한 선으로 도형, 화살표, 글자를 배치하는 오픈소스 화이트보드입니다. 이 페이지는 Excalidraw 라이브러리를 사이트 안에 직접 올려 한국어 메뉴로 띄운 것으로, 캔버스 위 도구 막대에서 사각형·마름모·원·화살표·선·자유곡선·텍스트·이미지를 골라 그리고, 왼쪽 메뉴에서 PNG·SVG 이미지로 내보내거나 다시 편집할 수 있는 .excalidraw 파일로 저장할 수 있습니다. 정교한 도면 대신 생각을 빠르게 그림으로 옮기는 데 맞춘 도구입니다.

언제 쓰나

  • 보고서나 제안서에 넣을 시스템 구성도의 초안을 빠르게 그릴 때
  • 업무 처리 절차를 상자와 화살표로 나눠 흐름도로 정리할 때
  • 화면 설계 회의 전에 와이어프레임을 대충 잡아 볼 때
  • 화상회의 중 화면을 공유해 아이디어를 그리며 설명할 때

사용 방법

  1. 캔버스 위쪽 도구 막대에서 도형이나 화살표를 고르고 캔버스에서 끌어 그립니다. 도형을 두 번 클릭하면 안에 글자를 넣을 수 있습니다.
  2. 화살표 끝을 도형 가장자리에 놓으면 도형에 붙어서, 도형을 옮겨도 화살표가 따라옵니다.
  3. 요소를 선택하면 왼쪽에 선 색, 배경색, 선 굵기, 손그림 정도, 글꼴 같은 속성 패널이 나옵니다.
  4. 작업 공간이 좁으면 [↗ 새 탭에서 전체화면]으로 엽니다.
  5. 왼쪽 위 메뉴에서 이미지로 내보내기(PNG/SVG) 또는 파일 저장을 고릅니다.

결과 해석

PNG는 문서에 바로 붙이기 좋고, SVG는 확대해도 깨지지 않아 인쇄물에 적합합니다. 내보내기 창에서 배경 포함 여부와 다크 모드를 정할 수 있으니, 흰 바탕 보고서에 넣을 때는 배경을 켠 상태로 내보내세요. .excalidraw 파일은 도형과 글자 정보를 담은 JSON 텍스트라 나중에 이 도구에서 다시 열어 고칠 수 있습니다. 같은 그림을 팀원에게 넘길 때는 이미지보다 이 파일을 함께 주는 편이 수정하기 편합니다.

주의할 점

이 페이지는 공동 편집이나 클라우드 저장 기능을 연결하지 않았습니다. 그린 내용은 서버로 전송되지 않는 대신, 탭을 닫거나 새로고침하면 지워질 수 있으므로 작업이 끝나면 반드시 .excalidraw 파일이나 이미지로 저장하세요. 손그림 느낌의 기본 글꼴은 공식 문서에 어울리지 않을 수 있으니 속성 패널에서 일반 글꼴로 바꾸고, 손그림 정도를 낮추면 깔끔한 도식이 됩니다.
