오픈소스 Rough.js(MIT, rough-stuff/rough)를 자체 호스팅합니다. 무작위 손그림 효과라 그릴 때마다 조금씩 달라집니다. 모든 처리는 브라우저에서만 이루어집니다.

손그림 도형 생성기 사용 안내

무엇을 하는 도구인가

오픈소스 라이브러리 Rough.js로 사각형, 타원, 원, 선, 화살표를 손으로 그린 듯 살짝 흔들린 선으로 그려 주는 도구입니다. 선이 얼마나 삐뚤어질지 정하는 '거칠기', 안쪽을 칠하는 방식인 '채움'(빗금·단색·지그재그·교차·없음), 선색과 채움색, 선굵기를 정한 뒤 [그리기]를 누르면 520×360 캔버스 가운데에 도형이 하나 그려집니다. 결과는 흰 배경 PNG로 저장합니다.

언제 쓰나

  • 발표 자료에 딱딱하지 않은 느낌의 강조 동그라미나 화살표가 필요할 때
  • 교육 자료나 카드뉴스에 손그림 분위기의 장식 도형을 넣을 때
  • '초안', '검토 중' 같은 미완성 느낌을 일부러 드러내고 싶은 와이어프레임 요소를 만들 때
  • 스케치 스타일 아이콘의 밑그림을 몇 가지 시험해 볼 때

사용 방법

  1. '도형'에서 모양을 고르고 '거칠기'(0~5)와 '채움' 방식을 정합니다.
  2. '선색', '채움색', '선굵기'(1~10)를 고릅니다.
  3. [그리기]를 누릅니다. 누를 때마다 같은 자리에 도형이 하나씩 겹쳐 그려집니다.
  4. 다시 시작하려면 [지우기]로 캔버스를 비우고, 마음에 들면 [⬇️ PNG]로 저장합니다.

결과 해석

거칠기 0은 자로 그은 듯 반듯한 선이고, 1~2는 자연스러운 손그림, 3 이상은 일부러 대충 그린 낙서 느낌이 납니다. 예를 들어 거칠기 1.5, 채움 '빗금', 선굵기 2는 화이트보드 스케치와 비슷한 인상을 줍니다. 손그림 효과는 매번 무작위로 만들어지므로 [지우기] 후 [그리기]를 몇 번 반복해 가장 보기 좋은 모양을 고르면 됩니다. 같은 자리에 [그리기]를 두세 번 겹치면 여러 번 덧그은 듯한 효과도 낼 수 있습니다.

주의할 점

도형의 위치와 크기는 캔버스 가운데에 고정되어 있어 마우스로 옮기거나 크기를 바꿀 수는 없고, 글자도 넣을 수 없습니다. 여러 도형을 자유롭게 배치한 도식이 필요하면 Excalidraw 화이트보드가 더 맞습니다. 선·화살표에는 채움이 적용되지 않습니다. 저장은 PNG만 지원하며 배경은 흰색으로 채워집니다.

자주 묻는 질문

투명 배경으로 저장할 수 있나요?
저장할 때 흰 배경을 깔기 때문에 투명 PNG는 만들 수 없습니다. 필요하면 이미지 편집 도구에서 흰색을 지우세요.
방금 그린 도형만 취소할 수 있나요?
되돌리기 기능은 없습니다. [지우기]로 전체를 비운 뒤 다시 그려야 합니다.
