3D 모델 뷰어

GLB·GLTF 3D 모델을 불러와 마우스로 돌리고 확대하며 살펴봅니다.

📦 .glb 파일, 또는 .gltf와 .bin·텍스처 파일을 함께 끌어다 놓거나 클릭해서 선택
오픈소스 <model-viewer>(Apache-2.0, Google, google/model-viewer)를 자체 호스팅합니다. 모델 파일은 업로드되지 않고 브라우저에서만 렌더링됩니다.

3D 모델 뷰어 사용 안내

무엇을 하는 도구인가

glTF 형식(.glb, .gltf)의 3D 모델 파일을 불러와 브라우저에서 돌려 보고 확대·축소하며 살펴보는 도구입니다. Google이 공개한 오픈소스 웹 컴포넌트 <model-viewer>를 사이트에 직접 올려 쓰며, 모델 아래에 부드러운 그림자를 깔고 기본으로 천천히 자동 회전시킵니다. 3D 프로그램을 설치하지 않은 컴퓨터에서도 모델이 어떻게 생겼는지 바로 확인할 수 있습니다.

언제 쓰나

  • 외주로 제작한 시설물·제품 3D 모델을 납품받아 형태와 색을 검수할 때
  • 홈페이지나 전시 콘텐츠에 올릴 3D 파일이 웹에서 제대로 보이는지 미리 확인할 때
  • 3D 프로그램이 없는 동료에게 모델을 보여 주며 의견을 받을 때
  • 인터넷에서 받은 glTF 샘플 모델의 구성을 살펴볼 때

사용 방법

  1. 점선 상자에 .glb 파일을 끌어다 놓거나 상자를 클릭해 고릅니다. .gltf라면 같은 폴더의 .bin 파일과 텍스처 이미지까지 한꺼번에 선택하거나 끌어다 놓습니다.
  2. 마우스 왼쪽 버튼으로 끌면 회전, 휠로 확대·축소합니다. 휴대폰에서는 한 손가락으로 돌리고 두 손가락으로 확대합니다.
  3. '자동 회전' 체크를 풀면 회전이 멈춰 원하는 각도에서 자세히 볼 수 있습니다.
  4. '와이어프레임'을 켜면 면 대신 폴리곤 모서리 선만 그려져 메시 구성과 폴리곤 밀도를 확인할 수 있습니다. 끄면 원래 재질로 돌아갑니다.

결과 해석

가장 다루기 쉬운 것은 .glb입니다. 모델 형상, 재질, 텍스처 이미지를 한 파일에 담은 바이너리라 이 도구에 그대로 넣으면 됩니다. 반면 .gltf는 {"asset":{"version":"2.0"}, "buffers":[{"uri":"model.bin"}], ...}처럼 형상 데이터(.bin)와 텍스처 이미지를 별도 파일로 가리키는 경우가 많습니다. 이런 .gltf는 참조하는 파일을 함께 넣어야 합니다. 여러 파일을 같이 고르면 .gltf 안의 파일 이름과 맞춰 연결하고, 빠진 파일이 있으면 상자 아래에 그 이름을 알려 줍니다. .bin이 없으면 형상을 만들 수 없어 불러오지 않고, 텍스처만 빠졌으면 색 없이 형상만 보입니다. 데이터를 파일 안에 포함(embedded)한 .gltf나 .glb는 파일 하나로 충분합니다. 모델이 너무 작거나 크게 보이면 제작 단위(미터·센티미터) 설정이 잘못된 경우가 많습니다.

주의할 점

.gltf와 리소스 파일은 이름(경로를 뺀 파일명)으로 짝을 짓기 때문에, 서로 다른 폴더에 같은 이름의 텍스처가 있으면 하나만 쓰입니다. 수십 MB가 넘는 모델은 기기 성능에 따라 불러오기와 회전이 느릴 수 있습니다. OBJ, FBX, STL 같은 다른 형식은 열 수 없으니 먼저 glTF로 변환해야 합니다. 파일은 서버로 올라가지 않고 이 브라우저에서만 표시됩니다.

자주 묻는 질문

휴대폰에서 AR(증강현실)로 볼 수 있나요?
AR 기능이 켜져 있어 지원 기기에서는 AR 버튼이 나타날 수 있지만, 내 파일을 불러온 경우 기기와 브라우저에 따라 동작하지 않을 수 있습니다.
모델 사진을 저장할 수 있나요?
저장 버튼은 없습니다. 원하는 각도에서 자동 회전을 끄고 화면 캡처를 이용하세요.
