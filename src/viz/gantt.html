간트 차트 생성기

작업·시작일·종료일·진행률을 적으면 프로젝트 일정표를 그려 줍니다.

보기
오픈소스 Frappe Gantt(MIT, frappe/gantt)를 자체 호스팅합니다. 한 줄에 작업명, 시작일, 종료일, 진행률(%) 형식으로 입력합니다. 모든 처리는 브라우저에서만 이루어집니다.

간트 차트 생성기 사용 안내

무엇을 하는 도구인가

작업 이름, 시작일, 종료일, 진행률을 한 줄씩 적으면 가로 막대로 된 일정표(간트 차트)를 그려 줍니다. 그리기에는 오픈소스 라이브러리 Frappe Gantt를 쓰며, 막대 안쪽의 진한 부분이 진행률을, 막대 길이가 기간을 나타냅니다. 보기 단위를 일·주·월로 바꿔 짧은 작업은 자세히, 긴 프로젝트는 넓게 볼 수 있습니다. 입력을 멈추면 잠시 뒤 자동으로 다시 그려집니다.

언제 쓰나

  • 사업계획서나 착수보고서에 넣을 추진 일정표를 만들 때
  • 주간 회의에서 작업별 진행률과 지연 여부를 함께 보여 줄 때
  • 용역 과업의 분석·설계·구축·시험 단계가 서로 얼마나 겹치는지 확인할 때
  • 행사 준비처럼 마감이 정해진 일을 거꾸로 배치해 볼 때

사용 방법

  1. 입력란에 한 줄에 하나씩 작업명, 시작일, 종료일, 진행률을 적습니다. 진행률은 0~100 숫자이며 빼면 0으로 봅니다.
  2. 날짜는 2026-07-01처럼 연-월-일 형식으로 적습니다.
  3. '보기'에서 일·주·월 단위를 고릅니다.
  4. 자동으로 갱신되지 않았다면 [그리기]를 누릅니다.

결과 해석

예를 들어 다음처럼 입력하면 세 개의 막대가 계단처럼 이어집니다.

현황 분석, 2026-09-01, 2026-09-12, 100
요구사항 정의, 2026-09-10, 2026-09-26, 50
설계, 2026-09-21, 2026-10-16, 0

앞 작업의 막대가 끝나기 전에 다음 막대가 시작하면 두 작업이 병행된다는 뜻입니다. 오늘 날짜가 지났는데 진행률이 낮은 막대는 지연 후보로 볼 수 있습니다. 화면의 막대는 마우스로 끌어 옮기거나 진행률 손잡이를 움직일 수 있지만, 그렇게 바꾼 내용은 입력란에 반영되지 않고 다시 그리면 원래대로 돌아갑니다. 일정을 고치려면 입력란의 날짜를 수정하세요.

주의할 점

날짜 형식이 틀리면 오류 문구가 뜨고 차트가 그려지지 않습니다. 작업 이름에 쉼표가 들어가면 구분자로 읽혀 칸이 밀리니 쉼표를 빼세요. 차트 라이브러리가 지원하는 언어가 한정되어 월 이름은 중국어 화면에서만 중국어로, 그 밖에는 영어로 표시됩니다. 작업 간 선후 관계(의존성) 화살표는 제공하지 않습니다. [⬇️ PNG 저장]은 가로로 스크롤되는 부분까지 차트 전체를 흰 바탕의 2배 해상도 이미지로 저장합니다.

자주 묻는 질문

주말이나 공휴일을 빼고 계산하나요?
아니요. 시작일부터 종료일까지 달력 날짜 그대로 막대를 그립니다. 근무일 기준 일정은 날짜를 직접 조정해 입력해야 합니다.
입력한 일정이 저장되나요?
저장되지 않습니다. 새로고침하면 예시로 돌아가므로 입력한 텍스트를 따로 복사해 두세요.
