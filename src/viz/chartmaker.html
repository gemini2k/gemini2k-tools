차트 메이커

데이터를 붙여넣으면 막대·선·원·산점도 차트를 바로 그려 줍니다. PNG로 내려받아 보고서·블로그에 쓰세요.

📖
사용 방법
  1. 차트 종류를 고르고, 데이터를 한 줄에 하나씩 입력합니다(이름,값 · 산점도는 x,y)
  2. 제목·색을 지정하면 실시간으로 차트가 갱신됩니다
  3. 'PNG 내려받기'로 이미지를 저장합니다
막대·선·원형은 이름,값, 산점도는 x,y 형식입니다. 라이브러리 없이 캔버스로 직접 그리므로 빠르고 외부 전송이 없습니다. 모든 처리는 브라우저에서만 이루어집니다.

차트 메이커 사용 안내

무엇을 하는 도구인가

붙여넣은 데이터를 막대·선·원형·산점도 차트로 그려 820×460 픽셀 PNG로 내려받게 해 주는 도구입니다. 차트 라이브러리를 쓰지 않고 브라우저 캔버스에 직접 그리기 때문에 화면 크기와 상관없이 항상 같은 크기의 이미지가 나오고, 흰 배경이 깔려 있어 문서에 붙였을 때 투명 배경 문제가 없습니다. 막대·선은 고른 색 한 가지로, 원형은 항목마다 정해진 색으로 칠하고 오른쪽에 비율(%) 범례를 붙입니다.

언제 쓰나

  • 한글·워드 보고서에 같은 크기의 차트 이미지를 여러 장 맞춰 넣을 때
  • 블로그나 사내 게시판에 간단한 월별 추이 그래프를 올릴 때
  • 교육 시간과 평가 점수처럼 두 수치의 관계를 산점도로 훑어볼 때
  • 엑셀을 열기 번거로운 상황에서 숫자 몇 개를 바로 그림으로 만들 때

사용 방법

  1. '종류'에서 막대·선·원형·산점도 중 하나를 고릅니다.
  2. '제목'과 '색'을 정합니다. 색은 막대·선·산점도에 적용됩니다.
  3. '데이터'에 한 줄에 하나씩 입력합니다. 막대·선·원형은 이름,값, 산점도는 x,y이며 쉼표 대신 탭도 됩니다.
  4. [⬇️ PNG 내려받기]로 저장합니다. [샘플]은 예시 데이터로 되돌립니다.

결과 해석

산점도는 두 숫자를 한 줄에 적습니다. 예를 들어 교육 이수 시간과 평가 점수라면 다음과 같습니다.

4,62
8,70
12,75
16,83
20,88

점이 오른쪽 위로 올라가면 두 값이 함께 커진다는 뜻이지만, 원인과 결과를 말해 주지는 않습니다. 막대·선의 세로축 눈금은 최댓값을 1·2·5·10 단위의 보기 좋은 값으로 올려 다섯 칸으로 나누며, 값에 음수가 있으면 0 아래까지 축이 내려갑니다. 원형의 범례 비율은 반올림 값이라 합이 100%에서 1% 정도 어긋날 수 있습니다.

주의할 점

산점도는 세로축의 최솟값·최댓값만 표시하고 가로축 눈금은 그리지 않으므로, 보고서에 쓸 때는 축 설명을 본문에 따로 적어 주세요. 원형에서 음수는 0으로 처리됩니다. 항목이 많거나 이름이 길면 가로축 라벨이 겹치니 이름을 줄이거나 항목을 묶으세요. 막대·선·원형에서는 항목,1,200처럼 값에 천 단위 쉼표가 들어가도 1200으로 읽습니다. 산점도는 x,y 두 숫자를 쉼표로 나누므로 천 단위 쉼표를 빼고 넣거나 x와 y를 탭으로 구분하세요.

자주 묻는 질문

여러 계열(작년·올해)을 한 차트에 그릴 수 있나요?
이 도구는 계열 하나만 그립니다. 두 계열을 겹쳐 비교하는 차트는 엑셀 같은 스프레드시트의 차트 기능으로 만드는 편이 낫습니다.
이미지 해상도를 더 키울 수 있나요?
출력 크기는 820×460으로 고정입니다. 더 큰 이미지가 필요하면 화면 해상도의 두 배로 저장하는 고급 차트 생성기(ECharts)를 이용해 보세요.
