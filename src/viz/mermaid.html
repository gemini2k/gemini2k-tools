Mermaid 다이어그램 사용 안내

무엇을 하는 도구인가

Mermaid는 짧은 텍스트 문법으로 순서도, 시퀀스 다이어그램, 간트 차트, 클래스 다이어그램, 파이 차트 등을 그리는 오픈소스 도구입니다. 이 페이지는 Mermaid 10 버전을 사이트에 직접 올려 두고, 입력이 멈추면 잠시 뒤 미리보기를 다시 그립니다. 위쪽 다섯 개의 예시 버튼(순서도·시퀀스·간트·클래스·파이)을 누르면 해당 형식의 기본 코드가 들어가므로 거기서부터 고쳐 쓰면 됩니다. 결과는 SVG 또는 두 배 해상도 PNG로 저장합니다.

언제 쓰나

  • 민원 처리나 결재 절차를 순서도로 정리해 업무 매뉴얼에 넣을 때
  • 시스템 간 요청과 응답 순서를 시퀀스 다이어그램으로 설계 문서에 남길 때
  • GitHub, 위키처럼 Mermaid를 지원하는 문서에 넣을 코드를 미리 확인할 때
  • 그림 파일 대신 텍스트로 관리해 나중에 고치기 쉬운 도식이 필요할 때

사용 방법

  1. 예시 버튼으로 형식을 불러오거나 입력란에 직접 코드를 씁니다.
  2. 아래 미리보기를 확인합니다. 문법이 틀리면 첫 줄 오류 메시지가 표시됩니다.
  3. [⬇️ SVG] 또는 [⬇️ PNG]로 저장합니다.

결과 해석

순서도는 첫 줄에 방향을 정합니다. graph TD는 위에서 아래, graph LR은 왼쪽에서 오른쪽입니다.

graph LR
  A[민원 접수] --> B{담당 부서 확인}
  B -->|해당| C[처리]
  B -->|비해당| D[이송]
  C --> E[결과 통보]

[ ]는 사각형, { }는 판단(마름모), ( )는 둥근 상자이고, -->|글자|는 화살표 위에 조건을 적습니다. 앞의 A, B 같은 영문 ID로 노드를 구분하므로 한 노드를 여러 줄에서 쓸 때는 같은 ID를 쓰면 됩니다. 시퀀스 다이어그램에서 ->>는 실선(요청), -->>는 점선(응답) 화살표입니다.

주의할 점

보안 설정이 엄격 모드라 노드 클릭 링크 같은 상호작용 문법은 동작하지 않습니다. 다크 모드로 페이지를 열면 다크 테마로 그려지는데, PNG는 흰 배경으로 저장되므로 글자가 흐리게 보일 수 있습니다. 보고서용 이미지는 라이트 모드에서 저장하는 것이 안전합니다. 괄호나 따옴표가 들어간 문구는 A["처리(1차)"]처럼 큰따옴표로 감싸야 오류가 나지 않습니다.
