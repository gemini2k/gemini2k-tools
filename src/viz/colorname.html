색 이름 변환기

색을 고르면 가장 가까운 CSS 색상 이름을, 색 이름을 입력하면 HEX를 알려 줍니다. 줄을 클릭하면 복사돼요.

자주 쓰는 CSS 표준 색상 이름 124개 중 가장 가까운 이름을 RGB 거리로 찾습니다. 정확히 일치하지 않으면 '가장 가까운' 이름입니다. 모든 처리는 브라우저에서만 이루어집니다.

색 이름 변환기 사용 안내

무엇을 하는 도구인가

CSS에는 tomato, steelblue처럼 이름만으로 쓸 수 있는 색이 정해져 있습니다. 이 도구는 고르거나 입력한 색에서 가장 가까운 CSS 색 이름을 찾아 주고, 거꾸로 색 이름을 입력하면 그 색의 HEX 값을 보여 줍니다. 결과는 '가장 가까운 CSS 이름', '이름의 HEX', 'RGB', 'HEX' 네 줄로 나오며, 줄을 클릭하면 값이 클립보드에 복사됩니다. 내장된 이름 목록은 자주 쓰는 CSS 색 이름 124개입니다(CSS 표준 전체 148개 중 일부).

언제 쓰나

  • 디자이너가 준 HEX 값을 개발 문서나 회의에서 말로 부를 이름이 필요할 때
  • CSS나 SVG 코드에서 본 darkslategray 같은 이름이 실제로 어떤 색인지 확인할 때
  • 차트나 지도 범례 색을 이름으로 정리해 스타일 가이드를 만들 때
  • HEX 값을 RGB 표기로 바꿔야 할 때

사용 방법

  1. 왼쪽 색상 선택 상자를 눌러 색을 고르거나, 오른쪽 입력란에 #4DA3FF, #f60 같은 HEX 또는 tomato 같은 이름을 적습니다.
  2. 가운데 견본 띠에서 입력한 색을 확인합니다.
  3. 아래 결과 줄을 클릭해 필요한 값을 복사합니다.

결과 해석

예를 들어 #4DA3FF를 넣으면 가장 가까운 이름 옆에 '(근사)'가 붙고, 그 이름의 실제 HEX가 함께 나옵니다. 입력값과 이름의 HEX를 나란히 놓고 보면 얼마나 차이가 나는지 알 수 있습니다. #FF6347처럼 이름이 있는 색과 정확히 같으면 '(정확)'으로 표시됩니다. 가까움은 빨강·초록·파랑 값의 단순 거리로 계산하므로, 사람 눈에 비슷해 보이는 정도와는 다를 수 있습니다. 특히 채도가 낮은 회색 계열이나 아주 어두운 색은 이름이 실제 느낌과 어긋나는 경우가 있습니다.

주의할 점

근사로 나온 이름을 코드에 그대로 쓰면 원래 색과 달라집니다. 브랜드 색처럼 정확해야 하는 곳에는 HEX 값을 쓰고, 이름은 부르기 위한 별칭 정도로만 쓰세요. 이름 입력은 영문 소문자 CSS 이름만 인식하며 '빨강' 같은 한국어 색 이름은 받지 않습니다. 목록에 없는 일부 CSS 이름은 인식되지 않을 수 있습니다.

자주 묻는 질문

gray와 grey는 같은 색인가요?
CSS에서는 두 철자 모두 같은 색(#808080)을 뜻하지만, 이 도구의 목록에는 gray 철자만 들어 있습니다.
투명도(알파)가 있는 색도 되나요?
아니요. 3자리나 6자리 HEX만 받습니다. 8자리 HEX나 rgba 값은 알파를 빼고 입력하세요.
