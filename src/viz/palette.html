색 팔레트 생성기

기준 색 하나로 보색·유사·삼각 배색과 명도·채도 변형 팔레트를 만듭니다. 색을 클릭하면 HEX가 복사됩니다.

기준 색
HSL 색상환을 기준으로 배색을 계산합니다. 보색(180°), 유사색(±30°), 삼각(120°), 사각(90°) 배색과, 같은 색의 명도(Shade)·옅은 톤(Tint)을 제공합니다. 색을 클릭하면 HEX 코드가 복사됩니다. 모든 처리는 브라우저에서 이루어집니다.

색 팔레트 생성기 사용 안내

무엇을 하는 도구인가

기준 색 하나를 정하면 색상환에서 일정한 각도만큼 떨어진 색을 계산해 배색 조합을 만들어 주는 도구입니다. 색을 색상(H)·채도(S)·밝기(L)로 나누는 HSL 방식으로 계산하며, 보색(180°), 유사색(±30°), 삼각 배색(120° 간격), 사각 배색(90° 간격) 네 가지 조합과, 같은 색상에서 밝기만 바꾼 명도 단계 5개, 채도와 밝기를 함께 바꾼 단색조 5개를 보여 줍니다. 색 견본을 클릭하면 HEX 코드가 복사됩니다.

언제 쓰나

  • 기관 대표 색을 기준으로 발표 자료의 강조색·보조색을 정할 때
  • 차트에서 항목별로 구분이 잘 되는 색 3~4개가 필요할 때
  • 보고서 표의 머리글·짝수 행 배경처럼 같은 계열의 옅고 진한 색이 필요할 때
  • 웹페이지 버튼·배경·테두리 색을 한 계열로 맞출 때

사용 방법

  1. 색상 선택 상자를 눌러 기준 색을 고르거나, 옆 입력란에 6자리 HEX(예: #2563EB)를 적습니다.
  2. 아래에 배색별 견본 줄이 바로 만들어집니다.
  3. 쓰고 싶은 견본을 클릭해 HEX 코드를 복사합니다.

결과 해석

예를 들어 기준 색이 파랑 계열(색상 약 220°)이면 보색은 주황 계열(약 40°)이 됩니다. 보색은 서로를 가장 강하게 돋보이게 하므로 '강조 한 곳'에만 쓰고 넓은 면적에 함께 쓰지 않는 것이 좋습니다. 유사색은 차분하게 어울려 배경과 보조 요소에 알맞고, 삼각·사각 배색은 차트 계열 색처럼 서로 구분돼야 하는 곳에 씁니다. 명도 줄은 밝기 20%·35%·50%·65%·80% 순서라, 왼쪽의 진한 색은 글자나 테두리에, 오른쪽의 옅은 색은 배경에 쓰면 됩니다.

주의할 점

HSL의 밝기 값이 같아도 노랑과 파랑은 사람 눈에 밝기가 꽤 다르게 느껴집니다. 그래서 계산상 같은 밝기의 삼각 배색이라도 어떤 색은 튀고 어떤 색은 묻혀 보일 수 있으니 실제 자료에 놓고 확인하세요. 글자색과 배경색 조합은 명암 대비가 충분한지 별도로 점검해야 읽기 쉬운 문서가 됩니다. 입력란은 6자리 HEX만 받으며, 3자리 줄임 표기는 반영되지 않습니다.

자주 묻는 질문

회색이나 흰색을 기준 색으로 하면 어떻게 되나요?
채도가 0인 색은 색상 각도가 의미가 없어 보색·유사색이 모두 같은 회색으로 나옵니다. 명도 줄만 쓸모가 있습니다.
만든 팔레트를 저장할 수 있나요?
저장 기능은 없습니다. 필요한 HEX를 복사해 문서나 스타일 가이드에 적어 두세요.
