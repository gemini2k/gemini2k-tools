UML 다이어그램 생성기

간단한 텍스트로 클래스·관계 다이어그램을 그립니다.

오픈소스 nomnoml(MIT, skanaar/nomnoml)을 자체 호스팅합니다. [클래스|속성|메서드], 관계는 -> 1-* -- 등으로 표현합니다. 모든 처리는 브라우저에서만 이루어집니다.

UML 다이어그램 생성기 사용 안내

무엇을 하는 도구인가

대괄호로 상자를 적고 기호로 관계를 이으면 UML 클래스 다이어그램 형태의 그림을 그려 주는 도구입니다. 텍스트 기반 다이어그램 라이브러리 nomnoml을 사이트에 직접 올려 쓰며, PlantUML보다 문법이 훨씬 짧아 몇 줄만으로 클래스와 관계를 표현할 수 있습니다. 상자 배치는 자동으로 계산되고, 결과는 SVG 또는 두 배 해상도 PNG로 저장합니다. 입력을 멈추면 잠시 뒤 다시 그려집니다.

언제 쓰나

  • 시스템 개발 산출물(분석·설계서)에 넣을 클래스 다이어그램 초안을 만들 때
  • 데이터 모델의 엔터티와 관계(1대다, 다대다)를 회의에서 빠르게 맞춰 볼 때
  • 기존 시스템의 구성 요소 관계를 문서로 정리할 때
  • 교육 자료에서 상속·포함 관계를 그림으로 설명할 때

사용 방법

  1. 입력란에 상자와 관계를 한 줄씩 적습니다. 처음에는 회원·주문·상품 예시가 들어 있습니다.
  2. 미리보기를 확인합니다. 문법 오류가 있으면 위에 오류 메시지가 나옵니다.
  3. [⬇️ SVG] 또는 [⬇️ PNG]로 저장합니다.

결과 해석

상자는 [이름|속성;속성|메서드()] 형식으로, 세로 막대가 칸을 나누고 세미콜론이 칸 안의 줄을 나눕니다. 관계는 두 상자 사이에 기호를 넣어 표현합니다.

#direction: right
[사용자|+아이디;+이름|+로그인()]
[관리자]-:>[사용자]
[사용자]1-*[신청서]
[신청서]+-[첨부파일]
[신청서]-->[결재선]

-:>는 상속(관리자는 사용자의 한 종류), 1-*는 한쪽 끝에 1, 다른 끝에 *를 적는 일대다 관계, +-는 신청서가 첨부파일을 소유하는 합성 관계, -->는 점선 의존 관계입니다. 맨 위 #direction: right를 넣으면 위→아래 대신 왼쪽→오른쪽으로 배치됩니다. 같은 이름의 상자는 한 번만 그려지므로, 속성은 처음 한 번만 적고 관계 줄에서는 이름만 쓰면 됩니다.

주의할 점

PlantUML이나 Mermaid 문법은 그대로 쓸 수 없습니다. 이름이나 속성에 |, ;, [, ]를 넣으면 구분자로 읽히니 피하세요. 배치는 자동이라 상자 위치를 손으로 옮길 수 없으며, 관계가 많아지면 선이 겹쳐 복잡해질 수 있으니 주제별로 다이어그램을 나누는 편이 읽기 좋습니다. 입력 내용은 저장되지 않습니다.
