인터랙티브 차트 메이커

데이터를 입력하면 툴팁·범례가 있는 인터랙티브 차트를 그려 줍니다. PNG로 저장하세요.

오픈소스 Chart.js(MIT, chartjs/Chart.js)를 자체 호스팅합니다. 마우스를 올리면 값이 표시됩니다. 모든 처리는 브라우저에서만 이루어집니다.

인터랙티브 차트 메이커 사용 안내

무엇을 하는 도구인가

'라벨,값' 형태로 적은 데이터 한 묶음을 오픈소스 차트 라이브러리 Chart.js로 그려 줍니다. 막대·선·원·도넛·레이더·극좌표 여섯 종류 가운데 고를 수 있고, 차트 위에 마우스를 올리면 해당 항목의 값이 툴팁으로 뜹니다. 원·도넛·극좌표처럼 항목별로 색이 다른 차트는 범례를 클릭해 항목을 잠시 숨겼다가 다시 켤 수 있습니다. 완성된 차트는 흰 배경의 PNG로 저장됩니다.

언제 쓰나

  • 월별 실적이나 분기별 민원 건수를 주간 보고 자료에 막대그래프로 넣을 때
  • 예산 항목별 비중을 원·도넛 차트로 보여 줄 때
  • 평가 항목 점수(예: 기획·실행·소통·성과)를 레이더 차트로 비교해 볼 때
  • 회의 중 화면을 공유하면서 값 위에 마우스를 올려 수치를 바로 짚어 줄 때

사용 방법

  1. '데이터' 칸에 한 줄에 하나씩 라벨,값을 적습니다. 엑셀에서 두 열을 복사해 붙여넣으면 탭으로 구분돼도 인식합니다.
  2. '종류'에서 차트 형태를 고릅니다.
  3. '제목'에 적은 내용은 차트 위 제목과 툴팁의 계열 이름으로 쓰입니다. 비우면 제목이 나오지 않습니다.
  4. [⬇️ PNG 저장]으로 이미지 파일을 받습니다.

결과 해석

예를 들어 아래처럼 입력하면 네 개 부서의 막대가 그려집니다.

기획팀,42
운영팀,35
정보화팀,28
감사팀,15

같은 데이터를 '원'으로 바꾸면 전체 합 120 중 기획팀이 35% 정도를 차지하는 식으로 비중이 보입니다. 원·도넛은 항목 수가 많아지면 조각이 가늘어져 읽기 어려우므로 대여섯 개 이하에서 쓰고, 그보다 많으면 막대가 낫습니다. 선 차트는 시간 순서가 있는 데이터(월, 연도)에만 쓰는 것이 원칙입니다. 부서처럼 순서가 없는 항목을 선으로 이으면 추세가 있는 것처럼 잘못 읽힙니다.

주의할 점

계열은 하나만 지원합니다. 올해와 작년처럼 두 계열을 겹쳐 비교하려면 다른 차트 도구를 쓰세요. 값 칸이 숫자가 아니면 0으로 처리되고, 천 단위 쉼표가 들어간 숫자(1,200)는 쉼표가 구분자로 읽혀 값이 1이 되므로 쉼표 없이 적어야 합니다. 저장되는 PNG 크기는 화면에 그려진 차트 크기를 따르므로, 큰 이미지가 필요하면 창을 넓힌 뒤 저장하세요.

자주 묻는 질문

음수 값도 그릴 수 있나요?
막대·선 차트는 음수를 0 아래로 그립니다. 원·도넛처럼 비중을 나타내는 차트에서는 음수가 의미가 없으니 쓰지 마세요.
입력한 데이터가 어딘가로 전송되나요?
아니요. 차트 라이브러리를 이 사이트에서 직접 제공하고, 그리기와 저장은 모두 브라우저 안에서 이루어집니다.
