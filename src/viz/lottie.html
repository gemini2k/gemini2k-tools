Lottie 애니메이션 뷰어

Lottie 애니메이션(.json)을 불러와 재생하며 미리봅니다.

✨ Lottie JSON 파일을 끌어다 놓거나 클릭해서 선택
속도 1x
오픈소스 lottie-web(MIT, airbnb/lottie-web)을 자체 호스팅합니다. 처음에는 샘플 애니메이션이 표시됩니다. 모든 처리는 브라우저에서만 이루어집니다.

Lottie 애니메이션 뷰어 사용 안내

무엇을 하는 도구인가

Lottie는 After Effects 같은 프로그램에서 만든 애니메이션을 JSON 텍스트로 내보내 웹과 앱에서 가볍게 재생하도록 만든 형식입니다. 이 도구는 오픈소스 재생 라이브러리 lottie-web을 사이트에 직접 올려 두고, 내 컴퓨터의 Lottie JSON 파일을 불러와 SVG 방식으로 재생합니다. 재생·일시정지, 처음부터 다시 보기, 0.25배~2배 속도 조절, 반복 재생 켜고 끄기를 할 수 있습니다. 처음 열면 크기가 커졌다 작아지는 파란 원 샘플이 재생됩니다.

언제 쓰나

  • 외주 디자이너에게 받은 로딩·완료 애니메이션 파일이 제대로 재생되는지 납품 검수할 때
  • 개발자에게 전달하기 전에 애니메이션 길이와 반복 시 끊김이 없는지 확인할 때
  • 공유 사이트에서 내려받은 애니메이션 여러 개를 비교해 보고 하나를 고를 때
  • 속도를 낮춰 특정 동작이 어떻게 움직이는지 자세히 살펴볼 때

사용 방법

  1. 점선 상자에 .json 파일을 끌어다 놓거나 상자를 클릭해 파일을 고릅니다.
  2. 불러오면 바로 재생되고, 상자에 파일 이름이 표시됩니다.
  3. [⏸ 일시정지]와 [↺ 처음부터]로 재생을 제어합니다.
  4. '속도' 슬라이더로 재생 속도를, '반복' 체크로 반복 여부를 바꿉니다.

결과 해석

Lottie JSON의 맨 앞에는 기본 정보가 들어 있습니다. 예를 들어 {"v":"5.7.4","fr":30,"ip":0,"op":60,"w":300,"h":300, ...}라면 초당 30프레임(fr)으로 0번부터 60번 프레임(ip~op)까지, 즉 2초 길이이며 화면 크기는 300×300(w, h)입니다. 반복 재생할 때 마지막 장면에서 처음 장면으로 넘어가며 툭 끊긴다면 시작과 끝 프레임의 모양이 서로 맞지 않는 것이니 제작자에게 수정을 요청하면 됩니다. 일부 요소가 보이지 않는다면 그 효과가 웹 재생기에서 지원되지 않는 경우일 수 있습니다.

주의할 점

파일이 JSON 문법에 맞지 않으면 오류 알림이 뜨고 불러오지 않습니다. 이미지가 별도 파일로 분리된 애니메이션은 JSON만 불러오면 이미지 부분이 빠지므로, 이미지가 JSON 안에 포함된 형태로 내보내야 제대로 보입니다. 압축된 .lottie 파일은 이 도구에서 열 수 없습니다. 파일은 브라우저 안에서만 읽고 서버로 보내지 않습니다.
