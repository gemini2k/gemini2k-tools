CSV·JSON → 엑셀(XLSX) 변환기

CSV나 JSON을 붙여넣으면 표로 미리보고 엑셀 파일(.xlsx)로 내려받습니다.

📖
사용 방법
  1. CSV(쉼표/탭 구분) 또는 JSON 배열을 붙여넣습니다
  2. 입력 형식과 시트 이름을 확인합니다
  3. '엑셀 다운로드'를 누르면 .xlsx 파일이 저장됩니다
표는 미리보기용이며 실제 변환은 전체 데이터로 이루어집니다. JSON은 객체 배열(예: [{"이름":"홍길동",…}])이어야 합니다. 모든 처리는 브라우저에서만 이루어집니다.

CSV·JSON → 엑셀(XLSX) 변환기 사용 안내

무엇을 하는 도구인가

붙여 넣은 CSV나 JSON을 표로 미리 보여 주고, SheetJS(xlsx 0.18.5) 라이브러리로 진짜 엑셀 통합문서(.xlsx)를 만들어 data.xlsx로 내려받게 합니다. CSV는 첫 줄을 머리글로 쓰며 쉼표·세미콜론·탭·세로줄 중 첫 줄에 가장 많이 나오는 기호를 구분자로 고르고, 큰따옴표로 감싼 값 안의 쉼표와 줄바꿈도 처리합니다. JSON은 객체 배열을 받아 모든 객체에 나온 키를 합쳐 열로 만듭니다.

언제 쓰나

  • 시스템에서 내려받은 CSV를 엑셀에서 열면 한글이 깨지거나 앞자리 0이 사라질 때
  • API 응답 JSON을 비개발 부서에 엑셀 파일로 전달해야 할 때
  • DB 쿼리 결과를 탭 구분으로 복사해 보고용 시트로 만들 때
  • 시트 이름을 정해 둔 엑셀 양식으로 데이터를 넘겨야 할 때

사용 방법

  1. 「데이터 입력」에 CSV나 JSON을 붙여 넣습니다. 아래 표가 바로 갱신됩니다.
  2. 「입력」에서 자동 감지·CSV·JSON 중 하나를 고릅니다. 자동 감지는 내용이 [나 {로 시작하면 JSON으로 봅니다.
  3. 「시트 이름」을 정합니다. 31자를 넘으면 자르고, 엑셀이 금지하는 \ / ? * [ ] :는 밑줄로 바꿉니다.
  4. 「⬇️ 엑셀 다운로드 (.xlsx)」를 누릅니다.

결과 해석

CSV에서 온 값은 모두 텍스트 셀로 들어갑니다. 기본 예제의 입사년도 2019도 텍스트로 저장되어 엑셀에서 셀 왼쪽 위에 「텍스트로 저장된 숫자」 표시가 뜰 수 있습니다. 대신 010으로 시작하는 전화번호나 사번의 앞자리 0이 지워지지 않고, =로 시작하는 값도 수식으로 실행되지 않습니다. JSON에서는 숫자형 값이 숫자 셀로 들어가 바로 합계를 낼 수 있습니다. JSON 안에 객체나 배열이 들어 있는 값은 JSON 문자열 그대로 한 셀에 들어갑니다.

주의할 점

  • 미리보기 표는 처음 50행까지만 보여 주지만, 내려받는 파일에는 전체 행이 들어갑니다.
  • CSV 숫자로 계산하려면 엑셀에서 해당 열을 선택해 「텍스트를 숫자로 변환」을 하거나, 데이터를 JSON 형태로 넣으세요.
  • 열 너비, 글꼴, 머리글 굵게 같은 서식은 넣지 않습니다. 시트는 하나만 만들어집니다.
