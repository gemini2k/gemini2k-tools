워드(DOCX) 텍스트 추출기

워드 문서(.docx)에서 본문과 표의 텍스트를 추출합니다. 워드가 없어도 내용을 바로 확인하고 가져갈 수 있어요.

📖
사용 방법
  1. 워드 파일(.docx)을 끌어다 놓거나 클릭해 올립니다
  2. 본문·표 텍스트가 자동으로 추출됩니다
  3. '복사' 또는 '.txt 다운로드'로 가져갑니다
📝
워드 파일(.docx)을 끌어다 놓거나 클릭
.docx (구형 .doc는 미지원)
.docx(2007 이후 형식)만 지원합니다. 구형 .doc는 워드에서 .docx로 저장한 뒤 사용하세요. 본문과 표의 글자만 추출하며 서식·이미지는 제외됩니다. 파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

워드(DOCX) 텍스트 추출기 사용 안내

무엇을 하는 도구인가

.docx 파일은 여러 XML 파일을 ZIP으로 묶은 형식입니다. 이 도구는 JSZip으로 파일을 열어 본문이 담긴 word/document.xml을 꺼내고, 문단 끝은 줄바꿈으로, 탭과 줄 나눔은 그대로, 표의 칸 경계는 탭, 행 끝은 줄바꿈으로 바꾼 다음 태그를 모두 걷어 내 순수 텍스트만 남깁니다. 결과 위에 글자 수와 문단 수를 함께 보여 줍니다.

언제 쓰나

  • 워드가 설치되지 않은 PC나 태블릿에서 받은 문서의 내용만 빨리 확인할 때
  • 보고서 본문을 메일·메신저·사내 시스템 입력란에 서식 없이 옮길 때
  • 문서 글자 수를 세거나, 번역·요약 도구에 넣을 원문을 뽑을 때
  • 표 내용을 탭 구분 텍스트로 꺼내 엑셀에 붙여 넣을 때

사용 방법

  1. .docx 파일을 점선 영역에 끌어다 놓거나 영역을 클릭해 고릅니다.
  2. 추출된 텍스트와 「글자 ○자 · 문단 ○개」 정보를 확인합니다.
  3. 「📋 복사」로 클립보드에 담거나 「⬇️ .txt 다운로드」로 원래 파일 이름의 .txt 파일을 받습니다.

결과 해석

표는 한 행이 한 줄이 되고 칸 사이가 탭으로 나뉘어, 결과를 복사해 엑셀에 붙이면 칸이 대체로 맞게 들어갑니다. 여러 줄 연속된 빈 줄은 빈 줄 하나로 줄이고, 줄 끝 공백은 지웁니다. 글자 수는 줄바꿈과 탭을 포함한 추출 결과의 길이라서, 워드의 「단어 수」 창에 나오는 글자 수(공백 포함)와 다를 수 있습니다. 문단 수는 내용이 있는 줄의 개수라 표의 각 행도 하나로 셉니다.

주의할 점

  • 본문 파일만 읽으므로 머리글·바닥글·각주·미주·메모의 글자는 빠집니다.
  • 자동 번호 목록의 「1.」 「가.」 같은 번호는 워드가 화면에 그릴 때 붙이는 것이라 결과에 나오지 않습니다.
  • 변경 내용 추적 중인 문서는 삭제 표시된 글자도 함께 나올 수 있고, 목차·페이지 번호 같은 필드는 필드 코드 문구가 섞일 수 있습니다. 결과를 한 번 훑어보세요.
  • 구형 .doc, 암호가 걸린 .docx, 한글(.hwp) 파일은 읽지 못합니다.

자주 묻는 질문

이미지 속 글자도 뽑을 수 있나요?
아닙니다. 문서에 글자로 입력된 내용만 추출하며, 그림 안의 글자를 읽는 OCR 기능은 없습니다.
문서가 서버로 올라가나요?
아닙니다. 파일은 브라우저 안에서만 열고 처리합니다.
