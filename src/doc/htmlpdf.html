HTML·글 → PDF 변환기

HTML 코드나 글을 입력하면 A4 PDF로 만들어 줍니다. 한글도 깨지지 않아요(이미지 렌더 방식).

오픈소스 jsPDF(MIT)·html2canvas(MIT)를 자체 호스팅합니다. 내용을 이미지로 렌더해 PDF에 담으므로 한글·이모지·CSS가 그대로 보존되며, 길면 자동으로 여러 페이지로 나눕니다. 모든 처리는 브라우저에서만 이루어집니다.

HTML·글 → PDF 변환기 사용 안내

무엇을 하는 도구인가

입력 칸에 넣은 HTML을 미리보기 영역에 그린 다음, html2canvas로 그 영역을 2배 해상도 그림으로 찍고 jsPDF로 A4 세로 PDF에 붙입니다. 글자를 PDF 텍스트로 넣는 대신 화면 모양 그대로 이미지로 담기 때문에, PDF 글꼴에 한글이 없어 깨지는 흔한 문제가 생기지 않습니다. 그림 높이가 A4 한 쪽(297mm)을 넘으면 같은 그림을 위치만 옮겨 다음 쪽에 이어 붙입니다.

언제 쓰나

  • 간단한 안내문이나 회의 공지를 HTML로 빠르게 써서 PDF 첨부 파일로 보내야 할 때
  • 웹 편집기에서 복사한 HTML 조각을 모양 그대로 보관용 PDF로 남길 때
  • 이메일 서명이나 견적 표처럼 표·목록이 들어간 짧은 내용을 인쇄용으로 만들 때

사용 방법

  1. 입력 칸에 HTML을 붙여 넣거나 씁니다. <h1>, <p>, <table> 같은 태그를 쓸 수 있고, 태그 없는 일반 글도 됩니다.
  2. 입력을 멈추면 잠시 뒤 아래 미리보기가 갱신됩니다. 바로 보려면 「미리보기 새로고침」을 누릅니다.
  3. 「📄 PDF 만들기」를 누르면 document.pdf 파일이 내려받아집니다.

결과 해석

PDF 안의 내용은 JPEG 그림이므로 PDF 뷰어에서 글자를 드래그해 복사하거나 검색할 수 없습니다. 쪽이 넘어가는 곳은 문단 단위가 아니라 높이 기준으로 잘리므로, 글줄 한가운데가 두 쪽에 걸쳐 나뉠 수 있습니다.

주의할 점

  • 미리보기 영역은 화면에서 최대 400px 높이로 스크롤되도록 되어 있습니다. 내용이 길면 PDF에 일부만 담길 수 있으니 저장 후 마지막 쪽까지 꼭 확인하세요.
  • 태그 없이 쓴 일반 글은 줄바꿈이 무시되어 한 문단으로 붙습니다. 줄을 나누려면 <p>나 <br>를 쓰세요.
  • 외부 주소의 이미지는 보안 정책 때문에 그림 캡처에서 빠질 수 있습니다.
  • 검색 가능한 문서가 필요하면 브라우저 인쇄의 「PDF로 저장」이 더 맞습니다.
