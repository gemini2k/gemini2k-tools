PDF → 이미지(PNG) 변환기

PDF의 각 페이지를 PNG 이미지로 바꿉니다. 발표 자료·문서를 이미지로 공유하거나 캡처할 때 좋아요.

📖
사용 방법
  1. PDF 파일을 끌어다 놓거나 클릭해 올립니다
  2. 화질(해상도)을 고르면 페이지별 이미지가 생성됩니다
  3. 각 페이지를 '저장'하거나 '전체 저장'으로 한꺼번에 내려받습니다
🖼️
PDF 파일을 끌어다 놓거나 클릭
.pdf
화질을 높이면 더 선명하지만 시간과 메모리를 더 씁니다. 페이지가 매우 많은 PDF는 처음 50페이지까지 변환합니다. 파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

PDF → 이미지(PNG) 변환기 사용 안내

무엇을 하는 도구인가

Mozilla의 PDF.js로 PDF를 열고, 각 페이지를 캔버스에 그린 뒤 PNG 파일로 저장합니다. 텍스트·도형·이미지가 화면에 보이는 그대로 한 장의 그림이 되므로, PDF를 열 수 없는 환경이나 이미지만 올릴 수 있는 게시판·메신저에 문서를 공유할 때 씁니다. 한 파일에서 처음 50페이지까지 변환합니다.

언제 쓰나

  • 보도자료나 안내문 PDF의 첫 장을 홈페이지 게시판·SNS용 이미지로 올릴 때
  • 발표 자료 PDF에서 필요한 슬라이드 몇 장만 그림으로 떼어 보고서에 붙일 때
  • 단체 대화방에 PDF 대신 바로 보이는 이미지로 공지 내용을 보낼 때
  • 도면·서식 PDF를 이미지 편집기에서 표시를 덧그리기 위해 PNG로 바꿀 때

사용 방법

  1. 점선 상자를 클릭하거나 PDF를 끌어다 놓으면 바로 변환이 시작되고 진행 막대가 차오릅니다.
  2. 「화질」에서 보통·높음(기본)·아주 높음을 고르면 전체 페이지를 다시 그립니다.
  3. 페이지 카드 아래의 「저장」으로 한 장씩, 「⬇️ 전체 저장」으로 모든 페이지를 차례로 내려받습니다.

결과 해석

화질 옵션은 PDF 기본 크기(1포인트 = 1/72인치)에 곱하는 배율로, 보통 1.5배·높음 2배·아주 높음 3배입니다. A4 한 쪽(595×842포인트)을 「높음」으로 바꾸면 약 1190×1684픽셀 이미지가 됩니다. 파일 이름은 「원본이름_p3.png」처럼 페이지 번호가 붙습니다. 51페이지 이상인 파일은 완료 메시지에 전체 페이지 수와 함께 50페이지까지만 변환했다고 표시됩니다.

주의할 점

  • 「아주 높음」은 페이지당 메모리를 많이 써서, 페이지가 많으면 브라우저가 느려지거나 멈출 수 있습니다.
  • 결과는 그림이라 글자를 선택하거나 검색할 수 없습니다. 글자가 필요하면 PDF 텍스트 추출기를 쓰세요.
  • 암호가 걸린 PDF는 열리지 않습니다.

자주 묻는 질문

「전체 저장」을 눌렀는데 파일이 몇 개만 받아집니다.
여러 파일을 연달아 내려받으면 브라우저가 허용 여부를 묻는 경우가 있습니다. 주소창의 다운로드 차단 알림에서 허용한 뒤 다시 누르세요.
