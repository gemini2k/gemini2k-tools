PPT(PPTX) 텍스트 추출기

파워포인트(.pptx)의 모든 슬라이드 텍스트를 순서대로 추출합니다. 발표 자료 내용을 빠르게 가져오세요.

📖
사용 방법
  1. 파워포인트 파일(.pptx)을 끌어다 놓거나 클릭해 올립니다
  2. 슬라이드별 텍스트가 순서대로 추출됩니다
  3. '전체 복사' 또는 '.txt 다운로드'로 가져갑니다
📑
파워포인트 파일(.pptx)을 끌어다 놓거나 클릭
.pptx (구형 .ppt는 미지원)
.pptx(2007 이후 형식)만 지원합니다. 구형 .ppt는 파워포인트에서 .pptx로 저장 후 사용하세요. 도형·텍스트 상자의 글자를 슬라이드 순서대로 추출하며 이미지·차트 그림은 제외됩니다. 파일은 브라우저 안에서만 처리됩니다.

PPT(PPTX) 텍스트 추출기 사용 안내

무엇을 하는 도구인가

.pptx 파일은 슬라이드마다 XML 문서가 하나씩 들어 있는 ZIP 묶음입니다. 이 도구는 JSZip으로 압축을 풀어 ppt/slides/slide1.xml, slide2.xml … 파일을 번호 순으로 읽고, 그 안의 글자 조각(<a:t>)만 모아 슬라이드별로 보여 줍니다. 제목, 본문 개체 틀, 텍스트 상자, 도형과 표 안의 글자가 모두 대상입니다.

언제 쓰나

  • 발표 자료 내용을 회의록이나 결과 보고서 본문으로 옮겨 적어야 할 때
  • 슬라이드 수십 장짜리 교육 자료에서 오탈자를 찾으려고 글자만 모아 맞춤법 검사기에 넣을 때
  • 파워포인트가 없는 PC에서 받은 발표 파일에 무슨 내용이 있는지 먼저 확인할 때
  • 외국어 발표 자료를 번역기에 한꺼번에 넣기 위해 텍스트로 뽑을 때

사용 방법

  1. 점선 상자를 클릭하거나 .pptx 파일을 끌어다 놓습니다.
  2. 「슬라이드 n개 · 단어 n개」 요약과 함께 슬라이드별 카드가 표시됩니다.
  3. 「📋 전체 복사」나 「⬇️ .txt 다운로드」를 누르면 각 슬라이드 앞에 「=== 슬라이드 n ===」 구분선이 붙은 전체 텍스트를 가져갑니다.

결과 해석

줄은 파워포인트의 문단 단위로 나뉩니다. 한 문장 안에서 일부 단어만 굵게 하거나 색을 바꿔 글자 조각이 나뉘어 있어도 「매출이 12% 늘었다」는 한 줄로 이어서 나오고, Shift+Enter로 넣은 줄바꿈은 그대로 줄바꿈이 됩니다. 그림이나 차트만 있는 슬라이드는 「(텍스트 없음)」으로 표시됩니다. 단어 수는 공백 기준으로 센 값이라 한국어에서는 어절 수에 가깝습니다.

주의할 점

  • 순서는 파워포인트 화면의 슬라이드 순서(presentation.xml에 기록된 순서)를 따릅니다. 이 정보가 깨진 파일만 내부 파일 번호 순(slide2가 slide10보다 앞)으로 정렬합니다.
  • 숨긴 슬라이드도 함께 추출되며, 발표자 노트와 슬라이드 마스터에 들어간 글자는 포함되지 않습니다.
  • 차트의 축·데이터 레이블, 그림 속 글자는 나오지 않습니다.
  • 구형 .ppt는 지원하지 않습니다. 파워포인트에서 .pptx로 저장한 뒤 넣으세요.
