엑셀 → CSV·JSON 변환기

엑셀 파일(.xlsx·.xls)을 올려 원하는 시트를 CSV 또는 JSON으로 변환·다운로드합니다.

📖
사용 방법
  1. 엑셀 파일을 끌어다 놓거나 클릭해 올립니다
  2. 변환할 시트와 출력 형식(CSV/JSON)을 고릅니다
  3. 미리보기를 확인하고 '다운로드' 또는 '복사'합니다
📊
엑셀 파일을 끌어다 놓거나 클릭
.xlsx · .xls · .ods
파일은 서버로 전송되지 않고 브라우저 안에서만 변환됩니다. CSV는 UTF-8(BOM 포함)로 저장되어 엑셀에서 한글이 깨지지 않습니다. 여러 시트가 있으면 시트를 바꿔 각각 변환할 수 있습니다.

엑셀 → CSV·JSON 변환기 사용 안내

무엇을 하는 도구인가

엑셀 통합문서(.xlsx·.xls)나 오픈오피스 스프레드시트(.ods)를 SheetJS 라이브러리로 읽어, 고른 시트 하나를 CSV 또는 JSON 텍스트로 바꿉니다. CSV는 셀에 보이는 값을 쉼표로 이은 형식이고, JSON은 첫 행을 열 이름으로 삼아 행마다 객체 하나를 만든 배열입니다. 변환은 모두 브라우저 안에서 이루어집니다.

언제 쓰나

  • 업무 시스템의 일괄 등록 기능이 CSV만 받는데 자료가 엑셀로 정리되어 있을 때
  • 시트가 여러 개인 통합문서에서 특정 시트만 따로 떼어 다른 부서에 넘길 때
  • 개발자가 화면 테스트용 목업 데이터를 엑셀로 받아 JSON으로 바꿀 때
  • 엑셀이 설치되지 않은 PC에서 첨부 파일 내용을 텍스트로 확인할 때

사용 방법

  1. 점선 상자를 클릭하거나 파일을 끌어다 놓습니다. 시트 수가 표시됩니다.
  2. 「시트」에서 변환할 시트를, 「형식」에서 CSV 또는 JSON을 고릅니다. 아래 칸에 결과가 바로 보입니다.
  3. 「⬇️ 다운로드」로 파일을 받거나 「📋 복사」로 클립보드에 담습니다. 파일 이름은 「원본이름_시트이름.csv」 형식입니다.

결과 해석

첫 행이 「이름, 부서」이고 둘째 행이 「김철수, 총무과」인 시트라면 CSV는 그 두 줄이 그대로 나오고, JSON은 [{"이름":"김철수","부서":"총무과"}]처럼 머리글이 키가 됩니다. JSON에서 빈 셀은 빈 문자열로 채워집니다. CSV는 화면에 보이는 표시 형식(예: 2026-03-02, 1,200)대로 나오고, JSON은 서식 없는 원래 값을 씁니다. 다만 날짜 서식이 지정된 셀은 엑셀 내부의 일련번호 숫자 대신 "2026-03-02"처럼 ISO 형식 문자열로 바꾸며, 시각이 있으면 "2026-03-02T09:30:00"처럼 붙입니다. 미리보기 칸은 2만 자까지만 보여 주지만 다운로드와 복사에는 전체가 들어갑니다.

주의할 점

  • 수식은 다시 계산하지 않고 파일에 저장된 마지막 결과값을 씁니다. 글꼴·색·테두리·메모·차트는 모두 빠집니다.
  • 병합된 셀은 왼쪽 위 칸에만 값이 들어가고 나머지는 빈칸이 됩니다.
  • 머리글 행이 두 줄이거나 표 위에 제목 줄이 있으면 JSON 키가 엉뚱하게 잡히니, 원본에서 머리글을 한 줄로 정리한 뒤 변환하세요.

자주 묻는 질문

받은 CSV를 엑셀로 열면 한글이 깨지나요?
CSV 파일 앞에 UTF-8 BOM을 붙여 저장하므로 엑셀에서 바로 열어도 한글이 정상으로 보입니다. 다만 「복사」로 가져간 텍스트에는 BOM이 없습니다.
모든 시트를 한 번에 바꿀 수 있나요?
한 번에 한 시트씩입니다. 시트를 바꿔 가며 각각 다운로드하세요.
