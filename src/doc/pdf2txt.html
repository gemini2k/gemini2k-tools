PDF 텍스트 추출기

PDF에서 텍스트를 페이지 순서대로 추출합니다. 보고서·논문·계약서 내용을 빠르게 가져오세요.

📖
사용 방법
  1. PDF 파일을 끌어다 놓거나 클릭해 올립니다
  2. 페이지별 텍스트가 추출됩니다 (큰 파일은 잠시 걸릴 수 있어요)
  3. '복사' 또는 '.txt 다운로드'로 가져갑니다
📕
PDF 파일을 끌어다 놓거나 클릭
.pdf
텍스트가 들어 있는 PDF의 글자만 추출합니다. 스캔(이미지)으로 만든 PDF는 글자 정보가 없어 추출되지 않습니다(그런 경우 문자인식 OCR이 필요). 파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

PDF 텍스트 추출기 사용 안내

무엇을 하는 도구인가

PDF 파일 안에는 화면에 보이는 모양과 별도로 글자 정보(텍스트 레이어)가 들어 있는 경우가 많습니다. 이 도구는 PDF.js로 페이지마다 그 글자 정보를 읽어 순서대로 이어 붙이고, 페이지 사이에 「── 3페이지 ──」 같은 구분선을 넣어 하나의 텍스트로 보여 줍니다. 원본에 줄 끝 표시가 있으면 줄을 바꾸고, 겹친 공백은 하나로 줄입니다.

언제 쓰나

  • 계약서나 지침 PDF에서 특정 조항 문구를 그대로 인용해 공문에 옮길 때
  • 논문·보고서 본문을 번역기나 요약 도구에 넣기 전에 텍스트만 뽑을 때
  • PDF 뷰어에서 드래그 복사가 줄 단위로 끊겨 불편할 때 전체를 한꺼번에 가져올 때
  • 받은 PDF가 스캔본인지 텍스트 PDF인지 빠르게 판별할 때

사용 방법

  1. 점선 상자를 클릭하거나 PDF를 끌어다 놓습니다. 진행 막대와 「n/전체 페이지」가 표시됩니다.
  2. 추출이 끝나면 페이지 수와 글자 수가 나오고 아래 칸에 결과가 보입니다.
  3. 「📋 복사」로 클립보드에 담거나 「⬇️ .txt 다운로드」로 원본 이름의 텍스트 파일을 받습니다.

결과 해석

어떤 페이지 아래에 「(텍스트 없음)」이 나오면 그 페이지는 그림으로만 되어 있다는 뜻입니다. 전체 글자 수가 0이면 「스캔 PDF로 보입니다」 안내가 함께 표시되는데, 이때는 문자인식(OCR)을 거쳐야 글자를 얻을 수 있습니다. 반대로 글자가 나오기는 하는데 순서가 뒤섞여 있다면, 다단 편집이나 표처럼 PDF 안의 글자 배치 순서가 읽는 순서와 다르게 저장된 경우입니다.

주의할 점

  • 표는 칸 구분 없이 공백으로 이어진 글자로 나옵니다. 표 구조가 필요하면 원본 프로그램에서 복사하세요.
  • 글꼴 정보가 깨진 PDF는 글자가 엉뚱한 기호로 나올 수 있습니다. 화면에는 정상으로 보여도 내부 문자 대응표가 없는 경우입니다.
  • 암호로 열람이 막힌 PDF는 읽지 못합니다.

자주 묻는 질문

스캔한 PDF에서 글자를 뽑을 방법은 없나요?
이 도구로는 안 됩니다. 이미지 문자인식(OCR) 기능이 있는 프로그램이나 도구를 써야 합니다.
페이지 구분선을 빼고 싶어요.
현재는 항상 들어갑니다. 받은 텍스트에서 「──」로 시작하는 줄을 찾아 바꾸기로 지우면 됩니다.
