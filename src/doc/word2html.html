오픈소스 mammoth.js(BSD-2, mwilliamson/mammoth.js)를 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어지며 파일은 업로드되지 않습니다.

워드(.docx) → HTML·마크다운 변환기 사용 안내

무엇을 하는 도구인가

워드 문서(.docx)를 mammoth.js로 읽어 HTML 코드와 마크다운 텍스트로 바꿉니다. mammoth는 글꼴 크기나 색 같은 겉모양보다 문서 구조를 옮기는 데 초점을 둔 변환기라서, 워드의 「제목 1」 스타일은 <h1>로, 굵게·기울임은 <strong>·<em>으로, 글머리 기호와 번호 목록은 목록 태그로, 표는 <table>로 바꿉니다. 문서 속 그림은 별도 파일 없이 HTML 안에 데이터 형태로 함께 들어갑니다.

언제 쓰나

  • 워드로 받은 공지문이나 보도자료를 홈페이지 게시판 HTML 편집기에 깔끔하게 옮길 때
  • 워드에서 그대로 복사해 붙였을 때 따라오는 지저분한 서식 코드를 피하고 싶을 때
  • 사내 위키, GitHub, 노션처럼 마크다운을 쓰는 곳으로 문서를 옮길 때

사용 방법

  1. 점선 상자를 클릭하거나 .docx 파일을 끌어다 놓습니다.
  2. 위쪽 「HTML」·「마크다운」 버튼으로 보고 싶은 결과를 고릅니다. 아래 「미리보기」에는 HTML 결과가 실제 모양으로 표시됩니다.
  3. 「📋 복사」로 코드를 가져가거나 「⬇️ 저장」으로 word.html 또는 word.md 파일을 받습니다.

결과 해석

결과가 기대보다 밋밋하다면 원본 문서가 스타일을 쓰지 않고 글자 크기만 키워 제목처럼 보이게 만든 경우입니다. 이때 그 줄은 <h1>이 아닌 일반 문단 <p>로 나옵니다. 워드에서 제목 줄에 「제목 1」, 「제목 2」 스타일을 지정한 뒤 다시 변환하면 구조가 살아납니다. 결과 HTML은 <html>, <head> 없이 본문 조각만 담고 있어 편집기에 그대로 붙여 넣기 좋습니다.

주의할 점

  • 글꼴, 글자 색, 형광펜, 줄 간격, 쪽 여백, 머리글·바닥글 같은 겉모양은 대부분 옮겨지지 않습니다.
  • 그림이 많은 문서는 그림 데이터가 코드 안에 들어가 결과가 매우 길어집니다. 게시판에 따라 붙여 넣기 용량 제한에 걸릴 수 있습니다.
  • 구형 .doc 파일과 한글(.hwp) 파일은 지원하지 않습니다. 워드에서 .docx로 저장한 뒤 넣으세요.
  • 마크다운 변환은 표나 복잡한 목록에서 HTML보다 단순하게 나올 수 있으니 미리 확인하세요.

자주 묻는 질문

문서가 서버로 올라가나요?
아닙니다. 변환은 모두 브라우저에서 이루어집니다.
변경 내용 추적이나 메모도 옮겨지나요?
메모는 결과에 들어가지 않습니다. 추적 중인 변경 내용은 의도와 다르게 섞일 수 있으니 변환 전에 워드에서 모두 수락하거나 거부해 정리해 두세요.
