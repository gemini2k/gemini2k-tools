한글(HWPX) 텍스트 추출기

한글 신형 형식(.hwpx)에서 본문 텍스트를 추출합니다. 한컴오피스 없이 내용을 바로 확인하세요.

📖
사용 방법
  1. 한글 파일을 .hwpx로 저장합니다 (한글에서 '다른 이름으로 저장 → HWPX')
  2. 파일을 끌어다 놓거나 클릭해 올립니다
  3. 본문 텍스트가 추출되면 '복사' 또는 '.txt 다운로드'
⚠️ 구형 .hwp는 한컴 독점 이진 형식이라 브라우저에서 안정적으로 읽을 수 없습니다. 한글에서 다른 이름으로 저장 → 한글 표준 문서(.hwpx)로 저장한 뒤 올려 주세요. (.hwpx는 표준 XML 압축 형식입니다)
📄
한글 파일(.hwpx)을 끌어다 놓거나 클릭
.hwpx (구형 .hwp는 .hwpx로 저장 후)
.hwpx 내부의 본문(섹션) 텍스트를 순서대로 추출합니다. 표·머리말 등 일부 요소는 단순 텍스트로 합쳐질 수 있고 서식·이미지는 제외됩니다. 파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

한글(HWPX) 텍스트 추출기 사용 안내

무엇을 하는 도구인가

HWPX는 한컴오피스의 개방형 문서 형식으로, 국가 표준(KS X 6101)인 OWPML 규격의 XML 파일들을 ZIP으로 묶은 패키지입니다. 이 도구는 패키지 안의 Contents/section0.xml, section1.xml … 본문 구역 파일을 번호 순서대로 꺼내, 문단이 끝나는 자리(</hp:p>)마다 줄을 바꾸고 나머지 태그를 모두 걷어내 글자만 남깁니다. 한컴오피스가 없는 PC에서도 문서 내용을 텍스트로 확인할 수 있습니다.

언제 쓰나

  • 공문서 HWPX에서 본문만 뽑아 메일 본문이나 메신저에 붙여 넣을 때
  • 보고서 문장을 맞춤법 검사기, 글자 수 세기, 번역기 같은 다른 도구에 넣기 전에
  • 한글이 설치되지 않은 노트북이나 맥에서 받은 첨부 문서 내용을 먼저 확인할 때
  • 여러 차례 고친 문서 두 개를 텍스트로 뽑아 비교 도구로 바뀐 곳을 찾을 때

사용 방법

  1. 구형 .hwp 파일이라면 한글에서 「다른 이름으로 저장」으로 .hwpx 형식으로 먼저 저장합니다.
  2. 점선 상자를 클릭하거나 .hwpx 파일을 끌어다 놓습니다.
  3. 추출 결과와 함께 글자 수·문단 수가 표시되면 「📋 복사」나 「⬇️ .txt 다운로드」를 누릅니다. 파일 이름은 원본 이름에 .txt가 붙습니다.

결과 해석

표 안의 각 칸도 내부적으로 문단이므로 칸 하나가 한 줄로 나옵니다. 「구분 | 내용」 두 칸짜리 표 한 행은 「구분」, 「내용」 두 줄이 됩니다. 문단 수는 빈 줄을 뺀 줄 수라서 한글 화면에서 세는 문단 수와 다를 수 있습니다. 결과가 비어 있다고 나오면 본문이 글상자나 그림 안에만 들어 있는지 확인해 보세요.

주의할 점

  • 구형 .hwp는 한컴 고유의 이진 형식이라 이 도구로 읽지 않으며, 올리면 .hwpx로 저장하라는 안내가 나옵니다.
  • 글꼴, 굵게, 들여쓰기, 표 테두리, 그림은 모두 빠지고 순수 글자만 남습니다. 표 구조를 살려야 하면 한글에서 직접 복사하는 편이 낫습니다.
  • 각주·머리말처럼 본문 구역 파일 안에 함께 들어 있는 요소는 본문 사이에 섞여 나올 수 있습니다.
  • 암호가 걸린 문서는 내용이 암호화되어 있어 추출되지 않습니다.

자주 묻는 질문

「본문 섹션을 찾을 수 없습니다」가 나옵니다.
확장자만 .hwpx로 바꾼 파일이거나 손상된 파일일 때 나옵니다. 한글에서 정식으로 HWPX 형식을 골라 다시 저장해 보세요.
문서가 서버로 올라가나요?
아닙니다. 압축 해제와 추출 모두 브라우저 안에서 이루어지므로 내부 문서도 외부로 나가지 않습니다.
