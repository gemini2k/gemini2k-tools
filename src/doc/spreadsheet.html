온라인 스프레드시트

엑셀처럼 셀을 편집하세요. 작업한 표는 CSV로 내보낼 수 있어요.

오픈소스 x-spreadsheet(MIT, myliang/x-spreadsheet)을 자체 호스팅합니다. 모든 데이터는 브라우저에서만 처리되며 저장되지 않습니다(새로고침 시 초기화).

온라인 스프레드시트 사용 안내

무엇을 하는 도구인가

브라우저에서 바로 쓰는 간단한 표 편집기입니다. 오픈소스 x-spreadsheet를 바탕으로 셀 입력, 글꼴·색·테두리·정렬 같은 서식, 셀 병합, 행·열 추가와 삭제, 시트 추가를 지원하고, =SUM(A1:A5)처럼 등호로 시작하는 수식도 계산합니다. 수식 함수는 SUM, AVERAGE, MAX, MIN, IF, AND, OR, CONCAT 정도로 기본적인 것만 들어 있습니다. 지금 보고 있는 시트를 CSV 파일로 내보낼 수 있습니다.

언제 쓰나

  • 엑셀이 없는 PC에서 참석자 명단이나 물품 목록을 표로 빠르게 정리할 때
  • 몇 줄짜리 숫자의 합계·평균을 계산기 대신 표로 확인할 때
  • 다른 시스템에 올릴 CSV를 손으로 몇 줄 만들어야 할 때

사용 방법

  1. 셀을 클릭하고 입력하거나 더블클릭해 내용을 고칩니다. 위쪽 도구 모음에서 서식을, 오른쪽 클릭 메뉴에서 행·열 삽입과 삭제를 고릅니다.
  2. 합계가 필요한 칸에 =SUM(B2:B10)처럼 입력합니다.
  3. 끝나면 내보낼 시트를 아래쪽 탭에서 고른 뒤 「⬇️ CSV 내보내기」를 누릅니다. 파일 이름은 시트 이름을 따라 sheet1.csv처럼 붙습니다.

결과 해석

CSV에는 수식 대신 계산된 값이 들어갑니다. B11에 =SUM(B2:B10)을 넣었다면 CSV의 그 칸에는 합계 숫자가 저장되므로, 다른 시스템에 그대로 올려도 됩니다. 반대로 수식 자체는 CSV에 남지 않으니 나중에 다시 고칠 표라면 수식을 따로 적어 두세요. 지원하지 않는 함수, 0으로 나누기, 순환 참조처럼 계산할 수 없는 수식은 #ERROR!로 저장되고, 셀에 지정한 % 같은 표시 형식은 적용되지 않은 원래 숫자로 나갑니다. 쉼표나 큰따옴표가 든 셀은 따옴표로 감싸 저장하고, 파일 앞에 BOM을 붙여 엑셀에서 한글이 깨지지 않게 했습니다.

주의할 점

  • 작업 내용은 어디에도 저장되지 않습니다. 새로고침하거나 탭을 닫으면 모두 사라지니 중간중간 CSV로 받아 두세요.
  • CSV 한 파일에는 시트 하나만 담깁니다. 시트가 여러 개라면 탭을 하나씩 골라 각각 내보내세요. 수식은 같은 시트 안의 셀만 참조해 계산합니다.
  • 서식, 병합, 색은 CSV에 담기지 않습니다. 기존 엑셀 파일을 불러오는 기능도 없습니다.

자주 묻는 질문

VLOOKUP이나 SUMIF 같은 함수도 되나요?
지원하지 않습니다. 위에 적은 기본 함수만 계산되므로 복잡한 계산은 엑셀이나 구글 시트를 쓰세요.
입력한 내용이 서버에 남나요?
아닙니다. 모든 데이터는 이 브라우저 탭의 메모리에만 있습니다.
