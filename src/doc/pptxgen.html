텍스트 → PPT 생성기

개요를 적으면 파워포인트(.pptx) 초안을 만들어 줍니다. # 제목은 새 슬라이드, - 로 시작하면 글머리 기호입니다.

테마 색
오픈소스 PptxGenJS(MIT, gitbrent/PptxGenJS)를 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어집니다.

텍스트 → PPT 생성기 사용 안내

무엇을 하는 도구인가

간단한 개요 텍스트를 읽어 파워포인트(.pptx) 파일을 만듭니다. # 로 시작하는 줄이 새 슬라이드의 제목이 되고, 그 아래 줄들이 글머리 기호 항목이 됩니다. 슬라이드는 16:9 와이드 크기이며, 위쪽에 테마 색 띠, 그 아래 32pt 굵은 제목(테마 색), 18pt 회색 글머리 기호 본문으로 구성됩니다. 파일 생성은 PptxGenJS 라이브러리로 브라우저 안에서 이루어집니다.

언제 쓰나

  • 주간 업무 보고나 회의 안건을 메모장에 적어 둔 상태에서 발표용 초안을 바로 만들 때
  • 교육 자료의 목차와 요점을 먼저 슬라이드로 뽑아 놓고 디자인은 나중에 입힐 때
  • 생성형 AI나 다른 문서에서 받은 개요를 슬라이드 뼈대로 옮길 때

사용 방법

  1. 입력 칸에 # 제목 줄과 - 항목 줄을 씁니다. 예시가 미리 들어 있으니 지우고 쓰면 됩니다.
  2. 입력하는 동안 오른쪽에 「n개 슬라이드」가 갱신됩니다.
  3. 「테마 색」(블루·그린·레드·퍼플·다크)을 고르고 파일명을 적습니다.
  4. 「📊 PPTX 만들기」를 누르면 「파일명.pptx」가 내려받아집니다.

결과 해석

기본 예시에는 # 줄이 세 개라 슬라이드 3장이 만들어집니다. 「- 매출 12% 성장」처럼 -나 * 뒤에 띄어쓰기가 있으면 기호를 떼고 항목이 되며, 기호 없이 쓴 일반 줄도 같은 슬라이드의 항목으로 들어갑니다. 첫 번째 # 줄보다 위에 쓴 내용은 어느 슬라이드에도 속하지 않아 버려집니다.

주의할 점

  • 들여쓰기로 하위 항목을 만들 수 없습니다. 줄 앞 공백은 지워지고 모두 같은 수준의 항목이 됩니다. ##도 제목으로 인식하지 않고 일반 항목으로 들어갑니다.
  • 본문 상자 높이가 고정되어 있어 항목이 많거나 길면 슬라이드 아래로 넘칩니다. 한 장에 대여섯 줄 정도로 나누는 편이 안전합니다.
  • 이미지, 표, 차트, 발표자 노트는 넣을 수 없습니다. 만든 파일을 파워포인트에서 열어 다듬는 초안 용도입니다.
  • # 줄이 하나도 없으면 슬라이드를 만들지 않고 안내 창을 띄웁니다.

자주 묻는 질문

한글 글꼴은 무엇으로 들어가나요?
글꼴을 따로 지정하지 않으므로 파일을 여는 프로그램의 기본 글꼴로 표시됩니다. 파워포인트의 「글꼴 바꾸기」로 한 번에 바꿀 수 있습니다.
구글 슬라이드나 한컴 한쇼에서도 열리나요?
표준 .pptx 형식이라 대부분 열립니다. 다만 줄 간격 같은 세부 모양은 프로그램마다 조금 다를 수 있습니다.
