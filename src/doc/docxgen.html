마크다운 → 워드(.docx)

마크다운으로 쓴 글을 워드 문서로 바꿔 줍니다. # ## ### 제목, - 목록, **굵게**·*기울임*을 지원합니다.

제목
오픈소스 docx(MIT, dolanmiu/docx)를 자체 호스팅합니다. 모든 처리는 브라우저에서만 이루어집니다.

마크다운 → 워드(.docx) 변환 사용 안내

무엇을 하는 도구인가

마크다운으로 쓴 글을 한 줄씩 읽어 워드 문서의 문단으로 바꾸고, docx 라이브러리로 .docx 파일을 만들어 내려받게 합니다. 지원하는 문법은 일부로 정해져 있습니다. #, ##, ###는 워드의 「제목 1~3」 스타일, 줄 앞의 - 또는 *는 글머리 기호 목록, 줄 안의 **굵게**와 *기울임*은 글자 서식이 됩니다. 나머지 줄은 일반 문단입니다.

언제 쓰나

  • 메모장이나 개발 도구에서 마크다운으로 쓴 주간 보고를 워드 양식으로 제출해야 할 때
  • AI 채팅 답변처럼 마크다운으로 받은 글을 제목 구조를 살려 문서로 옮길 때
  • 워드의 탐색 창에서 제목으로 이동할 수 있는 초안을 빠르게 만들 때
  • 회의록 뼈대를 텍스트로 잡고 서식은 워드에서 마저 다듬을 때

사용 방법

  1. 입력란에 마크다운을 붙여 넣습니다. 처음에는 업무 보고서 예시가 들어 있습니다.
  2. 「제목」 칸에 저장할 파일 이름을 적습니다. 확장자 .docx는 자동으로 붙습니다.
  3. 「📝 DOCX 만들기」를 누르면 파일이 내려받아집니다.
  4. 워드에서 열어 글꼴·여백 등 나머지 서식을 정리합니다.

결과 해석

기본 예시는 「업무 보고서」가 제목 1, 「개요」 「진행 사항」 「다음 주 계획」이 제목 2가 되고, - 기획안 검토 완료 같은 줄은 글머리 기호 목록이 됩니다. 제목 스타일이 실제로 적용되므로 워드에서 「목차 삽입」을 하면 이 제목들로 목차가 바로 만들어집니다. 마크다운의 빈 줄은 빈 문단 하나로 그대로 옮겨지므로, 줄 간격이 넓어 보이면 빈 줄을 지우고 다시 만들면 됩니다.

주의할 점

  • 표, 링크, 이미지, 코드 블록, 인용문, 번호 목록(1.), #### 이하 제목은 변환하지 않고 기호가 붙은 일반 문장으로 들어갑니다.
  • 들여쓴 하위 목록도 모두 같은 단계의 글머리 기호로 들어갑니다.
  • 각 줄 앞뒤 공백은 지워집니다. 한 문단 안에서 줄을 바꾼 부분은 각각 별도 문단이 됩니다.
  • 「제목」 칸은 파일 이름에만 쓰이며 문서 안 제목이나 문서 속성에는 들어가지 않습니다.
