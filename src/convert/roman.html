로마 숫자 변환기

아라비아 숫자와 로마 숫자를 서로 바꿉니다(1~3999). 아무 칸에나 입력하면 반대쪽이 즉시 바뀝니다.

표준 로마 숫자 규칙(I·V·X·L·C·D·M, 뺄셈 표기 IV·IX 등)을 사용하며 1~3999 범위를 지원합니다. 로마 숫자 입력은 대소문자를 가리지 않습니다. 모든 변환은 브라우저에서 이루어집니다.

로마 숫자 변환기 사용 안내

무엇을 하는 도구인가

아라비아 숫자와 로마 숫자를 양방향으로 바꿉니다. I(1)·V(5)·X(10)·L(50)·C(100)·D(500)·M(1000) 일곱 글자와 IV(4)·IX(9)·XL(40)·XC(90)·CD(400)·CM(900) 같은 뺄셈 표기를 쓰는 표준 규칙을 따르며, 1부터 3999까지 지원합니다. 한쪽 칸에 입력하면 다른 쪽 칸이 즉시 바뀝니다.

언제 쓰나

  • 책·보고서 서문의 쪽 번호나 목차 번호를 로마 숫자로 매길 때
  • 영화·게임 크레디트, 건물 머릿돌의 연도(MCMXCIV 등)를 읽을 때
  • 법령·계약서의 조항 번호(제Ⅲ장)나 행사 회차(제XXV회)를 표기할 때
  • 시험 문제나 퍼즐에서 로마 숫자 표기가 올바른지 확인할 때

사용 방법

  1. 「숫자」 칸에 1~3999 사이 정수를 넣으면 「로마 숫자」 칸에 결과가 나옵니다.
  2. 반대로 「로마 숫자」 칸에 입력하면 「숫자」 칸에 값이 나옵니다. 소문자로 써도 됩니다.
  3. 범위를 벗어나거나 규칙에 맞지 않는 입력은 칸이 오류 표시로 바뀌고 반대쪽이 비워집니다.

결과 해석

2026은 MMXXVI(1000+1000+10+10+5+1), 1994는 MCMXCIV(1000+900+90+4)가 됩니다. 로마 숫자를 입력할 때는 계산한 값을 다시 표준형으로 바꿔 입력과 같은지까지 확인하므로, IIII나 VX처럼 값은 계산되더라도 표준 표기가 아닌 입력은 오류로 처리합니다.

주의할 점

  • 0과 음수, 소수는 로마 숫자로 나타낼 수 없습니다.
  • 시계 문자판처럼 4를 IIII로 쓰는 전통 표기는 이 도구에서 오류로 나옵니다. 표준형인 IV로 확인하세요.
  • 워드프로세서의 「Ⅻ」 같은 한 글자짜리 로마 숫자 기호(유니코드 숫자 형태 문자)는 알파벳 I·V·X와 다른 문자라 인식하지 않습니다.

자주 묻는 질문

값을 더하면 1999지만 표준 표기는 MCMXCIX입니다. 이 도구는 표준형만 인정합니다.
