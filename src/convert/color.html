색상 변환기

HEX · RGB · HSL을 서로 변환하고 색을 미리봅니다.

#5B5BF5

rgb(91, 91, 245)

hsl(240, 89%, 66%)

색상 변환기 사용 안내

무엇을 하는 도구인가

색 하나를 HEX, rgb(), hsl() 세 가지 표기로 동시에 보여 줍니다. 색은 왼쪽 색상 선택 상자로 고르거나 R·G·B 세 칸에 0~255 값을 직접 넣어 정합니다. 값이 바뀔 때마다 미리보기 견본과 세 표기가 함께 갱신되고, 각 줄의 「복사」로 필요한 표기만 가져갈 수 있습니다.

언제 쓰나

  • 디자인 시안에 적힌 RGB 값을 CSS에 넣을 HEX 코드로 바꿀 때
  • 기존 HEX 색에서 명도만 조금 낮춘 변형 색을 만들려고 HSL 값을 확인할 때
  • 엑셀·파워포인트처럼 RGB 숫자만 받는 프로그램에 웹 색상을 옮길 때
  • 브랜드 가이드의 색 코드가 표기마다 같은 색을 가리키는지 맞춰 볼 때

사용 방법

  1. 색상 선택 상자를 눌러 색을 고르거나, RGB 칸 세 개에 빨강·초록·파랑 값을 차례로 입력합니다.
  2. 오른쪽 견본에서 색을 눈으로 확인합니다.
  3. HEX·RGB·HSL 줄 옆의 「복사」를 눌러 원하는 표기를 클립보드에 담습니다.

결과 해석

처음 열었을 때의 색 RGB(91, 91, 245)는 HEX #5B5BF5, HSL hsl(240, 89%, 66%)로 표시됩니다. 빨강·초록이 같고 파랑만 높으니 색상각이 정확히 240도(파랑)이고, 채도 89%·명도 66%로 밝은 남보라 계열이라는 뜻입니다. RGB(255, 0, 0)를 넣으면 #FF0000, hsl(0, 100%, 50%)가 나옵니다.

주의할 점

  • HSL 값은 정수로 반올림해 보여 줍니다. 이 HSL을 다른 도구에서 다시 RGB로 바꾸면 1 정도 차이가 날 수 있으니, 정확한 값을 넘겨야 할 때는 HEX나 RGB를 쓰세요.
  • RGB 칸에 255보다 큰 수나 음수를 넣으면 0~255로 잘리고, 소수점 이하는 버립니다.
  • 투명도(알파)는 다루지 않습니다. rgba()가 필요하면 결과 뒤에 직접 덧붙이세요.
