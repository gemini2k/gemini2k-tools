색상 대비 검사기

전경(글자)색과 배경색의 명도 대비비를 계산하고, 웹 접근성 기준 WCAG AA·AAA 통과 여부를 확인합니다.

일반 텍스트 — 본문 가독성을 이렇게 확인합니다.
12.6: 1
AA 일반 텍스트
AA 큰 텍스트
AAA 일반 텍스트
AAA 큰 텍스트
대비비는 WCAG 상대 휘도 공식으로 계산합니다(흰색·검정 = 최대 21:1). 기준: AA 일반 4.5, 큰 텍스트 3.0 / AAA 일반 7.0, 큰 텍스트 4.5. '큰 텍스트'는 약 18pt(24px) 이상 또는 14pt(18.66px) 굵은 글씨입니다. 색상값은 서버로 전송되지 않습니다.

색상 대비 검사기 사용 안내

무엇을 하는 도구인가

글자색과 배경색의 명도 대비비를 WCAG 2.x에 정의된 상대 휘도 공식으로 계산하고, AA·AAA 기준을 일반 텍스트와 큰 텍스트로 나눠 통과 여부를 표시합니다. 미리보기 상자에 두 색을 실제로 적용해 큰 글씨와 본문 글씨가 어떻게 보이는지도 함께 확인할 수 있습니다.

언제 쓰나

  • 웹 접근성 품질인증이나 사내 접근성 점검 전에 버튼·본문 색 조합을 미리 확인할 때
  • 디자이너가 고른 회색 본문 글씨가 흰 배경에서 기준을 넘는지 개발 단계에서 따져 볼 때
  • 다크 모드 색을 새로 정하면서 밝은 글씨와 어두운 배경의 대비를 맞출 때
  • 공문서·안내문 PDF의 강조 색이 인쇄 전 화면에서 충분히 읽히는지 볼 때

사용 방법

  1. 「전경색 (글자)」과 「배경색」을 색상 상자로 고르거나 옆 칸에 HEX를 입력합니다. #는 생략해도 되고 #333 같은 3자리도 받습니다.
  2. 가운데 큰 숫자로 대비비를, 아래 네 칸으로 기준별 통과·실패를 확인합니다.
  3. 「전경↔배경 바꾸기」로 두 색을 맞바꿔 반전 배색도 볼 수 있습니다(대비비 자체는 같습니다).

결과 해석

기본값인 #333333 글자에 흰 배경은 12.63:1로 네 기준을 모두 통과합니다. 흔히 쓰는 #777777 회색은 흰 배경에서 4.48:1이 나와 AA 일반 텍스트 기준 4.5에 아주 조금 못 미치고, #767676으로 한 단계만 어둡게 하면 4.54:1로 통과합니다. 기준은 AA 일반 4.5·큰 텍스트 3.0, AAA 일반 7.0·큰 텍스트 4.5이며, 큰 텍스트는 대략 18pt 이상 또는 14pt 이상 굵은 글씨를 말합니다.

주의할 점

  • 계산은 불투명한 단색 두 개만 대상으로 합니다. 반투명 글자, 그라데이션·사진 배경은 실제로 겹친 색을 따로 뽑아 넣어야 합니다.
  • 소수 둘째 자리에서 반올림해 보여 주지만 판정은 반올림 전 값으로 합니다. 화면에 4.50이 보여도 실제 값이 4.5 미만이면 실패로 나올 수 있습니다.
  • 아이콘·입력창 테두리 같은 비텍스트 요소는 WCAG 2.1에서 3:1 기준을 따로 둡니다. 「AA 큰 텍스트」 칸 결과를 참고하면 됩니다.

자주 묻는 질문

한국 접근성 지침도 같은 기준인가요?
한국형 웹 콘텐츠 접근성 지침(KWCAG)도 텍스트와 배경의 명도 대비를 4.5:1 이상으로 요구합니다. 인증 심사에서는 해당 지침의 세부 예외 조건을 함께 확인하세요.
APCA 값과 왜 다른가요?
APCA는 WCAG 3 초안에서 논의되는 다른 계산 방식입니다. 이 도구는 현재 표준인 WCAG 2.x 공식만 씁니다.
