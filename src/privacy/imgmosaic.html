이미지 모자이크·블러

사진에서 얼굴·이름·전화번호 같은 민감한 부분을 드래그로 칠해 가립니다. 가린 영역은 되돌릴 수 없게 픽셀이 합쳐집니다.

📖
사용 방법
  1. 이미지를 끌어다 놓거나 클릭해 올립니다
  2. 가릴 부분을 마우스로 드래그해 사각형으로 칠합니다 (여러 번 가능)
  3. 모자이크/블러와 강도를 고른 뒤 'PNG 다운로드'
🔲
이미지를 끌어다 놓거나 클릭
JPG · PNG · WebP
드래그로 칠한 영역만 즉시 가려집니다. '검정 칠'은 가장 안전하게 정보를 제거합니다(모자이크·블러는 강도를 충분히 높이세요). 모든 처리는 브라우저에서만 이루어지며 원본 이미지는 서버로 전송되지 않습니다.

이미지 모자이크·블러 도구 사용 안내

무엇을 하는 도구인가

사진이나 화면 캡처에서 가릴 부분을 마우스(또는 터치)로 드래그해 사각형으로 지정하면, 그 영역만 모자이크·블러·검정 칠로 덮어 PNG로 저장하는 도구입니다. 모자이크는 영역을 일정 크기의 블록으로 나눠 블록마다 평균 색 하나로 칠하고, 블러는 영역 안에서만 흐림 필터를 다시 그리며, 검정 칠은 영역을 검은색으로 채웁니다. 「강도」 슬라이더(5~40)는 모자이크 블록 크기와 블러 반경(픽셀)을 함께 조절합니다. 처리는 원본 해상도 기준으로 이루어집니다.

언제 쓰나

  • 보도자료·홍보물에 실을 현장 사진에서 행인 얼굴이나 차량 번호판을 가릴 때
  • 업무 매뉴얼이나 장애 보고서에 넣을 화면 캡처에서 이름, 연락처, 계정 정보를 지울 때
  • 민원 회신에 첨부할 서류 사진에서 주민등록번호 뒷자리나 서명을 가릴 때
  • 중고거래 사진에 찍힌 택배 송장, 주소를 지울 때

사용 방법

  1. 이미지를 점선 상자에 끌어다 놓거나 눌러서 고릅니다(JPG·PNG·WebP).
  2. 「방식」에서 모자이크·블러·검정 칠 중 하나를, 「강도」에서 세기를 고릅니다. 이 설정은 다음에 칠하는 영역부터 적용됩니다.
  3. 가릴 부분을 드래그합니다. 손을 떼는 순간 처리되며, 여러 영역을 차례로 칠할 수 있습니다.
  4. 잘못 칠했으면 「실행취소」로 한 단계씩, 「처음으로」로 원본 상태로 되돌립니다.
  5. 「PNG 다운로드」를 누르면 masked.png로 저장됩니다.

결과 해석

미리보기 캔버스에 보이는 그대로가 저장됩니다. 예를 들어 강도 14로 모자이크하면 원본 기준 14×14픽셀 블록 단위로 색이 뭉개집니다. 고해상도 사진에서는 같은 강도라도 화면에서 덜 흐려 보이니, 확대해서 글자가 읽히지 않는지 꼭 확인하세요.

주의할 점

  • 약한 모자이크나 블러는 복원 기법이나 추정으로 내용이 드러날 수 있습니다. 특히 숫자·글자처럼 경우의 수가 적은 정보는 검정 칠이 가장 확실합니다.
  • 저장 결과는 항상 PNG입니다. 원본이 JPG 사진이면 파일 크기가 커질 수 있습니다. 캔버스로 다시 그려 저장하므로 원본의 EXIF 같은 메타데이터는 결과 파일에 따라오지 않습니다.
  • 얼굴이나 글자를 자동으로 찾아 주지는 않습니다. 가려야 할 곳을 빠뜨리지 않았는지 사람이 직접 확인해야 합니다.
  • 가렸다고 해서 해당 이미지의 공개가 곧 적법하다는 뜻은 아닙니다. 사진 속 사람·장소·문서 내용에 따라 별도의 검토가 필요할 수 있습니다.

자주 묻는 질문

사진이 서버로 올라가나요?
아닙니다. 파일 열기, 가리기, 저장이 모두 브라우저 안에서 이루어집니다.
저장한 PNG에서 가린 부분을 되살릴 수 있나요?
가린 영역의 원래 픽셀은 저장 파일에 남지 않습니다. 다만 모자이크·블러는 남은 정보로 추정될 여지가 있으니 중요한 정보는 검정 칠을 쓰세요.
