비밀번호 강도 분석

비밀번호의 강도를 점수·예상 해킹 시간으로 평가하고 개선점을 알려 줍니다.

오픈소스 zxcvbn(MIT, Dropbox, dropbox/zxcvbn)을 자체 호스팅합니다. 입력한 비밀번호는 서버로 전송되지 않고 브라우저에서만 평가됩니다.

비밀번호 강도 분석 도구 사용 안내

무엇을 하는 도구인가

Dropbox가 공개한 오픈소스 zxcvbn으로 비밀번호를 분석해 0~4점의 강도 점수, 추정 경우의 수, 공격 상황별 예상 해킹 시간, 개선 제안을 보여 줍니다. 단순히 문자 종류를 세는 방식이 아니라, 내장된 흔한 비밀번호·영어 단어·이름 목록, 키보드 배열(qwerty 등), 반복·연속 문자, 날짜, @를 a로 바꾸는 식의 치환까지 찾아내고 공격자가 실제로 몇 번 만에 맞힐지를 추정합니다.

언제 쓰나

  • 규칙상으로는 대문자·숫자·특수문자를 다 넣었는데 실제로 안전한지 확인하고 싶을 때
  • 보안 교육에서 P@ssw0rd123 같은 비밀번호가 왜 약한지 근거를 들어 설명할 때
  • 회원가입 화면에 강도 표시 기능을 넣기 전에 zxcvbn이 어떤 결과를 내는지 미리 볼 때

사용 방법

  1. 입력 칸에 비밀번호를 넣습니다. 글자를 칠 때마다 바로 다시 계산됩니다.
  2. 막대 색과 등급(매우 약함·약함·보통·강함·매우 강함)을 봅니다.
  3. 표의 길이, 추정 경우의 수, 온라인·오프라인 공격 시간과 아래 경고·제안 문구를 확인합니다.

결과 해석

점수 0~4가 등급 다섯 단계에 그대로 대응합니다. 추정 경우의 수는 1.00e+10처럼 지수로 표시되는데, 대략 10의 10제곱 번 시도하면 맞힐 수 있다는 뜻입니다. 온라인 공격 시간은 로그인 시도 횟수가 시간당 100회 정도로 제한된 웹사이트를 상대로 하는 경우, 오프라인 고속 공격은 유출된 해시를 초당 100억 번 빠르게 대입하는 경우를 가정한 값입니다. 기본 예시 P@ssw0rd123는 11자에 네 종류 문자를 모두 썼지만 흔한 비밀번호 password의 치환 변형으로 인식되어 낮은 점수가 나옵니다. 길이보다 예측 가능성이 더 중요하다는 것을 보여 주는 예입니다.

주의할 점

  • zxcvbn의 단어 목록은 영어 중심입니다. 한글 단어를 영문 자판으로 친 비밀번호(예: 사랑해를 tkfkdgo로 입력)나 한국에서 흔한 패턴은 제대로 잡지 못해 점수가 실제보다 높게 나올 수 있습니다.
  • 경고와 제안 문구는 라이브러리가 만든 영어 문장으로 나옵니다.
  • 점수는 추정입니다. 이미 유출된 비밀번호인지 여부는 확인하지 않습니다. 유출 여부 확인과 재사용 금지는 별도로 챙기세요.
  • 입력은 브라우저 밖으로 나가지 않지만, 화면에 그대로 보이는 일반 입력 칸이므로 주변 시선이나 화면 공유 중인지 확인하세요.

자주 묻는 질문

「비밀번호 강도 측정기」와 무엇이 다른가요?
측정기는 문자 종류와 길이로 이론상 엔트로피를 계산하고, 이 도구는 사전 단어와 패턴을 찾아 현실적인 추측 횟수를 추정합니다. 두 결과가 크게 다르면 이 도구 쪽이 실제 위험에 더 가깝습니다.
몇 점 이상이면 쓸 만한가요?
일반적으로 3점 이상을 목표로 많이 잡습니다. 중요한 계정은 4점이 나오는 긴 문구형 비밀번호를 권합니다.
