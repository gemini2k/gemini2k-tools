TOTP 인증 코드 생성기

비밀 키(Secret)를 넣으면 30초마다 바뀌는 2단계 인증(OTP) 코드를 보여 줍니다.

------
오픈소스 otpauth(MIT, hectorm/otpauth)를 자체 호스팅합니다. 비밀 키와 코드는 서버로 전송되지 않으며 브라우저에서만 계산됩니다. RFC 6238 기준.

TOTP 인증 코드 생성기 사용 안내

무엇을 하는 도구인가

Base32로 된 비밀 키를 넣으면 Google Authenticator 같은 OTP 앱과 같은 방식으로 일회용 인증 코드를 계산해 보여 주는 도구입니다. RFC 6238(TOTP) 규칙에 따라 현재 시각을 주기(30초 또는 60초)로 나눈 값과 비밀 키로 HMAC을 계산해 6~8자리 숫자를 만듭니다. 해시 알고리즘은 SHA1, SHA256, SHA512 중 고를 수 있고, 남은 시간 막대는 1초마다 갱신됩니다. 계산에는 오픈소스 otpauth 라이브러리를 씁니다.

언제 쓰나

  • 업무 시스템에 2단계 인증을 붙이는 개발 중에, 서버가 검증하는 코드와 같은 값이 나오는지 맞춰 볼 때
  • OTP 앱에 등록이 안 될 때 비밀 키 자체가 올바른 Base32인지, 설정(자릿수·주기·알고리즘)이 맞는지 확인할 때
  • 보안 교육에서 OTP 코드가 비밀 키와 시각만으로 만들어진다는 점을 보여 줄 때

사용 방법

  1. 「비밀 키」 칸에 서비스가 준 Base32 키를 넣습니다. 띄어쓰기는 자동으로 지우고 소문자는 대문자로 바꿉니다.
  2. 「자릿수」(6·7·8), 「주기(초)」(30·60), 「알고리즘」(SHA1·SHA256·SHA512)을 서비스 설정과 같게 맞춥니다. 대부분의 서비스는 6자리·30초·SHA1입니다.
  3. 큰 숫자로 표시되는 코드를 확인하고 「코드 복사」로 가져갑니다.

결과 해석

같은 키와 설정을 넣은 OTP 앱과 이 화면의 코드가 같으면 키와 설정이 맞는 것입니다. 코드는 주기가 바뀌는 순간에 새로 나오므로, 남은 시간이 1~2초뿐이면 다음 코드를 기다렸다가 입력하는 것이 낫습니다. 비밀 키 칸에 Base32에 없는 문자(0, 1, 8, 9 등)가 섞이면 코드 대신 키 오류가 표시됩니다.

주의할 점

  • 코드는 이 기기의 시계로 계산합니다. PC 시각이 30초 이상 틀어져 있으면 서버와 다른 코드가 나오니, 시간 자동 동기화를 확인하세요.
  • 비밀 키를 가진 사람은 누구나 같은 코드를 만들 수 있습니다. 실제 계정의 키를 웹 페이지에 넣으면 2단계 인증의 의미가 약해지므로, 운영 계정 키는 OTP 앱에만 보관하고 이 도구는 테스트 키로 쓰세요.
  • QR 코드 읽기나 otpauth:// 주소 해석은 지원하지 않습니다. QR에 들어 있는 secret= 값만 따로 넣어야 합니다.
  • HOTP(횟수 기반) 방식이나 문자 인증과는 다른 방식입니다.

자주 묻는 질문

비밀 키가 서버로 전송되나요?
아닙니다. 코드 계산은 브라우저 안에서만 이루어지고 전송 코드는 없습니다.
기본으로 들어 있는 키는 무엇인가요?
예제용으로 널리 쓰이는 공개 테스트 키입니다. 실제 계정과는 관계가 없습니다.
