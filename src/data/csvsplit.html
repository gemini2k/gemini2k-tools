CSV 분할·샘플링

CSV를 비율로 두 덩어리로 나누거나, 무작위로 원하는 만큼 행을 뽑습니다. 학습/검증셋이나 샘플 만들 때 쓰세요.

📖
사용 방법
  1. CSV를 붙여 넣습니다(첫 행은 머리글, 모든 결과에 포함)
  2. '비율 분할' 또는 '무작위 추출'을 고르고 값을 정합니다
  3. '실행' 후 결과를 복사하거나 내려받습니다
헤더는 모든 결과에 포함됩니다. '섞은 뒤 분할'과 '무작위 추출'은 매번 다른 결과가 나옵니다. 모든 처리는 브라우저에서만 이루어집니다.

CSV 분할·샘플링 도구 사용 안내

무엇을 하는 도구인가

CSV 하나를 두 가지 방식으로 잘라 줍니다. '비율 분할'은 앞쪽 비율(%)만큼의 행과 나머지 행으로 두 덩어리를 만들고, 필요하면 행을 무작위로 섞은 뒤 나눕니다. '무작위 추출'은 전체 행 중에서 지정한 개수만큼을 중복 없이 무작위로 뽑습니다. 어느 방식이든 머리글 행은 모든 결과의 첫 줄에 그대로 들어갑니다.

언제 쓰나

  • 머신러닝 모델용 데이터를 학습 80%, 검증 20%로 나눌 때
  • 수만 행짜리 공공데이터에서 100행만 뽑아 담당자와 구조를 먼저 검토할 때
  • 현장 점검 대상 시설 목록에서 무작위로 표본 20곳을 고를 때
  • 대용량 파일 처리 스크립트를 짜기 전에 테스트용 작은 파일을 만들 때

사용 방법

  1. 'CSV 입력'에 데이터를 붙여 넣습니다. 첫 줄은 머리글이어야 하고 구분자는 자동으로 판단합니다.
  2. 위쪽에서 '비율 분할' 또는 '무작위 추출'을 고릅니다.
  3. 비율 분할은 '앞쪽 비율'(1~99%)을 넣고 필요하면 '섞은 뒤 분할'을 체크합니다. 무작위 추출은 '추출 행 수'를 넣습니다.
  4. '실행'을 누르면 결과 칸이 나타나고, 각 칸 제목 옆 '복사' 버튼으로 가져갑니다.

결과 해석

20행에 앞쪽 비율 80%를 주면 앞 16행과 뒤 4행으로 나뉘고, 각 결과 제목에 행 수가 표시됩니다. 비율에 따라 나오는 행 수는 반올림됩니다. '섞은 뒤 분할'을 끄면 원래 순서대로 앞부분과 뒷부분이 잘리므로, 날짜순으로 정렬된 데이터라면 과거 데이터와 최근 데이터로 나뉘는 셈입니다. 추출 행 수가 전체 행 수보다 크면 전체 행을 섞어서 돌려줍니다.

주의할 점

  • 무작위 결과는 실행할 때마다 달라지고, 같은 결과를 다시 만들 수 있는 시드(seed) 설정은 없습니다. 재현이 필요하면 결과를 바로 저장해 두세요.
  • 단순 무작위라서 지역별·성별 같은 비율을 유지하는 층화 추출은 하지 않습니다. 소수 그룹이 한쪽에 몰릴 수 있습니다.
  • 결과는 복사만 지원하고 파일 내려받기 버튼은 없습니다. 복사한 내용을 메모장에 붙여 .csv로 저장하세요.
  • 결과는 항상 쉼표 구분으로 나옵니다. 행이 수십만 개면 결과 칸 표시가 느려질 수 있습니다.

자주 묻는 질문

세 덩어리(학습·검증·테스트)로 나눌 수 있나요?
한 번에 두 덩어리만 됩니다. 먼저 70:30으로 나눈 뒤 30% 쪽을 다시 50:50으로 나누면 70:15:15가 됩니다.
머리글 없이 결과를 받을 수 있나요?
머리글은 항상 포함됩니다. 필요 없으면 결과의 첫 줄을 지우면 됩니다.
