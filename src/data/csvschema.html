CSV 스키마 검증기

열마다 규칙(필수·자료형·정규식·고유)을 정해 두고, 그 규칙을 어긴 행을 찾아 줍니다.

📖
사용 방법
  1. CSV를 붙여 넣으면 열 목록이 자동으로 나옵니다
  2. 각 열에 필수·자료형·정규식·고유 규칙을 설정합니다
  3. '검증'을 누르면 규칙을 어긴 행과 이유가 표로 나옵니다
자료형: 정수·숫자·날짜(YYYY-MM-DD)·이메일. 정규식은 비워 두면 검사하지 않습니다(예: ^010-\d{4}-\d{4}$). 고유는 열 안에서 값 중복을 검사합니다. 모든 검증은 브라우저에서만 이루어집니다.

CSV 스키마 검증기 사용 안내

무엇을 하는 도구인가

CSV의 열마다 지켜야 할 규칙을 정해 두고, 그 규칙을 어긴 셀을 행 번호와 이유까지 짚어 주는 검증 도구입니다. 열별로 설정할 수 있는 규칙은 네 가지입니다. 필수(빈칸 금지), 자료형(정수·숫자·날짜 YYYY-MM-DD·이메일), 정규식, 고유(열 안에서 중복 금지)입니다. DB에 적재하다가 중간에 오류가 나기 전에 미리 문제 행을 찾아내는 용도입니다.

언제 쓰나

  • 여러 기관에서 취합한 엑셀 양식을 DB에 넣기 전에 필수 항목 누락과 형식 오류를 걸러낼 때
  • 관리번호나 법정동코드처럼 유일해야 하는 열에 중복이 있는지 확인할 때
  • 전화번호, 우편번호(5자리), 사업자번호처럼 정해진 형식을 정규식으로 점검할 때
  • 공공데이터 개방 전 품질 점검표를 작성할 때

사용 방법

  1. 'CSV 입력'에 데이터를 붙여 넣으면 열마다 규칙 줄이 나타납니다.
  2. 각 열에 '필수' 체크, 자료형 선택, 정규식 입력, '고유' 체크를 필요한 만큼 설정합니다.
  3. '검증'을 누르면 위반 건수와 함께 행·열·값·이유가 표로 나옵니다. 위반이 없으면 통과 표시가 나옵니다.
  4. '샘플'을 누르면 이메일 형식, 정수, 고유 규칙이 걸린 예시로 결과를 확인할 수 있습니다.

결과 해석

행 번호는 헤더를 1행으로 센 실제 파일 줄 번호라서, 엑셀에서 연 행 번호와 그대로 맞습니다. 샘플에서는 3행의 'bad-email'이 이메일 형식 위반으로, 같은 3행의 id 1이 2행과 겹쳐 중복으로 잡혀 위반 2건이 나옵니다. 한 셀이 여러 규칙을 어기면 각각 따로 기록됩니다. 위반이 200건을 넘으면 표에는 앞 200건만 표시되지만 상단 건수는 전체 기준입니다.

주의할 점

  • 값은 앞뒤 공백을 지운 뒤 검사합니다. 빈칸은 '필수' 규칙만 검사하고 자료형·정규식·고유 검사는 건너뜁니다.
  • 날짜는 형식만 봅니다. 2024-13-45처럼 존재하지 않는 날짜도 통과하며, 2024.01.05나 20240105 형식은 위반입니다.
  • 숫자 형식은 -12.5 같은 일반 표기만 허용합니다. '1,000', '+3', '.5', '1e3'은 위반으로 잡힙니다.
  • 정규식은 셀 일부만 맞아도 통과합니다. 전체 일치를 원하면 ^와 $로 감싸세요. 문법이 틀린 정규식은 오류 없이 무시됩니다.
  • CSV 내용을 고치면 규칙 설정이 초기화됩니다.

자주 묻는 질문

설정한 규칙을 저장해 다음에 다시 쓸 수 있나요?
현재는 저장 기능이 없습니다. 자주 쓰는 정규식은 따로 메모해 두고 붙여 넣으세요.
법정동코드 10자리 검사는 어떻게 하나요?
해당 열 정규식에 ^\d{10}$을 넣으면 숫자 10자리가 아닌 값을 모두 찾아냅니다.
