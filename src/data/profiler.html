데이터 프로파일러 (EDA)

CSV를 붙여넣거나 파일을 올리면 열마다 자료형·결측치·고유값·통계와 상위 빈도값을 한눈에 보여줍니다. 고유값이 많은 열은 준식별자 후보로 표시되어 재식별 위험 점검의 출발점이 됩니다.

📖
사용 방법
  1. CSV를 붙여넣거나 파일을 끌어다 놓습니다
  2. 첫 행이 머리글이면 '첫 행을 헤더로'를 켭니다 (구분자는 자동 감지)
  3. '분석'을 누르면 열별 통계와 준식별자 후보가 표로 나옵니다
📄 CSV 파일을 끌어다 놓거나 클릭해서 선택 (또는 아래에 붙여넣기)
자료형은 비어 있지 않은 값으로 추정합니다(정수·숫자·날짜·불리언·문자열). 준식별자 후보는 고유값 비율이 높아(기본 90% 이상, 2건 초과) 개인을 특정할 수 있는 열입니다 — 재식별 위험성 평가기로 이어서 점검해 보세요. 모든 분석은 브라우저에서만 이루어지며 데이터는 전송되지 않습니다.

데이터 프로파일러 사용 안내

무엇을 하는 도구인가

처음 받은 CSV가 어떤 상태인지 열 단위로 진단하는 탐색적 데이터 분석(EDA) 도구입니다. 열마다 추정 자료형(불리언·정수·숫자·날짜·문자열), 결측치 개수와 비율, 고유값 개수, 숫자 열의 최소·최대·평균, 가장 많이 나온 값 상위 3개를 표 한 장으로 보여 줍니다. 비어 있지 않은 값의 90% 이상이 서로 다른 열은 '준식별자 후보'로 표시해 개인정보 재식별 위험을 점검하는 출발점으로 삼을 수 있게 합니다.

언제 쓰나

  • 공공데이터 포털에서 받은 파일을 분석에 쓰기 전에 결측치가 얼마나 되는지 확인할 때
  • DB 테이블을 설계하면서 각 열의 자료형과 값의 범위를 가늠할 때
  • 개방·제공 전 데이터에 개인을 특정할 수 있는 열이 남아 있는지 1차 점검할 때
  • 코드 열(시도명, 등급 등)에 오타나 예상 밖 값이 섞였는지 상위 빈도값으로 살필 때

사용 방법

  1. 파일을 끌어다 놓거나 클릭해 고르고, 또는 텍스트를 붙여 넣습니다. 파일을 올리면 바로 분석됩니다.
  2. 첫 줄이 열 이름이 아니면 '첫 행을 헤더로'를 끕니다. '구분자'는 보통 '자동'으로 두면 되고, 잘못 잡히면 직접 고릅니다.
  3. '분석'을 누르면 상단에 행 수·열 수·구분자·준식별자 후보 수가, 아래에 열별 프로파일이 나옵니다.
  4. '프로파일 복사(TSV)'를 누르면 결과를 엑셀에 바로 붙여 넣을 수 있는 탭 구분 텍스트로 복사합니다.

결과 해석

샘플 5행에서 나이 열은 1건이 비어 결측 1(20%), 고유값 3, 정수형으로 나오고 최소 28·최대 45·평균 34.25가 계산됩니다. 이름과 가입일 열은 값이 모두 달라 준식별자 후보로 표시됩니다. 결측 비율이 높은 열은 분석에서 뺄지, 고유값이 1개뿐인 열은 정보가 없는 열인지 판단하는 근거가 됩니다. 상위 빈도값에서 '서울'과 '서울시'가 따로 보이면 표기 통일이 필요하다는 신호입니다.

주의할 점

  • 0과 1만 있는 열은 정수가 아니라 불리언으로 분류됩니다. 'Y/N', '참/거짓'도 불리언으로 봅니다.
  • '1,000'처럼 천 단위 쉼표가 있는 숫자나 '15%'는 문자열로 분류되어 통계가 계산되지 않습니다. 반대로 '01012' 같은 우편번호·코드는 정수로 분류되니 해석에 주의하세요.
  • 준식별자 후보 표시는 고유값 비율만 본 단순 기준입니다. 성별·나이·지역처럼 각각은 고유하지 않아도 조합하면 개인이 특정되는 경우는 잡지 못합니다.
  • 파일은 UTF-8로 읽으며, 대용량 파일은 브라우저 메모리 한계로 느려질 수 있습니다.

자주 묻는 질문

중앙값이나 표준편차도 볼 수 있나요?
이 도구는 최소·최대·평균만 계산합니다. 한 열의 상세 통계가 필요하면 통계 계산기에 값을 붙여 넣으세요.
결측치로 보는 기준은 무엇인가요?
앞뒤 공백을 지운 뒤 빈 문자열인 셀만 결측으로 셉니다. 'NULL', '-', 'N/A' 같은 표기는 값이 있는 것으로 봅니다.
