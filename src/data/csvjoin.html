CSV 조인·결합기

두 CSV를 공통 키 열을 기준으로 합칩니다(엑셀 VLOOKUP과 같은 개념). 표 A에 표 B의 정보를 붙일 때 쓰세요.

📖
사용 방법
  1. 표 A와 표 B의 CSV를 각각 붙여 넣습니다(첫 행은 머리글)
  2. 두 표를 잇는 공통 키 열을 각각 고릅니다(예: 사번, ID)
  3. 조인 방식을 고르고 '결합' → 미리보기 확인 후 CSV로 내려받습니다
키 값이 같은 행을 짝지어 A 열 + B 열로 합칩니다. B에 같은 키가 여러 개면 첫 번째를 사용합니다. 같은 열 이름이 겹치면 B 쪽에 _b를 붙입니다. 모든 처리는 브라우저에서만 이루어집니다.

CSV 조인·결합기 사용 안내

무엇을 하는 도구인가

두 CSV를 공통 키 열로 짝지어 한 표로 합칩니다. 엑셀의 VLOOKUP이나 SQL의 JOIN과 같은 개념으로, 표 A의 각 행 오른쪽에 키가 같은 표 B의 행 전체를 붙입니다. 조인 방식은 두 가지입니다. '내부 조인'은 양쪽에 키가 모두 있는 행만 남기고, '왼쪽 조인'은 A의 모든 행을 남기되 짝이 없으면 B 쪽 칸을 비워 둡니다. 구분자는 표마다 자동으로 판단합니다.

언제 쓰나

  • 법정동코드만 있는 통계 CSV에 법정동명 목록을 붙여 사람이 읽을 수 있는 표로 만들 때
  • 시군구별 인구 표와 시설 수 표를 시군구코드로 합쳐 인구 대비 시설 수를 계산할 때
  • 사번 기준으로 인사 명단에 부서 정보를 붙일 때
  • GIS 경계 데이터의 속성표에 붙일 통계를 미리 코드 기준으로 정리할 때

사용 방법

  1. '표 A (CSV)'와 '표 B (CSV)'에 각각 붙여 넣습니다. 첫 줄은 머리글이어야 합니다.
  2. 'A 키 열'과 'B 키 열'을 고릅니다. 두 열 이름은 달라도 됩니다(예: A의 adm_cd와 B의 법정동코드).
  3. '조인 방식'을 고르고 '결합'을 누릅니다.
  4. 결과 행 수와 매칭 건수, 앞 50행 미리보기를 확인한 뒤 '복사' 또는 'CSV'(joined.csv)로 전체 결과를 받습니다.

결과 해석

샘플에서 A에 id 1·2·3, B에 id 1·2·4가 있으면 내부 조인은 2행(1, 2번), 왼쪽 조인은 3행이 나오고 3번 행의 부서 칸은 비어 있습니다. 결과 열은 A의 모든 열 뒤에 B의 모든 열이 이어지며, B의 키 열도 그대로 남습니다. 열 이름이 겹치면 B 쪽 이름 뒤에 _b가 붙어 id, 이름, id_b, 부서처럼 됩니다. 왼쪽 조인에서 '매칭' 수가 전체 행보다 크게 적다면 키 형식이 서로 다를 가능성이 큽니다.

주의할 점

  • 키는 글자 그대로 비교합니다. 엑셀을 거치며 '01'이 '1'로 바뀌었거나 뒤에 공백이 붙은 경우 매칭되지 않습니다. 법정동코드처럼 앞자리 0이 있는 코드는 특히 확인하세요.
  • B에 같은 키가 여러 행 있으면 첫 번째 행만 쓰고 나머지는 무시합니다. 1:N 결합이 필요하면 다른 도구를 써야 합니다.
  • A에 같은 키가 여러 행 있으면 각 행에 같은 B 정보가 반복해 붙습니다.
  • 오른쪽 조인과 전체 외부 조인은 지원하지 않습니다. 오른쪽 조인이 필요하면 A와 B를 바꿔 넣으세요.
