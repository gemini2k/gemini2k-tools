CSV 정제기

지저분한 CSV를 깔끔하게. 공백·중복 행·빈 행을 정리하고 헤더 이름을 정규화하며 구분자까지 바꿉니다. 구분자는 자동으로 감지합니다.

📖
사용 방법
  1. CSV를 붙여넣거나 파일을 올립니다
  2. 적용할 정리 옵션(공백·중복·빈행·헤더)을 고릅니다
  3. '정제'를 누르고 결과를 복사하거나 CSV로 내려받습니다
📄 CSV 파일을 끌어다 놓거나 클릭 (또는 아래에 붙여넣기)
↓
중복 행은 모든 열 값이 같은 행을 처음 1건만 남기고 제거합니다. 헤더 정규화는 공백을 _로 바꾸고 소문자화하며 중복 이름에 번호를 붙입니다(name, name_2). 빈 값 채우기는 비어 있는 셀을 지정 값으로 대체합니다. 모든 처리는 브라우저에서만 이루어집니다.

CSV 정제기 사용 안내

무엇을 하는 도구인가

사람이 손으로 만들었거나 여러 시스템에서 내려받아 합친 CSV에 흔히 남는 군더더기를 한 번에 정리합니다. 셀 앞뒤 공백 제거, 모든 열이 같은 중복 행 제거, 완전히 빈 행 제거, 헤더 이름 정규화, 빈 칸을 지정한 값으로 채우기, 구분자 변경을 체크박스로 골라 적용합니다. 입력 구분자는 첫 줄을 보고 쉼표·세미콜론·탭·파이프(|) 중에서 자동으로 판단하며, 따옴표로 감싼 셀 안의 쉼표나 줄바꿈도 올바르게 읽습니다.

언제 쓰나

  • 공공데이터 포털 CSV를 여러 달 치 이어 붙였더니 같은 행이 겹쳐 들어갔을 때
  • 엑셀에서 복사한 표의 셀마다 공백이 붙어 있어 VLOOKUP이나 조인이 안 맞을 때
  • '회원 ID', 'Member Name' 같은 헤더를 DB 적재용 member_name 형태로 바꿀 때
  • 통계 프로그램에 넣기 전에 빈 칸을 NA나 0으로 통일할 때
  • 유럽식 세미콜론 CSV를 쉼표 CSV로, 또는 탭 구분으로 바꿀 때

사용 방법

  1. 점선 상자에 파일을 끌어다 놓거나 클릭해 고르고, 또는 아래 칸에 직접 붙여 넣습니다. 파일을 올리면 바로 정제까지 실행됩니다.
  2. '셀 앞뒤 공백 제거', '중복 행 제거', '빈 행 제거', '헤더 정규화(소문자·_)' 중 필요한 것을 고릅니다.
  3. 첫 줄이 헤더가 아니면 '첫 행을 헤더로'를 끕니다. 빈 칸을 채우려면 '빈 값 채우기'를 켜고 값을 넣습니다.
  4. '출력 구분자'를 고르고 '정제'를 누른 뒤 '복사' 또는 'CSV 내려받기'(cleaned.csv)를 씁니다.

결과 해석

결과 위에 원본 행 수, 결과 행 수, 제거된 중복 행 수, 제거된 빈 행 수가 표시됩니다. 처리 순서는 공백 제거 → 빈 행 제거 → 빈 값 채우기 → 중복 제거라서, ' 홍길동 ,32'와 '홍길동,32'는 공백을 지운 뒤 같은 행으로 판단되어 하나만 남습니다. 헤더 정규화는 소문자로 바꾸고 공백을 _로 바꾼 뒤 영문·숫자·_·한글 외 문자를 지우며, 이름이 겹치면 name, name_2처럼 번호를 붙입니다.

주의할 점

  • 중복 판정은 모든 열 값이 글자 그대로 같을 때만입니다. 대소문자나 '1,000'과 '1000' 같은 표기 차이는 다른 행으로 봅니다.
  • '빈 값 채우기'를 켜면 빈 행이 남아 있을 때 그 행도 채워진 값으로 바뀌므로 '빈 행 제거'와 함께 쓰는 편이 안전합니다.
  • 파일은 UTF-8로 읽습니다. EUC-KR(CP949)로 저장된 공공기관 CSV는 한글이 깨지니 먼저 UTF-8로 다시 저장하세요.
  • 헤더 정규화는 괄호, 하이픈, 점 같은 기호를 지웁니다. '면적(㎡)'은 '면적'이 됩니다.
