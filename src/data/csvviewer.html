CSV 뷰어·필터

큰 CSV를 표로 깔끔하게 보고, 검색으로 거르고, 보고 싶은 열만 골라 페이지 단위로 탐색하세요.

📖
사용 방법
  1. CSV 파일을 올리거나 붙여 넣고 '열기'를 누릅니다
  2. 위 검색창에 단어를 넣어 행을 거르고, 체크로 열을 켜고 끕니다
  3. 아래 페이지 버튼으로 넘겨 봅니다
📄 CSV 파일을 끌어다 놓거나 클릭 (또는 아래에 붙여넣기)
행 100개 단위로 나눠 보여 줍니다. 검색은 모든 열에서 입력어를 포함하는 행만 남깁니다. 매우 큰 파일은 브라우저 메모리에 따라 느려질 수 있습니다. 모든 처리는 브라우저에서만 이루어집니다.

CSV 뷰어·필터 사용 안내

무엇을 하는 도구인가

엑셀을 켜기 애매하거나 엑셀에서 열면 형식이 망가지는 CSV를 브라우저에서 표로 열어 보는 도구입니다. 행을 100개씩 페이지로 나눠 보여 주고, 검색어를 넣으면 그 글자가 들어 있는 행만 남기며, 열 이름 옆 체크박스로 보고 싶은 열만 켜고 끌 수 있습니다. 구분자(쉼표·세미콜론·탭·파이프)는 자동으로 판단하고, 따옴표 안의 쉼표와 줄바꿈도 올바르게 읽습니다.

언제 쓰나

  • 공공데이터 포털에서 받은 CSV가 어떤 열로 되어 있는지 내용을 먼저 훑어볼 때
  • 엑셀로 열면 '00123' 같은 코드의 앞자리 0이 사라지거나 날짜로 바뀌는 파일을 원래 값 그대로 확인할 때
  • 수천 행짜리 목록에서 특정 지역명이나 관리번호가 들어간 행만 빠르게 찾을 때
  • 열이 너무 많아 가로 스크롤이 길 때 필요한 열만 남겨 볼 때

사용 방법

  1. 점선 상자에 파일을 끌어다 놓거나 클릭해 고릅니다. 텍스트로 붙여 넣었다면 '열기'를 누릅니다.
  2. 표 위 검색창에 단어를 넣으면 입력하는 즉시 해당 행만 남고, 옆에 걸러진 행 수가 표시됩니다.
  3. 열 이름 체크박스를 해제하면 그 열이 표에서 숨겨집니다.
  4. 표 아래 '이전'·'다음' 버튼으로 페이지를 넘깁니다. '샘플'은 250행짜리 예시를 엽니다.

결과 해석

샘플 250행을 열면 3페이지(100·100·50행)로 나뉩니다. 검색창에 '부산'을 넣으면 도시 열이 부산인 행만 남고 페이지 수도 그에 맞게 줄어듭니다. 검색은 대소문자를 구분하지 않고, 값의 일부만 맞아도 걸립니다. 화면의 값은 파일에 적힌 글자 그대로이며 숫자나 날짜로 다시 해석하지 않습니다.

주의할 점

  • 검색은 숨긴 열을 포함한 모든 열을 대상으로 합니다. 숨긴 열에만 검색어가 있는 행도 결과에 남습니다.
  • 파일은 UTF-8로 읽습니다. EUC-KR(CP949)로 저장된 공공기관 CSV는 한글이 깨지니 UTF-8로 다시 저장한 뒤 여세요.
  • 파일 전체를 브라우저 메모리에 올리므로 수백 MB 이상이면 느려지거나 탭이 멈출 수 있습니다.
  • 정렬, 열별 조건 필터, 편집, 내보내기 기능은 없습니다. 보기 전용 도구입니다.

자주 묻는 질문

특정 열에서만 검색할 수 있나요?
현재는 모든 열을 한꺼번에 검색합니다. 열 기준 집계나 추출이 필요하면 CSV 피벗·집계 도구나 열 편집기를 함께 쓰세요.
파일이 서버에 올라가나요?
아닙니다. 파일은 브라우저 안에서만 읽고 표시하며 외부로 전송하지 않습니다.
