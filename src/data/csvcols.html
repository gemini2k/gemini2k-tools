CSV 열 편집기

필요한 열만 고르고, 순서를 바꾸고, 이름을 바꿔 새 CSV를 만듭니다.

📖
사용 방법
  1. CSV를 붙여 넣으면 열 목록이 나옵니다
  2. 체크로 포함할 열을 고르고, ▲▼로 순서를, 입력칸으로 이름을 바꿉니다
  3. '적용' 후 결과를 복사하거나 내려받습니다
체크 해제한 열은 빠지고, 표시된 순서대로 출력됩니다. 이름을 비워 두면 원래 이름을 사용합니다. 모든 처리는 브라우저에서만 이루어집니다.

CSV 열 편집기 사용 안내

무엇을 하는 도구인가

CSV에서 필요한 열만 남기고, 열 순서를 바꾸고, 열 이름을 고쳐 새 CSV를 만듭니다. 붙여 넣는 즉시 첫 줄 헤더를 읽어 열 목록을 만들고, 각 열마다 포함 여부 체크박스, 새 이름 입력칸, 위·아래 이동 버튼을 보여 줍니다. 입력 구분자(쉼표·세미콜론·탭·파이프)는 자동으로 판단하고 결과는 쉼표 CSV로 내보냅니다.

언제 쓰나

  • 공공데이터 포털 CSV에 열이 40개씩 있는데 분석에 필요한 건 대여섯 개뿐일 때
  • 개인정보가 든 열(성명, 연락처 등)을 빼고 나머지만 다른 부서에 넘길 때
  • DB 테이블 컬럼 순서에 맞춰 CSV 열 순서를 재배치해 적재할 때
  • '시군구명' 같은 한글 헤더를 sgg_nm처럼 시스템 규칙에 맞는 이름으로 바꿀 때

사용 방법

  1. 'CSV 입력' 칸에 데이터를 붙여 넣습니다. 첫 줄은 헤더여야 합니다.
  2. 나타난 열 목록에서 ▲▼로 순서를 먼저 정합니다.
  3. 그다음 뺄 열의 체크를 해제하고, 이름을 바꿀 열은 입력칸에 새 이름을 적습니다. 비워 두면 원래 이름이 쓰입니다.
  4. '적용'을 누르고 결과를 '복사'하거나 'CSV'(columns.csv)로 내려받습니다.

결과 해석

예를 들어 id,name,age,city에서 age를 빼고 city를 맨 앞으로 올린 뒤 name을 '성명'으로 바꾸면 결과 헤더는 'city,id,성명'이 되고 각 행도 같은 순서로 재배치됩니다. 데이터 값 자체는 손대지 않으며, 셀 안에 쉼표나 따옴표가 있으면 결과에서 자동으로 따옴표로 감쌉니다.

주의할 점

  • ▲▼ 버튼으로 순서를 바꾸면 목록이 다시 그려지면서 체크 상태와 입력한 새 이름이 초기화됩니다. 순서 정리를 먼저 하고 체크·이름 변경은 마지막에 하세요.
  • 입력 칸의 CSV를 고치면 열 목록이 처음 상태로 다시 만들어집니다.
  • 열이 수십 개이고 행이 수십만 개면 붙여넣기와 변환에 시간이 걸리고 브라우저 메모리를 많이 씁니다.
  • 새 이름이 서로 겹쳐도 경고하지 않습니다. DB나 판다스에 넣기 전에 중복 이름이 없는지 확인하세요.

자주 묻는 질문

열을 복제하거나 새 열을 추가할 수 있나요?
지원하지 않습니다. 이 도구는 기존 열의 선택·순서·이름만 바꿉니다.
결과를 탭 구분으로 받을 수 있나요?
결과는 쉼표 구분으로 고정입니다. 다른 구분자가 필요하면 CSV 정제기의 '출력 구분자'를 거치세요.
