GeoJSON ↔ CSV 변환기

GeoJSON 포인트의 속성·좌표를 CSV 표로 빼내거나, 위경도가 든 CSV를 GeoJSON 포인트로 만듭니다.

📖
사용 방법
  1. 방향(GeoJSON→CSV / CSV→GeoJSON)을 고릅니다
  2. 입력을 붙여 넣습니다. CSV→GeoJSON은 경도·위도 열을 지정하세요
  3. '변환' 후 결과를 복사하거나 내려받습니다
GeoJSON→CSV는 Point 피처의 속성과 lon·lat를 표로 만듭니다(다른 도형은 geometry 유형만 표기). CSV→GeoJSON은 지정한 경도·위도 열로 Point 피처를 만들고 나머지 열을 속성으로 넣습니다. 모든 처리는 브라우저에서만 이루어집니다.

GeoJSON ↔ CSV 변환기 사용 안내

무엇을 하는 도구인가

점(Point) 데이터를 GeoJSON과 CSV 사이에서 오가게 해 주는 변환기입니다. GeoJSON → CSV 방향은 모든 피처의 속성 이름을 모아 열로 만들고, 맨 뒤에 lon, lat, geom_type 세 열을 붙입니다. CSV → GeoJSON 방향은 지정한 경도·위도 열로 Point 도형을 만들고 나머지 열은 properties로 넣습니다. 좌표계 변환은 하지 않으며, 경위도(WGS84) 값을 그대로 옮깁니다.

언제 쓰나

  • 웹 지도 API에서 받은 GeoJSON 지점 목록을 엑셀로 열어 검토하거나 보고서 표로 만들 때
  • 공공데이터 포털 CSV(위도·경도 열 포함)를 Leaflet·OpenLayers 같은 웹 지도에 바로 올릴 GeoJSON으로 바꿀 때
  • GeoJSON의 속성값을 엑셀에서 일괄 수정한 뒤 다시 GeoJSON으로 되돌릴 때
  • GeoJSON에 어떤 속성 키가 섞여 있는지 표로 펼쳐 확인할 때

사용 방법

  1. 위쪽에서 'GeoJSON → CSV' 또는 'CSV → GeoJSON'을 고릅니다.
  2. 입력 칸에 내용을 붙여 넣습니다. CSV는 쉼표·탭 등 구분자를 자동으로 판단합니다.
  3. CSV → GeoJSON이면 '경도(lon) 열'과 '위도(lat) 열'이 헤더 이름을 보고 자동 선택되니 맞는지 확인합니다.
  4. '변환'을 누른 뒤 '복사' 또는 '내려받기'(converted.csv / converted.geojson)를 씁니다. '샘플'로 동작을 먼저 확인할 수 있습니다.

결과 해석

예를 들어 name 속성만 있는 서울시청 Point를 CSV로 바꾸면 'name,lon,lat,geom_type' 헤더 아래 '서울시청,126.978,37.5665,Point'가 나옵니다. 선이나 면 피처는 lon·lat이 비고 geom_type에 LineString·Polygon 같은 유형만 적히므로, 좌표까지 필요하면 이 도구 대신 다른 방법을 써야 합니다. CSV → GeoJSON에서 경도·위도가 숫자가 아닌 행은 geometry가 null인 피처로 남습니다.

주의할 점

  • 열 자동 선택은 이름에 lon·lng·x·경도(위도는 lat·y·위도) 글자가 '포함'되는지로 판단합니다. 'index', 'type'처럼 x나 y가 들어간 열이 앞에 있으면 엉뚱한 열이 잡힐 수 있습니다.
  • CSV → GeoJSON의 속성값은 모두 문자열로 들어갑니다. 숫자 연산이 필요하면 받는 쪽에서 형 변환하세요.
  • 중부원점·UTM-K 같은 투영 좌표를 넣으면 그 숫자가 그대로 경위도 자리에 들어가 지도에서 위치가 틀어집니다. 먼저 좌표 일괄 변환기로 경위도로 바꾸세요.
  • 내려받는 CSV는 엑셀 한글 깨짐을 막기 위해 BOM이 붙은 UTF-8입니다.

자주 묻는 질문

속성이 피처마다 다르면 어떻게 되나요?
전체 피처에 나오는 키를 모두 열로 만들고, 해당 키가 없는 피처는 빈칸으로 둡니다.
파일을 직접 열 수는 없나요?
현재는 텍스트 붙여넣기만 지원합니다. 파일을 메모장 등으로 열어 내용을 복사해 넣으세요.
