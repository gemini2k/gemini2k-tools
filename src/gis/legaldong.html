법정동 코드 검색

법정동명 또는 10자리 법정동코드로 검색합니다. 시도를 골라 좁힐 수 있고, 결과를 클릭하면 코드가 복사됩니다.

데이터를 불러오는 중…

※ 현행 법정동만 포함합니다(폐지된 동 제외). 법정동코드 10자리 = 시도(2) 시군구(3) 읍면동(3) 리(2). 출처는 국토교통부 법정동 데이터이며, 모든 검색은 브라우저에서만 이루어집니다.

법정동 코드 검색 사용 안내

무엇을 하는 도구인가

법정동코드는 법률로 정한 행정구역(시도, 시군구, 읍면동, 리)마다 붙은 10자리 숫자입니다. 앞에서부터 시도 2자리, 시군구 3자리, 읍면동 3자리, 리 2자리로 나뉘며, 상위 단위를 나타낼 때는 뒷자리를 0으로 채웁니다. 예를 들어 1100000000은 서울특별시, 1111000000은 서울특별시 종로구, 1111010100은 종로구 청운동입니다. 이 도구는 현행 법정동 2만여 건을 페이지에 함께 내려받아 두고, 이름이나 코드로 즉시 찾아 줍니다. 목록 위에 데이터 기준일과 건수가 표시됩니다.

언제 쓰나

  • 건축물대장, 실거래가, 토지 관련 공공데이터 API를 호출할 때 필요한 시군구코드(앞 5자리)나 법정동코드를 찾을 때
  • 공공데이터 CSV에 코드만 있고 동 이름이 없어 어느 동인지 확인해야 할 때
  • 행정구역 경계 데이터와 통계표를 코드로 조인하기 전에 코드 체계를 점검할 때
  • 같은 이름의 동이 여러 시도에 있을 때 정확한 코드를 골라야 할 때

사용 방법

  1. '검색' 칸에 동 이름이나 코드를 입력합니다. 입력하는 대로 결과가 바뀝니다.
  2. 이름은 띄어쓰기로 여러 단어를 넣으면 모두 포함된 항목만 보여 줍니다. 예: '수원 영통', '종로구 청운'.
  3. 숫자만 넣으면 코드 안에 그 숫자열이 들어 있는 항목을 찾습니다. 시군구 단위로 보려면 앞 5자리(예: 11110)를 넣으세요.
  4. '시도'에서 시도를 고르면 그 안에서만 찾습니다. 결과 행을 클릭하면 코드가 복사됩니다.

결과 해석

각 행은 코드와 전체 이름으로 표시되고, 리 단위 이름은 회색으로 구분됩니다. '반월동'처럼 흔한 이름은 경기·충남·경남·전북 등 여러 곳에서 나오므로 시도와 시군구를 꼭 확인하세요. 일반구가 있는 시는 '창원시마산합포구'처럼 시와 구가 붙어서 표시됩니다. 결과가 300건을 넘으면 앞의 300건만 보여 주고 나머지 건수를 알려 주니 검색어를 더 구체적으로 넣으세요.

주의할 점

  • 현행 법정동만 들어 있어 폐지·통합된 옛 코드는 검색되지 않습니다. 과거 자료의 코드가 안 나오면 행정구역 개편 여부를 의심해 보세요.
  • 법정동과 행정동은 다릅니다. 주민센터 단위인 행정동코드(통계청·행정안전부 체계)는 이 목록에 없습니다.
  • 숫자 검색은 앞자리 일치가 아니라 '포함' 검색이라 짧은 숫자를 넣으면 엉뚱한 지역도 함께 나옵니다.

자주 묻는 질문

국토교통부 API에 넣는 지역코드는 몇 자리인가요?
API마다 다르지만 시군구 단위 조회는 법정동코드 앞 5자리를 쓰는 경우가 많습니다. 각 API 명세를 확인하세요.
검색어가 서버로 전송되나요?
아닙니다. 데이터 파일을 한 번 내려받은 뒤 검색은 브라우저 안에서만 이루어집니다.
