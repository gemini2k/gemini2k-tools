CSV → 지도·GeoJSON

위경도(또는 한국 좌표계) 좌표가 든 CSV를 붙여넣으면 지도 위 마커로 시각화하고 GeoJSON으로 내보냅니다.

※ 좌표계가 경위도가 아니면 proj4로 WGS84로 변환해 표시·저장합니다. 점을 클릭하면 속성이 보입니다. 모든 처리는 브라우저에서만 이루어집니다.

CSV → 지도·GeoJSON 변환 도구 사용 안내

무엇을 하는 도구인가

좌표 열이 있는 CSV나 TSV를 읽어 OpenStreetMap 배경 위에 점으로 찍고, 같은 내용을 GeoJSON 포인트 레이어로 내보냅니다. 구분자는 첫 줄에서 탭과 쉼표 중 많은 쪽으로 자동 판단합니다. 좌표계는 WGS84 경위도(EPSG:4326), UTM-K(EPSG:5179), 중부·동부·서부원점(EPSG:5186·5187·5185), 웹 메르카토르(EPSG:3857)를 고를 수 있고, 경위도가 아니면 proj4로 WGS84로 바꿔 표시·저장합니다.

언제 쓰나

  • 공공데이터 포털의 시설 목록(CCTV, 주차장, 약국 등)을 받아 위치가 제대로 찍히는지 빠르게 눈으로 확인할 때
  • 엑셀로 관리하던 조사 지점 목록을 QGIS나 웹 지도에 바로 올릴 GeoJSON으로 만들 때
  • 중부원점 X·Y로 된 자료를 경위도 GeoJSON으로 바꿔 다른 시스템에 넘길 때
  • 분석 전에 좌표 누락·이상치 행이 몇 개인지 세어 볼 때

사용 방법

  1. 텍스트 칸에 CSV를 붙여 넣거나 '파일 선택'으로 .csv·.tsv·.txt 파일을 엽니다. 첫 줄은 헤더여야 합니다.
  2. 헤더 이름이 lat·lng·위도·경도·x·y 등이면 'X (경도/E)', 'Y (위도/N)' 열이 자동으로 잡힙니다. 아니면 직접 고릅니다.
  3. '좌표계'에서 원본 좌표의 체계를 고르고 '지도에 표시'를 누릅니다.
  4. 점을 클릭하면 그 행의 모든 속성이 팝업으로 나옵니다. 확인이 끝나면 'GeoJSON 내려받기'(points.geojson) 또는 'GeoJSON 복사'를 누릅니다.

결과 해석

지도 위에 전체 행 수, 지도에 표시된 수, 건너뛴 수가 표시됩니다. 건너뛴 행은 좌표가 비었거나 숫자가 아니거나, 변환 결과가 위도 ±90·경도 ±180을 벗어난 경우입니다. 내보낸 GeoJSON의 좌표는 [경도, 위도] 순서, 소수 여덟째 자리까지이며 원본 행의 모든 열이 properties에 문자열로 들어갑니다.

주의할 점

  • 파일은 UTF-8로 읽습니다. 공공기관 CSV 중 EUC-KR(CP949)로 저장된 파일은 한글이 깨지므로 메모장이나 엑셀에서 UTF-8로 다시 저장한 뒤 여세요.
  • 좌표계를 잘못 고르면 점이 바다나 다른 나라에 찍히거나 '건너뜀'으로 빠집니다. 지도에서 위치를 꼭 눈으로 확인하세요.
  • 배경 지도는 OpenStreetMap 타일 서버에서 불러오므로 인터넷이 막힌 망에서는 배경이 보이지 않습니다. 데이터 자체는 외부로 전송되지 않습니다.
  • 수십만 행은 브라우저 메모리와 렌더링 속도 때문에 버벅일 수 있습니다.

자주 묻는 질문

숫자 속성이 GeoJSON에서 따옴표로 묶여 나옵니다.
CSV 값을 변환 없이 문자열로 그대로 담기 때문입니다. 숫자형이 필요하면 GIS 프로그램에서 필드 형식을 바꾸세요.
주소만 있고 좌표가 없는 CSV도 되나요?
안 됩니다. 이 도구는 주소를 좌표로 바꾸는 지오코딩을 하지 않으며, 좌표 열이 있어야 합니다.
