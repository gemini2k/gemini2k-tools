GIS 웹맵 뷰어

배경지도 위에서 거리·면적 측정, 버퍼, 히트맵, 클러스터를 바로 사용하세요.

배경지도

측정·점 모드를 켜고 지도를 클릭해 그리세요. 좌상단 ＋/－·전체화면 버튼도 사용할 수 있어요.

GIS 웹맵 뷰어 사용 안내

무엇을 하는 도구인가

설치 없이 브라우저에서 바로 쓰는 간단한 웹 지도입니다. 배경지도로 OpenStreetMap을 기본 제공하고, 설정에 따라 VWorld(국토교통부) 일반지도와 영상지도(위성+지명)를 고를 수 있습니다. 지도 위에서 거리와 면적을 재고, 점을 찍어 반경(버퍼) 안의 점을 세거나 히트맵·클러스터로 분포를 볼 수 있습니다. 축척 막대와 전체화면 버튼도 있습니다.

언제 쓰나

  • 현장 답사 전에 두 지점 사이 직선거리나 대상 부지의 대략적인 면적(m²와 평)을 확인할 때
  • 후보 입지 주변 500m 안에 경쟁 시설이나 민원 지점이 몇 개 있는지 빠르게 세어 볼 때
  • 회의 중 점을 찍어 가며 밀집 구역을 히트맵으로 보여 줄 때
  • 영상지도로 실제 지형이나 건물 배치를 확인할 때

사용 방법

  1. '배경지도'에서 지도 종류를 고릅니다.
  2. '거리'를 켜고 지도를 클릭해 선을 그립니다. 더블클릭하면 측정이 끝나고 결과 라벨이 남습니다. '면적'도 같은 방식으로 다각형을 그립니다. 버튼을 다시 누르면 모드가 꺼집니다.
  3. '점 찍기'를 켜고 지도를 클릭해 점을 여러 개 찍습니다.
  4. '버퍼'를 누르고 반경(m, 기본 500)을 입력한 뒤 중심이 될 위치를 클릭하면, 원 안에 든 점이 초록색으로 바뀌고 개수가 알림으로 표시됩니다.
  5. '히트맵'과 '클러스터'는 찍은 점을 밀도 지도나 숫자 원으로 보여 주는 켜고 끄기 버튼입니다. '지우기'는 모든 도형과 점을 지웁니다.

결과 해석

거리는 1km 미만이면 m, 넘으면 km 소수 둘째 자리로, 면적은 m² 또는 km²와 함께 평(1평 = 약 3.3058m²) 환산값이 나옵니다. 예를 들어 가로세로 약 100m인 땅을 그리면 10,000m² 안팎, 약 3,025평으로 표시됩니다. 측정은 구면 측지 계산이라 화면의 메르카토르 왜곡과 관계없이 실제 거리에 가깝습니다.

주의할 점

  • 측정값은 화면에서 손으로 클릭한 위치에 따른 근삿값입니다. 지적 면적이나 측량 성과를 대신할 수 없습니다.
  • 점은 직접 찍은 것만 다룹니다. CSV 좌표를 올려 보려면 CSV → 지도·GeoJSON 도구를 쓰세요.
  • 배경지도 타일은 OpenStreetMap과 VWorld 서버에서 불러오므로 외부 인터넷이 막힌 망에서는 지도가 보이지 않습니다. 그린 도형과 점은 새로고침하면 사라집니다.

자주 묻는 질문

VWorld 배경지도가 목록에 없습니다.
VWorld 지도는 API 키가 설정된 경우에만 목록에 나타납니다. 키가 없거나 불러오지 못하면 OpenStreetMap만 표시됩니다.
측정한 선이나 면을 파일로 저장할 수 있나요?
이 뷰어에는 내보내기 기능이 없습니다. 도형 좌표가 필요하면 지도 도형 그리기 도구에서 WKT·GeoJSON으로 받으세요.
